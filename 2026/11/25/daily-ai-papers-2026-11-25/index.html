多语言多模态安全不能只靠扩大模型

论文：Lingua-SafetyBench: A Benchmark for Safety Evaluation of Multilingual Vision-Language Models（arXiv:2601.22737）
作者：Enyi Shi、Pengyang Shao、Yanxin Zhang、Chenhang Cui、Jiayi Lyu、Xiaobo Xia、Fei Shen、Tat-Seng Chua
来源/分类：arXiv · cs.CV
原文：PDF · 代码与数据
全文状态：仅依据摘要。官方 PDF 约 46 MB，本次无法取回；未核验正文中的基线细节和逐模型数字。

  • 核心问题、方法与基线：现有安全基准常把语言和图像威胁分开测量。作者构建覆盖 10 种语言的 100,440 组有害图文配对，并按风险主要来自图像还是文字划分子集；在多种视觉语言模型上评测，再用 Qwen 系列检查模型扩展和迭代版本的影响。
  • 作者报告的结果：摘要称，图像主导风险在高资源语言中平均更突出；文字主导风险则在非高资源语言中更突出。扩大模型与迭代升级改善总体安全表现，但对高资源语言的收益更大，因而加剧文字主导风险下的语言差距。摘要未给逐语言、逐模型数字，不能据此判断风险幅度或统计不确定性。
  • 创新与证据边界：基准把多语言和多模态联合起来，并尝试区分风险模态来源，适合审视“总体安全分数”掩盖的语言差异。当前仅能确认作者报告的基准结论；公开数据可能与模型训练语料重叠，且摘要未提供独立复现、标注一致性、完整基线和算力成本。
  • 适合谁读、建议章节：适合多模态模型安全、红队评测和多语言对齐研究者。全文可访问后优先读数据构造与模态划分、Qwen 受控比较、污染检查和语言分组结果；章节编号本次未核实。

稀有解剖结构暴露视觉语言模型的先验偏差

论文：6 Fingers, 1 Kidney: Natural Adversarial Medical Images Reveal Critical Weaknesses of Vision-Language Models（arXiv:2512.04238）
作者：Leon Mayer、Piotr Kalinowski、Caroline Ebersbach、Marcel Knopp、Tim Rädsch、Evangelia Christodoulou、Annika Reinke、Fiona R. Kolbinger、Lena Maier-Hein
来源/分类：arXiv · cs.CV
原文：PDF · 代码 · 数据集
全文状态：已核阅官方 PDF 全文。

  • 核心问题、方法与基线：AdversarialAnatomyBench 收录多种成像模态和人体部位中的自然罕见解剖变体，并把罕见病例与典型解剖图像配对，以直接比较模型对“违背常见人体先验”案例的表现。作者评测 25 个通用与医学视觉语言模型，并进一步测试提示模型留意罕见变体、增加推理等干预。
  • 作者报告的结果：摘要报告基础医学感知任务的平均准确率从典型解剖图像上的 71% 降至罕见变体上的 28%；表现最好的 GPT-5、Gemini 2.5 Pro 和 Llama 4 Maverick 也下降 39–51%。作者称，扩大模型、偏差提示和测试时推理均未消除问题。
  • 创新与证据边界：成对设计使性能落差更容易归因于罕见解剖，而非只看总体准确率。全文明确说明图像来自公开来源，无法排除部分样本已进入模型训练集；作者认为这会使测得表现偏向乐观。任务以单图、客观问答为主，受提示和选项设计影响，也没有真实临床流程验证。
  • 适合谁读、建议章节：适合医学影像、模型泛化和临床安全评估读者。先读 Results 中典型/罕见图像对比，再读 Methods 的样本与标注构造、Limitations 的公开数据污染可能性；随后看提示干预和补充实验。

后训练让长文档 Agent 更会核查，但仍落后于前沿系统

论文：Post-Training Agents for Long-Document Reasoning（arXiv:2611.30090）
作者：Sushant Mehta、Logan Ritchie、Edwin Chen
来源/分类：arXiv · cs.AI
原文：PDF
全文状态：已核阅官方 PDF 全文。

  • 核心问题、方法与基线：检索式长上下文测试难以代表专业文档中跨页表格、图表和定义的组合推理。作者用 1,465 个专家任务对开放权重 Kimi-K2.7 做 LoRA 后训练：先进行一次带特权上下文的自蒸馏，再进行两轮按细粒度评分标准给奖励的强化学习。评测包括 100 项 GDP.pdf 留出任务和 220 项分布外 GDPval 工具型任务；与基座版本比较，并列出 GPT-5.6 Sol 作为外部参照。
  • 作者报告的结果：GDP.pdf 严格通过率从基座的 11.0% 升至第二轮后的 24.5%，输入最长至 240K token 时仍有提升；平均输出 token 数基本不变（9,803 对 9,733）。GDPval 的平均评分从 0.571 升至 0.746，零分任务由 54 降至 10，平均消息数减少 18%（70.9 至 58.2）。GPT-5.6 Sol 的严格通过率为 30.7%，平均输出约 3,422 token，比较的是不同模型与服务设置。
  • 创新与证据边界：任务级评分与 token、轮数一起报告，能显示准确度和支出之间的关系；全文说明 GDP.pdf 训练任务与 100 项留出任务不重叠。局限是留出任务只有 100 项，第二轮检查点的结果为单次运行；外部闭源模型并非严格同算力比较。论文展示了任务级去重，但没有独立审计 Kimi 基础模型预训练污染；训练算力和总训练成本也不足以换算为可比部署成本。
  • 适合谁读、建议章节：适合长上下文、文档 Agent 和强化学习工程读者。建议读 §3 的真实文档任务分布、§4 的蒸馏/RL 配方、§5 的准确率与 token 结果、§6 的轨迹分析及 §7 的评测建议。

多模态决策基准显示模型优势取决于题型和输入格式

论文：OmniDecisionBench: Evaluating and Benchmarking the Multimodal Jev-Style System One Decision Models（arXiv:2611.28924）
作者：Tianxiang Gao、Jinzhe Li、Yue Zhou、Dandan Guo、Qi Wang、Diana Inkpen、Yuan Wu、Yi Chang
来源/分类：arXiv · cs.AI
原文：PDF · 代码与数据
全文状态：已核阅官方 PDF 全文。

  • 核心问题、方法与基线：论文用 45 个公开数据集、192,975 条记录和四种结构化决策接口，比较 3 个 System One 模型与 2 个通用视觉语言模型；同时测准确率、概率校准和选择性风险。评测固定数据组件、图像哈希、答案集合与变换版本，避免不同模型答到不同题目。
  • 作者报告的结果：Jev 1.14 在离散题型上的宏平均准确率为 80.14%，ECE15 为 4.50%；通用 VLM 在序数评分和直接边框定位上有优势。一个受控呈现实验中，只把选项渲染成图像使 Jev 1.14 在 50% 覆盖率下的选择性风险由 3.23% 升至 8.82%，平均置信偏差基本不变。
  • 创新与证据边界：论文把题型、输入格式和置信质量放在同一框架，并冻结评测记录，较能揭示单一总分掩盖的适用边界。模型仅 5 个，部分 System One 服务闭源；测试为静态图像单轮任务，不覆盖视频、多轮交互或真实部署。摘要与全文没有给出统一推理成本，亦未独立审计全部模型的预训练数据污染；概率阈值在输入分布变化后需要重校准。
  • 适合谁读、建议章节：适合多模态模型选型、概率校准和基准设计读者。建议读 §3 的数据/接口冻结、§4 的总体和输入变换实验，再读 Limitations 与附录中的跨数据集阈值分析。

Agent 将稳定策略留在上下文、临场技能按需检索

论文：STRIDE: Strategy-to-Tactics Retrieval-Guided Skill Disclosure and Evolution for Agentic Reinforcement Learning（arXiv:2611.28907）
作者：Shixin Hong、Wanqing Cui、Yibo Hu、Naen Xu、Zhiwei Huang、Meiguang Jin、Junfeng Ma
来源/分类：arXiv · cs.AI
原文：PDF
全文状态：已核阅官方 PDF 全文。

  • 核心问题、方法与基线：扁平技能库容易让 Agent 在长任务中丢失全局计划，按整回合成败更新也难判断某次技能检索是否有用。STRIDE 把长期策略持续放在上下文，先展示简短战术目录，仅在遇到局部困难时取回完整技能；每次检索事件也用于过程反馈和技能库更新。作者在 ALFWorld 和 WebShop 比较强化学习、记忆/技能基线，并做去除策略、战术和分析器的消融。
  • 作者报告的结果：ALFWorld 上 Qwen3-4B、Qwen3-8B 的平均成功率分别为 92.7% 和 94.9%；WebShop 相对最强复现的技能增强基线高 4.5 个任务分数和 1.9 个百分点成功率。Qwen3-4B 消融中移除持续策略后成功率由 92.7% 降至 72.9%，移除战术后降至 89.1%，显示全局策略贡献更大。
  • 创新与证据边界：把技能是否检索当作独立决策事件，便于信用分配；同时比较多种复现基线并报告组件消融。证据限于 ALFWorld/WebShop 仿真，尚无真实网页服务或机器人环境验证；强基线复现条件和模型版本会影响差距。论文未在摘要列出统一 GPU 小时或推理成本，且公开可复现材料链接未见于摘要。
  • 适合谁读、建议章节：适合 Agent 记忆、长时程规划和技能学习研究者。建议读 §3 的策略/战术接口、§4 的 ALFWorld/WebShop 基线、§5 的消融以及附录训练参数。

LLM 评委的偏差需要随轨迹和审计样本一起估计

论文：Transport-Safe Evaluation of LLM Agents: Trajectory-Dependent Judge Error and Anytime-Valid Auditing（arXiv:2611.30742）
作者：Yulliwas Ameur、Samia Bouzefrane、Soumya Banerjee
来源/分类：arXiv · cs.AI
原文：PDF
全文状态：已核阅官方 PDF 全文。

  • 核心问题、方法与基线：如果 LLM 评委的错误率随 Agent 轨迹变化，且不同 Agent 产生的成功/失败轨迹不同，用同一标量错误率校正会带偏排名。论文推导该偏差，并比较标量校正、增强逆概率加权（AIPW）和均匀或设计感知的随机人工审计；另用 e-process 构造可自适应抽样并允许任意停止的置信序列。
  • 作者报告的结果：四 Agent 半合成实验中，知道标量校正参数仍导致最大偏差 0.245、平均点态覆盖率 0.016，250 次重复里没有一次恢复完整排名。AIPW 两种审计方案的最大偏差低于 0.003，平均覆盖率为 0.939 和 0.950。48 格压力测试中标注量从 600 增至 4,800，目标支持度仍只由 0.209 升至 0.805。
  • 创新与证据边界：重点不是提出更强 Agent，而是把评委偏差、可识别性、审计设计和排序不确定性纳入同一评估程序。实验是半合成，尚非真实 Agent 群体的外部验证；AIPW 依赖审计样本支持和识别假设，支持不足时作者改报界限或敏感性集合。人工标注预算、审计延迟和规模化成本仍需单独评估。
  • 适合谁读、建议章节：适合 LLM-as-judge、Agent 基准统计和实验设计读者。建议读 §2 的识别问题、§3 的审计/AIPW 方法、§4 的覆盖率和偏差实验，再读有关支持不足与敏感性集合的讨论。
