2026-11-25 GitHub 热榜简报：Agent 从技能包走向可验证系统

GITHUB TRENDING · 2026.11.25

今天的 GitHub all-languages 日榜继续把 Agent 推向更具体的工作边界：Claude-BugHunter、Superpowers和 CLI-Anything把它放进安全研究、开发流程和复杂软件操作，last30days-skill与 Firecrawl处理外部信息入口，OpenSRE处理失败后的工程反馈。另一端，MiniMind、OpenVINO、diagram-design、AFFiNE和 AutoClip则把训练、部署、视觉产物、知识工作和媒体交付落到可以运行的系统。

Agent 安全开发方法Agent-native CLI网页知识模型训练推理部署CI 可靠性Local-first

今日要点

今天最值得关注的不是单个项目的星标速度，而是 Agent 正在从“会调用工具”进入“要有边界、证据和复核”：Claude-BugHunter把授权安全研究和证据卫生写成技能包，Superpowers把需求、计划、TDD 与评审串成开发方法，CLI-Anything和 Stitch Skills则让软件与设计工具暴露出更稳定的结构化接口。OpenSRE把同一套思路推进到失败后的 CI/CD 现场：分析原因，生成修复，再交给人审阅。

另一条线是“生成”继续靠近可交付物：diagram-design输出可以直接打开的 HTML + SVG，MiniMind把训练链路压缩成可学习的实验，OpenVINO把模型送到具体硬件，AFFiNE与 AutoClip分别面向知识工作和媒体产物。以下数字是日榜快照，不是质量证明；真正要看的仍是代码、许可证、运行边界和失败时谁负责。

值得尝试

elementalsouls/Claude-BugHunter

Claude-BugHunter 是面向 Claude Code 的安全研究技能包，README 将 84 个技能、15 个命令、681 个披露报告模式、企业身份与基础设施攻击矩阵、engagement 文件夹脚手架和 Burp MCP 接入组织成可复用流程。它适合安全工程师研究 Agent 如何在授权范围内工作；限制是明显的双重用途，技能包不能替代目标范围、凭据隔离和人工复核。主要语言为 Python，日榜新增 1,826★，榜单快照总星标 21,527★，仓库页显示许可证为 MIT 与 CC-BY-4.0，最近 Release 为 v2.1（2026-06-05）。

obra/superpowers

Superpowers 把需求澄清、设计确认、计划、红绿 TDD、子代理执行和代码评审串成 coding agent 的完整工作方法，强调先理解目标再动手。它适合希望把 Agent 从“直接写代码”改造成可审阅流程的开发者；限制是它是方法论与技能集合而非独立测试框架，安装方式、自动触发行为和权限边界会随宿主变化。主要语言为 Shell，日榜新增 1,003★，榜单快照总星标 325,854★，许可证为 MIT，最近 Release 为 v7.0.2（2026-11-03）。

HKUDS/CLI-Anything

CLI-Anything 试图把图形软件和其他已有工具转换成带统一参数、JSON 输出、预览与端到端测试的 Agent-native CLI，并用 CLI-Hub 管理社区适配器，README 当前列出 18 个应用演示。它适合平台工程师研究“模型如何稳定调用复杂软件”；限制是每个适配器仍依赖目标软件、系统环境和集成质量，演示覆盖面不能等同于所有软件都能可靠自动化。主要语言为 Python，日榜新增 1,074★，榜单快照总星标 64,858★，许可证为 Apache-2.0，最近 Release 为 v0.4.0（2026-06-25）。

jingyaogong/minimind

MiniMind 用 PyTorch 原生代码覆盖模型结构、Tokenizer、预训练、SFT、LoRA、DPO、RLAIF、Tool Use、Agentic RL 和蒸馏，把“调用模型”还原成可读的训练链路。它适合想从代码和数据理解 LLM 的学习者；限制是“2 小时、3 块钱”的结果基于单张 RTX 3090 的特定实验，显存、数据和评测条件不能直接外推到生产模型。主要语言为 Python，日榜新增 727★，榜单快照总星标 70,257★，许可证为 Apache-2.0，最近 Release 为 v2（2026-10-21）。

firecrawl/firecrawl

Firecrawl 把抓取、爬取、网页映射、搜索、文档解析和 MCP 接入组合成 Agent 的知识入口，既有无需数据库的本地路径，也有带队列、Worker 和数据库的完整自托管服务。它适合做研究助手、RAG 或网页自动化的人；限制是本地路径需要 Rust 与 C 编译环境，自托管要承担浏览器和后台服务运维，AGPL-3.0 也会影响服务化分发。主要语言为 TypeScript，日榜新增 991★，榜单快照总星标 208,975★，许可证为 AGPL-3.0，最近 Release 为 v2.11.0（2026-06-19）。

openvinotoolkit/openvino

OpenVINO 面向深度学习模型的转换、优化和部署，README 覆盖 PyTorch、TensorFlow、ONNX、Keras、PaddlePaddle 与 JAX/Flax，并把运行目标扩展到 CPU、Intel GPU 与 Intel NPU。它适合研究推理后端、设备抽象和边缘部署的人；限制是实际收益取决于算子支持、模型结构、精度设置和硬件，支持矩阵不是你的模型性能保证。主要语言为 C++，日榜新增 185★，榜单快照总星标 12,474★，许可证为 Apache-2.0，最近 Release 为 2026.4.1（2026-10-01）。

cathrynlavery/diagram-design

diagram-design 把架构图、时序图、四象限等 52 种图形组织成 Agent Skill，目标是让 Agent 生成一个带品牌样式、可直接打开的单文件 HTML + SVG，而不是一段难以维护的 Mermaid。它适合前端、架构师和文档作者研究“自然语言到可审阅视觉产物”的边界；限制是布局、语义和品牌一致性仍需人工检查，README 的隐私说明也提示技能会发送网络数据。主要语言为 HTML，日榜新增 802★，榜单快照总星标 72,102★，许可证为 MIT，最近提交为 2026-11-25。

mvanhorn/last30days-skill

last30days-skill 把 Reddit、X、YouTube、Hacker News、Polymarket、GitHub 等多源搜索并行化，再按互动信号合成带来源的近 30 天研究简报，并适配 50 多种 Agent Skills 宿主。它适合研究跨平台检索、证据归因和“搜索结果如何被模型压缩”的工程实现；限制是部分来源需要 API key 或浏览器会话，互动量代表注意力而不是事实，平台权限与条款也会影响复现。主要语言为 Python，日榜新增 703★，榜单快照总星标 74,256★，许可证为 MIT，最近提交为 2026-11-24。

google-labs-code/stitch-skills

Stitch Design Skills 是面向 Google Stitch MCP 的 Agent Skills 与插件集合，按 Agent Skills 开放标准提供设计、构建和工具类能力，可供 Codex、Antigravity、Gemini CLI、Claude Code、Cursor 和 OpenCode 使用。它适合研究“设计系统、静态 HTML 和组件实现如何被 Agent 串起来”；限制是它不是独立设计引擎，实际使用前必须配置 Stitch MCP 与相应凭据。主要语言为 TypeScript，日榜新增 403★，榜单快照总星标 12,675★，许可证为 Apache-2.0，最近 Release 为 v1.0（2026-05-18）。

mjmirza/app-store-compliance

App Store Compliance Playbook 把 Apple App Store 与 Google Play 的常见拒审模式、隐私清单、Data safety 和政策日期整理成 playbook，并提供提交前扫描器；README 明确区分“扫描能证明什么”和仍需人工检查的部分。它适合移动端发布流程和 AI coding agent 的门禁设计；限制是平台政策会变，扫描结果不是上架批准，且仓库使用带收入条款的 OpenRoots ORA 2.3，商用前必须读原文。主要语言为 Shell，日榜新增 928★，榜单快照总星标 5,897★，许可证为 LicenseRef-OpenRoots-ORA-2.3，最近 Release 为 v2.5.1（2026-11-22）。

Tracer-Cloud/opensre

OpenSRE 面向 CI/CD 可靠性：读取失败运行、日志和仓库上下文，分析根因，再把修复推到分支供人审阅，并支持自托管模型。它适合平台工程师研究 Agent 如何进入失败后的反馈闭环；限制是项目明确标为 Public Alpha，API 与集成会变化，日志、凭据和自动修复权限必须放在组织边界内单独审查。主要语言为 Python，日榜新增 398★，榜单快照总星标 15,202★，许可证为 Apache-2.0，最近 Release 为 v0.1.2026.11.25（2026-11-25）。

toeverything/AFFiNE

AFFiNE 把文档、白板、表格、知识库和实时协作放进一个 privacy-first、local-first 工作区，并提供跨平台与自托管路径，README 还展示了 AI 辅助写作、幻灯片和思维导图能力。它适合研究富文本、画布、数据库和数据拥有权如何共存；限制是默认分支为 canary，仓库许可证标记为 Other/NOASSERTION，且不同目录和第三方组件可能适用不同授权，不能只看项目简介判断合规性。主要语言为 TypeScript，日榜新增 584★，榜单快照总星标 78,018★，许可证边界见 LICENSE，最近 Release 为 v2026.11.24-canary.1422（2026-11-24）。

zhouxiaoka/autoclip

AutoClip 把长视频链接、文件或直播回放转成短视频、字幕、封面和发布文案，支持智能取景、OBS/Twitch/YouTube 等直播回放来源，并提供桌面端、CLI 与 MCP。它适合研究模型选择、媒体处理和人工校正如何组成内容工作流；限制是本地计算和 FFmpeg 仍有环境成本，自动取景、字幕与文案需要人工复核，当前桌面包也未完成代码签名和 Apple 公证。主要语言为 Python，日榜新增 980★，榜单快照总星标 15,397★，许可证为 MIT，最近 Release 为 v1.6.0（2026-11-24）。
