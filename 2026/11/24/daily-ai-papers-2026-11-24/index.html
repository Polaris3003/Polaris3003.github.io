股票预测基准先要赢过“明天等于今天”

论文：A Methodologically Rigorous Benchmark of Linear Regression, RNN, and LSTM for S&P 500 Forecasting: Identifying Sources of Performance Inflation in Financial Deep Learning（arXiv:2611.27978，双主题：AI × 金融）
作者：Hari Sitaula、Joseph Opitz
来源/分类：arXiv · cs.LG
原文：PDF
全文状态：已核阅官方 PDF 全文。

  • 核心问题、方法与基线：用 2006–2025 年标普 500 收盘价、宏观指标和技术特征做次日收盘价预测，统一比较线性回归、RNN 与 LSTM。论文把常见的目标去噪、遗漏持久性基线、只报告多次运行中最佳结果三类做法逐一审计；采用时间顺序 80/20 切分，每个配置跑 30 个随机种子，以“明日收盘等于今日收盘”作为基线。
  • 作者报告的关键结果：朴素持久性基线 RMSE 为 53.16 点；最好的三层 RNN 为 53.97，最好的单层 LSTM 为 54.06，平均误差都没有胜过基线。某些模型与真实指数水平的相关系数仍接近 1，但作者指出近似随机游走的价格水平会让相关系数显得很高，不能据此判断模型有增量预测力。
  • 创新与证据边界：价值在于把评测协议的选择放在网络复杂度之前，30 次重复也比 best-of-N 更能暴露训练波动。结论局限于单一指数的价格水平和一个留出时段；没有验证可交易收益，也未提供代码链接。宏观数据若没有按历史可用时间点重建，实时预测仍可能有信息时点问题。
  • 适合谁读、建议章节：适合金融机器学习、时序基准与实验设计读者。先读 §3 的数据与切分，再读 §5 的评测审计、§6 的结果和 §8 的稳健性检验。

LLM 评委会被示例答案的标签比例带偏

论文：Your Judge Inherits Your Prompt: In-Context Label Bias in an LLM-as-Judge Is Directional, Not Symmetric（arXiv:2611.26881）
作者：Abdullah Ahmad、Ahmed J. O. Ahmed、Luca Citi
来源/分类：arXiv · cs.CL
原文：PDF · 代码、提示与人工标注
全文状态：已核阅官方 PDF 全文。

  • 核心问题、方法与基线：作者固定视频问答生成器产出的答案，只改 LLM 评委 few-shot 示例中的“接受/拒绝”比例，在 NExT-QA 与 MSVD-QA 上逐项比较；两位标注者对每个数据集各 200 个样例形成共识参照。生成模型为冻结的 LLaVA-NeXT-Video-7B，评委为冻结的 Llama 3.1-8B。
  • 作者报告的关键结果：示例偏向接受时，评委接受率在 NExT-QA 上约上升 30 个百分点、在 MSVD-QA 上约上升 20 个百分点；相反方向的拒绝偏置没有同等幅度的下降。单次抽样的差异可达 18 个百分点；以 NExT-QA 为例，一个单抽样看起来增加 16.09 点的结果，五组示例平均后为 5.88 点，且统计上未显著异于零。
  • 创新与证据边界：实验固定被评答案、只干预评委提示，有助于分离提示标签比例对评分的影响；作者也公开了示例、标注与代码。证据限于两个视频问答基准和小规模人工共识；接受率不是模型真实能力，示例组类别构成仍可能影响不对称结果。作者称所用生成模型早于后续纳入 NExT-QA 的微调语料，但这不等于完整排除了所有预训练污染。
  • 适合谁读、建议章节：适合 LLM-as-judge、基准评测和人类偏好评估读者。建议读 §3 的冻结流水线与示例设计、§4 的标签偏置结果、§5 的机制分析和 §6 的局限。

多模态安全分数可能只测到了单一模态捷径

论文：Unimodal Shortcuts and Joint Scene-Intent Dependence in Vision-Language Safety Representations（arXiv:2611.27339）
作者：Guijia Zhang、Hongbo Qiu、Guohao Cai、Hao Zheng、Jiajun Zha、Hanqing Wang、Zhenhao Zhang、Huihao Jing、Shing-Chi Cheung、Haoxuan Che、Harry Yang
来源/分类：arXiv · cs.CV
原文：PDF
全文状态：已核阅官方 HTML 全文；PDF 端点本次未能取回。

  • 核心问题、方法与基线：作者审计五个情境安全基准，再构造“安全/危险场景 × 观察/行动请求”的四格控制集，使只看图片或只看文字的规则至多达到 50% 组内排序准确率。对冻结的 Qwen3-VL-8B 与 SmolVLM2-2.2B 中间层训练线性探针，并与分开编码图像和文字后拼接的基线比较。
  • 作者报告的关键结果：在原有基准的同图配对提示上，一个不看图的探针 AUROC 达 0.9645，说明基准标签可由文字捷径预测。四格控制集上，中间层联合探针达到 0.958 与 0.930；但分开编码后拼接也达到 0.930 与 0.859，因此可解码不代表模型内部确实形成了跨模态融合。迁移到其他图像/基准时，探针 AUROC 降至 0.48–0.67。
  • 创新与证据边界：论文把“准确率高”与“模型同时依据场景和意图”分开测量；探针延迟低，但跨分布泛化不足，不能据此当作上线安全过滤器。还需留意版本：全文附录记录过一次数据切分索引错位，修正后使一个“缓存探针 vs 安全提示”对照的结论反转；论文同时保留了审计记录。引用该子实验前应检查最新表格与附录 S9–S10。
  • 适合谁读、建议章节：适合多模态安全评测、表示探针和基准构造读者。建议读 §2–4 的捷径审计与控制实验，再看 §5 的可靠性边界及附录 S9–S10 的修订记录。

机器人策略运行时可由 Agent 编写中断条件

论文：Tripwire: Robot Agents that Program Their Own Interrupts under Human Disturbance（arXiv:2611.27182）
作者：Sunli Chen、Yun Zong、Qinhong Zhou、Xiaowen Qiu、Jiaben Chen、Zeyuan Yang、Chuang Gan
来源/分类：arXiv · cs.RO
原文：PDF
全文状态：已核阅官方 PDF 全文。

  • 核心问题、方法与基线：机器人调用长时 VLA/WAM 策略时，Agent 常要等动作执行完才重新观察。TRIP 让 Agent 为策略运行编写轻量、有状态的 Python “绊线”，持续检测人或目标物的距离、位移和接近趋势；触发时暂停策略、把原因交回 Agent，再由 Agent 重规划。对照使用相同 Agent、工具与提示，只改变重新唤醒的时机。
  • 作者报告的关键结果：RoboHD 含 168 个 RoboCasa365 场景、三种 VLA 和一种 WAM；在最强策略上，安全比例由轮次式对照的 61.3% 升到 81.3%，有人干扰时任务成功率由 31.0% 升至 38.7%，每分钟机器人时间的 Agent 调用从 30.3 次降到 19.4 次。真实机械臂两项任务共 40 次试验，TRIP 成功 25 次，轮次式对照 5 次，单独策略 1 次。
  • 创新与证据边界：它把高频低成本感知交给并行监视器，把慢速推理留给真正需要重规划的时点。仿真干扰者是无碰撞实体的动作捕捉 avatar；运行时物理会在模型计算时暂停，报告的机器人时间不含推理延迟。一次约 1.5 分钟机器人时间的试验，作者报告墙钟约 12 分钟、API 费用约 0.2–0.3 美元；真实机器人样本也只有两项任务。
  • 适合谁读、建议章节：适合具身 Agent、机器人运行时和安全监控读者。建议读 §3 的绊线接口、§4.2–4.5 的匹配基线/实机实验，再读 §5 的限制和附录实现细节。

Agent 构建本体是否真的能提高任务完成率？

论文：AutoOntologyBench: A Task-Grounded Benchmark for Agentic Knowledge Engineering（arXiv:2611.27734）
作者：Minye Shao、Chenghao Xiao、Xingyue Zhao、Yang Long
来源/分类：arXiv · cs.CL
原文：PDF · 代码与资源
全文状态：已核阅官方 PDF 全文。

  • 核心问题、方法与基线：基准包含 19,947 个经审计任务，来自 18 个真实知识源、7 个领域，由来源自身规则验证结果；覆盖应用、修复、组织和构建四种任务。作者让 9 个前沿模型 Agent 在知识表示匹配的条件下比较检索、Agent 自建本体和专家本体等设置。
  • 作者报告的关键结果：在检索之上叠加 Agent 构建的本体，任务成功率提高 6.1 个百分点；但仍比专家构建的参照低 13.0 个百分点。作者据此认为瓶颈主要在自主获取和组织知识，而非本体是否能帮助下游任务。
  • 创新与证据边界：把知识表示质量连接到来源可验证的真实任务，而不是只测本体结构正确率；任务、代码与资源公开。结论仍受任务工厂、领域覆盖、模型版本和 Agent harness 影响；提升是基准任务成功率，不能直接等同科学发现或生产知识工程收益。摘要未提供统一算力成本数字。
  • 适合谁读、建议章节：适合知识图谱、科学 Agent 和 RAG 评测读者。建议读 §3 的基准构造、§4 的匹配条件、§5.2–5.7 的结果/成本，再看附录 D 的切分与污染控制。
