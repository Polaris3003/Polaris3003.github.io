仿真强化学习能否让开放模型直接操作真实机器人？

论文：Training Reasoning Models in Simulation to Natively Use Real Robots（arXiv:2611.18562）
作者：Jiaming Tang、Zhuoyang Zhang、Junxian Guo 等（共 11 位）
来源/分类：arXiv · cs.RO、cs.LG
原文：arXiv 摘要页 · PDF · 代码
全文状态：已核阅 arXiv 官方 HTML 全文；以下复述作者报告，非独立复现。

  • 研究问题、方法与基线：以 Qwen3.8-27B 推理模型为基础，PEAR 提供多轮 robot-use reinforcement learning；模型直接看相机画面并输出末端执行器位姿，不用示范数据或专门控制 harness。训练任务来自 LIBERO 与 RoboDojo，对照包括基础模型、演示微调的 π0.5，以及 GPT-6 Astra/GPT-6.1 Sol 等闭源模型。
  • 作者报告的结果：作者报告 LIBERO 成功率由基础模型 1.6% 提升到 74.4%；在训练未见的真实双臂机器人上，LIBERO 与 RoboDojo 混合训练模型成功率为 60%，仅用 LIBERO 的版本为 23%，基础模型为 0。LIBERO-Pro 在熟悉场景中的新任务上为 57.4%，π0.5 为 0.75%。九个推理、编程和视觉基准的平均变化为 −0.15 分。
  • 创新与局限/失败条件：新意是把计算机使用式的多轮 RL 迁移到真实机器人，并在没有机器人示范的前提下实测仿真到实机迁移。证据仍受训练规模限制：只用了两个模拟器和少量任务，RoboDojo 仅训练两个任务，作者称 GPU 资源不足；提示中机器人形态信息也会影响成功率。与演示微调 VLA 及闭源前沿模型的对照训练路径不同，不能视为同预算消融。推理每步平均约 4.3 秒，偶尔达到 32K tokens，速度和成本仍是瓶颈；结果也未证明不同机器人、环境和任务下普遍成立。
  • 适合谁读、建议章节：适合具身智能、机器人 RL 与开源模型训练工程读者。建议先读 §3.2–3.3 的训练引擎和课程，再看 §4.1、§4.4 的 LIBERO/实机结果，以及 §4.6 与 §5 的速度和失败边界。代码：PEAR。

WebArena-Pro：网页 agent 的跨应用和媒体能力仍有明显缺口

论文：WebArena-Pro: A Heterogeneous, Multimodal, Reproducible Benchmark for Web Agents（arXiv:2611.17955）
作者：Imene Kerboua、Fatemeh Pesaran Zadeh、Xing Han Lù 等（共 22 位）
来源/分类：arXiv · cs.AI、cs.CL、cs.LG
原文：arXiv 摘要页 · PDF · 项目页
全文状态：已核阅 arXiv 官方 HTML 全文；以下复述作者报告，非独立复现。

  • 研究问题、方法与基线：基准包括 300 个任务、20 个自托管应用和六个领域，其中 204 个单站点、96 个跨站点任务，另有 79 个音频/视频任务。作者以四类 agent harness、12 个模型骨干和 50 步上限比较，并用任务 rubric 评估完整成功与部分完成。
  • 作者报告的结果：作者报告 Codex + GPT 6.1 Sol 与 Claude Code + Claude Opus 5.5 均达到 62.3% 整体成功率；GenericAgent 的最佳配置为 30.3%。对 43 个需要实际读取媒体内容的子集，Claude Code + Opus 5.5 从无媒体工具时 14.0% 升至启用转录/帧提取工具后的 48.8%，显示媒体访问是关键基线条件。
  • 创新与局限/失败条件：贡献是可复现的多应用任务集，而不是单一新模型。最高分同时依赖模型与 agent harness，不能把 62.3% 归因于模型本身；38% 任务仍未成功。300 题 API 成本因 harness 约为 166–689 美元（不含主机设施），闭源模型版本会变化；论文没有提供可证明数据污染已排除的审计。
  • 适合谁读、建议章节：适合网页自动化、agent 评测与浏览器工具工程读者。建议读 §3.1–3.4 的站点、任务和验收协议，§4.1–4.4 的主结果/媒体消融，再读 §5 的成本讨论。项目主页：WebArena-Pro。

作者：Hua Yang、Aditya Bhardwaj、Shidong Pan、Bowen Xu
来源/分类：arXiv · cs.CR、cs.AI、cs.SE
原文：arXiv 摘要页 · PDF · DOI/数据
全文状态：已核阅 arXiv 官方 HTML 全文；以下复述作者报告，非独立复现。

  • 研究问题、方法与基线：作者整理 2018–2024 年 1,469 个仓库的 4,131 个合并 PR，保留 diff、评审讨论和修复上下文；数据包括 1,169 个高置信隐私修复、1,643 个非修复 PR，以及人工检查的 Verified/Small 子集。评测时回退已接受的修复以重新引入缺陷，再用两种 coding agent 分别执行通用代码审查或明确隐私审查。
  • 作者报告的结果：在 Small 集（100 个修复、100 个非修复）上，通用审查提示发现 42%–51% 隐私缺陷；明确要求检查隐私后升至 88%–91%，但会误报 11%–15% 的非修复 PR。对 GDPR 原则标签，两位标注者共同认可约 72%，细粒度标注的一致性较弱。
  • 创新与局限/失败条件：贡献是基于真实开发者接受的修复，而非合成漏洞。主要边界是提示意图本身带来巨大提升，结果只测两个 agent 和 200 条 Small 子集；标注者能看到 LLM 预标记，可能抬高认可率，且 21.3% patch 经截断。它证明的是受控审查任务的检出率，不等于生产代码审计安全。
  • 适合谁读、建议章节：适合安全工程、隐私合规和代码 agent 评测读者。建议读 §II-C 的标注流程、§II-E 的标签一致性、§III 的回退评测，再读 §IV 的边界。数据及代码：Zenodo DOI。

来源/分类：arXiv · cs.AI
原文：arXiv 摘要页 · PDF · 代码 · 数据集
全文状态：已核阅 arXiv 官方 HTML 全文；以下复述作者报告，非独立复现。

  • 研究问题、方法与基线：数据从 2026 年六种公开资格考试抽取，包含 321 个评分单元、267 道原始问题，覆盖会计、税务、理财和银行业务；coding agent 编写格式转换器，人类逐题核验。作者以 12 个 LLM 三次运行评测，主要设置是不使用工具的单次 API 回答，另测终端/网页工具。
  • 作者报告的结果：无工具设置下，Claude Fable 5 得分 95.8±0.4，GPT-6 Astra 为 93.6±0.6；最佳开放权重 Kimi K3.1 Pro 为 83.4±0.9。工具使用后 Kimi 达 92.9、GPT-6 Astra 达 97.3，最高闭源与开放模型的差距从约 12 缩至约 4 分。
  • 创新与局限/失败条件：可更新题源是主要创新，但只覆盖能由主办方公开 PDF 的六类考试，顶级闭源模型除税务题外接近饱和。考试时间晚于模型公开知识截止并不能排除训练或后训练污染；主要对手使用闭源 API，复现实验受模型版本、价格和工具 harness 影响。高分也不是职业资格，不能替代注册会计师或税务师。
  • 适合谁读、建议章节：适合金融 LLM 基准、日语模型和数据污染研究者。建议读 §3 的数据构造、§5 的模型与工具结果，及 Coverage/Contamination/Saturation 局限段。代码：GitHub；数据：Hugging Face。

TelePhysica：用重力预检把单图生成变成可执行的物理场景

论文：TelePhysica: Agentic Reconstruction of Physically Interactive Scenes（arXiv:2611.18078）
作者：Ruiqi Shu、Xufeng Zhan、Yuanzhi Liang 等（共 6 位）
来源/分类：arXiv · cs.CV、cs.AI
原文：arXiv 摘要页 · PDF · 项目主页
全文状态：已核阅 arXiv 官方 HTML 全文；以下复述作者报告，非独立复现。

  • 研究问题、方法与基线：系统从单张照片让 vision-language coding agent 生成几何网格和声明式物理模型，先做轮廓检查，再做零力重力平衡预检，之后由统一求解器模拟刚体、关节链、布料与弹性体；模拟轨迹再作为视频扩散的结构条件。对照包括单次开环场景生成，以及不带物理轨迹条件的直接图生视频。
  • 作者报告的结果：在 100 个桌面场景中，二阶段闭环将平衡验证通过率从单次合成 0/100 提到 81/100，中位数需 7 次场景提交；完整 5 秒受力 rollout 验证率为 49/100。物理轨迹条件视频把运动掩膜 IoU 从 0.17–0.27 提升至 0.48–0.87，力方向反转的反事实场景也恢复正向对齐。
  • 创新与局限/失败条件：创新是把物理可执行性放入生成闭环，而不只看像素相似度。实测限于作者构造的 100 个桌面场景和模拟器，不等于真实物体系统辨识，也没有独立团队复现；密度、弹性模量和摩擦来自材料先验，没有通过多步视觉反馈在线识别。14B 视频模型需要约 41GB GPU 显存，成本高于 1.3B 配置。
  • 适合谁读、建议章节：适合世界模型、生成视频、物理仿真与机器人场景建模读者。建议读 §3.1 的闭环重建、§4.1 的 100 场景实验、§4.2–4.3 的物理与视频消融。项目主页：interactive4d。
