2026-11-17 GitHub 热榜简报：从 Agent 控制面到本地工具链

GITHUB TRENDING · 2026.11.17

今天的 GitHub all-languages 日榜更像一张 Agent 工程边界图：AG-UI处理 Agent 与界面的事件协议，Plannotator把人的判断接回会话，SkillEvaluator和 OpenCodeReview把质量门与确定性约束放进执行链。另一端，Chrome DevTools MCP、ffmpeg-skill和 Arcane把 Agent 或开发者带进浏览器、媒体与容器这些真实运行环境；值得关注的不是 stars 本身，而是权限、证据、验证和本地执行如何被做成接口。

Agent 协议人类反馈Office SDK容器运维技能评估代码审查浏览器调试本地媒体

今日要点

今天最清晰的主线是 Agent 的控制面正在变厚：AG-UI用事件流连接 Agent、实时上下文与用户界面，Plannotator让人类可以在计划、文档、消息和 diff 上批注，SkillEvaluator开始测量一个 skill 是否真的改变任务结果。它们共同说明，提示词只是入口；长期可维护的系统还需要稳定协议、明确暂停点和可复现的质量门。

执行面也在向真实环境下沉：OpenCodeReview把必须精确的文件选择和评论定位留给工程逻辑，Chrome DevTools MCP把浏览器调试暴露给 Agent，ffmpeg-skill则用探测、编辑、检查的闭环约束本地媒体处理。再加上 Univer把 Office 能力嵌入产品、PaperOrchestra把研究写作拆成多 Agent 流程，今天的信号不是“模型又聪明了一点”，而是软件边界正在重新分层。

值得尝试

ag-ui-protocol/ag-ui

AG-UI 是面向 Agent—用户交互的轻量事件协议，用双向事件流承载流式文本、工具调用、共享状态、人工介入和子 Agent 等交互。它适合研究实时聊天、生成式 UI 与 human-in-the-loop 的前端边界；限制是它只解决协议和事件层，不提供模型或 Agent，后端适配、权限和错误处理仍要由集成方负责。主要语言为 TypeScript，日榜新增 791★，仓库页核验总计 19,084★，许可证为 MIT，最近 Release 2026-11-13 发布。

backnotprop/plannotator

Plannotator 是面向编码 Agent 的本地浏览器审查层，可以标注计划、规格、Markdown、HTML、Agent 消息、代码 diff 和 PR，再把反馈送回会话。它适合需要在多 Agent 并行时保留人类决策入口的团队；限制是仍需通过各宿主的插件、hooks 或 MCP 接入，分享功能也有本地状态、链接权限和过期策略需要单独评估。主要语言为 TypeScript，日榜新增 696★，仓库页核验总计 12,608★，许可证为 Apache-2.0 / MIT，最近 Release v0.28.66 于 2026-11-16 发布。

dream-num/univer

Univer 是可嵌入产品的 Office SDK，提供表格与文档编辑、计算、协作、文件处理以及面向 Agent 的 Facade API。它适合研究如何把 Office 能力作为产品基础设施暴露给人和 Agent；限制是仓库的 Apache-2.0 部分主要是 Web SDK 核心，Server SDK、商业插件和商业 AI 扩展要分别核对许可与部署边界。主要语言为 TypeScript，日榜新增 1,828★，仓库页核验总计 27,832★，许可证为 Apache-2.0，最近 Release v1.5.2 于 2026-11-16 发布。

getarcaneapp/arcane

Arcane 是用 Go 实现的现代 Docker 管理项目，目标是为个人和团队提供可自托管的容器管理界面。它适合观察容器运维如何从命令行走向可视化控制面；限制是主分支已经是 v3，README 将 v2 放在单独分支，实际部署前应按文档确认版本迁移和宿主机权限。主要语言为 Go，日榜新增 46★，仓库页核验总计 8,775★，许可证为 BSD-3-Clause，最近 Release v3.0.1 于 2026-11-15 发布。

DeanChensj/jiangshan-map

江山时序 是从战国到当代的中国历史交互地图，把时间轴、疆域快照、古城与关隘、人物行迹和诗文路线放到同一浏览器画布。它适合学习如何把长时段、结构化史料和可探索叙事组合成教育型可视化；限制是内容依赖作者整理的数据与考据，不是通用 GIS，语音讲解还依赖浏览器的 Speech Synthesis。主要语言为 JavaScript，日榜新增 288★，仓库页核验总计 6,853★，许可证为 GPL-3.0，最近 Release v1.3.0 于 2026-11-13 发布。

NVIDIA/SkillEvaluator

SkillEvaluator 为 Agent skills 提供分层评估：Tier 1 做质量与安全检查，Tier 2 检测重复和语义重叠，Tier 3 在沙箱中测量 skill 对 Agent 任务结果的影响，并可接入 CI。它适合把“这个 skill 看起来不错”改成可复现的质量门；限制是完整实时评估仍需要支持的 Agent、模型提供商和 sandbox，静态检查不能替代真实安全审查或效果验证。主要语言为 Python，日榜新增 873★，仓库页核验总计 2,756★，许可证为 Apache-2.0，最近 Release v0.9.0 于 2026-11-13 发布。

alibaba/open-code-review

OpenCodeReview 是 AI 代码审查 CLI：把确定性的文件选择、文件分组、规则匹配和评论定位交给工程逻辑，再让 LLM Agent 处理动态判断，支持 diff review 与整目录 scan。它适合研究“哪些步骤必须由系统保证，哪些步骤适合交给模型”；限制是需要配置模型端点，README 的 benchmark 明确偏向高 precision、recall 较低，不能直接外推到你的代码库。主要语言为 Go，日榜新增 951★，仓库页核验总计 52,985★，许可证为 Apache-2.0，最近 Release v1.13.10 于 2026-11-15 发布。

google-research/paper-orchestra

PaperOrchestra 是多 Agent 研究写作框架，把想法和实验日志编排成包含文献综合、章节写作、内容精炼和图表生成的 LaTeX 稿件。它适合研究如何把长流程任务拆成有角色分工的 Agent 管线；限制是数据集不随仓库提供，运行需要 Conda、模型和文献 API 配置，而且 README 明确说明它不是 Google 官方支持产品。主要语言为 Python，日榜新增 313★，仓库页核验总计 1,587★，许可证为 Apache-2.0，最近 2026-11-15 UTC 提交。

ChromeDevTools/chrome-devtools-mcp

Chrome DevTools MCP 让编码 Agent 通过 MCP 或 CLI 控制并检查实时 Chrome，覆盖性能 trace、网络请求、控制台、截图、source map 和 Puppeteer 自动化。它适合把浏览器调试和性能工程纳入 Agent 工具链；限制是官方只支持 Chrome 与 Chrome for Testing，浏览器内容会暴露给 MCP 客户端，usage statistics 也默认开启，需要先评估数据边界。主要语言为 TypeScript，日榜新增 841★，仓库页核验总计 57,713★，许可证为 Apache-2.0，最近 Release v1.13.0 于 2026-11-11 发布。

sveltejs/svelte

Svelte 是编译器型前端框架，把声明式组件转换成直接更新 DOM 的高效 JavaScript，适合用来理解“编译时承担多少运行时工作”的 Web 工程路线。它的价值在于提供了一个成熟、持续维护的前端基线；限制是它本身不是 Agent 平台或后端框架，选型仍要结合生态、团队经验和目标运行环境。主要语言为 JavaScript，日榜新增 115★，仓库页核验总计 89,020★，许可证为 MIT，最近 Release svelte@5.57.3 于 2026-10-26 发布。

kajisho5/ffmpeg-skill

ffmpeg-skill 给编码 Agent 一个本地视频编辑器，用 42 个带机器可读契约的工具完成 probe、剪辑、转码、字幕、响度处理和交付检查，并可作为 MCP 服务调用。它适合学习如何用“测量—执行—验证”闭环约束高风险媒体操作；限制是依赖本机 FFmpeg、ffprobe 和 Python，且它只负责执行与验收，不替用户决定剪什么或内容是否值得发布。主要语言为 Python，日榜新增 367★，仓库页核验总计 6,829★，许可证为 MIT，最近 Release v3.10.1 于 2026-11-15 发布。
