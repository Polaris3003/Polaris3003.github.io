2026-11-18 GitHub 热榜简报：从 Agent 交付闭环到可复现学习

GITHUB TRENDING · 2026.11.18

今天的 GitHub all-languages 日榜更像一张 Agent 工程边界图：LoopForge、OpenCodeReview和 Superpowers把交付、审查和开发方法做成流程，AG-UI与 Plannotator把协议和人的判断接回执行链。另一端，Univer、Arcane、Svelte、MiniMind和 PaperOrchestra把能力落到 Office、容器、前端、模型训练和研究写作这些具体环境。

Agent 交付确定性审查人类反馈Office SDK容器运维Agent 协议编译型前端小模型训练

今日要点

今天最清晰的主线是 Agent 正在从“能不能调用工具”转向“能不能稳定交付”：LoopForge用 Docker sandbox、SOP、checkpoint 和 human gate 组织团队交付，OpenCodeReview把文件选择、规则匹配和评论定位留给确定性工程，Superpowers则把澄清需求、写计划、TDD、子 Agent 和代码审查串成强制流程。它们共同说明：模型只是执行器，真正决定长期成本的是上下文、权限、验证和暂停点如何被编码。

另一条线是 Agent 与真实应用之间的接口正在变厚：AG-UI用事件协议承载流式文本、工具调用、共享状态和人工介入，Plannotator把计划、文档、HTML 和 diff 的反馈送回会话，Univer把表格、文档和计算能力嵌入产品。再看 MiniMind和 PaperOrchestra，今天的学习价值不在于追逐最大模型，而在于理解训练链路和长流程编排怎样被拆解、复现与验收。

值得尝试

elementalsouls/Claude-BugHunter

Claude-BugHunter 是面向授权安全测试的 Claude Code skill bundle，README 列出 83 个 skills、15 个命令、漏洞报告模式、企业身份与基础设施攻击面，以及 Burp MCP 接入。它适合安全研究者学习如何把侦察、验证、证据整理和报告卫生做成可复用流程；限制是只应作用于自有或明确授权的目标，代码与内容还分别受 MIT 和 CC BY 4.0 约束，不能把技能包当成未经授权的攻击工具。主要语言为 Python，日榜新增 1,005★，仓库页核验总计 9,411★，最近 2026-11-17 提交，最近 Release 为 v2.1。

alibaba/open-code-review

OpenCodeReview 是 AI 代码审查 CLI：它读取 Git diff 或整目录，把精确文件选择、文件分组、规则匹配和评论定位交给工程逻辑，再让 Agent 处理动态判断。它适合研究“哪些步骤必须确定，哪些步骤可以交给模型”；限制是需要配置模型端点，仓库给出的 benchmark 明确偏向更高 precision、recall 较低，不能直接外推到你的代码库。主要语言为 Go，日榜新增 763★，仓库页核验总计 53,772★，许可证为 Apache-2.0，最近 Release v1.13.11 于 2026-11-17 发布。

Tencent/LoopForge

LoopForge 是面向团队的自托管 Agent 交付工作区：它在 Docker sandbox 中检出仓库、调用多个 coding-agent CLI、按角色协作，并通过 SOP、checkpoint 和 human gate 产出 PR、文档或代码。它适合把一次性的“让 Agent 修 bug”改造成可暂停、可重试、可观察的重复流程；限制是需要 Docker、模型凭据和外部 Agent CLI，当前版本也仍处于快速迭代阶段，部署权限与运行成本不能省略。主要语言为 Go，日榜新增 591★，仓库页核验总计 3,227★，许可证为 MIT（第三方组件保留各自条款），最近 Release v0.4.0 于 2026-11-17 发布。

dream-num/univer

Univer 是可嵌入产品的 Office SDK，提供表格和文档编辑、计算、协作、文件处理，以及面向 Agent 的 Facade API；其插件架构把内容模型、命令、公式和 UI 扩展拆开。它适合产品团队研究如何把 Office 能力作为基础设施暴露给人和 Agent；限制是开源仓库的 Apache-2.0 核心与 Server SDK、商业插件、商业 AI 扩展的边界需要分别核对。主要语言为 TypeScript，日榜新增 1,774★，仓库页核验总计 28,928★，许可证为 Apache-2.0，最近 Release v1.5.2 于 2026-11-16 发布。

getarcaneapp/arcane

Arcane 是用 Go 实现的现代 Docker 管理界面，目标是把镜像、容器和自托管运维集中到一个可视化控制面。它适合个人服务器或小团队观察容器运维如何从命令行走向可审计的 Web 工作区；限制是主分支已进入 v3，实际部署前应按 官方文档确认版本迁移、宿主机权限和数据持久化。主要语言为 Go，日榜新增 618★，仓库页核验总计 9,356★，许可证为 BSD-3-Clause，最近 Release v3.0.1 于 2026-11-15 发布。

obra/superpowers

Superpowers 是由可组合 skills 和启动指令组成的编码 Agent 开发方法论，核心流程覆盖需求澄清、设计、实现计划、TDD、子 Agent 开发和独立代码审查。它适合希望把“先想清楚再写代码”变成 Agent 默认行为的开发者；限制是不同 harness 需要分别安装和验证，视觉 companion 默认会向项目网站发送版本级遥测，可按 README 设置 SUPERPOWERS_DISABLE_TELEMETRY 关闭。主要语言为 Shell，日榜新增 1,917★，仓库页核验总计 319,373★，许可证为 MIT，最近 Release v7.0.2 于 2026-11-03 发布。

ag-ui-protocol/ag-ui

AG-UI 是面向 Agent—用户交互的开放事件协议，用双向事件流承载流式文本、工具调用、共享状态、人工介入和子 Agent，并提供 TypeScript、Python 与 .NET SDK。它适合做实时聊天、生成式 UI、状态同步和 human-in-the-loop 集成；限制是它只解决运行时协议，不提供模型或 Agent，事件映射、权限、错误处理和后端适配仍由集成方负责。主要语言为 TypeScript，日榜新增 1,445★，仓库页核验总计 20,034★，许可证为 MIT，最近 Release 2026-11-17 发布。

backnotprop/plannotator

Plannotator 是面向编码 Agent 的本地浏览器审查层，可以标注计划、规格、Markdown、HTML、Agent 消息、代码 diff 和 PR，再把反馈送回会话；Inbox 还允许 Agent 在继续工作时留下问题和待决策项。它适合需要在多 Agent 并行时保留人类决策入口的团队；限制是仍需通过宿主的插件、hooks 或 MCP 接入，共享链接由持有完整链接者读取，大内容上传后会加密并在 7 天后过期。主要语言为 TypeScript，日榜新增 691★，仓库页核验总计 13,087★，许可证为 Apache-2.0 / MIT，最近 Release v0.28.67 于 2026-11-17 发布。

sveltejs/svelte

Svelte 是编译型前端框架，把声明式组件转换成直接更新 DOM 的 JavaScript，把更多工作从运行时移到编译阶段。它适合用来理解编译时优化、组件模型和前端运行时边界；限制是它本身不是 Agent 平台或后端框架，选型仍要结合团队生态、构建链和目标运行环境。主要语言为 JavaScript，日榜新增 477★，仓库页核验总计 89,620★，许可证为 MIT，最近 2026-11-17 提交，最近 Release 为 svelte@5.57.3。

jingyaogong/minimind

MiniMind 是从零训练约 64M 参数小语言模型的教学项目，公开了从 tokenizer、预训练、SFT、LoRA 到 RLHF、Tool Use、Agentic RL 和蒸馏的完整链路，并尽量使用 PyTorch 原生实现。它适合想理解 LLM 内部机制而不满足于调用高层框架的人；限制是 README 中“2 小时、3 元”指单张 RTX 3090 上的 SFT 阶段实测，不等于完整训练成本，数据、显存和实验配置仍需自己复现。主要语言为 Python，日榜新增 192★，仓库页核验总计 66,037★，许可证为 Apache-2.0，最近 2026-10-27 提交。

google-research/paper-orchestra

PaperOrchestra 是多 Agent 研究写作框架，把想法和实验日志编排成包含文献综合、章节写作、内容精炼、图表生成和 LaTeX 输出的研究稿件。它适合研究如何把长流程任务拆成有角色分工的 Agent 管线；限制是数据集不随仓库提供，运行需要 Conda、模型和文献 API 配置，README 也明确说明它不是 Google 官方支持产品。主要语言为 Python，日榜新增 1,072★，仓库页核验总计 3,081★，许可证为 Apache-2.0，最近 2026-11-15 提交。
