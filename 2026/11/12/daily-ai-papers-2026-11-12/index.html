BuySideFlow: A Point-in-Time Benchmark for LLM Agents in Investment Research

全文状态与研究问题。 已核阅 arXiv PDF 与当前 HTML 全文。论文问的是：金融研究智能体算对了结果，是否也使用了当时可得的信息。408 个中文投研任务涵盖股票、基金、固收和宏观，基于一家持牌生产数据库的固定快照；任务明确要求披露截止日、历史成分/分类状态和记录版本。九种 agent 配置生成 SQL 或 SQL-Python 流程，结果检查之外，研究者再审计运行步骤。

作者报告的主要结果。 3,672 次完整运行中有 993 次通过结果检查，整体通过率 27.0%，九种配置准确率为 16.18%–36.76%；169 个任务没有任何配置通过。对共同的 100 个任务抽查 900 次运行，380 次通过结果校验，其中 193 次仍存在至少一项点时违规，占 50.8%。独立复核 200 份运行记录时，是否存在点时错误的一致率为 91.0%，Cohen’s κ=.818。

创新、基线与证据边界。 基线是九种 agent 配置，任务经投研人员整理、投资组合经理审阅，参考流程也由金融数据工程师实现；研究同时检查答案正确和执行依赖，避免“答案恰好正确”被误当成历史回测合规。单个模型—任务只保留一次运行，模型随机性未估计；不同配置通过的任务集合不一，错误率比较有组成差异。数据库快照受授权限制，不能完整公开重放；基准只覆盖中文买方研究，不说明任何组合的预测收益，也不构成投资建议。

适合谁读。 金融智能体、回测数据治理与量化研究平台团队。建议先读第 2 节任务/PIT 定义，再读第 3 节人工流程审计和第 4.2–4.3 节通过率与错误类型，最后看 Limitations 的数据和抽样边界。

LM-SimBench: A Unified Framework, Dataset, and Benchmark for Large Language Model Training Simulation

全文状态与研究问题。 已核阅 arXiv HTML 全文。论文针对大模型分布式训练配置选择昂贵、不同模拟器难以公平比较的问题，提出从编译/设备绑定、执行表示、计算与通信估计到 schedule 汇总的评测框架，并发布昇腾 NPU profiling 数据：10 个稠密/MoE 家族的 23 个模型设置、348 个可行配置，变化覆盖 DP/TP/PP/CP/EP 五类并行及激活重计算。

作者报告的结果与比较。 在 Qwen1.5-1.8B、8K token 的 NPU 测试配置中，vTrain 对六个共同测试配置的迭代时长 MAE 为 0.207 秒，Calculon 为 1.059 秒；sMAPE 为 1.86% 对 8.88%。模拟耗时则为 25.46ms 对 1.78ms，说明更准的模型更慢。跨平台的两个 Qwen3 配置中，按 NPU 运行时间挑选前三名均包含 GPU 最快配置，Top-3 shortlist regret 为 0；直接挑 NPU 最快配置映射到 GPU 时，一个设置有 6.9% regret。

创新、成本与局限。 将系统预测精度、候选排序、显存可行性与模拟成本分开测量，也暴露显存和通信估计的误差。现有跨平台对照只有两个模型设置，且 NPU 结果不能替代目标 GPU 的端到端实测；profiling 自身也需要实际硬件。公开仓库提供评估与预处理代码，但说明目前未包含 vTrain adapter 和跨平台校准/测试 split。代码与数据：GitHub · Hugging Face。

适合谁读。 大模型训练系统、集群规划与性能模拟研究者。建议读第 3 节统一问题定义、第 4–5 节数据/协议、第 6.1 和 6.3–6.4 节模拟误差与跨平台筛选，再看附录 F 的 GPU/NPU 成对设置。

Specification-based Security Evaluation of Real-World Agents Tool-Calling under Long-Horizon Context Tasks

全文状态与研究问题。 已核阅当前 v2 的 arXiv HTML 全文。问题是最终日志和终态可能掩盖中途发生、随后被覆盖的权限违规。RAS-Eval 把效用、安全目标写成线性时序逻辑，逐步观察工具调用和所需环境变量，再由 nuXmv 模型检查器给出确定性判定；作者同时构建 200 个正常任务和 800 个攻击任务，包含间接提示注入、工具投毒、技能代码注入和工具代码注入。

作者报告的结果与比较。 论文比较规则化检查、LLM-as-a-Judge/Agent-as-a-Judge 等评估方式，并在多种 agent harness 上测攻击与防御。当前版本结论是：逐步状态监测能发现终态检查遗漏的瞬态违规，判定不需追加 LLM 推理；被评估的防御没有一种全面覆盖四类攻击面。全文未给出可脱离特定任务/配置的通用安全率。

创新、限制与复现性。 优点是把行为规范和环境状态显式化；但模型检查只能证明代码化规格，不证明规格本身充分。没写进 LTL 的性质、无法观测的副作用或与基准不同的工具实现都可能漏检。攻击任务由多智能体构造，评测结果不等于生产部署风险率。代码：RAS-Eval。

适合谁读。 工具型智能体、MCP 安全和运行时监控工程师。建议读第 3.2 节规格和状态建模、第 4.3–4.7 节攻击/防御、质量与成本，再看第 6 节限制。

GTAGym: Real AAA Game Tasks Environment for Evaluation and Reinforcement Learning

全文状态与研究问题。 已核阅 arXiv HTML 全文。论文要解决游戏智能体评测依赖人工判断、难以给强化学习自动奖励的问题。GTAGym 从 GTA V 主线任务重建 103 个在线任务（九类），另提供 47 个图像射击/狙击任务；3D 场景由游戏状态谓词验收，图像任务按目标命中判断，并可用固定模板和参数范围生成训练环境。

作者报告的主要结果与基线。 六种前沿模型在传统 GUI 协议下测试，AGI 分支以 Codex harness 运行；最优 GPT-6-Astra 配置 70.9%±4.4%，人类均值 89.8%±1.4%。Qwen3.8-27B 以 50 个不与基准任务重合的生成导航场景作 GRPO-LoRA 训练，在 100 个原生 GTA V 导航/交互任务上的成功率从 15% 到 23%。论文还报告空中导航、逃避和拦截仍明显困难。

创新、基线公平性与失败条件。 自动游戏状态校验比只读文本输出更接近真实任务完成；但闭源模型、不同 harness 和推理预算使横向排名不完全等价。DeepSeek 在某 JSON 设置下输出 token 约为 Astra 的 26 倍，说明准确率还需结合成本。游戏特定控制技能不能直接外推至网页、机器人或开放世界；训练样本和游戏版本也影响复现。代码与基准：GTAGym · GTAVBench 数据。

适合谁读。 GUI/游戏智能体与强化学习研究者。建议读第 3 节环境和验收器、第 4.1–4.3 节模型协议与训练、第 5 节失败模式和 harness 权衡；附录 A、B 给出任务及奖励细节。

Meituan-Robotics-0: A Vision-Language-Action Foundation Model for Desktop Manipulation

全文状态与研究问题。 已核阅 arXiv v2 PDF/HTML 全文。MR0 面向固定底座桌面操作，将 1.47 亿图文样本与 15,060 小时、12 种 embodiment 的机器人轨迹对齐；训练分离离散动作 token 预训练、连续 flow-matching 跨本体中训和真实环境后训练。Rollback 把被替换的失败策略片段配对人工纠正，供 CFG-DAgger 使用；事件记忆负责在任务进展改变时触发高层重规划。

作者报告的结果与比较。 作者报告 RoboTwin 2.0 成功率 93.6%，RoboDojo VLA 排名第五。真实机器人部分在三类任务中用匹配 HG-DAgger 后训练比较 MR0 与 pi0.5，MR0 平均成功率和进度分更高；以太网插入任务中，Rollback 数据训练的 CFG-DAgger 成功率为 70%、进度分 0.90。仿真基准分数与实机结果是两类证据，不能互换。

创新与局限。 多 embodiment 数据接口、人工纠错和事件级记忆同时处理动作连续性、执行恢复与长程状态；匹配后训练是较公平的对照。局限是依赖大规模数据和特定双臂/相机/动作接口，真实评测任务数有限，摘要没有报告训练总算力或完整跨实验室复现；排行榜比较还受评测协议差异影响。资源：项目主页 · 代码 · 模型 · RoboDesk 数据。

适合谁读。 VLA、机器人数据工程和长时任务规划团队。建议读第 2 节数据筛选、第 3 节训练方法、第 4 节事件记忆、第 5.2 节实机比较。
