2026-11-12 GitHub 热榜简报：Agent 的指南、执行边界与真实系统

GITHUB TRENDING · 2026.11.12

今天的 GitHub all-languages 日榜把 Agent 的能力拆成几个可核验的层次：Modern Web Guidance把现代 Web API、兼容性、性能与无障碍规则带进编码 Agent，agent-browser负责按 accessibility tree 操作浏览器，Codex Security负责扫描、验证和修复漏洞；Astryx与 HA-MCP则把能力接到 UI 和真实设备。另有 daily_stock_analysis 与 Sure把 LLM 或本地自托管推到金融应用，但数据源、凭证和误差边界应排在 stars 之前。

Agent Skills现代 Web浏览器执行应用安全MCP 与家居自托管金融

今日要点

今天最值得关注的不是某个仓库的 star 数，而是 Agent 的工作面正在被拆成互相衔接的工程层：Modern Web Guidance提供面向现代平台的检索、评估和 legacy-scan，addyosmani/agent-skills把定义、计划、构建、测试、评审和发布编码成技能，agent-browser再把读状态和执行动作压缩成可重复的浏览器闭环。它们适合拿来研究“如何减少 Agent 的自由发挥”，但都不能替代真实测试、权限设计和人工复核。

另一条主线是从工具链进入真实环境：Astryx尝试让人和 Agent 共享组件、CLI 与文档，HA-MCP把家庭设备能力暴露为 MCP 工具，Codex Security把扫描结果接到报告、修复和协作流程。daily_stock_analysis与 Sure则提醒我们：一旦涉及金融数据，外部 API、部署成本、权限和结果解释就必须和模型能力一起评估。

值得尝试

meta/astryx

Astryx是基于 React 19 和 StyleX 的开源设计系统，README 介绍它提供 150+ 可访问组件、主题、模板、CLI、文档和 sandbox，并让人和 AI 助手使用同一套 API 与参考资料。它适合前端团队研究 Agent-ready UI 如何落到组件命名、可组合实现和文档；限制是项目仍处于 Beta，要求 React 19+，实验性组件与图表包还有 canary 发布边界。主要语言为 TypeScript，日榜快照显示当日新增 2,776★；仓库页核验总计 25,090★、MIT 许可证、最近 Release v0.7.14 和 2026-11-12 UTC 的提交。

ZhuLinsen/daily_stock_analysis

这个 Python 项目把多市场行情、新闻、LLM 分析、决策看板和企业微信/飞书/Telegram/Discord/Slack/邮件推送串成可定时运行的股票分析系统，也提供 Docker 与 GitHub Actions 路径。它适合研究“数据源—模型—报告—通知”的端到端流水线；限制是 README 明确提醒免费行情源会受限流、接口变化和网络波动影响，模型 API key、付费数据源和输出质量都需要自行管理，不能把自动化当作收益证明。主要语言为 Python，日榜快照显示当日新增 278★；仓库页核验总计 70,321★、MIT 许可证、最近 Release v3.34.0 和 2026-11-10 UTC 的提交。

GoogleChrome/modern-web-guidance-src

这是 Modern Web Guidance 的源仓库，负责内容编写、校准和评估；其 CLI 可以安装技能、搜索指南、按 ID 取回指南，并扫描代码库中的 legacy patterns。它适合前端工程师和 Agent 工具链作者学习如何把平台级 API、浏览器兼容性、性能和无障碍知识压缩进模型上下文；限制是它是指南与评估源代码，不是 Web 框架，安装向导和指南结果仍需结合目标浏览器与真实项目验证。主要语言为 TypeScript，日榜快照显示当日新增 159★；仓库页核验总计 1,808★、Apache-2.0 许可证、最近 Release audit-data 和 2026-11-12 UTC 的提交。

addyosmani/agent-skills

Agent Skills把需求定义、计划、构建、测试、评审和发布拆成 /spec、/plan、/build、/test、/review、/ship 等可安装工作流。它适合希望把团队工程纪律沉淀为 Agent 可执行步骤的人；限制是 README 明确指出单独安装一个 skill 可能漏掉仓库级 references/，而且不同 Agent 宿主的插件发现与命令兼容性仍要单独验证。主要语言为 JavaScript，日榜快照显示当日新增 787★；仓库页核验总计 115,987★、MIT 许可证、最近 Release 0.6.15 和 2026-11-01 UTC 的提交。

vercel-labs/agent-browser

agent-browser是 Rust 编写的浏览器自动化 CLI，用 snapshot 把页面读成紧凑的 accessibility tree，并给元素分配 refs，让 Agent 逐步执行 open、click、fill 和 get。它适合研究可读状态、动作闭环和持久会话；限制是首次需要安装 Chrome for Testing，页面导航或 DOM 变化后旧 refs 必须重新 snapshot，认证、域名白名单和动作策略仍由使用者负责。主要语言为 Rust，日榜快照显示当日新增 708★；仓库页核验总计 49,904★、Apache-2.0 许可证、最近 Release v0.42.0 和 2026-11-11 UTC 的提交。

we-promise/sure

Sure是 Maybe Finance 归档后延续下来的社区 fork，提供可用的个人财务管理应用，可通过 Docker 自托管，并包含预算、资产负债和 AI 助手等产品路径。它适合研究如何把成熟 Rails 应用重新交给社区维护；限制是上游已停止开发，README 直接列出数据量较大时的性能问题，自托管还需要 Ruby、PostgreSQL 和 Redis，当前最新 Release 仍带有 alpha 标记。主要语言为 Ruby，日榜快照显示当日新增 1,078★；仓库页核验总计 13,000★、AGPL-3.0 许可证、最近 Release v2026.11.10-alpha 和 2026-11-11 UTC 的提交。

homeassistant-ai/ha-mcp

HA-MCP把 Home Assistant 的设备和自动化能力接入 Claude、ChatGPT 等 AI 助手，README 当前标注 87 个工具，并推荐在 Home Assistant 2026.11+ 通过 Marketplace 或 HACS 安装进程内集成。它适合研究 MCP 如何落到真实家庭设备和权限边界；限制是初始配置需要管理员令牌或专用管理员账户，远程连接要明确选择认证方式，文件与 YAML 编辑工具默认关闭且应单独评估风险。主要语言为 Python，日榜快照显示当日新增 645★；仓库页核验总计 7,396★、MIT 许可证、最近 Release v9.3.0.dev3501 和 2026-11-12 UTC 的提交。

openai/codex-security

Codex Security提供 CLI、TypeScript SDK 和 GitHub Action，用于扫描仓库、验证发现、生成补丁、复核修复，并可导出 SARIF/JSON/CSV 或接入协作系统。它适合安全工程师研究“发现—证据—修复—复核”的 Agent 工作流；限制是 README 要求特定 Node.js 与 Python 版本，部分请求和受保护发现需要登录或额外权限，发布到云端或外部跟踪器前还必须确认数据边界。主要语言为 TypeScript，日榜快照显示当日新增 52★；仓库页核验总计 11,784★、Apache-2.0 许可证、最近 Release action-v0.9.1 和 2026-11-12 UTC 的提交。
