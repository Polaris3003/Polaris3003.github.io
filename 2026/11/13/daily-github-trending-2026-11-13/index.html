2026-11-13 GitHub 热榜简报：Agent 从规则、执行到本地推理

GITHUB TRENDING · 2026.11.13

今天的 GitHub all-languages 日榜呈现出一条清晰的 Agent 工程链：Modern Web Guidance把 Web 平台知识变成可检索规则，Agent Skills把工程阶段固定成工作流，Qwen Code与 OpenBot承担执行面，Codex Security补上安全闭环，TensorFold和 llama.cpp则把推理能力拉回本地硬件。Sure提供了一个完整的自托管应用样本；stars 只是榜单信号，真正值得评估的是许可证、最近活动、部署边界与验证成本。

Agent 规则工程工作流应用安全本地推理自托管系统Agent-ready UI

今日要点

今天的重点不是某一个 Agent 应用，而是能力边界开始被拆成可组合的层：现代 Web 指南负责约束知识，工程技能负责约束流程，终端编码 Agent与 可自托管 coworker负责执行，安全工具负责把结果带回证据、修复和复核。这样的拆分比“让模型更聪明”更接近可维护系统，但也意味着权限、日志、回滚和人工确认不能被隐藏在提示词后面。

另一条值得关注的线是本地化：TensorFold尝试用 Zig 直接连接 Metal、CUDA 等后端，llama.cpp继续提供成熟的本地推理与 OpenAI 兼容服务路径。它们适合用来学习模型服务的硬件、量化和后端取舍；如果目标只是快速得到一个可用 Agent，先确认模型兼容性、显存预算和运维成本，通常比追逐榜单更重要。

值得尝试

GoogleChrome/modern-web-guidance-src

这是 Modern Web Guidance 的源仓库，包含指南内容的编写、校准、评估以及 CLI，可搜索指南、按 ID 取回，并扫描代码中的 legacy patterns。它值得前端团队和 Agent 工具链作者研究，因为平台 API、浏览器兼容性、性能和无障碍知识被组织成了 Agent 可检索的工程约束；限制是它是指南与评估源代码，不是 Web 框架，结果仍需结合目标浏览器和真实测试。主要语言为 TypeScript，日榜新增 739★；仓库页核验总计 3,106★、Apache-2.0 许可证、最近 Release audit-data 和 2026-11-13 UTC 提交。

openai/codex-security

这个项目提供 CLI、TypeScript SDK 和 GitHub Action，用于扫描仓库、验证发现、生成补丁、复核已有修复，并导出 SARIF、JSON、CSV 或接入协作系统。它的学习价值在于把“发现—证据—修复—复核”串成安全工作流，适合安全工程师研究 Agent 如何参与漏洞处理；限制是 README 要求特定 Node.js 与 Python 版本，部分云端发现和外部跟踪器需要登录或额外权限。主要语言为 TypeScript，日榜新增 643★；仓库页核验总计 12,469★、Apache-2.0 许可证、最近 Release npm-v0.10.0 和 2026-11-12 UTC 提交。

QwenLM/qwen-code

Qwen Code 是运行在终端中的开源编码 Agent，README 同时覆盖编辑器、桌面、浏览器和聊天入口，并提供 daemon mode、能力说明和评测路径。它值得尝试，是因为它把编码 Agent 的安装、交互、长驻进程和模型接入放进一个可直接运行的工程对象，适合比较不同 Agent 宿主的编排方式；限制是要求 Node.js 22+，模型访问、供应商兼容性和运行成本仍由使用者承担。主要语言为 TypeScript，日榜新增 151★；仓库页核验总计 29,845★、Apache-2.0 许可证、最近 Release v0.27.3 和 2026-11-13 UTC 提交。

ashhart/TensorFold

TensorFold 用 Zig 二进制在 Apple Silicon 和 NVIDIA GPU 上直接运行语言模型，读取 checkpoint、完成 tokenization，并调用 Metal 或 CUDA kernel，不要求安装 Python 或 MLX。它适合想理解本地推理引擎、硬件后端和服务延迟取舍的人；限制是硬件与模型兼容性决定实际体验，README 还把 Living Weights 标为 experimental，不能把示例性能直接外推到其他设备。主要语言为 Zig，日榜新增 54★；仓库页核验总计 1,954★、Apache-2.0 许可证、最近 Release v1.2.7 和 2026-11-13 UTC 提交。

addyosmani/agent-skills

Agent Skills 把需求定义、计划、构建、验证、评审和发布拆成可安装的工程技能，并以 25 个技能覆盖从想法到上线的阶段。它适合团队把工程纪律沉淀为 Agent 可执行的检查点，也适合研究“流程约束”如何降低 Agent 的自由发挥；限制是部分技能依赖仓库级 references 和宿主的插件发现机制，单独复制文件后必须重新验证上下文是否完整。主要语言为 JavaScript，日榜新增 816★；仓库页核验总计 116,706★、MIT 许可证、最近 Release 0.6.15 和 2026-11-01 UTC 提交。

meta/astryx

Astryx 是基于 React 19+ 和 StyleX 的开源设计系统，提供可组合的组件包、主题、模式和文档，并试图让人和 Agent 使用同一套 API 与参考资料。它值得前端团队研究，因为“Agent-ready UI”被落在 foundations、components、patterns 和 architecture 等可检查的结构上，而不是只停留在宣传语；限制是项目仍处于 Beta，React 版本和 API 稳定性需要在真实项目中单独评估。主要语言为 TypeScript，日榜新增 1,830★；仓库页核验总计 26,615★、MIT 许可证、最近 Release v0.7.15 和 2026-11-13 UTC 提交。

CopilotKit/OpenBot

OpenBot 是模块化、可自托管的 AI coworker 工作区，让每个 Agent 拥有浏览器、文件和工具，并记录它在执行前作出的动作决策与执行后结果，也支持接入 AG-UI Agent。它适合研究 computer-use 如何进入团队工作区，以及模型、工具、记录和基础设施如何组合；限制是部署、模型供应商、权限和审计边界都需要自行配置，不能因为默认工作流可运行就跳过权限评估。主要语言为 TypeScript，日榜新增 298★；仓库页核验总计 11,652★、MIT 许可证、最近 Release v1.0.2 和 2026-11-13 UTC 提交。

we-promise/sure

Sure 是面向个人财务的开源应用，README 覆盖预算、现金流、资产负债、自动化规则、AI 助手和本地开发/部署路径。它值得看，不是因为它是一个金融 demo，而是因为它展示了一个完整 Rails 应用如何把数据模型、权限、备份和自托管一起交付，适合想研究真实业务系统的人；限制是 README 明确列出性能问题与部署要求，金融数据接入、备份和生产安全需要自行验证。主要语言为 Ruby，日榜新增 967★；仓库页核验总计 13,960★、AGPL-3.0 许可证、最近 Release v0.7.6-hotfix.1 和 2026-11-12 UTC 提交。

ggml-org/llama.cpp

llama.cpp 是用 C/C++ 实现的 LLM 推理基础设施，README 提供从 Hugging Face 直接下载模型、启动服务和使用 OpenAI 兼容 API 的路径，并列出多种后端。它适合学习本地推理、量化、后端适配和服务化之间的真实取舍，也是构建本地 Agent 的底层材料；限制是模型格式、量化方式和硬件后端会共同决定性能，项目本身不是开箱即用的 Agent 产品。主要语言为 C++，日榜新增 176★；仓库页核验总计 134,584★、MIT 许可证、最近 Release b12340 和 2026-11-12 UTC 提交。
