2026-11-19 GitHub 热榜简报：Agent 工程进入评测与真实应用

GITHUB TRENDING · 2026.11.19

今天的 GitHub all-languages 日榜把注意力集中到 Agent 的工程边界：Claude-BugHunter、SkillEvaluator和 ECC分别从安全、质量和运行方法切入，CLI-Anything、last30days和 PaperOrchestra把模型接到软件、信息和研究流程。另一端，Appwrite、n8n、Arcane、uv、OpenVINO和 江山时序则把这些能力落到云、容器、依赖、推理和可视化。

Agent 评测安全边界Agent-native CLI研究编排工作流自动化本地推理开发环境历史可视化

今日要点

今天最值得观察的变化，是 Agent 项目开始把“会不会生成内容”让位给“能不能被约束、评测和接入既有系统”：Claude-BugHunter把授权安全测试拆成技能与验证门，SkillEvaluator把技能质量、重叠、兼容性和实际效果纳入流水线，ECC则尝试把记忆、安全和研究优先固化为 Agent harness。它们的共同价值不在于星数，而在于把隐含的工程判断变成可以检查的文件、规则和步骤；热度只表示今天有人注意到它们，不是质量证明。

另一条主线是 Agent 正在从聊天界面伸进真实工作面：CLI-Anything把桌面软件包装成可调用 CLI，last30days把多平台信息汇总成研究技能，PaperOrchestra把材料编排成 LaTeX 论文；Appwrite和 n8n则提供应用与自动化的承载面。基础设施侧的 uv、Arcane和 OpenVINO提醒我们：可靠的 Agent 仍然受制于环境、权限、依赖和算力。

值得尝试

elementalsouls/Claude-BugHunter

Claude-BugHunter 是面向 Claude Code 的安全测试 skill bundle，README 列出 83 个 skills、15 个命令、漏洞报告模式、企业身份与基础设施攻击面，以及 Burp MCP 接入。它适合安全研究者学习如何把侦察、验证、证据整理和报告卫生组织成可复用流程；限制是只能用于自有或明确授权的目标，代码与内容还分别受 MIT 和 CC BY 4.0 约束。主要语言为 Python，日榜新增 2,322★，仓库页核验总计 11,416★，最近 2026-11-18 提交，最近 Release 为 v2.1。

HKUDS/CLI-Anything

CLI-Anything 的目标是把图形软件和复杂工具包装成 Agent 可调用的 CLI，并提供 CLI-Hub、预览/轨迹循环和多个软件适配示例。它适合研究“Agent 如何通过稳定命令面操作真实软件”，但生成的 harness 仍需要针对目标软件维护、测试和审查，不能把演示数量当成通用兼容性。主要语言为 Python，日榜新增 384★，仓库页核验总计 59,797★，许可证为 Apache-2.0，最近 Release v0.4.0。

mvanhorn/last30days-skill

last30days-skill 把 Reddit、X、YouTube、Hacker News、Polymarket、GitHub 等来源并行检索，再按互动信号汇总成 Agent 可调用的研究简报。它适合做“最近一个月发生了什么”的信息侦察；限制是不同来源需要各自的 API key 或浏览器会话，外部内容也必须防范提示注入、样本偏差和不可复核的热度判断。主要语言为 Python，日榜新增 1,062★，仓库页核验总计 70,061★，许可证为 MIT，最近 Release v4.3.2。

getarcaneapp/arcane

Arcane 是用 Go 实现的 Docker 管理界面，把镜像、容器和自托管运维集中到可视化控制面；README 明确说明主分支已经是 v3。它适合个人服务器或小团队研究容器运维如何走向可审计的 Web 工作区；限制是升级时要区分 v3 与 2.x 分支，并认真评估宿主机 Docker 权限和数据持久化。主要语言为 Go，日榜新增 547★，仓库页核验总计 9,836★，许可证为 BSD-3-Clause，最近 Release 为 v3.1.0。

NVIDIA/SkillEvaluator

SkillEvaluator 用分层检查评估 Agent skills 和 plugins 的质量、安全、重叠、兼容性及实际效果，README 说明第一层包含 500+ 静态规则，并可接入 CI。它适合已经在维护 skills 的团队建立合并前门禁；限制是更完整的多层评估需要额外系统依赖与模型/构建环境，静态规则也不能替代真实任务中的人工复核。主要语言为 Python，日榜新增 869★，仓库页核验总计 3,750★，许可证为 Apache-2.0，最近 Release 为 v1.0.1。

astral-sh/uv

uv 是 Rust 编写的 Python 项目与包管理器，试图用一个工具覆盖 pip、pip-tools、pipx、poetry、pyenv、virtualenv 等常见工作，并提供 lockfile、workspace、脚本和工具运行。它适合想减少 Python 环境漂移、统一项目与单文件脚本入口的开发者；限制是迁移时仍要核对构建后端、原生依赖和团队现有发布流程，速度指标也不能替代实际项目基准。主要语言为 Rust，日榜新增 260★，仓库页核验总计 92,244★，许可证为 Apache-2.0 / MIT，最近 Release 为 0.13.9。

google-research/paper-orchestra

PaperOrchestra 把想法和实验日志交给多个角色化 Agent，串起提纲、文献综合、章节写作、内容精炼、图表生成和 LaTeX 输出。它适合研究长流程写作怎样被拆成可替换的 Agent 管线；限制是 README 明确要求 Conda、模型和文献 API 配置，数据集不随仓库提供，而且项目不是 Google 官方支持产品。主要语言为 Python，日榜新增 1,529★，仓库页核验总计 4,336★，许可证为 Apache-2.0，最近 2026-11-15 提交。

sveltejs/svelte

Svelte 是编译型前端框架，把声明式组件转换成直接更新 DOM 的 JavaScript，把更多工作从运行时移到编译阶段。它适合用来理解编译时优化、细粒度响应式和组件运行时边界；限制是它本身不是完整后端或部署平台，选型仍要结合 SvelteKit、构建链和团队生态。主要语言为 JavaScript，日榜新增 694★，仓库页核验总计 89,633★，许可证为 MIT，最近 Release 为 svelte@5.58.0。

appwrite/appwrite

Appwrite 是面向 Agent 和开发者的开源云平台，把 Auth、数据库、存储、Functions、Messaging、Realtime、Hosting、WAF 与 MCP 放进同一套产品。它适合研究 Agent 如何操作真实应用资源，也适合希望自托管后端能力的团队；限制是自托管仍需要 Docker、权限和升级运维，MCP 接入更不能绕过项目级授权与审计。主要语言为 TypeScript，日榜新增 239★，仓库页核验总计 58,247★，许可证为 BSD-3-Clause，最近 Release 为 2.7.3。

openvinotoolkit/openvino

OpenVINO 是用于优化和部署深度学习模型的工具包，README 列出 PyTorch、TensorFlow、ONNX、Keras、JAX/Flax 等模型入口，并覆盖 CPU、GPU 和 Intel NPU。它适合在边缘或本地推理场景学习模型转换、设备选择与资源权衡；限制是最佳收益取决于模型算子、目标硬件和后端支持，不能把通用 benchmark 直接外推到自己的模型。主要语言为 C++，日榜新增 18★，仓库页核验总计 11,347★，许可证为 Apache-2.0，最近 2026-11-18 提交。

affaan-m/ECC

ECC 把 skills、instincts、memory、安全检查和 research-first 开发组合成面向 Claude Code、Codex、OpenCode、Cursor 等 harness 的工程化工具箱。它适合对比不同 Agent 的启动约定、持久状态和安全门如何被固化；限制是安装面很大，且 README 要求只从仓库、npm、GitHub App 或官方插件等已验证渠道安装，不能把第三方镜像当作等价来源。主要语言为 JavaScript，日榜新增 1,109★，仓库页核验总计 306,561★，许可证为 MIT，最近 2026-11-17 提交。

DeanChensj/jiangshan-map

江山时序 是从战国到今天的中国历史交互地图，把 2,400 多年、18 个历史时期、领土快照、古城、关隘、事件和诗词路线放进可拖动时间轴。它适合学习大体量历史数据如何被组织成可探索的叙事界面；限制是历史资料、边界口径和可视化选择都需要回到 README 与仓库引用逐项核对，GPL-3.0 也会影响二次分发方式。主要语言为 JavaScript，日榜新增 991★，仓库页核验总计 8,000★，许可证为 GPL-3.0，最近 Release v1.3.0。

n8n-io/n8n

n8n 是可自托管或使用云服务的 AI Agent 与工作流自动化平台，以可视化画布、代码节点、人类审批、可观测性和 1,500+ 集成连接真实系统。它适合把模型调用放进可重试、可审计的业务流程；限制是其许可不是传统宽松开源许可，仓库同时列出 Sustainable Use License 与 Enterprise License，自托管前必须核对功能边界和安全责任。主要语言为 TypeScript，日榜新增 315★，仓库页核验总计 211,119★，最近 2026-11-18 提交。
