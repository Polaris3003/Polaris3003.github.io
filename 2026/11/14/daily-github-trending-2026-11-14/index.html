2026-11-14 GitHub 热榜简报：Agent 的审查、人机协作与可运行基础设施

GITHUB TRENDING · 2026.11.14

今天的 GitHub all-languages 日榜把 Agent 从“会生成文本”推进到“可被审查、可被约束、可在真实环境中执行”：OpenCodeReview 与 Codex Security把 review 和 scan 变成带证据的闭环，Modern Web Guidance 与 Plannotator分别约束知识和人类反馈，Buzz、Tailcat、Chrome DevTools MCP、Veyra则把能力推进到协作、网络、浏览器和 GPU 运行时。Sure提供了一个完整自托管业务应用的参照；stars 只是榜单信号，真正需要看的是许可证、最近活动、权限边界和可复现程度。

代码审查应用安全Agent 反馈人机协作加密网络浏览器调试GPU 视频自托管

今日要点

今天的主线是 Agent 的执行面开始拥有控制面：OpenCodeReview 将审查分成确定性工程与 Agent，Codex Security 把漏洞结果转成验证、修复和复核；Modern Web Guidance 把知识约束提前，Plannotator 把人类判断放回会话。这样的分层比继续堆提示词更能形成可维护路径，但代价是必须明确权限、版本、模型端点、审计日志和失败回滚。

另一条线是把执行放入真实系统：Buzz 以签名事件和 relay 组织人／Agent 协作，Tailcat 从用户态网络组件提炼出无需控制平面的加密通道，Chrome DevTools MCP 让 Agent 进入浏览器调试，Veyra 则把 GPU 视频处理链落到桌面硬件。它们适合做小规模实验或学习架构边界；要进入生产，先验证数据暴露、硬件／驱动兼容、身份模型和运维成本，不要把日增 stars 当成安全性或稳定性的替代指标。

值得尝试

alibaba/open-code-review

OpenCodeReview 是 Alibaba 开源的 AI 代码审查 CLI：把确定性的文件选择、规则匹配、评论定位与 LLM Agent 组合起来，支持 diff review 和整目录 scan。它适合做 CI review、代码质量或 Agent 工具链的人研究“确定性工程 × 动态决策”的边界；限制是需要 Git 2.41+ 和可用模型端点，README 中的 benchmark 不能直接外推到你的仓库。主要语言为 Go，日榜新增 215★；仓库页核验总计 50,661★、Apache-2.0 许可证，最近 2026-11-13 UTC 提交。

GoogleChrome/modern-web-guidance-src

Modern Web Guidance 源仓库把现代 Web API、浏览器兼容、性能与无障碍知识组织成可安装的 Agent skills，CLI 支持 search、retrieve 和 legacy-scan。它适合前端团队或编码 Agent 作者学习如何把平台知识压缩成可检索规则；限制是它是指南与评估源代码，不是 Web 框架，结果仍需结合目标浏览器和真实测试。主要语言为 TypeScript，日榜新增 1,925★；仓库页核验总计 4,903★、Apache-2.0 许可证，最近 2026-11-14 UTC 提交。

openai/codex-security

Codex Security 提供 CLI、TypeScript SDK 和 GitHub Action，覆盖扫描、验证发现、生成补丁、复核修复以及 SARIF、JSON、CSV 导出。它适合安全工程师和要把 Agent 放进 CI 的团队研究“发现—证据—修复—复核”的闭环；限制是需要 Node.js 22.13+（22.x、24.x 或 26.x）和 Python 3.10+，部分请求、云端发现及外部跟踪器需要额外权限。主要语言为 TypeScript，日榜新增 751★；仓库页核验总计 13,157★、Apache-2.0 许可证，最近 2026-11-13 UTC 提交。

we-promise/sure

Sure 是 Maybe Finance 归档后的社区 fork，提供可用 Docker 自托管的个人财务应用，覆盖现金流、资产负债、预算和 AI 助手路径。它适合研究真实 Rails 业务应用如何在社区维护、自托管和多客户端之间折中；限制是 AGPLv3、历史代码库带有数据量较大时的性能问题，生产部署还要自行负责备份、数据源与权限。主要语言为 Ruby，日榜新增 925★；仓库页核验总计 14,777★、AGPL-3.0 许可证，最近 2026-11-13 UTC 提交。

backnotprop/plannotator

Plannotator 是面向 Claude Code、Codex、Copilot CLI 等编码 Agent 的本地浏览器审查层，可以标注计划、规格、HTML、Agent 消息、diff 和 PR，再把反馈送回会话。它适合需要在多 Agent 并行时保留人类决策入口的团队；限制是各宿主通过插件、hooks 或 MCP 接入，代理兼容性、权限边界和本地状态管理仍需逐一配置。主要语言为 TypeScript，日榜新增 108★；仓库页核验总计 10,479★、Apache-2.0 许可证，最近 2026-11-14 UTC 提交。

block/buzz

Buzz 把人、Agent、代码仓库和工作流放进一个自托管 workspace：底层用 Nostr relay 的签名事件记录消息、审批、Git 事件和执行轨迹，并提供 Rust relay、移动端和独立桌面端。它适合研究 Agent 如何从聊天参与到可审计协作，尤其是身份、事件日志和工作流统一；限制是 README 明确把 mobile、workflow approval gates、huddle lifecycle 列为正在接线，很多愿景还不是稳定产品。主要语言为 Rust，日榜新增 97★；仓库页核验总计 37,308★、Apache-2.0 许可证，最近 2026-11-14 UTC 提交。

tailscale/tailcat

Tailcat 将 Tailscale 的用户态网络组件改造成类似 netcat 的加密点对点通道，不依赖 Tailscale control plane，连接元数据通过带外方式交换。它适合学习 WireGuard、NAT traversal、DERP relay 和端口转发的最小实现；限制是浏览器 demo 目前只经 DERP 中继，默认 relay 有限流，真实部署需理解地址分发和中继信任边界。主要语言为 Go，日榜新增 256★；仓库页核验总计 9,476★、BSD-3-Clause 许可证，最近 2026-11-05 UTC 提交。

Likely7/Veyra-NRVideo

Veyra 是面向 Windows 11、DirectX 12 的 C++ 实时 GPU 视频增强工具，覆盖超分、降噪、HDR、帧生成、采集和游戏串流，并提供 NVIDIA／AMD 发行包。它适合有 GPU 或采集卡的开发者研究多阶段图像处理、模型与渲染链路；限制是硬件和驱动强相关，README 说明 AMD 路径仍实验性，分辨率、显存和帧生成效果不能从示例直接外推。主要语言为 C++，日榜新增 256★；仓库页核验总计 1,638★、GPL-3.0 许可证，最近 2026-11-11 UTC 提交。

ChromeDevTools/chrome-devtools-mcp

Chrome DevTools MCP 让编码 Agent 通过 MCP 或 CLI 控制并检查 Chrome，覆盖性能 trace、网络请求、控制台、截图、source map 和 Puppeteer 自动化。它适合做浏览器调试和性能工程的 Agent 化工具链；限制是官方只支持 Chrome／Chrome for Testing，浏览器内容会暴露给 MCP 客户端且 usage statistics 默认开启，需要按场景关闭或评估数据边界。主要语言为 TypeScript，日榜新增 67★；仓库页核验总计 55,478★、Apache-2.0 许可证，最近 2026-11-13 UTC 提交。
