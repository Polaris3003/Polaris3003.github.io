2026-11-23 GitHub 热榜简报：Agent 工具走向可验证的工作面

GITHUB TRENDING · 2026.11.23

今天的 GitHub all-languages 日榜几乎复刻昨日，但项目的工程边界更清楚：Superpowers把编码 Agent 的需求、计划、测试和评审串起来，CLI-Anything把桌面软件转成可调用 CLI，Firecrawl与 last30days处理外部信息入口，OpenSRE处理失败后的 CI 反馈。与此同时，MiniMind、OpenVINO、AFFiNE和 AutoClip把训练、推理、知识工作和媒体交付落到真实系统。

Agent 工作流Agent-native CLI网页知识小模型训练推理部署CI 可靠性Local-first媒体生产

今日要点

今天最值得观察的不是“又有多少个 Agent Demo”，而是 Agent 正在接管更具体的接口：last30days把分散的公共信号收进研究流程，CLI-Anything让既有软件暴露出结构化命令接口，OpenSRE面对失败构建，Claude-BugHunter则把安全测试的范围、证据和授权边界写进技能。真正的工程问题因此变成权限如何收敛、结果如何复核，以及失败后能否留下可审计的中间产物。

另一条线是“生成”正在靠近交付物：diagram-design输出可直接打开的 HTML + SVG，MiniMind把训练链路压缩成可学习的实验，AFFiNE把文档、画布和表格放进 local-first 工作区，Ghost Downloader与 AutoClip则把下载和视频处理做成桌面产品。星标只表示注意力，不是质量证明；下面的判断以仓库 README、API 元数据、许可证和近期提交为准。

值得尝试

elementalsouls/Claude-BugHunter

Claude-BugHunter 是面向 Claude Code 的安全研究技能包，README 将 83 个技能、15 个命令、24 类漏洞模式、企业身份与基础设施攻击矩阵以及 Burp MCP 接入组织成可复用流程。它适合安全工程师研究 Agent 如何在授权范围内工作；限制是内容具有明显双重用途，只能用于自有或明确授权的目标。主要语言为 Python，日榜新增 1,716★，仓库当前为 17,921★，许可证为 MIT，最近提交为 2026-11-22。

obra/superpowers

Superpowers 把需求澄清、设计确认、计划、TDD、子代理执行和代码评审串成 coding agent 的工作方法，重点是让模型动作进入可检查的步骤。它适合希望降低 Agent 随意改动风险的开发者；限制是会改变 harness 的触发方式和权限边界，README 还说明可选视觉伴侣存在遥测设置，安装前应按环境审查。主要语言为 Shell，日榜新增 788★，仓库当前为 324,203★，许可证为 MIT，最近提交为 2026-11-03。

HKUDS/CLI-Anything

CLI-Anything 试图把图形软件和其他已有工具转换成带统一参数、JSON 输出、预览与端到端测试的 Agent-native CLI，并用 CLI-Hub 管理社区适配器。它适合平台工程师研究“模型如何可靠地调用复杂软件”；限制是每个适配器仍依赖目标软件、系统环境和集成质量，演示覆盖面不能等同于所有软件都能稳定自动化。主要语言为 Python，日榜新增 699★，仓库当前为 62,820★，许可证为 Apache-2.0，最近可核验提交为 2026-09-22。

jingyaogong/minimind

MiniMind 用 PyTorch 原生代码覆盖模型结构、Tokenizer、预训练、SFT、LoRA、DPO、RLAIF、Tool Use、Agentic RL 和蒸馏，把“调用模型”还原成可读的训练链路。它适合想从代码和数据理解 LLM 的学习者；限制是 README 中“2 小时、低成本”的结果基于单张 RTX 3090 的特定实验，显存、数据和评测条件都不能直接外推。主要语言为 Python，日榜新增 473★，仓库当前为 68,719★，许可证为 Apache-2.0，最近提交为 2026-11-22。

firecrawl/firecrawl

Firecrawl 把网页抓取、爬取、映射、文档解析和 MCP 接入组合成 Agent 的知识入口：Local 路径可以在本机运行，完整自托管服务则包含队列、Worker 和数据库。它适合做研究助手、RAG 或网页自动化的人；限制是本地路径仍有 Rust、C 编译器和浏览器等环境要求，自托管要承担运维，云端路径还涉及额度与数据边界。主要语言为 TypeScript，日榜新增 915★，仓库当前为 207,083★，许可证为 AGPL-3.0，最近提交为 2026-11-22。

openvinotoolkit/openvino

OpenVINO 面向深度学习模型的转换、优化和部署，README 覆盖 PyTorch、TensorFlow、ONNX、Keras 等框架，并把运行目标扩展到 CPU、Intel GPU 与 Intel NPU。它适合研究推理后端、设备抽象和边缘部署的人；限制是实际收益取决于算子支持、模型结构、精度设置和硬件，支持矩阵不是你的模型性能保证。主要语言为 C++，日榜新增 158★，仓库当前为 12,096★，许可证为 Apache-2.0，最近提交为 2026-11-22。

cathrynlavery/diagram-design

diagram-design 把架构图、时序图、四象限等图形组织成 Agent Skill，目标是让 Agent 生成一个可直接打开的单文件 HTML + SVG，目前 README 列出 51 种图形类型。它适合前端、架构师和文档作者研究“自然语言到可审阅视觉产物”的边界；限制是布局、语义和品牌一致性仍需人工检查，README 的隐私说明也提示技能会发送网络数据。主要语言为 HTML，日榜新增 518★，仓库当前为 70,340★，许可证为 MIT，最近提交为 2026-11-22。

mvanhorn/last30days-skill

last30days-skill 并行搜索 Reddit、X、YouTube、Hacker News、Polymarket 和网页，再按互动信号合成带来源的近 30 天研究简报，并适配多种 Agent Skills 宿主。它适合研究跨平台检索、证据归因和“搜索结果如何被模型压缩”的工程实现；限制是额外来源依赖 API key 或登录会话，互动量代表注意力而不是事实，平台权限和条款也会影响复现。主要语言为 Python，日榜新增 668★，仓库当前为 72,779★，许可证为 MIT，最近提交为 2026-11-23。

mjmirza/app-store-compliance

App Store Compliance 把 Apple App Store 与 Google Play 的常见拒审模式、隐私清单、Data safety 和政策日期整理成 playbook，并提供提交前扫描器。它适合移动端发布流程和 AI coding agent 的门禁设计；限制是 README 明确说明扫描不是批准保证，平台政策会变化，仓库使用自定义的 OpenRoots ORA 2.3 许可，商用前应读原文。主要语言为 Shell，日榜新增 621★，仓库当前为 4,030★，许可证说明见 LICENSE，最近提交为 2026-11-22。

Tracer-Cloud/opensre

OpenSRE 面向 CI/CD 可靠性：读取失败运行、日志和仓库上下文，分析根因，再把修复推到分支供人审阅，并支持自托管模型。它适合平台工程师研究 Agent 如何进入失败后的反馈闭环；限制是 README 当前明确标为 Public Alpha，日志、凭据和自动修复权限要放在组织边界内单独审查。主要语言为 Python，日榜新增 399★，仓库当前为 14,442★，许可证为 Apache-2.0，最近提交为 2026-11-22。

toeverything/AFFiNE

AFFiNE 把文档、白板、表格、知识库和实时协作放进一个 privacy-first、local-first 工作区，并提供 Docker 自托管路径。它适合研究富文本、画布、数据库和数据拥有权如何共存；限制是仓库默认分支为 canary，README 说明 Community Edition 可按 MIT 自托管，但具体目录和其他 edition 仍应回到许可证原文确认。主要语言为 TypeScript，日榜新增 542★，仓库当前为 76,856★，许可证见 LICENSE，最近提交为 2026-11-22。

XiaoYouChR/Ghost-Downloader-3

Ghost Downloader 3 是跨平台下载器，把多种下载协议、浏览器扩展、桌面端和 aria2 兼容 RPC 组合到一个工具中，README 列出 Windows、macOS、Linux、Android 四个平台。它适合学习 Python/Qt 桌面应用如何组织多协议任务与跨平台交付；限制是 GPL-3.0 会影响分发方式，Qt 6.6+ 不再支持没有 AVX 指令集的 CPU，下载内容也必须遵守版权与站点条款。主要语言为 Python，日榜新增 701★，仓库当前为 15,211★，许可证为 GPL-3.0，最近提交为 2026-11-22。

zhouxiaoka/autoclip

AutoClip 把长视频链接转成短视频、字幕、封面和发布文案，提供桌面端、CLI 与 MCP，并允许用户在编辑器里修正自动剪辑结果。它适合研究模型选择、媒体处理和人工校正如何组成内容工作流；限制是云端分析会发送字幕、音频或抽样画面并产生用量成本，本地与云端路径的隐私边界需要先看 README 的说明。主要语言为 Python，日榜新增 641★，仓库当前为 13,504★，许可证为 MIT，最近提交为 2026-11-23。
