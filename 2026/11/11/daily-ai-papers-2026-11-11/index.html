Safeguarding Agentic AI in Radiology Workflows: A Multimodel Evaluation of Rule-based and Large Language Model-based Verification（arXiv:2611.11541）

全文状态与问题。 已核阅公开 PDF。研究在智能体即将写入放射科工作记录前加一道动作检查，能否减少错误记录。实验由放射科医师审阅 48 个合成德语病例场景，覆盖检查结果沟通、肿瘤委员会准备和随访管理；43 个场景另有误导信息版本，共 91 个变体。六个智能体模型分别在仅有权限控制、加入确定性规则、再加入本地 LLM 检查器三种设置下完成任务，共 1,638 次运行。主要基线是同一环境下逐步增加的两层保护。

作者报告的关键结果。 仅有权限控制时，跨模型至少出现一次高严重度违规的比例为 19.4%；加入规则后为 16.7%，差值 −2.8 个百分点，95% 区间为 −6.1 至 0.5，不能排除零；再加入 LLM 检查器后为 13.2%，相对仅权限控制低 6.2 点，95% 区间为 −9.5 至 −3.0。检查器相对规则单独使用又降低 3.5 点，区间为 −6.3 至 −0.7。作者未检测到任务成功率下降。误导信息变体中，智能体在 83% 的运行里打开了被修改的文件；错误陈述有 58% 引用了该文件。64%–68% 的拦截本来不会造成违规，说明增加保护也会带来不必要的返工。

创新、基线与证据边界。 检查发生在每次状态改变动作执行之前，确定性规则检查来源、版本和记录状态，再由本地 Gemma 检查确定性规则未覆盖的语气、时序和矛盾。相比只测最终答案正确率，这一设计直接检查写入病历的具体行动。结果仍是合成文本环境的风险率，不是临床发生率或临床获益；只有 48 个独立基础场景，跨模型汇总属探索性分析。研究不含影像理解，也未测真实患者数据；误导内容没有恶意指令，因此不代表对提示注入攻击的防护。四位量化/专有模型的版本可复现性不一，论文也未直接审计模型训练污染；场景加入 canary 只能帮助发现公开样本泄漏，不能证明模型未见过相似内容。

适合谁读。 医疗智能体、工具权限、临床 AI 安全和工作流评估团队。建议读 Materials and Methods 的场景与动作门控设计、Results 中三种保护层的比较，以及 Limitations。代码、评估器和逐次结果：作者仓库。

Tail-risk-aware Agent Safety: Constraining Tail Risks Across Multi-step LLM Agent Workflows（arXiv:2611.10411）

全文状态与研究问题。 已核阅 arXiv HTML 全文。论文关注多步工具调用中风险如何从早期步骤传到后续动作；逐步设置相互独立的规则检查，可能漏掉小概率但高代价的累积失败。作者提出 TAS：把智能体工作流表示为安全状态序列，用 MDP 描述状态转移，以谱风险度量罕见严重风险，并把一个共同风险预算分配到各步骤，得到逐步安全策略。实验在三个基准上比较 11 种既有基线和消融设置。

作者报告的结果与比较。 在 Llama-3 70B 的直接提示注入测试中，TAS 的攻击成功率为 43.50%；移除尾部风险度量的消融为 69.75%。间接提示注入下相应数值为 13.95% 与 22.25%。数值表明该组件在作者的攻击设置中降低了失败率，但这只是基准内结果，不能据此说线上智能体风险已被控制。论文另比较移除 MDP、安全预算、采样估计等组件，以检验整套方法中各部分的作用。

创新、局限与资源成本。 它将“平均风险低”与“严重尾部风险受控”分开处理，并显式考虑依赖步骤。风险分数仍由规则和 LLM 评估器估计，评估偏差会造成误拒或漏检；作者也指出更严格约束和更大采样量可能降低正常任务效用并增加延迟、计算成本。跨三个基准的优势不等同于真实工具环境中的安全保证，论文未提供统一硬件下相对所有基线的成本账本。

适合谁读。 智能体安全、工作流风险预算和红队评估研究者。建议读第 3 节状态建模与尾风险约束、第 4.2 节整体结果、附录 B.4 计算开销及附录 D.2 局限。

MetaPI: Constructing Prompt Injection Benchmarks from LLM Agent Benchmark（arXiv:2611.10026）

全文状态与研究问题。 已核阅公开 PDF。MetaPI 把已有智能体任务基准转换成间接提示注入测试：自动寻找可注入位置、生成攻击目标、优化自适应载荷，再在原任务环境里执行验证。作者应用于 AppWorld、VitaBench、Terminal-Bench 三个文本工具智能体基准，并比较攻击成功率、干净任务效用和 token 开销。合格攻击集由每个基准 50 个任务生成，经筛选后共有 183 个攻击。

关键结果与公平性。 在 AppWorld 公共任务子集、以 DeepSeek-V4-Flash 为被测模型时，无防御的攻击成功率为 50.0%、干净任务效用为 82.5%；Spotlighting 将成功率降至 25.0%，同时效用为 80.4%，token 用量为基线的 1.09 倍。其他防御在不同任务环境中的表现并不一致；作者的总体结论是，没有被测方法能在真实任务和自适应攻击下同时做到强安全与强效用。比较在共同任务子集上进行，但部分防御需要不同模型底座、与特定模拟器不兼容，Terminal-Bench 也有显存不足的运行，因此不能把每一行都视作完全同条件比较。

创新与证据限制。 贡献在于把攻击面放回具有真实工具、状态和任务完成标准的环境，避免只测静态攻击字符串。基准仍只有三个文本环境，不能代表多模态或所有智能体部署；183 个攻击经过生成和质量过滤，依赖其攻击目标与注入位置设计。论文计划公开工具链、基准包、提示和实验配置，基础基准通过固定提交获取。建议安全团队关注任务生态覆盖，而非只追单一攻击成功率。

适合谁读。 智能体安全、提示注入防护和基准构建团队。建议读第 3 节 MetaPI 流水线、第 4.1–4.2 节设置与结果，以及附录 B–D 的模块、环境和防御适配说明。代码与实验配置：MetaPI 仓库。

Scaling Adaptive Prompt Injection Attacks with Agent Swarms（arXiv:2611.11861）

全文状态与问题。 已核阅公开 PDF。论文研究多个自动攻击智能体能否通过反复观察目标模型反馈，找到人类静态红队或已有提示注入基准漏掉的载荷。作者构造合成任务：攻击目标是与用户原始任务无关、但本身无害的工具调用，以便测量模型是否遵守指令层级，而不是仅测它是否识别恶意内容。攻击者使用协作式智能体群、策略库和自适应搜索；与单次/较弱的攻击方法及多种防御模型比较。

关键结果与指标解释。 主指标 ARR@k 是经过 k 次自适应尝试后仍未被攻破的场景比例，越高代表防御越强。面对最强的 Gemini 4 Argon 攻击者，Gemini 4 Argon 防御者在 150 次查询内仍抵抗 87% 场景，但在最大查询预算下只抵抗 66%；其他被测模型的抗性更低。作为公开基线，在 AgentDojo 的 80 个场景上，Prompt Siren 的 mini-goat 攻击成功 2 个，论文的自适应优化攻击在 25 次查询内成功 6 个。该结果说明自动化搜索提高了攻击能力，不代表真实系统一定会以同样比例失败。

创新、局限与适合读者。 将无害的无关动作也计作攻击目标，有助于把“跟从被检索内容”与“知道网络安全术语”区分开。其成功率依赖合成攻击目标、可查询次数、模型版本和攻击者能力；论文没有证明攻击造成真实资金或数据损失，也未给出广泛线上防御的独立复现。适合做智能体红队、指令层级和自动化攻防的团队。建议读第 3 节评测定义、第 4 节攻击者设计、第 5.2–5.3 节结果与 AgentDojo 对比。

WorkflowArena: Benchmarking Executable Workflow Orchestration in LLM-Based Multi-Agent Systems（arXiv:2611.12856）

全文状态与研究问题。 已核阅 arXiv HTML 全文。PDF 文件体积较大，本条的实验、资源使用和局限依据 HTML 全文。论文把“智能体如何组织工作、创建 worker、分配上下文、整合并核验结果”作为独立能力，而不是预先固定多智能体结构。WorkflowArena 包含 145 个长程任务，跨 8 个专业领域和 17 类任务形式；每题给初始工作区与相互依赖的交付物，以隐藏的领域验收器评分，并记录所有委派流程。实验比较九个模型在不同 agent harness 和推理预算下的表现。

关键结果、基线与成本。 最强配置 Claude Opus 5.5 + Claude Code + max effort，在所有领域平均只有 36.95% 的任务满足全部验收条件；数学任务最高为 95.83%，法律领域最高不超过 9.09%，金融领域不超过 18.75%，没有一个配置在所有领域领先。高 effort 下，Claude Code 的 Opus/Sonnet 平均每题发起 0.86/0.76 次 workflow，每个 workflow 调用 5.55/6.14 个 worker；Codex 的 Astra/Sol 每题发起 2.09/1.94 次，每次只调用约 1.72/1.69 个 worker。资源比较也显示推理成本差异：Opus high 以每题估算 6.66 美元完成率 34.11%，Astra xhigh 每题 29.26 美元、完成率 30.80%。

创新、局限与失败条件。 任务完成率与工作流结构同时记录，能分辨“会安排工作”与“能完成任务”。但每个配置每题只跑一次，近似成绩之间没有方差估计；Claude 与 GPT 分别使用不同 harness，模型和执行框架效果无法完全拆开。部分内容与 3D 交付由 LLM 判分，尚未报告与人工评分的一致性；迁移实验只覆盖一个子集，而且工作流说明本身可能向 worker 传递任务知识。因此结果说明系统配置依赖领域与预算，不是单纯的模型能力榜单。

适合谁读。 多智能体编排、agent harness、长任务评测和推理成本管理团队。建议读第 3 节任务/验收设计、第 4.2–4.3 节完成率与资源成本、第 4.6 节工作流迁移及 Limitations。项目主页：WorkflowArena。

FinCutBench: A Continually Updated Benchmark for Measuring the Temporal Boundaries of LLM Financial Knowledge（arXiv:2611.11588）

全文状态与研究问题。 已核阅公开 PDF。量化回测可以限制外部输入的日期，但模型参数可能记得当时尚未公开的财务事实，形成参数记忆导致的前视偏差。FinCutBench 每月更新，当前包含 9,000 道中英双语四选一问题，覆盖 2023 年 1 月至 2026 年 9 月的中美市场和四类金融信息。作者按事实可验证的公开月份生成固定模型的月度知识曲线；通过下降检验和分段拟合估计知识开始衰退的时间点，并用重抽样报告日期稳定性。

作者报告的结果。 下游检验将独立估计的 Boundary 用作时间分组参照。美国资产排序的四模型平均相对 IC 在 Boundary 后下降 0.331，单侧 p=0.0049；中国市场下降 0.051，p=0.2482，未达到常用显著性水平。季度财报回忆中，Sol 命中率由 87.33% 降至 31.33%，Luna 由 51.67% 降至 25.33%；但按披露期配对的八项预测误差比较，未经多重校正的 p 值均大于 0.10。因而较强证据集中在美国资产排序和部分模型的财报回忆，不能概括成所有市场和预测任务都被显著污染。

创新、限制与适用价值。 它尝试用可观测的参数知识时间边界，为 point-in-time 评测和回测窗口选择提供经验标尺。IC 变化不等于策略收益，研究没有证明任何交易收益或经济显著性。题目允许猜测；事实首次公开时间难完全核实；模型可能通过选项推断答案；Boundary 可能仍高于随机水平，且单个事实的知识可能继续存在。数据生成使用 LLM，人工仅审查抽样题目，训练集污染也不能仅靠 Boundary 估计完全排除。

适合谁读。 金融大模型评测、量化回测审计、数据污染与时间序列评估团队。建议读第 5 节 Boundary 的估计、第 7.4 节市场/任务结果和第 9 节限制。项目代码与数据说明：FinCutBench 仓库。
