Risk-Sensitive Reinforcement Learning for an Options Market Maker: An Empirical Study with Real S&P 500 Options（arXiv:2611.10956）

全文状态与研究问题。 已核阅公开 PDF。作者检验风险敏感强化学习对冲策略是否因训练于历史真实市场路径，而比在理想化模拟市场训练更能控制期权做市商的尾部损失。实验以 S&P 500 指数和期权数据重放市场，1996–2017 年训练，2018–2023 年留出测试；使用分布式 TD3，并在相同组合机制、客户期权随机到达、成本与测试期条件下比较传统 delta hedge、训练期选出的 hedge-ratio 规则、GBM、SABR 和 Black–Scholes 混合训练环境。

作者报告的结果与显著性。 测试期 CVaR95 为 −77.7，delta hedge 为 −80.2，作者称尾部损失约降低 3.1%；跨 1,386 个窗口起点的聚类 bootstrap 给出 CVaR95 改善 1.1–3.8 点的 95% 区间。下跌且波动较高的情形改善 8.9%，但上涨市场的风险结果反而恶化 7%–10%。这些是对同一历史测试路径的回放/模拟指标；区间反映窗口起点抽样，不等于跨多个独立市场周期都有效。论文没有报告可实现净利润或实盘成交结果，CVaR 改善也不能直接称为经济收益。

创新、基线公平性与失效条件。 多种训练环境共享相同投资组合结构和测试期，较有针对性地隔离训练市场数据来源的影响；作者还发现经验数据训练学到的状态依赖性短 delta 暴露，在 GBM 训练下消失。主要限制是只有一个 2018–2023 样本外历史区间，优势随市场方向反转；模型中的成交成本与随机到达仍是回放环境设定，不等于真实市场冲击、容量或执行风险。

适合谁读。 期权做市、风险敏感强化学习、市场微观结构和金融回放环境研究者。建议读数据与环境设计、CVaR95 主表、训练环境比较和限制部分，特别留意上涨市场反转结果。

Diversification Across Predictors: Heterogeneous Ensemble Learning for Cross-Sectional Return Prediction（arXiv:2611.12389）

全文状态与研究问题。 已核阅公开 PDF。论文把组合分散思想用于预测器：线性模型容易欠拟合，神经网络容易拟合噪声；如果两类模型的误差协方差较低，异质集成可能比只增加同类模型更有效。方法将线性与非线性预测器通过 bagging 组合，并用偏差—方差—协方差分解解释误差抵消。实证在 CSI 300 日频 Alpha158 因子上，测试期为 2017–2020 年，对照线性回归、MLP、随机森林、Double Ensemble、LightGBM 与 XGBoost。

作者报告的关键结果。 10 次运行中，DEE 的 RankIC 为 0.060±0.001，XGBoost 为 0.059±0.001，LightGBM 为 0.058±0.000，Double Ensemble 为 0.056±0.001，MLP 为 0.053±0.001；作者报告相对单一 MLP 提升 13.2%，相对最强集成基线 Double Ensemble 提升 7.1%。作者还做 top-50 等权组合的历史测试期表现比较。RankIC 提升是预测排序统计，不是因果效应或可交易收益；文中报告的运行间标准差也不是跨年份、跨市场的稳健置信区间。

创新、限制与比较口径。 论文用同一特征集比较不同函数族，并通过同类集成消融支持“异质性有价值”的解释。测试集中于单一指数及 2017–2020 四年，市场制度变化、现实交易摩擦、冲击成本和策略容量未系统检验；预测组合的历史回报不能替代扣费、可执行的实盘结果。论文称已被 ICAIF 2026 接收。

适合谁读。 横截面收益预测、因子模型、机器学习集成与量化研究者。建议读第 3 节误差分解、第 6.2 节测试集结果、第 6.3 节异质性消融及第 7 节局限。arXiv 与会议 DOI：arXiv DOI · 会议 DOI。

DeepFinance: Can AI Diligence a $100MM Deal?（arXiv:2611.10926）

全文状态与研究问题。 已核阅 arXiv HTML 全文；本轮 PDF 未能取回。论文指出传统金融问答主要测文档检索和单个数字，而私募股权/投行尽调还要在冲突资料中选证据、设定假设、串联长流程并留下可审计轨迹。DeepFinance 将这些要求做成 21 个端到端任务：每项任务平均需专业人员 27.1 小时，数据室平均 19 个文件，平均按 84 条专家编写的输出、流程和判断标准评分。作者比较 12 家实验室的 22 个模型配置，各自使用原生 agent harness，每题多次运行。

作者报告的结果与比较。 最佳配置 GPT-6 Astra max 满足 57.6% 的 rubric 标准，95% bootstrap 区间为 49.5%–66.2%；Claude Opus 5.5、Claude Sonnet 5.5 和 GPT-6.1 Sol 分别为 54.8%、54.6% 和 54.3%，四者统计上不可区分。GPT-6 Astra 平均每任务 API 成本为 6.73 美元；GPT-6.1 Sol 为 54.3%，成本 1.17 美元。即使在复杂金融流程上，得分仍不到六成，模型也可能从错误输入算出正确形式的数字，或找到关键证据后没有用到它。

创新、公平性与证据边界。 以最终交付、引用证据和工作轨迹共同评分，比只核对最后一个估值数字更接近专业工作审阅。不同模型使用各自原生 harness，模型、推理预算与工具链并非完全受控；榜首多为闭源模型，任务由论文作者团队构建，公开资料提供 leaderboard 和示例任务，但全文未给可独立重建完整任务集的代码链接。榜单分数和 API 费用不代表实际尽调生产率、投资回报或人工替代率。

适合谁读。 金融文档智能体、投行/私募工作流、长时程任务评测和 AI 采购评估团队。建议读第 4 节任务构造与评分、第 5.1 节定量结果、第 5.2 节失败案例及第 6 节结论。论文提供样例任务与 leaderboard。

JUBILEE: A Benchmark Environment for Off-Policy Evaluation in Debt Collections（arXiv:2611.10972）

全文状态与研究问题。 已核阅 arXiv HTML 全文。债务催收策略通常只能用既有策略留下的日志评估新策略，而未记录的困难程度可能同时影响催收动作与回收结果，造成观察性偏差。JUBILEE 用催收模拟器生成百万贷款面板，包含竞争风险、稀少回收和隐藏的动作分配因素；以独立策略模拟得到参考值，比较表格法与梯度提升估计器。实验包括两种结果机制下的 80 次比较和 190 组参数网格，同时分别评估合成奖励分数与模拟现金。

关键结果与方法边界。 隐藏混杂存在时，多个表格估计器彼此接近，却会低估现场拜访策略的价值；双重稳健区间在无隐藏分配依赖的控制中较常覆盖参考值，在隐藏依赖下多数漏掉参考值。165 次参数网格决策中，交叉拟合 DR 选对策略 106 次（64.2%），平均遗憾为每次决策 4.79 美元；同表的 context-blind DM 选对 145 次（87.9%），但这并不证明它在其他分配机制下更好。排序还取决于目标定义：现场拜访按奖励分数排名最后，按不含渠道成本的模拟现金排名第一；在现金目标下，带隐藏分配依赖的日志估计常错过最佳策略。

创新与局限。 该基准的价值在于知道模拟真值后，能直接研究估计误差、区间覆盖和策略选择错误，而不是用估计器间一致性假定准确。所有结果都是指定机制下的合成实验，不是银行真实催收样本，也没有经过随机政策试验；模拟参数并未校准到具体金融机构，现金还排除渠道成本。结论只能说明何种混杂条件会让 OPE 失败，不能指导真实借款人策略。

适合谁读。 离线策略评估、信用决策、催收公平性与因果机器学习研究者。建议读第 3 节模拟环境、第 4 节估计协议、第 5.2–5.8 节混杂和目标函数结果、第 6 节局限。代码与可复现实验数据：JUBILEE 仓库 · Zenodo 数据。

Track or Follow? A Jev-Compatible Multi-Agent Trading System When Web News Lags the Market（arXiv:2611.10414）

全文状态与研究问题。 已核阅公开 PDF。论文区分模型是在识别新闻所报事件对应的价格反应，还是新闻发布较晚、模型只是在“跟随”已经发生的价格变动。作者将问题嵌入多智能体交易系统：使用点时数据存储、固定 LLM 的事件选项概率和 Jev 托管决策接口，并用代码限制文本信号最多能改变多少仓位。研究在解锁结果前哈希锁定问题集、提示、模型版本、攻击模板和分析代码；比较新闻判断与公告窗口异常回报，并以 code-only 特征作为增量信息基线。

作者报告的结果与因果/收益边界。 确认性测试中，模型判断与公告窗口异常回报的周度 Spearman 相关为 0.119，95% 区间 0.098–0.140；财报事件类型与公司 8-K 分类的 AUC 为 0.833。然而这是新闻判断和价格反应的相关性，不表示模型导致价格变化或能赚到这段回报。探索性分析显示 2,709 条相关财报新闻中 72% 晚于公司文件申报，新闻发布后至下个交易日收盘的相关只有 0.023（区间 0.005–0.041）。在周频确认性检验中，模型判断相对 code-only 特征没有增量排名信息，估计值 −0.016（区间 −0.029 至 −0.002）。论文没有给出策略净收益；相关性不能转写为可交易超额收益。

创新、基线公平性与局限。 预注册、按新闻发布时间切分和独立发布时钟检查，有助于识别模型是否从事件后的文章读取已发生价格变化。文中还发现不少文章在事件后发布，因而只按事件日期评分会把后见信息误当预测。材料包括许可新闻交给托管模型处理，文章全文未公开；读者难以完全重放文本输入。Jev 接口和固定模型配置也是系统组成部分，证据不能直接外推到其他模型、交易周期或真实成交。

适合谁读。 新闻因子、点时数据库、事件研究和 LLM 交易系统审计团队。建议读第 2 节问题形式、第 3 节预注册和数据、第 4.2–4.3 节发布前后结果及第 5 节周频增量检验。代码、提示、模型固定版本和预注册：作者仓库。

Objective Diversification of Dynamic Hedging（arXiv:2611.10333）

全文状态与研究问题。 已核阅公开 PDF。传统动态对冲通常直接根据最终风险偏好估计 hedge ratio；本文研究其他损失目标下估出的 hedge ratio 是否也包含有用信号。作者从同一历史股票—市场收益数据建立五种滚动估计器：最小方差、绝对偏差、下行半方差、下尾分位和 Expected Shortfall；再以固定最终目标比较等权、硬选择以及用 ExtraTrees 按形成日信息自适应加权。基线为同一目标的滚动 hedge ratio，预设 60、90、120、180 日四种窗口。

作者报告的结果与统计边界。 自适应加权在 16 个目标—窗口组合中都降低对应损失；例如 60 日下行半方差的目标损失改善 2.01%，Q10 分位损失改善 0.98%，而 MSE 和 LAD 分别只改善 0.27% 和 0.22%。自适应方法在各组合中有 63.4%–96.0% 的个股优于对应滚动基线。等权组合在下行和分位目标下已能取得大部分改善，说明多目标估计的互补性可能比复杂状态模型本身更关键。

证据限制与交易含义。 作者明确将差异描述为样本外表现比较，但未报告能处理时间序列和横截面依赖的统计置信区间；该设计不识别每个形成日预测变量的因果贡献。摘要/全文指标是对冲损失而非投资组合净收益，也未证明计入冲击、价差和调仓限制后仍有经济显著性。预设窗口是稳健性设置，不是从市场中选出的最优窗口。

适合谁读。 风险对冲、风险度量、机器学习组合和模型选择研究者。建议读第 3 节五种目标与组合方式、第 5 节目标匹配结果、第 6 节局限。
