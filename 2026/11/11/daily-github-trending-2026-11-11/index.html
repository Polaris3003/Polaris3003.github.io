2026-11-11 GitHub 热榜简报：Agent 的技能、浏览器与可执行系统

GITHUB TRENDING · 2026.11.11

今天的 GitHub all-languages 日榜把注意力集中到 Agent 的可执行边界：技能目录负责复用行为，浏览器 CLI和 HA-MCP负责连接真实系统，Astryx则把 UI、文档和 Agent 参考放进同一套设计系统。日增 stars 只是注意力的时间切片，不是质量证明。

今日要点

今天最清晰的主线，是 Agent 正从“会生成文本”转向“有可复用的行为接口”：Anthropic Skills用 SKILL.md、脚本和资源组织能力，addyosmani/agent-skills则把需求、计划、实现、测试、评审和发布拆成工程生命周期。两者的学习价值分别在格式与方法，不能把技能数量直接当成可靠性。

另一条线是进入真实执行环境：agent-browser把浏览器状态压成 accessibility tree 和 refs，HA-MCP把家庭设备控制暴露成 MCP 工具，Astryx则尝试让人和 Agent 使用同一套组件、CLI 与文档。与此同时，Topcoat和 MuJoCo提醒我们，真正耐用的能力仍然落在运行时、仿真、数据和边界条件上。

值得尝试

meta/astryx

Astryx是基于 React 19 和 StyleX 的开源设计系统，README 介绍它提供 150+ 可访问组件、主题、模板、CLI、文档与 sandbox，并让人和 AI 助手使用同一套 API 与参考资料。它适合前端团队研究“Agent-ready UI”如何落实到组件命名、可组合实现和文档；限制是项目仍处于 Beta，要求 React 19+，部分图表包只有 canary 发布。日榜快照显示主要语言 TypeScript、当日新增 3,108★；仓库页核验总计 23,005★、采用 MIT 许可证，最近 Release 为 v0.7.13，最近提交为 2026-11-11 UTC 的 0a1e23e。

anthropics/skills

Anthropic Skills把指令、脚本和资源放进带有 SKILL.md 的自包含目录，并提供开发、文档、设计和企业工作流示例，同时附带 Agent Skills 规范。它适合学习如何把 Agent 行为、元数据和可重复流程编码进仓库；限制是 README 明确称其为演示与教育实现，关键任务仍需自行测试，且根仓库没有统一可由 API 识别的许可证——README 只说明多数 skills 为 Apache-2.0，第三方声明见 THIRD_PARTY_NOTICES.md。日榜快照显示主要语言 Python、当日新增 1,679★；仓库页核验总计 192,385★，最近提交为 2026-11-06 UTC 的 2c5958e，未发现公开 Release。

addyosmani/agent-skills

Agent Skills把工程工作拆成 /spec、/plan、/build、/test、/review、/ship 等命令，目标是让编码 Agent 遵循定义、实现、验证和发布的质量门。它适合想把团队工程纪律沉淀成可安装工作流的人；限制是 README 记录了单 skill 安装可能漏掉仓库级 references/ 检查清单的可移植性问题，不能因此省略真实测试和评审。日榜快照显示主要语言 JavaScript、当日新增 465★；仓库页核验总计 115,212★、采用 MIT 许可证，最近 Release 为 0.6.15，最近提交为 2026-11-01 UTC 的 301b02b。

google-deepmind/mujoco

MuJoCo是面向机器人、生物力学、图形学和机器学习的通用物理引擎，提供 C API、原生与浏览器可视化，以及 Python bindings 和 Unity 插件。它适合研究关节结构、控制器和环境交互的高速仿真；限制是 WebAssembly 版本慢于原生 C，README 也提醒直接跟踪 main 可能不稳定，实验结果仍需自行验证模型与数值稳定性。日榜快照显示主要语言 C++、当日新增 456★；仓库页核验总计 17,391★、采用 Apache-2.0 许可证，最近 Release 为 4.0.0，最近提交为 2026-11-10 UTC 的 01ca66c。

we-promise/sure

Sure是 Maybe Finance 的社区维护 fork，提供可用的个人财务管理应用，可通过 Docker 自托管，并从浏览器、macOS、移动端、API 客户端和 LLM Agent 访问。它适合想研究自托管财务产品、跨端客户端和 AI 辅助理财界面的人；限制是上游 Maybe 已归档，项目明确仍有数据量较大时的性能问题，开发环境还需要 Ruby、PostgreSQL 与 Redis。日榜快照显示主要语言 Ruby、当日新增 159★；仓库页核验总计 12,014★、采用 AGPLv3 许可证，最近 Release 为 v0.7.6，最近提交为 2026-11-11 UTC 的 e71564a。

homeassistant-ai/ha-mcp

HA-MCP把 Home Assistant 的设备和自动化能力接入 Claude、ChatGPT 等 AI 助手，README 当前标注 87 个工具，并推荐在 Home Assistant 2026.11+ 通过 Marketplace 或 HACS 安装进程内集成。它适合研究 MCP 如何落到真实家庭设备和权限边界；限制是初始配置需要管理员令牌或专用管理员账户，远程连接要明确选择 webhook/认证方式，文件与 YAML 编辑工具也默认关闭并且应单独评估风险。日榜快照显示主要语言 Python、当日新增 790★；仓库页核验总计 6,701★、采用 MIT 许可证，最近 Release 为 v9.1.2，最近提交为 2026-11-11 UTC 的 fabdea6。

vercel-labs/agent-browser

agent-browser是 Rust 编写的原生浏览器自动化 CLI，用 snapshot 把页面读取成紧凑的 accessibility tree，并给元素分配 refs，让 Agent 逐步执行 open、click、fill 和 get 等命令。它适合研究可读状态、动作闭环和持久会话；限制是首次需要下载 Chrome for Testing，页面导航或 DOM 变化后旧 refs 必须重新 snapshot，认证、域名白名单和动作策略仍由使用者负责。日榜快照显示主要语言 Rust、当日新增 780★；仓库页核验总计 49,260★、采用 Apache-2.0 许可证，最近 Release 为 v0.42.0，最近提交为 2026-11-10 UTC 的 d129226。

tokio-rs/topcoat

Topcoat是模块化的 Rust 全栈框架：服务端渲染 HTML，$(...) 表达式在服务端首屏执行并转换为浏览器端 JavaScript，还提供 view! 模板、模块化路由、可编辑 UI 组件、资源打包和 Tailwind 集成。它适合 Rust 开发者研究如何在不引入 wasm 客户端包的情况下实现类型安全的全栈交互；限制是项目明确处于 early-stage、experimental 状态，预计会有 breaking changes，不应直接当作稳定生产框架。日榜快照显示主要语言 Rust、当日新增 192★；仓库页核验总计 6,853★、采用 MIT 许可证，最近 Release 为 v0.12.1，最近提交为 2026-11-10 UTC 的 61a939a。
