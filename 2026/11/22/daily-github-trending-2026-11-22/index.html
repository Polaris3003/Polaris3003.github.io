2026-11-22 GitHub 热榜简报：Agent 进入输入、执行与验收

GITHUB TRENDING · 2026.11.22

今天的 GitHub all-languages 日榜仍然被 Agent 工具占据，但重点已经从“会不会调用模型”转向“能不能进入真实边界”：Claude-BugHunter把安全研究流程写成技能，CLI-Anything把桌面软件包装成 Agent 可调用的 CLI，Firecrawl和 last30days-skill处理外部信息入口，OpenSRE则把 Agent 放进失败构建后的调查与修复。另一端，OpenVINO、AFFiNE和 AutoClip分别把模型、知识工作和媒体产物推向可部署的系统。

Agent 安全可调用 CLI网页知识CI 可靠性模型训练推理部署Local-first媒体生产

今日要点

今天最值得看的不是日榜新增星标，而是 Agent 开始被放进输入、执行和验收三个边界：Firecrawl负责把网页和数据源变成可处理内容，CLI-Anything负责让已有软件暴露出更稳定的命令接口，OpenSRE负责面对失败构建，Claude-BugHunter则把范围、证据和报告约束写进安全流程。真正的工程问题因此变成权限如何收敛、结果如何复核，以及失败后能否留下可审计的中间产物。

另一条线是“生成”正在靠近交付物：diagram-design生成可直接打开的 HTML + SVG，MiniMind把训练链路压缩成可学习的实验，AFFiNE把文档、画布和表格放进 local-first 工作区，Ghost Downloader与 AutoClip则把下载和视频处理做成桌面产品。星标只说明注意力；以下项目的价值判断基于 README、代码入口、许可证和近期活动，不能把热度直接当成质量证明。

值得尝试

elementalsouls/Claude-BugHunter

Claude-BugHunter 是面向授权漏洞赏金与外部红队的 Claude Code 技能包，README 将侦察、漏洞模式、企业边界、范围确认、证据卫生和报告组织成一套可复用流程。它适合安全工程师研究“如何让 Agent 在范围内工作”，限制是内容具有明显双重用途，只能对自有或明确授权的目标使用；代码与内容还分别涉及 MIT 和 CC BY 4.0。主要语言为 Python，日榜新增 1,832★，仓库当前为 16,131★，最近提交为 2026-11-21，最近 Release 为 v2.1（2026-06-05）。

obra/superpowers

Superpowers 把需求澄清、设计确认、计划、TDD、子代理执行和代码评审串成 coding agent 的工作方法，而不是只增加几个提示词。它适合希望把 Agent 的自主动作变成可检查步骤的开发者；限制是它会改变 harness 的触发方式和权限边界，README 还单独说明了可选视觉伴侣的遥测设置，安装前应按环境审查。主要语言为 Shell，日榜新增 883★，仓库当前为 323,762★，许可证为 MIT，最近 Release 为 v7.0.2（2026-11-03）。

HKUDS/CLI-Anything

CLI-Anything 试图把图形软件和其他已有工具转换成带统一参数、JSON 输出、预览和端到端测试的 Agent-native CLI，并配套 CLI-Hub 管理社区构建的适配器。它适合平台工程师研究“模型如何可靠地调用复杂软件”，限制是每个适配器仍依赖目标软件、系统环境和具体集成质量，不能把演示覆盖面当成所有软件都能稳定自动化。主要语言为 Python，日榜新增 769★，仓库当前为 62,103★，许可证为 Apache-2.0，最近可核验提交为 2026-09-22，最近 Release 为 v0.4.0（2026-06-25）。

jingyaogong/minimind

MiniMind 用 PyTorch 原生代码覆盖小型语言模型的结构、Tokenizer、预训练、SFT、LoRA、DPO、强化学习、Tool Use 和 Agentic RL，把“调用模型”还原成可读的训练链路。它适合想从代码和数据理解 LLM 的学习者；限制是 README 中“2 小时、低成本”的结果取决于硬件、数据和训练配置，复现时应重新记录显存、吞吐和评测条件。主要语言为 Python，日榜新增 488★，仓库当前为 68,175★，许可证为 Apache-2.0，最近提交为 2026-11-21，最近 Release 为 v2（2025-10-21）。

firecrawl/firecrawl

Firecrawl 把网页抓取、爬取、搜索、文档解析和 MCP 接入组合成 Agent 的知识入口，既提供本地二进制，也提供需要队列、Worker 和数据库的完整自托管服务。它适合做研究助手、RAG 或网页自动化的人，限制是本地与自托管路径的运维成本不同，云端还涉及额度和数据边界；分发时必须阅读 AGPL-3.0。主要语言为 TypeScript，日榜新增 1,006★，仓库当前为 206,249★，最近提交为 2026-11-21，最近 Release 为 v2.11.0（2026-06-19）。

openvinotoolkit/openvino

OpenVINO 面向深度学习模型的转换、优化和部署，README 明确覆盖 CPU、Intel GPU 与 Intel NPU，并支持从 PyTorch、TensorFlow、ONNX、Keras 等框架接入。它适合研究推理后端、设备抽象和边缘部署的人；限制是实际收益取决于算子支持、模型结构、精度设置和硬件，支持矩阵不是你的模型性能保证。主要语言为 C++，日榜新增 200★，仓库当前为 11,941★，许可证为 Apache-2.0，最近提交为 2026-11-21，最近 Release 为 2026.4.1（2026-10-01）。

cathrynlavery/diagram-design

diagram-design 把架构图、时序图、四象限等图形组织成 Agent Skill，目标是生成一个可直接打开的单文件 HTML + SVG，而不是一段难维护的 Mermaid。它适合前端、架构师和文档作者研究“自然语言到可审阅视觉产物”的边界；限制是布局、语义和品牌一致性仍需人工检查，README 的 隐私说明也应先看清技能会发送哪些网络数据。主要语言为 HTML，日榜新增 583★，仓库当前为 69,823★，许可证为 MIT，最近提交为 2026-11-22。

mvanhorn/last30days-skill

last30days-skill 并行搜索 Reddit、X、YouTube、Hacker News、Polymarket 和网页，再按互动信号合成带来源的近 30 天研究简报，并适配多种 Agent harness。它适合研究跨平台检索、证据归因和“搜索结果如何被模型压缩”的工程实现；限制是部分来源需要 API key 或登录会话，互动量代表注意力而不是事实，外部平台权限和条款也会影响复现。主要语言为 Python，日榜新增 560★，仓库当前为 72,031★，许可证为 MIT，最近提交为 2026-11-21，最近 Release 为 v4.5.0（2026-11-21）。

mjmirza/app-store-compliance

App Store Compliance 把 App Store、Google Play 的拒审模式、隐私清单、Data safety 和政策日期整理成 playbook，并提供提交前扫描器。它适合移动端发布流程和 AI coding agent 的门禁设计；限制是规则会随平台政策变化，README 明确写着扫描“不是批准保证”，而且许可证是自定义的 OpenRoots Agent License 2.3，商用和模型训练边界必须先读原文。主要语言为 Shell，日榜新增 720★，仓库当前为 3,424★，最近提交为 2026-11-22，最近 Release 为 v2.5.0（2026-11-22）。

Tracer-Cloud/opensre

OpenSRE 面向 CI/CD 可靠性：读取失败运行、日志和仓库上下文，分析根因，再把修复推到分支供人审阅，并支持自托管模型。它适合平台工程师研究 Agent 如何进入失败后的反馈闭环；限制是项目当前明确标为 Public Alpha，日志、凭据和自动修复权限要放在组织边界内单独审查。主要语言为 Python，日榜新增 450★，仓库当前为 14,001★，许可证为 Apache-2.0，最近提交为 2026-11-22，最近 Release 为 v0.1.2026.11.22（2026-11-22）。

toeverything/AFFiNE

AFFiNE 把文档、白板、表格、知识库和实时协作放进一个 privacy-first、local-first 工作区，并提供自托管路径。它适合研究富文本、画布、数据库和数据拥有权如何共存；限制是当前默认分支为 canary，许可证也不是单一条款：LICENSE说明大多数内容为 MIT，但 backend/native 目录和第三方组件另有授权。主要语言为 TypeScript，日榜新增 574★，仓库当前为 76,330★，最近提交为 2026-11-21，最近 Release 为 v2026.11.21-canary.904（2026-11-21）。

XiaoYouChR/Ghost-Downloader-3

Ghost Downloader 3 是跨平台下载器，把 HTTP、Magnet/BT、FTP、M3U8、MPEG-DASH 和 eD2k 等协议，以及桌面端、浏览器扩展和 aria2 兼容 RPC 组合到一个工具中。它适合学习 Python/Qt 桌面应用如何组织多协议任务与跨平台交付；限制是 GPL-3.0 会影响分发方式，README 还提示 Qt 6.6+ 不再支持没有 AVX 指令集的 CPU，下载内容则必须遵守版权与站点条款。主要语言为 Python，日榜新增 779★，仓库当前为 14,481★，许可证为 GPL-3.0，最近提交为 2026-11-21，最近 Release 为 v4.5.11（2026-11-20）。

zhouxiaoka/autoclip

AutoClip 把长视频链接转成短视频、字幕、封面和发布文案，提供桌面端、CLI 与 MCP，并允许用户在编辑器里修正自动剪辑结果。它适合研究模型选择、媒体处理和人工校正如何组成内容工作流；限制是云端分析会发送字幕、音频或抽样画面并产生用量成本，自动取景和文案仍要人工复核。主要语言为 Python，日榜新增 683★，仓库当前为 12,886★，许可证为 MIT，最近可核验提交为 2026-11-03，最近正式 Release 为 v1.5.8（2026-11-02）。
