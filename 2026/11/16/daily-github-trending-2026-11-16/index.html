2026-11-16 GitHub 热榜简报：Agent 的协议、审查与可重复交付

GITHUB TRENDING · 2026.11.16

今天的 GitHub all-languages 日榜呈现出一条比“又多了几个 Agent”更具体的主线：AG-UI在定义 Agent 与界面的事件边界，Modern Web Guidance把平台知识变成可检索的技能，Plannotator则把人的判断接回 Agent 会话。另一端，OpenCodeReview、LoopForge和 SkillEvaluator分别约束审查、交付与评估；真正值得观察的是这些项目如何把上下文、权限、证据和暂停点做成工程接口。

Agent 协议Web 知识人类反馈浏览器调试代码审查可重复交付AI Office技能评估

今日要点

今天最清晰的变化是 Agent 的“控制面”正在成形：AG-UI用标准事件连接 Agent、实时上下文与用户界面，Modern Web Guidance把浏览器平台的最佳实践压缩进可检索的 skills，Plannotator则让人可以在计划、文档、消息和 diff 上批注并把反馈送回会话。它们共同说明：提示词只是入口，稳定的协议、可验证的知识和明确的人类决策点才是长期可维护的 Agent 结构。

执行面也在向真实开发环境下沉：Chrome DevTools MCP让 Agent 进入浏览器调试，OpenCodeReview把确定性文件选择与 LLM 判断组合成代码审查，LoopForge用沙箱、SOP 和人类门控组织交付，SkillEvaluator开始测量 skill 是否真的改善任务结果。再加上 Univer把表格、文档和计算能力暴露给产品与 Agent，今天的信号更像“围绕 Agent 重建软件边界”，而不是单点模型能力竞赛。

值得尝试

dream-num/univer

Univer 是可嵌入产品的 Office SDK，把表格、文档、计算、协作和文件处理放进自己的应用，并通过 Facade API 与事件连接 Agent。它适合研究“Office 能力如何成为产品基础设施”，但仓库同时区分 Apache-2.0 开源核心与商业扩展，接入前要把功能边界和许可证逐项核对。主要语言为 TypeScript，官方日榜记录 +988★/日，仓库页当前核验 26,068★，许可证为 Apache-2.0，最近 Release v1.5.0 于 2026-11-14 发布。

ag-ui-protocol/ag-ui

AG-UI 是面向 Agent—用户交互的轻量事件协议，定义标准事件，并兼容 SSE、WebSocket、webhook 等传输方式，还提供参考 HTTP 实现和 connector。它适合做实时聊天、生成式 UI、状态同步和 human-in-the-loop 集成；限制是它只解决协议与事件层，不提供模型或 Agent，后端适配、错误处理和权限边界仍由集成方负责。主要语言为 TypeScript，官方日榜记录 +355★/日，仓库页当前核验 17,932★，许可证为 MIT，最近 Release 2026-11-13 发布。

backnotprop/plannotator

Plannotator 是面向编码 Agent 的本地浏览器审查层，可以标注计划、规格、Markdown、HTML、Agent 消息、代码 diff 和 PR，再把反馈送回会话。它适合需要在多 Agent 并行时保留人类决策入口的团队；限制是仍需通过各宿主的插件、hooks 或命令接入，适配层和本地状态边界要单独验证。主要语言为 TypeScript，官方日榜记录 +866★/日，仓库页当前核验 11,891★，许可证为 Apache-2.0 / MIT，最近 Release v0.28.65 于 2026-11-15 发布。

ChromeDevTools/chrome-devtools-mcp

Chrome DevTools MCP 让编码 Agent 通过 MCP 或 CLI 控制并检查实时 Chrome，覆盖性能 trace、网络请求、控制台、截图、source map 和 Puppeteer 自动化。它适合把浏览器调试和性能工程纳入 Agent 工具链；限制是官方只支持 Chrome 与 Chrome for Testing，浏览器内容会暴露给 MCP 客户端，usage statistics 也默认开启，需要先评估数据边界。主要语言为 TypeScript，官方日榜记录 +717★/日，仓库页当前核验 57,011★，许可证为 Apache-2.0，最近 Release v1.13.0 于 2026-11-11 发布。

alibaba/open-code-review

OpenCodeReview 是 AI 代码审查 CLI：把确定性的文件选择、文件分组、规则匹配、评论定位与 LLM Agent 组合起来，支持 diff review 和整目录 scan。它适合研究“哪些步骤必须由工程逻辑保证，哪些步骤适合交给模型”；限制是默认需要配置模型端点，仓库 benchmark 也明确偏向高 precision、recall 较低，不能直接外推到你的代码库。主要语言为 Go，官方日榜记录 +691★/日，仓库页当前核验 52,158★，许可证为 Apache-2.0，最近 Release v1.13.10 于 2026-11-15 发布。

Tencent/LoopForge

LoopForge 是面向团队的自托管 Agent 交付工作区：在 Docker sandbox 中检出仓库、调用多个 coding-agent CLI，以角色、SOP、checkpoint 和 human gate 组织从需求到 PR 的流程。它适合研究如何把一次性的“让 Agent 修 bug”变成可暂停、可审计、可重复的交付；限制是默认 Docker socket 赋予服务控制宿主 Docker daemon 的能力，README 明确不适合不受信任的多租户环境。主要语言为 Go，官方日榜记录 +423★/日，仓库页当前核验 1,573★，许可证为 MIT（含第三方组件例外），最近 Release v0.3.9-rc.1 于 2026-11-13 发布。

GoogleChrome/modern-web-guidance-src

Modern Web Guidance 源仓库把现代 Web API、浏览器兼容、性能与无障碍知识组织成可安装的 Agent skills，CLI 支持 search、retrieve 和 legacy-scan。它适合前端团队或编码 Agent 作者学习如何把平台知识压缩成可检索规则；限制是它是指南与评估源代码而不是 Web 框架，输出仍需结合目标浏览器和真实测试。主要语言为 TypeScript，官方日榜记录 +1,219★/日，仓库页当前核验 7,246★，许可证为 Apache-2.0，最近 2026-11-14 UTC 提交。

NVIDIA/SkillEvaluator

SkillEvaluator 为 Agent skills 提供分层评估：Tier 1 做质量与安全检查，Tier 2 检测重复与语义重叠，Tier 3 在沙箱中测量 skill 对 Agent 任务结果的影响，并可接入 CI。它适合把“这个 skill 看起来不错”改成可复现的质量门；限制是完整覆盖仍需要外部扫描器、模型提供商、支持的 Agent 和运行中的 sandbox，静态分数不能替代真实安全审查或效果验证。主要语言为 Python，官方日榜记录 +122★/日，仓库页当前核验 1,748★，许可证为 Apache-2.0，最近 Release v0.9.0 于 2026-11-13 发布。
