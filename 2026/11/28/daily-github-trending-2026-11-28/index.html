2026-11-28 GitHub 热榜简报：Agent 开始获得工具、证据与发布边界

GITHUB TRENDING · 2026.11.28

今天的 GitHub all-languages 日榜把注意力推向“Agent 不再只是模型外壳，而是开始拥有可调用的工具、可追溯的证据和可审阅的结果”：Claude-BugHunter、Superpowers与 CLI-Anything分别处理安全研究、开发方法和复杂软件接口，Firecrawl与 last30days-skill把外部信息变成可检索输入，OpenSRE与 App Store Compliance则把验证推进到 CI 和发布门禁。

Agent 安全开发方法Agent-native CLI证据与检索模型训练推理部署设计产物发布门禁

今日要点

今天最值得看的不是某个项目获得了多少星，而是“完成一件事”所需要的边界正在被写进工具：Claude-BugHunter把授权范围、分诊和证据卫生放进安全研究流程，Superpowers把需求、计划、测试与评审串成开发方法，CLI-Anything让复杂软件拥有结构化入口，OpenSRE则把失败后的调查和修复送回 CI/CD。真正可复用的部分不是“自主”这个词，而是权限、输入、输出和人工接管点都能被审阅。

另一条线是从信息到交付物的闭环：Firecrawl和 last30days-skill负责带来源的网页研究，diagram-design与 Stitch Skills把设计要求变成可打开的文件，AutoClip把长视频变成可发布素材，App Store Compliance提醒发布前必须让扫描结果和人工检查分工。单日星标只能说明注意力集中在哪里，许可证、最近代码、环境依赖和失败边界才决定项目能否进入长期工作流。

值得尝试

elementalsouls/Claude-BugHunter

Claude-BugHunter 是面向 Claude Code 的安全研究技能包，README 将 85 个技能、16 个命令、681 个披露报告模式、企业身份与基础设施攻击矩阵、Burp MCP 集成以及范围门禁和证据卫生组织成可复用流程。它适合安全工程师研究 Agent 如何在授权范围内工作；限制是明显的双重用途，技能包不能替代目标授权、凭据隔离和人工复核。主要语言为 Python，日榜快照新增 2,688★，快照总星标 26,111★，许可证为 MIT，最近提交为 9b7fc8d（2026-11-27）。

obra/superpowers

Superpowers 把需求澄清、设计确认、计划、红绿 TDD、子代理执行和代码评审串成 coding agent 的完整工作方法，强调先理解目标再动手。它适合希望把 Agent 从“直接写代码”改造成可审阅流程的开发者；限制是它是方法论与技能集合而非独立测试框架，安装方式、自动触发行为和权限边界会随宿主变化。主要语言为 Shell，日榜快照新增 922★，快照总星标 328,323★，许可证为 MIT，最近 Release 为 v7.0.2（2026-11-03）。

HKUDS/CLI-Anything

CLI-Anything 试图把图形软件和其他已有工具转换成带统一参数、JSON 输出、预览与端到端测试的 Agent-native CLI，并用 CLI-Hub 管理社区适配器。它适合平台工程师研究“模型如何稳定调用复杂软件”；限制是每个适配器仍依赖目标软件、系统环境和集成质量，演示覆盖面不能等同于所有软件都能可靠自动化。主要语言为 Python，日榜快照新增 666★，快照总星标 67,013★，许可证为 Apache-2.0，最近可核验提交为 34f5195（2026-09-22）。

jingyaogong/minimind

MiniMind 用可读代码覆盖小型语言模型的结构、Tokenizer、预训练、SFT、LoRA、偏好优化、工具调用和 Agentic RL，把“调用模型”还原成可以逐步复现的训练链路。它适合想从代码和数据理解 LLM 的学习者；限制是“2 小时、3 块钱”的结果基于特定硬件、数据和评测条件，不能直接外推到生产模型。主要语言为 Python，日榜快照新增 660★，快照总星标 72,215★，许可证为 Apache-2.0，最近提交为 96de892（2026-11-26）。

firecrawl/firecrawl

Firecrawl 把抓取、爬取、网页映射、搜索、文档解析和 MCP 接入组合成 Agent 的知识入口，并通过一个 API 连接 550 多个数据提供方。它适合做研究助手、RAG 或网页自动化的人；限制是本地路径和自托管都要承担浏览器、编译环境与后台服务运维，AGPL-3.0 也会影响服务化分发。主要语言为 TypeScript，日榜快照新增 822★，快照总星标 211,692★，许可证为 AGPL-3.0，最近提交为 3f8516d（2026-11-27）。

openvinotoolkit/openvino

OpenVINO 面向深度学习模型的转换、优化和部署，README 覆盖常见训练框架，并把运行目标扩展到 x86/ARM CPU、Intel GPU 与 Intel NPU。它适合研究推理后端、设备抽象和边缘部署的人；限制是实际收益取决于算子支持、模型结构、精度设置和硬件，支持矩阵不是你的模型性能保证。主要语言为 C++，日榜快照新增 151★，快照总星标 12,953★，许可证为 Apache-2.0，最近提交为 67f7f12（2026-11-27）。

cathrynlavery/diagram-design

diagram-design 把架构图、时序图、四象限等 52 种图形组织成 Agent Skill，目标是让 Agent 生成带品牌样式、可直接打开的单文件 HTML + SVG，而不是一段难以维护的 Mermaid。它适合前端、架构师和文档作者研究“自然语言到可审阅视觉产物”的边界；限制是布局、语义和品牌一致性仍需人工检查，仓库的 隐私说明也提示技能的网络数据边界需要审阅。主要语言为 HTML，日榜快照新增 725★，快照总星标 74,468★，许可证为 MIT，最近提交为 795eec4（2026-11-26）。

mvanhorn/last30days-skill

last30days-skill 把 Reddit、X、YouTube、Hacker News、Polymarket、GitHub 等多源搜索并行化，再按互动信号合成带来源的近 30 天研究简报，并适配多种 Agent Skills 宿主。它适合研究跨平台检索、证据归因和“搜索结果如何被模型压缩”的工程实现；限制是部分来源需要 API key 或浏览器会话，互动量代表注意力而不是事实，平台权限与条款也会影响复现。主要语言为 Python，日榜快照新增 675★，快照总星标 76,376★，许可证为 MIT，最近 Release 为 v4.8.0（2026-11-27）。

google-labs-code/stitch-skills

Stitch Skills 是面向 Google Stitch MCP 的 Agent Skills 与插件集合，按 Agent Skills 开放标准提供设计、构建和工具类能力，可供 Codex、Antigravity、Gemini CLI、Claude Code、Cursor 和 OpenCode 使用。它适合研究“设计系统、静态 HTML 和组件实现如何被 Agent 串起来”；限制是它不是独立设计引擎，实际使用前必须配置 Stitch MCP 与相应凭据。主要语言为 TypeScript，日榜快照新增 311★，快照总星标 13,596★，许可证为 Apache-2.0，最近提交为 75f4696（2026-11-24）。

mjmirza/app-store-compliance

App Store Compliance Playbook 把 Apple App Store 与 Google Play 的常见拒审模式、隐私清单、Data safety 和政策日期整理成 playbook，并提供提交前扫描器；README 明确区分“扫描能证明什么”和仍需人工检查的部分。它适合移动端发布流程和 AI coding agent 的门禁设计；限制是平台政策会变，扫描结果不是上架批准，且仓库使用带收入条款的 OpenRoots ORA 2.3，商用前必须读原文。主要语言为 Shell，日榜快照新增 530★，快照总星标 7,920★，许可证元数据为 Other/NOASSERTION，最近 Release 为 v2.5.3（2026-11-26）。

Tracer-Cloud/opensre

OpenSRE 面向 CI/CD 可靠性：读取失败运行、日志和仓库上下文，分析根因，再把修复推到分支供人审阅，并支持自托管模型；README 还列出 Kubernetes、Grafana、Datadog、Slack 和 GitHub 等集成方向。它适合平台工程师研究 Agent 如何进入失败后的反馈闭环；限制是项目明确标为 Public Alpha，API 与集成会变化，日志、凭据和自动修复权限必须放在组织边界内单独审查。主要语言为 Python，日榜快照新增 328★，快照总星标 16,136★，许可证为 Apache-2.0，最近 Release 为 v0.1.2026.11.28（2026-11-28）。

toeverything/AFFiNE

AFFiNE 把文档、白板、表格、知识库和实时协作放进一个 privacy-first、local-first 工作区，并提供跨平台与自托管路径，README 还展示了 AI 辅助写作、幻灯片和思维导图能力。它适合研究富文本、画布、数据库和数据拥有权如何共存；限制是当前默认分支为 canary，许可证元数据为 Other/NOASSERTION，后端目录和第三方组件的边界不能只靠项目简介判断。主要语言为 TypeScript，日榜快照新增 474★，快照总星标 79,457★，许可证说明见 LICENSE，最近提交为 bae99fc（2026-11-27）。

zhouxiaoka/autoclip

AutoClip 把长视频链接、文件或直播回放转成短视频、字幕、封面和发布文案，并提供桌面端、CLI 与 MCP 路径；README 还列出 OBS、Twitch、YouTube、Kick、Discord 和本地录制等直播回放来源。它适合研究模型选择、媒体处理和人工校正如何组成内容工作流；限制是本地计算、FFmpeg 和模型配置仍有环境成本，自动取景、字幕与文案需要人工复核，示例效果也不能当成普遍保证。主要语言为 Python，日榜快照新增 718★，快照总星标 17,596★，许可证为 MIT，最近 Release 为 v1.6.2（2026-11-26）。
