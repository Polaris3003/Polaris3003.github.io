AgentVQA：先测清楚智能体看到了什么

论文：AgentVQA: A Unified Benchmark for Agentic Visual Understanding（arXiv:2610.31494）
全文状态：已核阅公开 PDF。

问题是视觉语言模型在真实智能体任务中的能力，不能由普通图像问答分数直接替代。作者从 23 个公开数据集人工整理 1,000 道选择题，覆盖 Web Agents、机器人、第一视角视频、游戏和空间规划五域，每域 200 题；自动筛选后只有约 22% 候选进入人工复核，最后比较 22 个 VLM，并让非视频任务使用 32 帧等统一设置。作者报告最佳 Gemini 3.7 Flash 总体准确率 58.5%，各域平均约为第一视角 59%、游戏 51.5%、空间规划 46%、机器人 38%、Web Agents 29%；12 个重叠模型在匹配的空间类别上与 SpatialWorld 的在线结果 Spearman ρ=.895。创新是把感知、动作历史、视角与空间推理拆开；失败分析显示 Web Agents 约 78% 为 grounding、机器人约 65% 为空间混淆，空间规划约 62% 为视角差距。局限是离线 MCQ 不等于真实执行，题目来源和人工筛选会影响排名，相关性也不是行为因果。适合多模态/具身智能评测读者，建议优先读数据筛选、表 2、错误类型和跨基准验证。

Certified Execution Harness：把安全边界放到工具执行层

论文：Certified Execution Harness for Agentic AI: Safe and Least-Intrusive Petri-Net Supervisory Control Between Reasoning and Action（arXiv:2610.31376）
全文状态：已核阅公开 PDF。

问题是提示词和模型自律不能保证工具动作符合权限、审批和预算。论文用带标记的扩展 Petri 网（AEPN）表示状态、能力、审批和预算，在 LLM 与工具之间加入四项准入检查：解析/映射、验证器、启用迁移和监督器；未启用的动作无论措辞如何都会拒绝。作者在四个明确假设下证明安全属性可由网的可达性转移，并比较最大许可监督器与按重规划代价细化的最少侵入式监督器：发布代理例子中，若测试后过早开始的概率为 h，则 h>43/60 时强制先扫描；h=.9 时表中当前监督器额外拒绝为 75/17，最少侵入式为 20/17。创新是把一次性审批做成可消耗资源，避免重放，并把“拒绝成本”纳入控制器。局限是形式化结果依赖网忠实、不可绕过、状态可控和提议稳定等假设；提示载荷、数据泄漏和审批洗白仍未被实证覆盖。适合 agent runtime、安全架构和形式化方法读者，建议读定义、定理、发布代理案例和假设清单。

EpiSEM-Bench：安全证据缺失时，模型会不会错误放行

论文：EpiSEM-Bench: Evaluating Safety and Evidence Recovery in LLM Agents under Missing Evidence（arXiv:2610.31650）
全文状态：已核阅公开 PDF。

问题是安全决策的关键事实被隐藏后，模型是否仍能识别不安全状态，而不是仅考“能否找到更多文本”。作者构造 300 个匹配的安全/不安全任务对、600 个世界和 60 个任务族，共 1,363 个证据原子（944 个关键、419 个无关），用 Full SWS/UCR、Critical UCR、Recovery UCR、SBM 与 PUR 六项指标测试 10 个模型；每个模型覆盖 6,052 个条件，并加入恢复检索。作者报告差距非常大：GPT-6-Luna 的 Full SWS/UCR/Critical UCR/Recovery UCR/SBM/PUR 为 51.0/3.0/21.0/3.0/84.8/30.5，Qwen3-14B 为 92.0/77.3/97.3/94.0/7.8/3.8，恢复证据会降低十个模型的不安全行为但恢复与使用能力不一致。创新是把“关键证据缺失”与“普通信息缺失”分离，并测恢复后的行为。局限是合成可执行世界、服务配置和拒答策略未必代表真实系统风险；高分也可能来自保守拒答。适合安全评测和 agent policy 读者，建议读任务生成、指标定义、表 3–4 与恢复性分析。

AgentPhishing：钓鱼评测应看智能体是否真的做了危险动作

论文：AgentPhishing: A Benchmark of LLM Email Agents Under Adaptive Attack（arXiv:2610.31404）
全文状态：已核阅公开 PDF。

问题是邮件智能体可能识别出“钓鱼”却仍然点击、提供信息或起草不安全回复。作者用 PhishOpt 对目标代理的生成技能做一次有界编辑，以目标反馈、现实感约束和 Cialdini 说服线索生成可复用的目标化攻击，在六个主目标及九个额外目标上分别测检测和合规行为；公开钓鱼语料对照中六个代理检测率为 100%、合规为 0。作者报告 Qwen 的易感性从 0.12 升到 0.95；额外代理中 4/9 的检测率低于 10% 且合规率高于 45%，承诺/一致性线索与检测失败/合规的 Spearman 相关分别约 .2407/.1391，喜欢线索与检测失败约 .1914。创新是把目标化生成与行为指标分开；通用技能并未显著优于 GPT 派生技能。局限是合成单消息、固定目标代理和评分动作/草稿而非真实执行，相关性不能当作说服因果；原始双用途语料不公开。适合邮件安全、红队和 agent policy 读者，建议读威胁模型、指标、表 2–4 和跨代理失败分析。

RoleFlow：让多智能体工作流按失败反馈重新布置角色

论文：RoleFlow: Self-Evolving Multi-Role Agentic Collaboration via Structural Adaptation（arXiv:2610.30429）
全文状态：已核阅公开 PDF。

问题是固定角色链在任务变化或失败后会浪费调用，完全自由的结构搜索又难以训练。RoleFlow 由 Global Router 生成初始角色链，验证器失败后只执行一次原子编辑（Add、Prune、Swap、Reroute 或不变），并用 SECPO 在同一状态下比较“编辑/不编辑”的反事实回报；执行器冻结为 gpt-4o-mini。作者在 HotpotQA、2Wiki、MuSiQue、MATH-500、MBPP、HumanEval、WebShop 七项任务上报告平均 67.1%，比 W4S 62.4% 高 4.7 个百分点，单项包括 MATH 81.1、MBPP 89.0、HumanEval 95.7；禁用适应性下降 3.8–8.5 个百分点，SECPO 比 GRPO 在 QA 上再高约 2.1–2.6 个百分点。创新是把“工作流结构”作为有预算的决策变量；代价是 SECPO 每题约 13.5 次链执行、GRPO 约 9.1 次，训练 token/GPU 小时约 1.48 倍，重编辑反而下降。局限是基准与单执行器设定，额外重试成本和生产可靠性尚未证明。适合 agent orchestration 与 RL 工程读者，建议读路由器、反事实目标、主表和消融。

ATTUNE：用可验证实验调优任意训练配方

论文：ATTUNE: Agentic Throughput Tuning for LLM Training（arXiv:2610.17528）
全文状态：已核阅公开 PDF。

问题是训练配方的有效改动往往依赖经验，而盲目搜索消耗昂贵 GPU。ATTUNE 是编码智能体：先诊断失败，再一次只改一个变量，并用外部确定性正确性门检查目标与已知缺陷，接受后继续同一目标；实验覆盖 H100/H200/B200。作者报告生产后训练吞吐平均 1.7 倍、最高 3.9 倍；留出模型上 MiniMax-M2 +164.2%、GLM-4.5 +33.9%、Llama-405B +6.8%、Mixtral 0%，且部分任务用 203–669 GPU 小时，少于若干基线约 1,407 GPU 小时。GLM 的 +33.9% 超过 OptiCo 0、贝叶斯优化 1.8/3.9 和随机 7.8；门能通过 460 个合法变体并拒绝改变目标或已知缺陷，但第一步 5% loss 检查会漏掉某些细错，启用同一 agent skill 的失败率仍约 50%。创新是把调参、外部验证和预算闭环，限制是高算力、特定软件栈/模型和不完备的语义正确性。适合 LLM 训练基础设施读者，建议读实验协议、门设计、留出结果和失败案例；代码与 OpenRecipes 链接见条目。
