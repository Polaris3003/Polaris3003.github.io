QuantEval: A Benchmark for Financial Quantitative Tasks in Large Language Models

  • 作者：Zhaolu Kang、Junhao Gong、Wenqing Hu、Yingjie He、Kehan Jiang、Leqi Zheng、Shuo Yin、Zhicheng Fang、Chunlei Meng、Eric Hanchen Jiang、Yunfei Feng、Yitong Leng、Junfan Zhu、Xiaoyou Chen、Xi Yang、Richeng Xuan
  • 来源/分类：arXiv，AI / 金融量化模型评测
  • 直接 PDF：PDF
  • 核心问题：金融量化模型不能只回答事实题；它是否能完成“计算—实现—验证”的完整工作流，并把策略真正放进可执行的回测框架？
  • 方法与基线：QuantEval 含 1,575 个专家验证实例：知识问答 660、定量数学推理 855、策略编码 60。作者评估 13 个开源和闭源 LLM，编码任务用确定性的 CTA 风格回测比较风险收益指标，并以专家基线作参照；另做 SFT 和 GRPO 训练实验。
  • 关键结果：专家基线在知识问答、数学推理、可执行编码上的准确率分别为 91.75%、89.05%、100%。论文报告 GPT-5 在两类问答上的准确率为 83.9%/82.8%、55.0%/33.8%，策略编码可执行率 53.3%；Claude Sonnet 4.5 的两类问答为 86.0%/90.8%、43.1%/44.6%，可执行率 65%。许多开源模型的可执行率为 0；在作者的领域训练实验中，推理改善伴随事实问答小幅下降。
  • 创新、局限与失败条件：把代码能否执行、回测风险指标和事实/推理拆开，比只看答案字符串更接近量化工作流；但编码子集只有 60 题，固定 CTA 接口可能偏向某些模型，闭源模型不可完全复现，且数据去重不能等同于证明没有训练污染。这里的回测是评测协议，不是实盘交易能力证明。
  • 适合谁读：做金融 LLM、代码 agent、量化评测和可复现基准的人。建议先读第 2–3 节、主结果表、可靠性/泄漏分析和附录。
  • 证据状态：已核阅摘要与 PDF；以上为论文报告，尚未独立复算。

Scaling Multilingual Safety and Reasoning Evaluation through Reasoning-Guided Translation

  • 作者：Zahraa Al Sahili、Ioannis Patras、Matthew Purver
  • 来源/分类：arXiv，AI / 多语言安全与推理评测
  • 直接 PDF：PDF
  • 核心问题：把英语安全、对话和数学基准翻译到低资源语言时，是否仍保留伤害意图、推理结构和对话语用，而不是只得到字面上通顺的题目？
  • 方法与基线：作者先用推理模型选择翻译配置，再做任务感知验证、定向修复和独立质量筛查；集合覆盖 7 个资源、11 种语言，包括 WildChat、WildJailbreak、StrongREJECT、JBB、XSTest、MATH500 和 AIME。两个下游模型 Llama-3.1-8B 与 Qwen2.5-7B 在配对题目上比较拒答和推理。
  • 关键结果：需要修复的两个子集保留了 6,816/6,820 个目标“题目—语言”对，覆盖率 99.94%；人工独立筛查仍发现约 1.2% 条目残留英语。论文报告 Llama 在有害拒答上从英语 97.5% 降到土耳其语 69.5%，JBB 有害样本从 94% 降到 74%；MATH500 上 Llama 从英语 44% 降到阿拉伯语 24%，Qwen 从英语 74% 降到土耳其语 58.6%。在 70 条泰语试验中，作者选用的 GPT-5-mini 配置正确 68 条（97.1%），GPT-5.1 为 70 条，但前者估计成本更低。
  • 创新、局限与失败条件：把翻译配置选择和大规模生成分离，并把覆盖率、语义保持和下游行为同时报告；但配置选择由 GPT-5.4 Thinking 参与，自动语义筛查不是双语人工等价性证明，70 条试验不足以代表全部语言，且下游只测两个开放模型。低资源语言的差异也可能混合了模型预训练覆盖、翻译误差和提示效应，不能直接归因于某一个因素。
  • 适合谁读：做多语言安全、跨语言 benchmark、低资源 NLP 和公平评测的人。建议先读第 3–5 节及附录的人审和验证分析。
  • 证据状态：已核阅摘要与 PDF；以上为论文报告，尚未独立复核。

Beyond Benchmark Accuracy: A Diagnostic Test for LLM Chemical Prediction

  • 作者：Yanyi Su、Yu Zeng、Hongshuai Wang、Chenyan Wang、Zhifeng Gao、Xiaohui Yang
  • 来源/分类：arXiv，AI / 科学推理与化学预测
  • 直接 PDF：PDF
  • 核心问题：化学预测 benchmark 的高分来自可迁移的结构—性质推理，还是来自目标实体名称、来源标签和训练语料中的记忆线索？
  • 方法与基线：Identity-Blinded Reasoning Diagnostic 隐去目标实体身份，只给出来源实体和明确的结构编辑操作；C0 是常规任务，C1/C2/C3 分别改变身份信息和来源标签。作者在手性气味、BACE、HIV、逆合成和反应产率等六类任务上测试 Claude Opus 4.8、DeepSeek V4 Pro Preview、GPT-5.5 和 Gemini 3.1 Pro。
  • 关键结果：论文报告四个模型都能恢复每个手性目标的结构，结构重建率为 86.05%–100%，但常规 BACE 准确率仅 51.5%–57.4%、HIV 为 31.4%–61.2%、逆合成精确匹配为 34.9%–48.8%，产率 MAE 为 32.34–56.46，高于均值/中位数基线约 21.98/21.65。只替换来源标签而保持目标、结构编辑和真值不变时，二元预测会向替换标签移动；例如 Claude 的比例为 91.2%，GPT-5.5 为 58.8%。
  • 创新、局限与失败条件：反事实身份控制比单一准确率更能诊断信息依赖；但任务是小规模、人工整理的诊断集，只测四个模型家族，且仍需从来源和编辑操作推导目标，因此它能证明敏感性，不能单独证明训练数据污染或“模型完全没有结构推理”。工具证据在相关任务上可能帮助，也可能因不完整而伤害预测。
  • 适合谁读：做 AI for Science、数据污染审计、科学 agent 和可靠性评测的人。建议先读第 3 节、各任务结果和显著性检验附录。
  • 证据状态：已核阅摘要与 PDF；以上为论文报告，尚未独立复算。

RuleTrek: Benchmarking Agentic Rule Reasoning in Complex Scenarios

  • 作者：Chenhao Yuan、Bohan Yu、Yinhao Xu、Chao Yin、Chenxi Zhou、Zhaoxuan Wang、Shuwen Xu、Shaoping Huang、Haolin Ren、Jiaxiang Liu、Yao Xu、Jun Zhao、Kang Liu
  • 来源/分类：arXiv，AI / 复杂规则推理 agent
  • 直接 PDF：PDF；代码与数据：GitHub
  • 核心问题：当规则分散在多个文件、存在依赖关系并需要交互式检索时，LLM agent 能否先找对规则，再正确演绎，最后完成端到端任务？
  • 方法与基线：RuleTrek 有 240 个实例，覆盖税务、PostgreSQL、网络安全、软件政策、采购和游戏规则六域；平均规则图有 9.05 个节点、8.69 条边，深度 2.69。作者把能力拆为规则识别 RI、规则演绎 RD 和端到端 E2E，在禁网交互工作区中评估 11 个前沿 LLM，每个设置运行三次。
  • 关键结果：论文报告最高 RI、RD、E2E 分数分别只有 62.47%、60.43% 和 55.29%，最低模型的三项为 33.35%、35.26% 和 26.97%。规则节点数从不超过 3 增到至少 14 时，E2E 从 76.5% 降到 23.6%；规则选择错误占 GPT-6.1-Sol 失败轨迹的 54.9%。E2E 比 RD 还低 3.79–8.15 个百分点，说明规则找到后仍有组合与执行损失。
  • 创新、局限与失败条件：规则图、人工核验、分布式文件和依赖感知子场景比“几条事实+一条规则”的基准更接近复杂工作；但场景由模型辅助生成，评分含 LLM judge，覆盖以英文为主，预定义仓库不能代表真实企业知识库。分数也不能直接解释为部署时的法律、合规或安全能力。
  • 适合谁读：做 agent benchmark、工具检索、规则引擎和可复现评测的人。建议先读第 3–4 节、轨迹分析、限制和附录。
  • 证据状态：已核阅摘要与 PDF；以上为论文报告，代码与数据链接来自论文公开信息。

CausalDS: Benchmarking Causal Reasoning in Data-Science Agents

  • 作者：Andrej Leban、Theo Saarinen、Yuekai Sun
  • 来源/分类：arXiv，AI / 因果数据科学 agent
  • 直接 PDF：PDF
  • 核心问题：一个数据科学 agent 是否能同时处理结构因果模型、带噪观察数据、代码工具、不确定性和“不可识别时应拒答”，而不是只在固定的符号题上给出答案？
  • 方法与基线：CausalDS 用完全合成但按真实数据分布锚定的 SCM 场景生成新考试；953 个场景覆盖 Pearl 三层任务、编码/工具使用、区间估计和 abstention。作者在 realistic exam 与 hard exam 上比较 12 个 agent，每个设置运行三次，并把图结构、识别、数值估计和工具错误分开。
  • 关键结果：作者报告现实考试中不同模型的 CausalDSScore、通过率、数值误差和 token 成本出现明显分离：例如表中 GPT-6 Astra 的分数为 0.2112、通过率 96.1%，GPT-5.5 的分数为 0.5603、通过率 81.0%；困难考试中模型间分数和有效答案率也有较大差异。所有模型的图结构 F1 损失接近 0，但 95% 区间常低覆盖，且对不可识别目标的主动 abstain 约只覆盖一半；token 消耗相差两个数量级。
  • 创新、局限与失败条件：可重复生成新试卷、把图结构与测量难度拆开、把拒答作为正确行为，是对污染和固定题库过拟合的有力控制；但场景仍是合成的，真实案例有效性未被证明，judge/agent harness、供应商拒答和故事生成质量都会影响结果。它不能直接代表真实数据科学家或生产因果分析的表现。
  • 适合谁读：做因果推理、数据科学 agent、合成评测和不确定性量化的人。建议先读场景生成、realistic/hard exam 结果、区间覆盖和 limitation。
  • 证据状态：已核阅摘要与 PDF；以上为论文报告，尚未独立复核。

TabFORGE: A Tabular Foundation Model for Generative Modelling

  • 作者：Xiangjian Jiang、Mingxuan Liu、Nikola Simidjievski、Tassilo Klein、Mateja Jamnik
  • 来源/分类：arXiv，AI / 表格数据生成
  • 直接 PDF：PDF；代码：GitHub；模型：Hugging Face
  • 核心问题：表格基础模型能否学习可迁移的特征依赖结构，在未见过的数据集上生成既保留全局结构、又能支持下游模型的合成数据？
  • 方法与基线：TabFORGE 冻结结构感知的特征编码器，用 score-based diffusion Transformer 建模潜变量，再训练与去噪潜表示对齐的解码器。作者在 45 个真实数据集上与 22 类方法比较，采用重复划分和独立 holdout，并排除 43 个预训练数据集。
  • 关键结果：论文报告全局结构保真度从 TabICL 的 0.41 提高到 0.64，最高的数据集专用 TabSyn 为 0.57；局部机器学习效用从 TabEBM 的 0.72 提高到 0.83。TabFORGE 在未见数据集上拟合耗时约为 TabSyn 的 9.71%，生成耗时约为 TabEBM 上下文时间的 1.66%；作者也观察到 SMOTE 的局部效用高但更靠近潜在过拟合区。
  • 创新、局限与失败条件：把可迁移表征、扩散建模和解码分布偏移拆开，是比单纯逐数据集调参更清晰的基础模型路线；但作者明确说结构保真度只是经验代理，不能证明显式因果图、干预或反事实机制被学到。45 个数据集的 OOD 覆盖、预训练语料审计、算力规模和指标选择仍限制结论，未见饱和曲线也不等于模型已高效。
  • 适合谁读：做合成数据、表格基础模型、隐私/数据增强和结构评测的人。建议先读架构、主结果、消融、效率和 limitation。
  • 证据状态：已核阅摘要与 PDF；以上为论文报告，代码与模型链接来自论文公开信息。
