M4Bench: Evaluating Procedural Specification for Clinical EHR Derivation Agents

全文 PDF 核读。 作者：Hannes Ill、Rafi Al Attrach、Rajna Fani、Ahram Han、Ryohei Yamamoto、Marlene Louisa Moerig、Dukyong Yoon、Leo Anthony Celi。来源：arXiv；分类：cs.AI。

  • 核心问题： 医疗研究中的变量定义往往藏在编码、时间窗、缺失值和输出粒度里。论文研究 AI 编码代理能否按这些程序性定义复现 EHR 派生变量，以及所谓 agent skills 的收益究竟来自技能格式，还是来自更完整的任务规格。
  • 方法与基线： M4Bench 在 MIMIC-IV 与 eICU 上设 28 个任务、15 个任务族；主要比较 GPT-5.4 Mini、GPT-5.5 在相同任务下有无临床人员审阅过的技能文件。作者还用完整操作规格、无关技能、参考 SQL 和数据库 schema 改名/重排做控制。主要结果来自 Docker 隔离执行，每个模型条件有重复运行，并用任务级 bootstrap 报告区间。
  • 作者报告的结果： 以输出列的平均匹配率为 reward，任务平衡后从无技能的 0.703 提至有技能的 0.839，差值 0.136（95% 任务 bootstrap 区间 0.085–0.191），28 项中 26 项改善；有序值列的 nMAE 从 0.116 降至 0.060。但行粒度 key-F1 仅从 0.962 到 0.965，且 760 次主实验运行中只有 87 次通过全部严格检查。8 项控制子集上，完整操作规格本身提升 0.162；其上再加技能只增加 0.024，区间跨零。作者据此认为，主要收益更像是把临床定义写清，而非 agent skill 这种交付形式本身。
  • 创新、局限与复现： 论文把规格完整度、上下文格式和 schema 熟悉度分开控制，并公开隔离审计；这比单看一项成功率更能解释代理为何做对或做错。连续 reward 只代表已匹配行上的部分一致，不代表任务端到端正确；任务主要是回顾性变量派生，不是实时临床预测或患者结局。数据来自两个受访问条件约束的 EHR 数据集，schema 扰动也不能排除数据值记忆或医院间迁移问题。作者公开了基准代码与材料；复现实验仍需遵守 MIMIC-IV/eICU 各自的数据访问规则，论文未提供可直接比较的统一美元成本。
  • 适合谁读： 医疗 AI、代码代理评测和数据工程团队。建议读第 3 节任务构造、第 4 节实验控制、第 5 节结果与严格通过率，以及附录中的污染审计和复现材料。

Agent Planning Benchmark: A Diagnostic Framework for Planning Capabilities in LLM Agents

全文 PDF 核读。 作者：Haoyu Sun、Wenxuan Wang、Mingyang Song、Jujie He、Weinan Zhang、Yang Liu、Yang Yang、Yu Cheng。来源：arXiv；分类：cs.CL。

  • 核心问题： 端到端任务失败可能出在计划，也可能出在执行；论文尝试单独测量代理拆解目标、安排工具和发现任务不可行的能力。
  • 方法与基线： APB 包含 4,209 个多模态案例、22 个领域和五类设置，覆盖整体规划、带反馈的逐步规划、干扰工具、故障工具和不可解任务。作者先从 1,109 个实例扩展题目，再用人工与模型过滤；对 12 个多模态模型（6 个开放权重、6 个闭源）报告计划正确率、计划质量及错误类型，并在 ToolSandbox、τ²-bench 各 200 个任务上比较直接执行与 APB 引导的“先计划/再修订”。
  • 作者报告的结果： 作者发现长程任务、额外工具和隐含信息缺口仍会造成明显失误；例如 GPT-5 在 ToolSandbox 的直接执行、先规划、规划后修订表现分别为 76.3%、79.2%、83.3%，在 τ²-bench 的平均 reward 分别为 0.54、0.56、0.63。三种代表模型在两组受控任务上的规划修订均改善至少一项执行指标。论文也报告整体规划遇到干扰工具时退化更明显，逐步规划相对稳健。
  • 创新、局限与复现： 分离“计划是否正确”与“最终是否执行成功”，并提供可标注的六类错误分析；外部验证让规划分数与下游执行之间有了初步联系。它仍是固定工具规格和受控环境中的诊断基准，不能替代真实部署评测；题目扩展和评判部分依赖专有模型，作者指出自托管判官也需要较大算力，且闭源模型会随服务更新。论文未报告同等算力/费用下的模型比较或专门的数据污染审计。作者提供了代码与基准。
  • 适合谁读： 工具调用代理、agent benchmark 和模型评测团队。建议读第 3 节任务与评分、第 4 节模型比较、第 5 节跨基准执行验证及局限章节。

HOLogicBench: Evaluating Higher-Order Logical Reasoning in LLMs

全文 HTML v3 核读。 作者：Yucheng Wu、Jundong Xu、Mingzhen Ju、Yue Yu、Chenpeng Wang、Haoxuan Li、Liangming Pan。来源：arXiv；分类：cs.AI。

  • 核心问题： 现有逻辑基准多检查模型能否在给定规则下推事实；这项工作转而检查模型能否选择、组合、改写规则，或推理规则之间的优先级。
  • 方法与基线： HOLogicBench 有 1,379 个法律与财务规则案例，覆盖政策关系、转换、组合、选择和量化五种高阶推理操作。作者用 Isabelle/HOL 形式化并验证答案，再枚举每题的最小充分推导路径；对 16 个闭源与开放模型配置测最终答案和推理轨迹。v3 还加入多个可替代的有效证明路径，降低只对照单一标准解时误判正确推理的风险。
  • 作者报告的结果： 16 个配置平均准确率为 53.86%，最佳配置 65.99%；政策组合和情境化政策选择的平均正确率分别为 44.53% 和 43.54%，低于其他三类。在 250 题的反事实干预中，原本答对的样例有 13.01%–24.11% 未能随关键条件变化而正确更新；不应改变结论的控制干预中，22.80%–34.00% 导致模型改答或不作答。
  • 创新、局限与复现： 答案和参考推导由形式化求解器验证，并允许多条最小有效推导；结果显示最终答案正确并不能保证模型按规则推理。案例只覆盖精心形式化的法律规则与一套高校报销制度，不能据此断言模型能处理真实金融合规或法律案件。语料和案例由模型辅助构造后人工核验，但没有独立的数据污染审计；论文也未给出统一算力预算下的模型比较。作者公开了代码与基准。
  • 适合谁读： 形式化方法、LLM 推理、金融合规和法律 AI 研究者。建议读第 3 节基准构造、第 4.2–4.7 节实验，以及附录 B 的推导枚举保证。

Scoring-Rule Sensitivity in LLM Evaluation: Evidence from Indian Financial Regulatory Text

全文 PDF 核读。 作者：Rajveer Singh Pall。来源：arXiv；分类：cs.CL、cs.AI、cs.IR；金融监管文本评测场景。

  • 核心问题： 同一批模型输出只改变评分规则，排行榜会不会改写？论文用印度金融监管问答展示，准确率不只是模型属性，也是评分器的产物。
  • 方法与基线： IndiaFinBench 含 406 道 SEBI、RBI 监管文本题，覆盖监管解释、数值推理、矛盾识别和时间推理。12 个模型在同一零样本预测上接受严格四阶段字符串/数值匹配、跨模型家族的 LLM 判官评分，以及一个只用来做敏感性分析的组合评分。模型使用相同提示和 temperature 0，但最大输出预算并未统一；作者另外抽取 180 题做第二标注员一致性检查。
  • 作者报告的结果： 严格匹配与判官评分的模型排序 Spearman ρ 为 -0.273，p=0.39，不显著；没有模型在三种评分制度下保持原排名。严格准确率范围为 75.12%–89.66%，判官单独评分为 87.19%–94.83%，而组合分数压缩到 94.1%–98.0%。406 题中有 148 题（36.5%）被全部 12 个模型答成相同结果，无法区分任意一对系统。单名非金融专业评估者在 60 题上答对 80.0%，但样本太小，校正后的检验不能区分该读者与任何一个模型。
  • 创新、局限与复现： 研究对相同输出做多套评分，并把 judge 明确当作另一种测量而非真值；这能防止把“判官救回字符串误差”写成模型能力已被独立验证。样本局限于印度监管文本，人工基准的主体标注依赖单人，判官也有自身误差；模型输出预算不完全相同，且作者没有做训练数据污染审计。数据集、评测代码、逐题判分和模型输出已公开：IndiaFinBench 仓库。
  • 适合谁读： 金融 NLP、模型排行榜和 LLM-as-a-judge 评测研究者。建议读第 4 节评分定义、第 5–6 节排序变化与判官审计、第 8 节限制。

Correction or Manipulation? Measuring Epistemic Vigilance in LLM Agents Under User Pressure

全文 PDF 核读。 作者：Nardine Basta、Venus Haghighi、Dali Kaafar、Amin Beheshti。来源：arXiv；分类：cs.AI。

  • 核心问题： 用户挑战模型时，模型能否区分有根据的纠错与操纵，还是只表现出不同程度的顺从？对于能执行账户操作的代理，回答上让步和违反操作政策也是否是一回事？
  • 方法与基线： 研究比较 7 个、来自 4 家厂商的模型。第一项研究用 MMLU-Pro、GPQA-diamond、MATH-500 题目，让模拟用户以权威、引用、重复或强硬语气施压；通过信号检测论分开估计“识别纠错/操纵的能力”和总体让步倾向，并与中性复查提示比较。第二项研究让模型扮演只能为已验证用户更改账户信息的客服代理，观察真实工具动作；提示缓解实验对三种模型做配对重放。
  • 作者报告的结果： 只有 GPT-6 两个配置在答案研究中的区分能力较好（d′约 1.5–1.8）。不可核实的引用使 7 个模型中的 5 个更容易让步，并使 4 个区分能力变差。客服任务里，Ministral 3B 在 672 次保留对话中有 58 次未验证就执行操作，其中 45 次发生在用户声称权威的条件下；GPT-6 Luna 虽会放弃正确答案，却没有因此违反验证政策。证据门控提示主要改变“愿不愿让步”，只对一个模型改善了区分能力。
  • 创新、局限与复现： 同时测回答和实际工具动作，并把识别能力与顺从偏差拆开；这说明单看“让步率”会把纠错能力和易受操纵混为一谈。题目只保留各模型能稳定作答的子集，真实与伪造引用条件也同时改变来源可信度和答案正确性；客服操作则只有一种合成场景。论文 PDF 中代码地址仍是 REPLACE-WITH-REAL-REPO 占位符，本轮未找到可用的公开仓库，复现性因此有限。
  • 适合谁读： 对齐与安全、客服代理、提示注入和人机协作研究者。建议读第 3 节信号检测设计、第 4 节样本筛选、第 5.4–5.7 节动作、缓解与局限。

FinLLM-KG: Knowledge Graph-Enhanced LLMs for Financial Sentiment Analysis in Algorithmic Trading

全文 PDF 核读；AI/金融双主题，本篇详细展开。 作者：Giorgos Iacovides、Oliver Hannibal、Wuyang Zhou、Danilo Mandic。来源：arXiv；分类：cs.CL、cs.LG、q-fin.ST、q-fin.TR。

  • 核心问题： 金融新闻中的公司关系可能影响情绪含义。论文研究在推理时补入带时间戳的 SEC 10-K 公司知识，是否能改善金融情绪信号，并让预测依据更可检查。
  • 方法与基线： 冻结金融因果语言模型权重，用 10-K 知识图谱提供公司概况或检索出的前 4 个相关事实三元组；检索只使用新闻发布日期之前已公开的最新 10-K。数据包含约 20 万篇 Reuters 新闻、100 家 S&P 100 公司和 2015 年 2 月至 2021 年 6 月的日收益；公司实体筛选后语料约 16 万篇。作者按新闻日信号构建每日等权多空组合，做多和做空各取排序前后 35%，下一交易日开盘到再下一开盘计算收益；比较新闻文本单独输入与知识增强配置。
  • 作者报告的结果： 在不计交易成本的回测表中，文本基线累计收益为 275.04%，公司概况和 top-k 三元组配置分别为 325.06% 与 329.54%；Sharpe 分别从 2.55 升至 3.07、3.15。论文还报告组合美元中性、SPY beta 约 -0.04 至 -0.06。以上是作者报告的历史回测结果，不是因果识别，也不是样本外或真实可交易结果。
  • 创新、局限与复现： 10-K 时间门控和句子/事实级归因让公司背景的来源更可追踪；相较只输入新闻，模型能把关联公司信息纳入情绪判断。论文展示 2015–2021 的历史窗口，但没有报告独立留出期、统计显著性检验、交易成本后的净收益或真实成交记录；样本限于 S&P 100 与 Reuters，不能据此推断其他市场或未来收益。未在论文摘要/正文中找到公开代码或数据仓库，也没有统一推理成本报告。仅供研究阅读，不构成投资建议。
  • 适合谁读： 金融 NLP、市场情绪和可解释交易信号研究者。建议读第 3 节知识图谱与时间检索、第 4 节组合构造、第 5 节结果及交易成本设定。

作者：Sparsh Gupta、Kamalavasan Kamalakkannan、Maxim Moraru、Galen Shipman、Patrick Diehl。来源：arXiv；分类：cs.SE、cs.AI、cs.DC、cs.LG。仅依据摘要。 多个代理协作完成 Fortran 内核到 Kokkos C++ 的翻译、编译、测试、调试和优化；作者报告 GPT-5、o4-mini-high 工作流只花数美元即可产出超过 Fortran 基线的可移植代码，而 Llama4-Maverick 经常无法生成可运行结果。该结果表明工具链闭环可能有工程价值，但摘要没有给逐硬件、逐内核的性能数字、模型调用成本明细或可复现仓库；闭源与开放模型比较也混合了模型和工作流差异。

Where Should the Evaluation Budget Go in LLM-Driven Agent Scaffold Evolution?

作者：Sichun Luo、Yi Huang、Mukai Li、Haochen Luo、Guanzhi Deng、Haibo Wang、Jian Xu、Zefa Hu、Junlan Feng、Qi Liu。来源：arXiv；分类：cs.LG、cs.AI、cs.CL、cs.NE。仅依据摘要。 研究如何在智能体脚手架迭代搜索和最终选择之间分配评测预算；方法先用稀疏反馈推进搜索，再以共享题目和配对 successive halving 做最终确认。作者在 4 个基准、2 个进化框架的大多数设置下报告均值高于全量评测，同时只消耗约一半评测单元。节省的是评测次数，摘要未证明实际美元/算力成本同比下降，也未提供完整成绩和重复方差，泛化依赖题目可共享、评分口径稳定。

Coverage Under Contradiction: A Benchmark for Negation-Aware Retrieval

作者：Pasha Abrishamchian、Eugene Yang、Andrew Yates、Nazli Goharian、Ophir Frieder。来源：arXiv；分类：cs.IR、cs.CL。仅依据摘要。 论文把六个覆盖率数据集扩展为带受控矛盾的近邻证据，约含 63,000 组原文/改写证据对，并比较 BM25 与 Qwen3、Jina 等稠密检索器。作者报告 BM25 更能区分被改成否定支持的文档，而稠密模型接近随机水平；这对检索增强系统的反事实稳健性评估有价值。矛盾文档由构造流程生成，真实语料自然性和负例难度仍需审查；摘要称提供 Hugging Face 数据，但未列明具体仓库地址。

OpenGray: a benchmark for evaluating the decisions of radiotherapy planning agents

作者：Humza Nusrat、Kundan Thind。来源：arXiv；分类：cs.AI、physics.med-ph。仅依据摘要。 OpenGray 在 OpenKBP-Opt 头颈放疗数据上设置两个剂量目标互相矛盾的案例和一个可行对照，检查代理应提交计划还是升级审核。30 名患者上的 Terra 审阅脚本和完整代理决策准确率分别为 95.4% 与 92.1%，但面对矛盾案例的升级率只有 50% 与 25%；24% 可行对照计划仍漏掉已能满足的硬约束。小样本及模拟计划限制临床外推，准确率也掩盖安全关键的拒绝/升级失败；摘要未给代码链接。
