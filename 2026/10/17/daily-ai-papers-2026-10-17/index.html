MYOPIA: Understanding the Limits of Tree-Based Reasoning in Vision-Language Models

  • 作者：Islam Mesabah、Sary Elmansoury、Gerrit Großmann、Peter Neigel、Sebastian J. Vollmer
  • 来源/分类：arXiv，AI / 视觉语言模型与可解释分类
  • 直接 PDF：PDF
  • 核心问题：把视觉分类拆成一连串可解释的树节点问题，是否真的比一次性 zero-shot 分类更可靠？论文关注贪心、不可回溯的路径在早期判断错误后会不会永久排除正确类别。
  • 方法与基线：MYOPIA 用四棵由 LLM 生成、人工修订的决策树覆盖 GTSRB、MNIST、CIFAR-10 和 MSCOCO；样本分别为 901、1,000、1,000 和 850 张图像。作者比较 GPT-4o、Qwen-VL Max、LLaMA-3.2 11B Vision 的 zero-shot、链式思考和树遍历，并加入冻结 CLIP 基线；另把标签属性回忆、图像 grounding、路径选择和答案解析分开诊断。
  • 关键结果：12 个“数据集—模型”组合中，树遍历都低于 zero-shot，配对 bootstrap 也一致支持后者。标签条件与图像条件的平均准确率差距在 GPT-4o、Qwen-VL Max、LLaMA 上分别为 9.5、13.8、12.6 个百分点；节点审计显示 split entropy 与节点准确率有弱但稳定的负相关，而深度、分支数和节点内 grounding 的关系不稳定。
  • 创新、局限与失败条件：贡献不在于宣称层级推理无效，而是把“属性记忆”和“视觉落地”拆开，指出不可回溯路径与输出解析各自的损失。数据集仍是四类公开任务，树由 LLM 生成并由人工修订，API 模型和提示版本会影响结果；CUB-200 的树只验证了可构造性，没有据此声称分类准确率。
  • 适合谁读：做 VLM 评测、可解释分类、视觉 grounding 和提示设计的人。建议先读第 3 节树构造、第 4 节 benchmark 设置、第 5 节主结果与诊断。
  • 证据状态：已核阅摘要与 PDF；以上为论文报告，尚未独立复算。
  • 相关链接：摘要页 · DOI · 代码

THEIA: A Multimodal Dataset and Benchmark for Vision-Language Analysis of Layout

  • 作者：Giuseppe Chiari、Michele Piccoli、Federico Viola、Davide Zoni
  • 来源/分类：arXiv，AI / 模拟集成电路布局理解
  • 直接 PDF：PDF
  • 核心问题：通用 VLM 能否理解模拟集成电路 GDSII 布局中的器件、拓扑和计数关系，还是必须进行面向工艺和设计域的适配？
  • 方法与基线：THEIA 将经过 DRC/LVS 检查的模拟布局转为图像、元数据和问答，覆盖五类任务：器件识别、基础拓扑识别、器件计数、复杂混合电路计数和复杂布局中的拓扑识别。数据共有 77,354 个问答，分为 19,997 个 easy、33,369 个 medium、23,988 个 hard。作者微调 InternLM-4KHD，并用 Qwen2.5-VL-7B 做跨骨干迁移；比较未微调的 InternLM、GPT-5.2、Qwen2.5-VL-7B 以及闭集 CNN 参考基线，Qwen3-32B 用作语义评判器。
  • 关键结果：微调 InternLM-4KHD 在五项任务上的准确率为 100%、84%、83%、63%、81%；Qwen2.5-VL-7B 在相同划分、提示和确定性解码下从 19%–24% 的 zero-shot 准确率提升到 85%–100%，提升 65–81 个百分点。跨生成器的 ALIGN 留出集上，拓扑识别为 89.5%（34/38），器件计数为 73.7%（84/114）；作者报告的总体优势最高约 73 个百分点。
  • 创新、局限与失败条件：把 GDSII 的几何和元数据组织成可复用的视觉问答 benchmark，并在相同提示、划分和解码设置下做微调前后对照，较好地隔离了域适配效果。限制是布局主要来自 SkyWater 130 nm PDK，不能代表其他工艺节点或全部模拟设计；高分也不等于可直接完成 sign-off，训练和推理实验使用 4 张 40 GB A100，成本与生产环境延迟仍需评估。
  • 适合谁读：做多模态模型、EDA、芯片布局验证和领域数据集的人。建议先读第 3 节数据构造、第 4 节实验表格和第 7 节限制；另注意 CNN 只提供闭集任务参考，不能与开放式 VLM 结果直接等价比较。
  • 证据状态：已核阅摘要与 PDF；以上为论文报告，尚未独立复算。

VELD-QA: A Large-Scale Dataset for Visual Evidence Grounding and Question Answering in Long Documents

  • 作者：Zhivar Sourati、Marianne Menglin Liu、Rongguang Wang、Zheng Wang、Yazhe Hu、Lan Guo、Yuying Wang、Mengqing Guo、Bhavesh Dnyaneshwar Gore、Shubham Pathak、Ramapriya Ranganath、Sandeep Sharma、Tao Sheng、Sujith Ravi、Dan Roth
  • 来源/分类：arXiv，AI / 长文档视觉证据定位与问答
  • 直接 PDF：PDF
  • 核心问题：长 PDF 问答失败究竟来自没有找到证据页，还是找到了页面却没有正确读懂图表、表格和复杂布局？
  • 方法与基线：VELD-QA 包含 15,000 个全人工问答，覆盖 5,859 份真实 PDF、372,445 页，并为问题标注支持页、视觉元素及其描述。作者评估 9 个 VLM 的 question-only、gold pages、top-3 RAG 和 all-pages 四种证据条件，还比较 7 个检索增强或 agent 系统。准确率由固定 rubric 的 Gemini 2.5 Flash judge 评估，并用 GPT-5.5 对 3,323 个分层答案做一致性检查。
  • 关键结果：没有文档时最高准确率不超过 21.4%；给出金标准证据页后，9 个模型为 39.1%–81.7%，Claude Opus 5.5 达到 81.7%，但仍有 9.2% 的问题没有被任何模型完整回答。GPT-6 Astra 的 gold-pages/all-pages/top-3 RAG 分别为 80.2%/75.4%/72.5%，Claude Opus 5.5 为 81.7%/79.1%/74.9%；视觉检索器在非图表问题上 top-3 找到金标准页面的比例为 83%–88%，证据跨两页以上时 Recall@3 下降约 15 个百分点。加入视觉元素标注使差距缩小 17%–24%。
  • 创新、局限与失败条件：把检索、证据使用和视觉解释拆成可测组件，避免只报一个端到端分数。结果也显示“把整份 PDF 都喂给模型”不一定优于精确证据页，且 agent 增益伴随更高 token 成本；LLM judge、闭源模型、PDF 分布和长文档的人工标注方式仍会影响可复现性，表格问题是所有模型的硬失败区。
  • 适合谁读：做文档 agent、RAG、表格/图表理解和评测设计的人。建议先读第 3 节数据与证据标注、第 4 节 agent 设置、第 5 节检索与问答结果，以及附录 C/F 的 judge 和检索控制。
  • 证据状态：已核阅摘要与 PDF；以上为论文报告，尚未独立复算。

Shortcut Sensitivity in Agent-Safety Evaluations

  • 作者：Hasan Demirkiran、Jens Ernstberger
  • 来源/分类：arXiv，AI / agent 安全评测有效性
  • 直接 PDF：PDF
  • 核心问题：安全 benchmark 的标签或格式线索是否让 guard 看起来很准，却没有测到真正的安全属性？更强的问题是：只改这些线索，guard 的决策会不会改变？
  • 方法与基线：论文提出三级 shortcut audit：标签可预测性、公开记录中的 guard 关联、保持候选动作不变的成对决策敏感性。作者审计 LinuxArena、AgentDojo-Traj 和 AgentHarm-Traj，并在冻结的 64 条 AgentDojo-Traj 样本上对 <INFORMATION> 标记和工具别名做重复交错调用，同时加入格式 placebo；比较 mixed-domain 与 domain holdout、row weighting 与 equal-interaction weighting。
  • 关键结果：LinuxArena 中命令长度的 AUC 达到 .910；AgentDojo-Traj 的 exact-tool lookup F1 从混合域的 .901 降到 domain holdout 的 .495；AgentHarm-Traj 的 TS-Guard F1 在改变评测单位后从 .902 降到 .719。对 Haiku，改写 marker 使 blocking 下降 8.33 个百分点，工具别名使 blocking 上升 11.46 个百分点；所有 unsafe call 仍被阻断，变化主要是继承标签下的 false positive。Luna 的对应效应为 0.00 和 +1.04 个百分点，确定性 Q8 TS-Guard 仅改变 64 对中的 3 对。
  • 创新、局限与失败条件：它把“标签容易预测”与“guard 真依赖该线索”分开，并用成对干预和 placebo 避免把相关性误当敏感性。限制是 64 条样本不是概率抽样，区间是探索性且未多重校正；marker 和别名可能改变语义，Luna 不复现 Haiku 效应，研究评测有效性而非真实部署安全，也没有执行工具调用。
  • 适合谁读：做 agent safety、benchmark 设计、红队评测和分布外泛化的人。建议先读第 2 节审计框架、第 4–5 节数据和干预结果、第 8 节限制。
  • 证据状态：已核阅摘要与 PDF；以上为论文报告，尚未独立复算。

SciΠvot: Benchmarking Principal-Investigator Judgment at Pivotal Moments of Scientific AutoResearch Agents

  • 作者：Youran Sun、Xingyu Ren、Chugang Yi、Di Wu、Yingkang Cao、Allen Zhou、Jianping Ye、Suying Liu、Jiaxuan Guo、Jianda Du、Weicheng Ye、Kecheng Liu、Hefan Zhang、Haixin Wang、Jie Xiao、Eric Yang、Haizhao Yang 等
  • 来源/分类：arXiv，AI / 科学自动研究 agent 评测
  • 直接 PDF：PDF
  • 核心问题：科学 agent 能长期运行实验，并不代表它能在关键节点判断“原计划还是人工修正计划更合理”；这种研究判断能否被系统评测？
  • 方法与基线：SciΠvot 从 6 个月、26 个项目、6 个科学领域的研究记录中构造 248 个案例。每个案例只给模型修正前可见的项目记录，让它在原 LLM 方案和资深研究者修正方案之间选择；评估 5 个 frontier 模型的不同 reasoning effort、是否提供项目记录和两轮 reconsideration，并用选项顺序反转、每案例等权和 10,000 次 paired bootstrap。另以 13 名博士生/博士后组成 fresh-researcher 参照。
  • 关键结果：在 project condition 下，五个模型的中等 effort 平均准确率为 39.2%，四个模型低于随机水平；最佳观察条件是 Astra 的 xhigh，准确率 63.5%，仍低于 fresh researchers 的 73.4%。在中等 effort 下，加入项目记录反而使每个模型相对于 options-only 降低准确率，reconsideration 也没有稳定改善；49 个案例中五个模型都选择被人类否决的原计划。
  • 创新、局限与失败条件：基准测的是“识别已发生的科学纠错”，而不是让模型事后生成漂亮解释；项目记录来自真实研究监督，能保留上下文与判断的不确定性。局限是案例由资深研究者选择且来自 CPU/GPU 计算研究，未覆盖湿实验和专用商业软件；fresh-researcher 样本也不是长期 PI 监督基线，结果不能直接外推到所有科学 agent。
  • 适合谁读：做 AutoResearch、科学 agent、研究流程自动化和人机协同评测的人。建议先读第 3 节案例构造、第 4 节主表、第 5 节上下文效应和第 9 节限制。
  • 证据状态：已核阅摘要与 PDF；以上为论文报告，尚未独立复算。

RICE-Alpha: Reliability-Informed Correction with Event Graphs for LLM-Agent Stock Forecasting

  • 作者：Tong Liu、Lanmiao Liu、Xiang Hu
  • 来源/分类：arXiv，双主题：AI / 金融 LLM agent 股票预测
  • 直接 PDF：PDF
  • 核心问题：新闻不是独立样本，而是同一发行人持续演化的事件；在严格 point-in-time 约束下，如何判断历史事件延续是否比当前多视图预测提供了增量信息？
  • 方法与基线：RICE-Alpha 先用 sentiment、technical、fundamental、macro 视图生成 Base Alpha，再用 Multi-Tier Memory Layer 注入时间上可用的发行人历史。Typed Event Agent 在发行人内部形成事件 successor 关系，只有在本地配对后才跨公司汇总；成熟转移按频率、regime lift、滞后和后续收益关联做可靠性校准，并对 Base Alpha/technical view 残差化得到 RICE Delta。作者在 2024–2026 年 Nasdaq-100 和 Hang Seng 日频面板上，以 2023 年 warm-up 后的 T+1 规则比较 MEME、R&D-Agent-Quant、AI Hedge Fund 和动量基线。
  • 关键结果：美国 562 个、香港 551 个评估日期上，作者报告 RICE 的 IC/RankIC 为美国 0.0350/0.0360、香港 0.0283/0.0395；净 Sharpe 为 1.656/1.725，而最佳基线为 0.889/1.130。美国消融中 IC 从不含主要组件的 0.0064，经 memory 0.0191、直接修正 0.0260，升至完整系统 0.0350；Newey–West 与 5,000 次 block bootstrap 的 Holm 校正用于比较。提高到每边 20/28 bp 成本后，作者仍报告 Sharpe 1.551/1.659。
  • 统计与经济边界：IC/RankIC 是横截面预测相关性，不是事件图导致收益的因果估计；Newey–West 显著性和 block bootstrap 也只对应作者的面板与组合协议。2024–2026 是 warm-up 后的样本外评估，但组合仍是规则化回测，不是实盘成交、容量、冲击或延迟验证。论文承认只覆盖两个大盘股票池，评估期选择可能偏乐观，预训练 LLM 可能含有晚于预测日期的信息，存在数据污染/前视风险。
  • 创新、局限与失败条件：把 issuer-local chronology、可靠性校准和残差修正分开，能比“把所有历史新闻塞进 prompt”更清楚地问增量信号来自哪里；但事件抽取、模型版本、市场状态和股票池变化都可能削弱迁移。Sharpe 是作者回测结果，不能推出未来收益或投资建议。
  • 适合谁读：做金融 agent、事件驱动预测、量化评测和 point-in-time 数据审计的人。建议先读第 3 节方法、第 4.1–4.3 节回测/消融、第 6 节限制。
  • 证据状态：已核阅摘要与 PDF；以上是作者在指定回测协议下的报告，尚未独立复算。
  • 相关链接：摘要页 · DOI
