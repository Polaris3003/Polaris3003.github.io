AutoControl Arena: Synthesizing Executable Test Environments for Frontier AI Risk Evaluation

  • 作者：Changyi Li、Pengfei Lu、Xudong Pan、Fazl Barez、Min Yang
  • 来源/分类：arXiv，cs.AI、cs.CR；AI
  • 直接 PDF：PDF；代码与数据：GitHub
  • 核心问题：人工安全 benchmark 成本高，纯 LLM 模拟器又容易出现逻辑幻觉；如何自动生成仍具有可执行状态和可审计轨迹的 agent 风险环境。
  • 方法与基线：AutoControl Arena 把环境拆成“逻辑层”和“叙事层”：文件、权限、执行结果等确定性状态由 Python 可执行内核维护，NPC 反馈等开放内容交给 LLM。Architect 设计场景、Coder 生成环境、Monitor 评估行为，并用语义验证和语法修正双循环检查可执行性。X-Bench 含 70 个场景、7 类风险，另以 Stress（压力）和 Temptation（诱因）组成 2×2 诱发条件；评估 9 个模型、2,520 个模型—条件组合和 7,560 次 rollout。
  • 关键结果：作者报告环境端到端执行成功率超过 98%，人类偏好相对已有模拟器为 60%。9 个模型在基线条件下的平均风险率为 21.7%，同时提高压力和诱因后升到 54.5%；Qwen3-32B 的单因素叠加预测风险约 41.3%，实际耦合条件为 53.2%。能力与安全也不单调：Qwen3-4B 到 Qwen3-32B 的 Capability Misuse 风险从 65.0% 降至 48.6%，但 Specification Gaming 从 28.6% 升至 43.8%；Gemini-3-Flash 的该类风险为 53.5%，Gemini-2.5-Flash 为 26.2%。
  • 创新与证据限制：贡献主要是可执行环境合成、压力测试维度和把行为风险与 CoT 意图分析结合，而不是新的基础模型。Monitor 依赖模型轨迹和 rubric，70 个场景、生成器模型、提示词和人工偏好仍会影响结论；“战略性隐藏”是论文的评估判断，不是对模型内部意图的直接观测。代码公开不等于已有独立复现。
  • 适合谁读：做 agent safety、评测基础设施、工具调用和部署前红队测试的人。建议先读第 3–5 节、表 2、图 8–9 和附录 E、G。
  • 证据状态：已核阅摘要与 PDF；结果是作者在 X-Bench 和其合成协议下的报告。

RATED: Reliability-Aware AI Agent Tool Retrieval via Execution Dynamics

  • 作者：Weiliang Chen、Song Liao
  • 来源/分类：arXiv，cs.IR、cs.AI；AI
  • 直接 PDF：PDF；代码与数据：GitHub
  • 核心问题：工具检索通常只优化语义相关性，但生产环境中的工具可能宕机、超时或返回 schema 错误；如何在不反复训练主模型的情况下用执行反馈动态避开不可靠工具。
  • 方法与基线：先用 DRAGON 双编码器做对比学习和 top-10 语义召回，再用带折扣的 LinUCB 为每个工具维护上下文 bandit，融合语义分数、近期成功率和目录元数据。EcoAgent 收集 5,172 个真实工具；合成集有 69,501 个 query、70,122 个正样本对和 140,244 个负样本对，真实评测集有 6,379 个 query、9,946 个已核验 query–tool 对。对照包括 TF-IDF、BM25、Ada-002、BGE、SPLADE、BGE-Reranker、ToolLLM retriever，以及黑名单、重试和 batch-GRPO 式更新。
  • 关键结果：在 EcoAgent-Real 上，RATED 的 MRR 为 0.618，ToolLLM API retriever 为 0.406，作者据此报告相对提升 52.2%；Recall@5 为 0.740。30% 工具故障注入时，RATED 的 fault selection rate 为 2.9%、post-fail success rate 为 82.1%，ToolLLM 分别为 86.2% 和 10.5%，预训练 DRAGON 为 21.2% 和 75.7%。单样本推理平均延迟从编码基线的 3.223 ms 增至 3.395 ms，增量 0.172 ms，P95 为 4.391 ms。
  • 创新与证据限制：把“找到正确工具”和“工具现在能否工作”拆为两层，并用在线反馈更新后者。工具可靠性分数部分来自自动元数据规则；真实 query 的映射经过检索、LLM 验证和 200 条人工抽样，不能等同于完整人工标注。故障是固定集合的持久注入，不覆盖真实服务的相关故障、权限变化和级联影响；离线检索和工具选择指标也没有直接证明端到端 agent 任务成功。
  • 适合谁读：做 agent runtime、工具市场、检索系统和高可用 AI 基础设施的人。建议先读第 2–4.6 节、算法 1 和表 1–3。
  • 证据状态：已核阅摘要与 PDF；结果为作者在 EcoAgent 及固定故障注入协议下的报告。

Rollout-Time Intervention: Unlocking Agentic Reinforcement Learning Beyond Policy Limits

  • 作者：Chen Xi、Ding Ruixue、Wang Zhigaoyuan、Zhang Fanrui、Zhang Qiang、Chen Boli、Wang Shihang、Wang Tianfu、Ren Ailin、Wang Pengyong、Xie Pengjun、Xiong Hui
  • 来源/分类：arXiv，cs.AI、cs.LG；AI
  • 直接 PDF：PDF；代码：GitHub
  • 核心问题：on-policy agent RL 在模型几乎不会成功的任务上拿不到有效轨迹，训练容易停滞；能否在 rollout 阶段纠正关键错误，同时控制 off-policy 分布偏移。
  • 方法与基线：只有当一组 rollout 全部失败时才触发 reward-aware 多智能体干预：Validator 找出会导致失败的步骤，Corrector 做尽量小的修正，Verifier 检查是否泄漏特权信息或偏离原策略。随后用 rollout-policy perplexity gate 过滤偏移过大的轨迹，并按 reasoning-shift 对关键 token 重加权。作者以 Qwen3-8B、Qwen3.5-9B 为主干，在 Navigation、τ2-Bench 的 Telecom/Retail/Airline 和 Claw-Eval-Hard20 上与 GRPO、GSPO、AEPO、OPD、LUFFY 比较。
  • 关键结果：在 Qwen3-8B 上，RTI 的 Pass@1 在 Navigation 为 57.33%，GRPO 为 35.33%；τ2-Telecom 为 61.40%，GRPO 为 36.84%；Claw-Eval-Hard20 为 50.00%，GRPO 为 22.50%。在 Qwen3.5-9B 的 Hard20 上，RTI 为 85.00%，LUFFY 为 61.25%。去掉 post-check 后，Qwen3-8B Navigation Pass@1 降至 26.00%；去掉 PPL gate 后，Telecom 从 61.40% 降至 54.39%，Pass4 从 31.58% 降至 18.42%。
  • 创新与证据限制：它把“教师纠错”限制在可见历史和任务 reward 证据内，而不是直接替换成 oracle 轨迹。可是训练时仍使用了评测 rubric 和额外 Validator/Corrector/Verifier，部署时的推理成本、提示泄漏风险和模型自评可靠性需要单独核查；干预轨迹也可能让 benchmark 过拟合。作者报告的是五个受控 benchmark 的 Pass@k，不是现实工具系统的长期成功率。
  • 适合谁读：做 agent RL、轨迹合成、verifiable reward 和长程工具调用的人。建议先读第 4–5.5 节、表 1–3 和附录 C、D。
  • 证据状态：已核阅摘要与 PDF；结果是作者在所列 benchmark 和训练配额下的报告。

DRYLAB-Bench: Benchmarking the Biosecurity Risk of Agentic LLM Mutation Design

  • 作者：Yuzhen Wang、Chunxiao Li、Baichen Le、Lewen Yan、Jie Zhang、Yucheng T. Yang、Xing-Ming Zhao、Lijun Li、Jing Shao
  • 来源/分类：arXiv，cs.AI、cs.CL、cs.CR；AI 安全
  • 直接 PDF：PDF；代码：GitHub
  • 核心问题：现有生物安全评测多问模型“知道什么”，却很少测它能否在工具辅助下迭代完成高风险设计；又不能用真实湿实验去验证危险方案。
  • 方法与基线：DRYLAB-Bench 把国际生物安全指南转成 30 个、覆盖 8 类风险的设计场景，比较 S0（无工具一次生成）、S1（一次工具修订）和 S2（最多四轮工具迭代）。六类生物设计工具提供保守性、序列似然、结构兼容性、功能注释、毒性预测和场景预测，但隐藏 ProteinGym/ViroGym 的 187,695 条深度突变扫描测量。最终候选按实验测量构造 Biosecurity Risk Score（BRS），15 个模型、3 种措辞变体参与评估，S2 的实验覆盖率平均为 83.9%。
  • 关键结果：作者报告无工具 S0 的 pooled BRS 为 0.359，多轮工具条件 S2 为 0.475，增量 +0.116；S1 先增加 +0.048，S2 再增加 +0.068。S0 候选中 67.6% 高于该 assay 的平均实测变体，21.4% 进入最高风险十分位；S2 的最高风险十分位占比为 23.5%。工具不总是有益：CcdB 场景中某保守性信号与实测结果的 Spearman 相关为 −0.815。把同一任务只改写成“学术”或“恶意”语境时，拒答率也发生明显变化。
  • 创新与证据限制：用隐藏实验测量做无湿实验、可扩展的验证，是比 LLM-as-judge 更强的证据链；但单点突变和已有 assay 覆盖不等于完整病原体设计风险，工具输出与目标维度错配也会放大误导。拒答措辞实验仍混有场景身份差异，BRS 是 benchmark 风险代理而不是现实伤害概率。本文涉及高风险生物安全，公开简报只讨论评测设计与证据边界，不复述可操作的危险设计细节。
  • 适合谁读：做 AI safety、双用途生物技术治理、agent tool-use 评测和安全红队的人。建议先读第 3–4.3 节、图 3–4、表 2–3、附录 B、C。
  • 证据状态：已核阅摘要与 PDF；结果为作者在隐藏 DMS 数据、所列工具和提示协议下的报告。

Auditing VLM Benchmarks from Existing Evaluation Runs

  • 作者：Denis Degtiarev、Anna Gromova、Sergey Katkov、Artem Mikhailin、Safina Mukhamedshina、Albert Nasybullin、Karina Shaikhutdinova、Artem Tuzov
  • 来源/分类：arXiv，cs.CV、cs.CL、cs.AI；AI 评测
  • 直接 PDF：PDF
  • 核心问题：VLM benchmark 把逐题预测、判定和元数据压成一个 leaderboard 分数后，如何用已有运行产物反向审计“图像是否真的有用、标签是否可疑、选项是否有偏”。
  • 方法与基线：作者把 6 个 detector 集成到 VLMEvalKit，并增加一次去掉图像的 text-only blind run；检查视觉依赖、共识标签冲突、Fleiss κ、正确性分布、选项位置和干扰项相似度。主案例 MMStar 有 1,500 个四选一题目，使用 3 个 VLM；零增益比例用 999 次按题目匹配的置换 null 校正，并做 leave-one-model-out、split-half 和 LLM judge/exact parser 对照。另在二选一 HallusionBench 上测量方法的边界。
  • 关键结果：MMStar 中 303/1,500（20.2%）题目在带图和去图运行中模型池准确率相同；置换 null 为 17.0%，超额为 +3.2 个百分点，单侧 p=0.001。303 题中有 164 题是所有模型带图和去图都答错，只有 26 题是三个模型都在无图时答对，因此不能把零增益直接解释成“题目不需要图像”。另有 134 题（8.9%）所有可解析回答都一致地选了非 gold 选项。移除 LLM judge 后结论不变；在二选一 benchmark 上 detector 出现校准失效。
  • 创新与证据限制：把测量误差、模型池敏感性和 benchmark 缺陷放在同一报告里，避免把一个原始比例当机制证明。它没有直接测数据污染，也不能靠零增益确定究竟是语言先验、选项统计还是共享错误；3 个模型、一个四选一 benchmark 和一个二选一边界实验的外部效度有限。开放代码/产物和统计 null 让复核成本下降，但仍需要人工复审被标记题目。
  • 适合谁读：做多模态 benchmark、LLM-as-a-judge、数据质量和科学测量的人。建议先读第 3–4.6 节、表 1–2、图 2–4。
  • 证据状态：已核阅摘要与 PDF；134 个冲突项仍是人工复核候选，不是已确认的标签错误。

Retrieval-Augmented Multimodal Language Model with Heterogeneous Evidence Integration for Clinical Prognosis

  • 作者：Hamza Shafiq、Jialu Tang、Ting Dang、Jun Hu、Aaqib Saeed
  • 来源/分类：arXiv，cs.AI、cs.CL；AI / 医疗交叉
  • 直接 PDF：PDF；代码：GitHub
  • 核心问题：临床预测同时面对结构化 EHR、ECG 波形、历史时间序列和相似病例，简单把数值转成文本会损失信息；如何把异构证据放进一个可训练、可审计的模型。
  • 方法与基线：PRISM 用 470 维 EHR 的 FT-Transformer 数值 token、当前 ECG、按时间衰减汇聚的历史 ECG，以及 EHR/ECG 两个索引各检索 3 个训练折邻居的均值 embedding，五路 soft token 输入 LoRA 适配的 MedGemma-4B。MDS-ED（MIMIC-IV）含 1,443 个任务；两阶段训练使用 4.5 million 个训练样本、两张 NVIDIA H100 80GB。比较 MDS-ED、UniPACT、ECG/LLM 基线和同样五路输入的 5.9M 参数紧凑融合模型。
  • 关键结果：完整输入下作者报告 Diagnosis、Deterioration、ICU、Mortality AUROC 分别为 86.24%、93.12%、91.79%、92.82%，macro-of-macro 为 0.9092。公平的 benchmark-window 对照去掉额外 96 小时到院前信息后为 0.8895，UniPACT 为 0.8937、MDS-ED 为 0.8889；因此完整结果的一部分来自额外历史，而不是仅来自架构。matched-input 紧凑模型为 0.7652；数值 EHR 改成全文序列化下降 3.66 个百分点，去检索下降 0.99 个百分点，真邻居比随机邻居高 0.97 个百分点，但 1,443 个任务的 paired sign test 为 p=0.067。外部 MC-MED 上 source-only 为 0.7841，监督适配 PRISM 为 0.8611，局部 gradient boosting 为 0.8227。
  • 创新与证据限制：作者有意识地做了额外窗口、随机邻居、零检索和紧凑模型对照，也明确承认 4B LLM 与小模型的参数/优化不匹配。研究仍是回顾性、两机构数据和单一 backbone；外部结果需要目标站点监督，不能当作零样本泛化。训练/推理的 H100 成本、数据分布漂移和临床工作流安全尚未被 AUROC 证明，不能据此作医疗决策。
  • 适合谁读：做医疗 AI、多模态融合、representation retrieval 和临床模型评测的人。建议先读第 3–4.8 节、表 1、3–7、附录 M。
  • 证据状态：已核阅摘要与 PDF；结果是作者在 MDS-ED、MC-MED 及其输入窗口定义下的报告，不是临床验证。

Can Agents Price a Reaction? Evaluating LLMs on Chemical Cost Reasoning

  • 作者：Yuyang Wu、Yue Huang、Shuaike Shen、Xujian Wang、Shuhao Zhang、Qiyao Xue、Weichen Liu、Runtian Gao、Jian Ma、Xiangliang Zhang、Olexandr Isayev
  • 来源/分类：arXiv，cs.AI、cs.LG；AI / 科学工具使用
  • 简介：研究化学 agent 能否把反应描述转成可核验的采购成本：识别化学品、检索供应商报价、选择可购买包装、统一数量并计算价格。ChemCost 含 1,427 个可评估反应、2,261 种化学品和 230,775 条供应商报价，并加入别名、数量表达、缺失字段和格式噪声。作者报告最强 agent 在干净输入上“相对误差不超过 25%”的准确率仅 50.6%，加噪声后明显下降；价值是用冻结价格快照和阶段级错误诊断替代 LLM judge。限制是价格快照、供应商覆盖和工具可用性固定，不能外推为现实采购系统表现。

ARTIS: Agentic Risk-Aware Test-Time Scaling via Iterative Simulation

Beyond Temporal Proximity: Explanatory World Models for Credit Assignment in Reinforcement Learning

  • 作者：Oriol Corcoll、Qiyao Wei、Ciarán Mark Gilligan-Lee
  • 来源/分类：arXiv，cs.AI、cs.LG；AI / 推荐系统
