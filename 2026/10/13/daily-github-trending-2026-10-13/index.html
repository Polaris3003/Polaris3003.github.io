今日要点

今天最清晰的一条线，是 Agent 正从“会调用工具”转向“能管理证据与状态”：REA把逆向分析结果连同证据和限制返回，Context Mode把大段工具输出留在沙箱与本地索引里，Diagram Design则把版式规则固化为可复用的 Agent Skill。值得学习的不是某个提示词，而是输入、过程和复核边界如何成为系统的一部分。

第二条线是把现实世界与创作过程做成可操作的界面：God's Eye View把飞机、船舶、卫星、地震和公共摄像头放到 3D 地球上，ArtCraft把 2D 合成、3D 场景和多家生成模型组织成桌面 IDE。两者都提醒人，数据来源、第三方条款、API 配额和模型可用性，才是 Demo 之外真正决定能否长期使用的部分。

最后是计算约束本身：AirLLM用分层加载把大模型拆成显存可承受的工作集，bitnet.cpp则从 1-bit 权重和 CPU/GPU kernel 方向压低推理成本；Open WebUI把本地与云端模型接入同一套自托管界面。它们共同说明，模型能力之外，运行时、数据持久化、硬件和许可边界同样值得研究。

值得尝试

morluto/rea

REA通过 MCP 把 Agent 接到原生二进制、JavaScript/Electron、.NET、网站等分析目标，在本地返回结论、证据与限制，适合安全研究、互操作和学习可追溯的逆向工作流。它要求 Node.js 22.19+ 等环境，原生分析还需要 Hopper、Ghidra 或 IDA；项目采用 MIT，最新 Release 是 rea-agents v6.4.0，最近提交见 ca2d15b。日榜快照显示主要语言为 TypeScript，当日新增 45,327 stars、总 stars 160,713。

bilawalsidhu/gods-eye-view

God's Eye View把航班、船舶、卫星、地震、天气和公共摄像头等公开信号放进可交互的 3D 地球，并提供语音控制与可扩展的数据层，适合学习 GEOINT/OSINT 数据融合和 WebGL 地图界面。它可以无 API key 启动，但更高质量的 3D 地形和部分搜索能力涉及 Cesium/Google 的配额与条款；代码的 MIT许可不覆盖第三方数据、模型和运行时数据源，细节见 DATA_SOURCES.md。最新 Release 是 v0.2.1，最近提交见 8b8ccc9；日榜快照显示主要语言为 JavaScript，当日新增 1,895 stars、总 stars 53,766。

mksglu/context-mode

Context Mode是面向编码 Agent 的 MCP server：把工具输出放进隔离子进程，只把必要的 stdout 带回上下文，并用本地 SQLite FTS5/BM25 索引保存会话状态和相关片段。它适合经常处理日志、代码库和长会话的人；限制是各宿主的 hook 能力不同，项目数据会写入本机 ~/.context-mode/content/，而 Elastic License 2.0禁止把它作为托管/管理服务提供。最新 Release 是 v1.0.169，最近提交见 1a1bed1；日榜快照显示主要语言为 TypeScript，当日新增 246 stars、总 stars 27,340。

storytold/artcraft

ArtCraft把交互式 AI 图像与视频创作做成桌面 IDE：可以在 2D 中合成、在 3D 中布景，并选择图像、视频、声音、网格和世界等模型工作流，适合艺术家、设计师和影视创作者研究可重复的构图与镜头控制。稳定下载主要面向 Windows/macOS，Linux 需要从源码构建，模型和提供商的可用性、价格以及受限模型仍需逐项核对；项目按 MIT 或 Apache-2.0 双许可。最新 Release 是 ArtCraft v0.41.0，最近提交见 d4e4ac6；日榜快照显示主要语言为 Rust，当日新增 4,095 stars、总 stars 22,228。

open-webui/open-webui

Open WebUI是可自托管、可离线运行的 AI 平台，连接 Ollama 与 OpenAI-compatible API，并把插件、MCP、Agent、RAG、权限和多模型对话放进同一界面，适合搭建个人或团队的模型工作台。它的 Docker、GPU、数据库、对象存储和外部模型能力需要分别配置，README 也明确标注 :dev 镜像不稳定；项目采用带 Open WebUI 品牌约束的自定义许可，历史代码的适用条款见 LICENSE 与 LICENSE_HISTORY。最新 Release 是 v0.12.0，最近提交见 f8ae8a6；日榜快照显示主要语言为 Python，当日新增 157 stars、总 stars 155,068。

cathrynlavery/diagram-design

Diagram Design是面向多种 Agent 宿主的技能包，当前 README 列出 45 类图表，输出可双击打开的单文件 HTML 与内联 SVG，并支持从 Mermaid、draw.io 和 Excalidraw 导入、导出 SVG/PNG。它适合制作需要品牌化和版式约束的发布型图表；已知限制是输出质量依赖模型、同一提示可能产生不同布局，结果不是可在 Git 中逐行比较的源格式，持续变更的技术文档仍更适合 Mermaid。项目采用 MIT，最近提交更新了 2.6.88 插件清单；日榜快照显示主要语言为 HTML，当日新增 2,081 stars、总 stars 52,706。

lyogavin/airllm

AirLLM通过分层加载和流式处理，让 GPU 一次只保留一个模型层，并提供在小显存设备上训练适配器的路径，适合研究“大模型规模受限时如何换取显存、磁盘和时间”的工程取舍。它不是无条件的 4GB 魔法：不同模型需要匹配 Transformers、CUDA、Flash-Attention 和磁盘空间，门控模型还需要 Hugging Face token，README 中的显存数字不能直接推广到任意硬件；项目采用 Apache-2.0。最新 Release 是 v4.0.0，最近提交见 7bb8a86；日榜快照显示主要语言为 Jupyter Notebook，当日新增 879 stars、总 stars 37,583。

microsoft/BitNet

bitnet.cpp是 Microsoft 的 1-bit LLM 推理框架，提供面向 CPU/GPU 的优化 kernel，并围绕 BitNet b1.58 与 1-bit embedding 模型探索更低的内存和能耗，适合学习量化模型、边缘推理和硬件相关优化。它的性能与可用模型取决于 CPU/GPU 架构、kernel 和模型组合，README仍把 NPU 支持列为后续方向；最近提交是 2026-07-27 的 VibeASR.cpp 发布说明，代码采用 MIT。日榜快照显示主要语言为 C++，当日新增 97 stars、总 stars 40,931。
