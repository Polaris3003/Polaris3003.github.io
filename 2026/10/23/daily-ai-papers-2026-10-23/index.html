DiffResearch: Accelerating Deep Research with Diffusion Language Models

  • 作者：Alan-Barsag Gazzaev、Alexey Gavrilov、Mikhail Mozikov、Sergey Muravyov。
  • 来源/分类：arXiv cs.AI；论文称已接收 EMNLP 2026 Industry Track。
  • 核心问题：深度研究 agent 的规划、检索、综合和写作都在关键路径上逐 token 生成，如何在不牺牲报告质量的前提下减少端到端等待？
  • 方法与基线：作者固定多 agent 脚手架、检索代码、提示词和评测，只替换骨干模型；用 diffusion 模型 DiffusionGemma-26B-A4B-it 与可比的自回归 Gemma-4-26B-A4B-it，对 100 个 Deep Research Bench 博士级任务（中英文各 50、覆盖 22 个领域）进行比较。dFast 进一步在中间去噪状态读取子查询，用 Gemini 2.5 Pro 做 RACE 评分，并做人工引用审计。
  • 关键结果（论文报告）：扩散配置 dFull/dFast 的平均端到端延迟为 11.89/11.97 秒，自回归基线为 71.45 秒；p90 为 16.13/16.33 对 111.87 秒，规划阶段约从 39.32 秒降到 3.68/3.64 秒，写作阶段约从 59.78 秒降到 5.11/5.29 秒。dFast 的子查询分解中位数延迟为 243.4ms，对比完整解码的 484.9ms；最终输出质量 RACE 为 dFull 0.3895、dFast 0.3969、AR 0.3904，作者给出的配对区间包含零。10 份报告的人工审计仅有 14/50 条主张完全得到支持，26/50 条未被建立；76 条引用中 41 条完全蕴含、14 条不蕴含。
  • 创新、局限与失败条件：贡献是把并行去噪的速度优势放进完整研究系统，而不是只报单轮生成速度；但实验只有一组模型替换、H200 环境和 Semantic Scholar 检索，且 dFast 主要适合查询分解，系统级提升并不稳定。报告质量仍受检索和引用质量限制，榜单快照也不能当成扩散骨干的因果证据。
  • 适合谁读：深度研究 agent、LLM serving、检索与引用可靠性研究者。建议优先读系统设计、实验设置与延迟表，再读引用审计和局限性。
  • 证据状态：已核读摘要页与 PDF；数字与质量结论均为作者报告，未作独立复现实验。
  • 相关链接：摘要页 · PDF · 代码 · arXiv DOI

TabAgent: Distilling LLM Agent Components into Cheap Classifiers

  • 作者：Ido Levy、Segev Shlomov、Avi Yaeli、Nir Mashkif、Asaf Adi、Yinon Goldshtein、Eilam Shapira、Leshem Choshen。
  • 来源/分类：arXiv cs.AI。
  • 核心问题：工具、技能和应用选择等 agent 内部的封闭集决策，是否可以从成功轨迹中蒸馏为低成本分类器，而不是每次调用大语言模型？
  • 方法与基线：TabSchema 把状态、schema 和依赖关系转成结构化特征，TabSynth 做 schema 对齐的改写，TabHead 用 CatBoost 等表格模型做决策；实验覆盖 3 类决策、7 个 benchmark/8 个任务，并与 GPT-5.4 短名单器及小型生成模型比较。
  • 关键结果（论文报告）：在 AppWorld 工具短名单任务中，TabHead 单次调用约 2.682ms、成本约 2.0×10^-7 美元，对比 GPT-5.4 约 7.50 秒、0.052 美元；作者据此报告约 99.96% 延迟下降和 99.9996% 成本下降。SkillsBench 的 P@R80/Recall@9 均为 91，Mind2Web 操作选择 F1 为 92，应用选择 macro-F1 为 97。真正放入 AppWorld 的 24 个跨应用留出任务中，TabAgent Pass@1 为 27.1%，GPT 短名单器为 29.2%，差值 -2.1 个百分点，95% 区间为 [-18.8,+16.7]，包含零；低置信度回退到 LLM 的 AUROC 为 0.88。
  • 创新、局限与失败条件：把 agent 决策显式化为可审计的结构化特征，并让分类器只处理闭集选择；但它依赖成功轨迹池，主要是同一脚手架内的分布内问题，遇到新工具、新 schema 或不同 agent 架构不能直接外推。抽样在线任务很小，模型仍继承轨迹数据偏差。
  • 适合谁读：agent 基础设施、工具路由和成本优化工程师。建议优先读特征流水线、跨脚手架迁移、消融和在线热切换实验。
  • 证据状态：已核读摘要页与 PDF；成本、延迟和任务分数是作者报告的 benchmark 结果，不等于所有生产流量的真实成本。
  • 相关链接：摘要页 · PDF · 代码 · 项目页 · arXiv DOI

From Reasoning to Action: Benchmarking Frontier AI Models on LIBERO-10 Robot Manipulation Tasks

  • 作者：May Espinola、Qifan Zhang、Yu Xiang。
  • 来源/分类：arXiv cs.RO、cs.AI；技术报告。
  • 核心问题：前沿通用模型在没有任务专门训练、示范或预训练技能时，能否把视觉推理稳定转化为仿真机器人操作？
  • 方法与基线：统一闭环 zero-shot 协议，Franka Panda 以 20Hz 接收两路 256×256 相机和本体感知，模型只能调用 move_to/done/give_up；六个模型、三档 reasoning effort、18 个配置，每配置 100 回合，共 1,800 回合。论文还讨论 Octo、OpenVLA、pi0.5、UniVLA、UniAct 等传统机器人策略，但没有在同一协议下完成微调 VLA 的直接竞赛。
  • 关键结果（论文报告）：总体成功率为 22.2%（400/1,800）；最高为 GPT-6 Astra 高推理档 44%，Gemini-4 Argon 高档 43%。最佳任务成功率为 58%，但两个需要多物体精确操作的任务为 0%。失败中模型主动停止 968 次、超出时域 195 次、达到调用/步数上限 237 次；实际位移约为指令的 64–72%，21–36% 的动作不足目标距离一半。作者报告最佳模型每回合成本约 7–8 美元，结果随模型和 reasoning effort 显著变化。
  • 创新、局限与失败条件：价值在于把模型、努力档位、调用上限、成本和失败类型放进同一闭环协议；但 LIBERO-10 是仿真环境，API 版本、价格和控制接口决定结果，没有真实机器人验证，也没有证明“更多推理”具有因果上的物理技能提升。文本中传统 VLA 只是背景基线，不能把该表格理解为公平的端到端策略排行榜。
  • 适合谁读：具身智能、机器人评测和模型服务成本研究者。建议优先读协议与表格，再读失败类型和控制误差分析。
  • 证据状态：已核读摘要页与 PDF；这是作者报告的仿真 benchmark 和成本测量，不是实机成功率或生产系统成本。
  • 相关链接：摘要页 · PDF · 项目页 · 代码 · arXiv DOI

Beyond Binary Labels: Diagnostic Evaluation of LLM Safety with Prompt-Level Rubrics

  • 作者：Hongyu Li、Xinlong Huang、Zhan Yu、Jing Zhao、Zhe Zhao、Juntao Zhong、Xiong Kuang、Rui Yuan、ZhenXiang Yan、Huilin Xu、Haitao Yu、Lilin Wang、Rui Chen、Blaze Chen、Fengzong Lian、Renfen Hu。
  • 来源/分类：arXiv cs.CL、cs.AI。
  • 核心问题：把安全性压缩成一个“拒答/不拒答”标签，无法同时发现过度拒答、部分违规和有用性损失；能否用 prompt-level rubric 做可诊断的安全评测？
  • 方法与基线：构建 84 类中英双语风险 taxonomy，覆盖普通、单轮、多轮和 jailbreak 数据，并用 DiagAttack 把有害意图嵌入正常指令外壳；每个 prompt 同时有安全条目、豁免规则和 8 项 0–3 分有用性条目。评估 11 个 8B–1.6T 开源模型，比较通用 judge、标签专用 judge 和 rubric judge。
  • 关键结果（论文报告）：表 3 中 rubric judge 的最高人类一致性为 95.34%，对照 judge 的相应值约为 69%–87%；跨 judge 一致性为 93.33%–94.78%，对应 Cohen κ 约 0.828–0.864。DiagAttack 的不安全率是 DiagBase 的 1.9–8.4 倍，11 个模型中 8 个在攻击集上的不安全率超过 40%；中文和多轮场景更高。论文强调可把“安全”和“有用”分开看，而不是奖励无差别拒答。
  • 创新、局限与失败条件：诊断维度比二元标签更接近真实部署风险；但 prompt、标签和 rubric 含有 LLM 生成成分，覆盖范围受 taxonomy 限制，实验只包含 11 个开源模型和单一推理模式，也没有覆盖工具调用 agent。
  • 适合谁读：安全评测、对齐和 judge 模型研究者。建议优先读 rubric 构造、表 3/4、攻击诊断和覆盖边界。
  • 证据状态：已核读摘要页与 PDF；一致性和不安全率为作者报告的评测结果，不能直接外推为生产安全率。
  • 相关链接：摘要页 · PDF · 代码与数据 · arXiv DOI

BIRD-RL: Scaling Agentic Reinforcement Learning over Stateful Data-Centric Environments

  • 作者：Ge Qu、Jinyang Li、Xiaohan Xu、Xiaolong Li、Bowen Qin、Nan Huo、Ziwei Tang、Chenhao Ma、Reynold Cheng。
  • 来源/分类：arXiv cs.AI、cs.LG。
  • 核心问题：SQL 调试等数据 agent 任务会改变持久化环境状态；如果复用脏数据库，强化学习轨迹就会互相污染，如何在可扩展训练中保持每条轨迹的状态隔离？
  • 方法与基线：提出 Trajectory-Scoped Persistent Execution Infrastructure，用 worker 分区数据库池、registry 和 dirty-aware lazy reset 管理环境；训练采用四阶段 curriculum：推理模仿、多轮工具使用模仿、自适应 reasoning RL、stateful agentic RL。评估 BIRD-CRITIC-SQLite 与 BIRD-ZENO，并做奖励信号和训练阶段消融。
  • 关键结果（论文报告）：数据库基础设施空间效率提高 12.8 倍；BIRD-CRITIC-SQLite 上 BIRD-TALON 7B/14B 的结果为 44.40%/48.00%，Claude-Opus-4.6 Agent 为 48.20%；BIRD-ZENO 统一模型在 dev 上 EX 为 63.90%。7B 消融中完整流程为 44.40%，只保留前 3 阶段为 40.60%，只到第 2 阶段为 39.20%，只做第 1 阶段为 35.20%；代理奖励和 LLM judge 奖励分别为 42.80% 和 41.40%，低于直接执行奖励 42.00%（不同设置不可简单横比），作者据此警告 proxy reward hacking。
  • 创新、局限与失败条件：把“持久化环境本身”作为训练系统的一等公民，并用直接执行结果做奖励；但实验围绕 SQL benchmark，数据生成使用专有 Claude-Sonnet-4.5 教师，基础设施和轨迹规模仍是主要成本，不能把 SQL 结果等同一般 agent 能力。
  • 适合谁读：agentic RL、工具环境和数据操作系统研究者。建议优先读 curriculum、状态隔离实现、主表和奖励消融。
  • 证据状态：已核读摘要页与 PDF；数字来自作者报告的 benchmark，未独立复现。
  • 相关链接：摘要页 · PDF · 代码 · arXiv DOI

Quant-Arena: Benchmarking LLM Agents for Quantitative Trading Research

  • 作者：Houde Qian、Zheng Jiang、Wenyi Li、Chenxi Xu、Xinjie Lin、Yuzhao Peng、Ruoyu Han、Youjie Zheng、Kaisen Yang、Qinhuai Na、You Fu、Calvin Xiao。
  • 来源/分类：arXiv cs.AI、q-fin.TR、q-fin.CP；与金融研究交叉。
  • 核心问题：LLM agent 是否能从原始市场数据出发，完成研究、选股、回测和冻结策略，而不是只生成看似合理的量化叙述？
  • 方法与基线：使用 3,042 只 A 股的日线与 Level-2 数据；研究期为 2022–2023 年，最多保留 5 个候选策略，冻结后在封存的 2024 年测试。执行使用前 75 只等权、现金账户、100 股整手和交易成本/模拟订单簿冲击；比较 9 个前沿模型、38 个迭代配置，并与等权市场组合对照。
  • 关键结果（论文报告）：2024 年没有模型明显超过等权市场；最佳 Sol 中档年化收益 18.4%，市场基准 17.1%，差值约 1.4 个百分点；13/38 配置为正年化收益，只有 1 个超过市场。Astra 高档年化收益 10.7%、超额收益 -6.3 个百分点、Sharpe 0.86、最大回撤 -6.8%，其收益主要来自约 70%–75% 时间持有现金，而非更好的选股。前十策略分位的表现常差于中间分位，RankIC 与年化收益的 Spearman 相关约 0.09；迭代使 9 个模型总分都上升，但只有 4 个模型年化收益上升。
  • 创新、局限与失败条件：把研究流程、策略冻结、时间隔离和模拟执行放进同一评测，能暴露“研究分数上升但收益不升”的错位；但它仍是单一年份的封存回测，不是实盘交易，订单簿冲击是模拟的，模型、harness 和推理努力也不完全同质。不能把正收益解释成因果选股能力或可持续 alpha，也不构成投资建议。
  • 适合谁读：AI agent 评测、量化研究自动化和金融机器学习研究者。建议优先读 benchmark protocol、主表、分位分析和迭代/局限部分。
  • 证据状态：已核读摘要页与 PDF；这是作者报告的样本外回测与模拟执行结果，仍需跨市场、跨时期和真实可交易成本验证。
  • 相关链接：摘要页 · PDF · 项目页 · arXiv DOI

  • 来源/分类：arXiv cs.AI、cs.SE。

  • 作者：Sukesh Kumar、Dilip Singh。
  • 来源/分类：arXiv cs.LG、cs.AI。
  • 简介：论文提出 DDF/SDSAE，用互信息、成本归一化的显著性门槛和治理输入估计数据的边际价值，并在 284,807 笔交易、5 个候选资产的欺诈检测 benchmark 上比较数据增量。作者报告只有差异化数据带来约 +0.0029 AUC（DeLong p=1.4×10^-9，Holm 校正 p=7.2×10^-9），DDS 为 +0.663，冗余数据为 -0.135；22 次权重中 19 次稳定，阈值范围为 0.15–0.66。

Agentic Video Understanding: A Survey
