Auditing evaluation artifacts and data leakage in large language model systems for rare disease diagnosis

全文核读。 作者：Jian Yang、Peilin Liu、Xiaohan Li 等。

  • 核心问题： 增强型 LLM 的罕见病诊断分数有多少来自候选病例泄漏、机构分布过拟合、病历中的事后治疗线索和知识库时间错位？
  • 方法与基线： 作者使用逾 60,000 个病例，重建 DeepRare 智能体并以 DeepSeek-V4-Flash 运行；把常见 one-vs-rest 检索与严格隔离测试集的设置比较，也比较线性、XGBoost 和 MLP 分类器的内部与外部队列表现。独立临床队列来自中国两家三级医院。
  • 作者报告的结果： 跨队列 Recall@1 从 one-vs-rest 的 54.3% ± 18.2% 降至严格隔离下的 40.3% ± 11.1%；监督分类器的平均准确率从内部 42.9% 降至外部 16.7%。这是作者对其队列和复现实验的报告，不代表所有临床 LLM 的普遍降幅。
  • 创新、限制与复现： 论文把候选空间隔离、跨数据集 PMID 去重和回顾性线索审计纳入同一评测框架。原研究使用的参考病例库并非完整公开；两家临床队列都来自中国，专有模型训练语料的污染程度也无法完全测定，因此结论应理解为评测脆弱性的证据。作者公开了本研究代码。
  • 适合谁读： 临床 AI、RAG 与基准设计研究者。建议先读系统复现和队列隔离方法，再看外部验证、文本线索消融和局限章节。

Measurement Without Validity: The Compounding Reliability Problem in Agentic AI Evaluation

全文核读。 作者：William Caban。

  • 核心问题： 智能体评测从任务构造、模拟器到自动评分，测量效度如何逐层损失？
  • 方法与基线： 提出总效度上界模型 V_total ≤ V₁×V₂×V₃，并检查 5 种基准配置及 55 篇智能体评测论文；四位独立评审复核评分者一致性指标。这里的主要比较对象是评测设计和统计量选择，不是模型能力排行榜。
  • 作者报告的结果： 论文估算若三个环节各保留 70% 效度，端到端有效信号最多约 34%（估计范围 17%–54%）；55 篇目的性样本中约 82% 的论文使用了与评分设计不匹配、不完整或缺失的评分者一致性指标；10 个常用基准中有 7 个被判定存在任务效度缺陷。以上比例是作者的审计结果，不能直接外推到所有基准。
  • 创新、限制与复现： 把任务效度、模拟器校准和自动判分可靠性分开审查，并公开了复现代码。文中三层相乘是知识驱动的上界框架；文献样本为目的性抽样，指标阈值也依后果领域而变，不能把 34% 当成某个基准的实测准确率。
  • 适合谁读： 智能体基准作者、LLM-as-judge 使用者和采购评测团队。建议读模型假设、55 篇审查的编码方法、案例计算和分级可靠性建议。

PatentAgentBench: Benchmarking LLM Agents with Professional Patent Task Suites

全文核读。 作者：Yijie Hu、Wei Li、Junjie Zhou 等。

  • 核心问题： LLM 智能体能否处理需要自行检索证据、比较技术特征并撰写专业文件的专利工作流？
  • 方法与基线： 基准包含 510 个实例、8 类任务，覆盖新颖性检索、自由实施分析、无效检索、权利要求对照、专利撰写、审查意见答复和翻译等；比较 7 个模型与 4 种 agent harness，使用任务专属召回率、F1 和专家审阅 rubric。检索代理可调用商业专利搜索 MCP，rubric 任务由 GPT-6-Sol 评判。
  • 作者报告的结果： Claude Opus 5 + Hermes 的八任务平均分最高，为 52.8/100；设计专利 FTO 的 Recall@200 在所有配置中都低于 4，说明视觉检索仍很弱。模型和 harness 的排序会随任务及组合改变，不能把单一平均分当作模型固有能力。
  • 创新、限制与复现： 相比只给候选材料的问答测试，它要求系统自行找证据并覆盖完整工作流。商业检索工具、部分模型与评判器形成依赖，Opus 与 Codex 配置也不兼容；论文主分数未统一计入调用成本。公开专利可能与模型训练语料重合，文中未见专项污染审计；当前文章未提供直接公开的 benchmark 代码链接。
  • 适合谁读： 法律科技、专利检索和 agent 工具链评估人员。建议读基准构造、模型与 harness 对照、设计 FTO 失败案例及各任务指标定义。

RobotAgentBench: Towards Open-world Robot Autonomy

全文 HTML 核读。 作者：Lingjun Mao、Jinglin Cao、Lukun He 等。

  • 核心问题： 机器人基准能否同时测出任务发现、上下文理解、操作、失败恢复和开放式家务完成，而不只测试孤立的抓取动作？
  • 方法与基线： 作者以真实家庭房间构建 Isaac Sim 场景，扩成 50 种布局，包含 90 个原子任务、18 个短任务、8 个长任务和 4 种开放式情境；比较 8 个 VLA、3 个 WAM 基线及 5 类 agent 架构。agent 对照统一使用 GPT-6 Astra 编码代理，部分配置再调用学习到的 VLA 执行器，并在 AgiBot G1 上做有限实机对照。
  • 作者报告的结果： 代码规划/策略/验证架构整体优于单独 VLA/WAM；Codex 配置的任务平均分从仿真 34.2 降至实机 31.9，开放式场景分从 8.7 降至 6.0。这个落差说明仿真得分不能直接等同真实自主能力。
  • 创新、限制与复现： 基准把规划、执行和恢复放进同一闭环，并公开了代码、模型和项目页。场景仍围绕一个家庭构建，实机测试只覆盖部分任务；agent 排名受 GPT-6 Astra、工具配置和生成轨迹影响，论文未提供统一算力/成本对照。
  • 适合谁读： 具身智能、机器人评测和仿真到现实迁移研究者。建议读场景构建、五类能力评分、开放式场景结果及实机对照。
