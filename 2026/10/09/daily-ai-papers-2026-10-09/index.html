CANDO: Cooperative Agentic Network for Layout Design Optimization

  • 作者：Athanasios Masouris、Zheng Jing、Benjamin Sam Chandler、Hadi Jamali-Rad
  • 来源/分类：arXiv，cs.MA；AI
  • 直接 PDF：PDF
  • 核心问题：真实设施布局同时受不规则边界、功能区包含、非重叠、通行路径和朝向等硬/软约束影响，常见矩形拼图基准不能代表这类问题。论文构造了 ALPS-Bench：从 CAD 资料专业标注的 1,000 个真实运营场地布局，含 14 个语义类别，900 个开发样本和 100 个测试样本。
  • 方法与基线：CANDO 是免训练的多智能体 in-context 工作流，由结构相似案例初始化、Verifier 的确定性几何/运动工具、Historian、Planner 和 Generator 组成；用并行分支和 blockwise best-of-N 搜索。作者比较单智能体、训练模型、普通 LLM 生成器、GPT-5.2 与 Qwen3.6-35B-A3B 等设置，并在 PubLayNet、RICO、PKU-PosterLayout 上做分布外测试。实验在 H100 80GB 上完成。
  • 关键结果：在 ALPS 测试集，CANDO 的 GPT-5.2 CoDe 版本聚合分数约 0.60，Qwen 版本约 0.62、空间一致性约 0.83、约束合规率 74%；消融去掉 CoDe 后聚合分数降至约 0.35，去掉工具核验后降至约 0.27。论文报告两种 CANDO 版本在 ALPS 的聚合、空间一致性和可读性上相对基线经 Holm 校正后均有显著差异（最大校正后 p 约 0.0059）。公开数据集上也取得较高 mIoU，但在 PKU 上的 FID 并非始终最好。
  • 创新与证据限制：贡献主要在把几何工具、约束核验和多智能体搜索组合成可审计流程，而不是提出新的生成模型。作者报告的成功依赖特定设计手册、开发语料和大量 LLM 调用；数据集与规则仍有领域特异性，分布指标与人工可用性也可能冲突，最终仍需工程师复核。基线调用预算、提示和模型版本的公平性需要读者结合附录检查。
  • 适合谁读：做布局生成、具身规划、工具调用评测和约束优化的人。建议优先读第 3–6 节、表 1–4 及限制讨论。
  • 证据状态：已核阅摘要与 PDF；结果是作者自报，未作独立复现实验。

OOM-RL: Out-of-Money Reinforcement Learning Market-Driven Alignment for LLM-Based Multi-Agent Systems

  • 作者：Kun Liu、Liqun Chen
  • 来源/分类：arXiv，cs.AI、cs.SE、q-fin.TR；AI / 金融交叉，本篇作 AI 侧详述，金融篇仅作索引
  • 直接 PDF：PDF
  • 核心问题：LLM 交易系统的“学习”如何被真实损失、执行摩擦和软件回归约束，而不是只在离线回测中优化指标。论文把资金耗尽阈值和交易结果作为外部负反馈，研究一个持续演化的长仓股票系统 QuantPits。
  • 方法与基线：这是 2024 年 7 月至 2026 年 2 月约 20 个月的在线工程记录，不是标准可重复的梯度 RL。系统使用人工触发的 Epistemic Autopsy、面向 AST 的定向补丁、只读测试和 RO-Lock；目标是约 8,300 行代码达到至少 95% 的覆盖，并把本金 20% 损失作为吸收阈值。作者将不同阶段与 CSI300、被动组合和阶段内基准比较，同时报告交易成本冲击。
  • 关键结果：成熟阶段 94 个交易日作者报告年化收益 34.48%、Sharpe 2.06、信息比率 2.66、最大回撤 -5.50%、beta 0.83、年化 alpha 30.07%；但 OLS alpha 的 t=1.692、p=0.094，在 5% 水平下不能拒绝零 alpha。成熟阶段结果大多发生在正式提交 STDAW 规则之前；全区间被动组合约 39.82%，量化系统约 30.09%，阶段内比较约为 13.17% 对 7.40%。
  • 创新与证据限制：价值在于记录“损失—诊断—代码变更—回归测试”的闭环，并承认持续修改会破坏稳定的因果比较。它不是证明 STDAW 产生 alpha 的实验：没有冻结模型/代码的对照组，原始经纪商与盘中日志未公开，样本阶段短，部分结果是观察性关联；模拟高换手 alpha 与真实成本结果也不能混为一谈。
  • 适合谁读：做 agent 工程、软件安全、在线学习和量化系统审计的人。建议优先读第 3–4.6 节、表 1–2 与限制部分；不要将其视为投资建议。
  • 证据状态：已核阅摘要与 PDF；作者自报的真实交易观察不能替代可复现实验或因果识别。

RT-Safe: Benchmarking Agent Safety in Real-Time Embodied Environment

  • 作者：Tianruo Rose Xu、Jiawei Ren、Yichi Yang、Zhaoxu Zheng、Lianhui Qin
  • 来源/分类：arXiv，cs.AI、cs.LG；AI
  • 直接 PDF：PDF
  • 核心问题：离线具身安全评测通常允许模型“静止思考”，但真实系统在模型推理和动作执行期间世界仍在变化。RT-Safe 在 Unreal Engine/SimWorld 中构造 36 条路线、5 张城市地图和 3 档动态体密度，让每次决策都有实时延迟。
  • 方法与基线：评估 8 个视觉语言模型，每个模型在每个难度下 36 条路线、共 108 个 episode；比较静态与实时条件、不同推理预算及主动/被动碰撞。另用离线 RL（IQL+CQL、LoRA）在 105 个 episode、4,632 条训练转移和自生成轨迹上训练，并与提示、行为克隆和 RL 专家基线比较。模拟器事件直接给出碰撞与任务成功信号，没有外部 LLM judge。
  • 关键结果：平均任务成功率从静态 91.3% 到实时 94.1%，但安全成功率从 19.8% 降到 0.7%，碰撞从每回合 3.31 次升至 40.68 次，约 12.3 倍；延迟与决策次数联合解释约 93.4% 的碰撞变化。默认到更高推理预算时成功率约 94.1%→94.8%，碰撞却约 40.7→62.0。离线 RL 专家在固定延迟测试中约 2.0 次/100 米碰撞，提示基线约 17.8、行为克隆约 6.7。
  • 创新与证据限制：论文把“能力成功”和“实时安全”拆开，并将系统延迟纳入环境动力学。限制包括仿真城市而非实体机器人、供应商 VLM、提示/延迟约定以及离线 RL 专家使用特权状态；静态和实时条件的提示差异也会影响公平比较，不能直接推出真实道路安全。
  • 适合谁读：做 VLM agent、机器人安全、实时系统和 offline RL 的读者。建议优先读第 2–3.5 节、表 1、11、15–16 及限制部分。
  • 证据状态：已核阅摘要与 PDF；数值为仿真基准中的作者报告结果。

Not Every Call Needs a Frontier Model: Per-Call-Site Evaluation of Small Language Models in a Deployed Agentic Home-Automation System

  • 作者：Panagiotis Kasnesis、Christos Chatzigeorgiou、Lazaros Toumanidis、Amalia Contiero Syropoulou
  • 来源/分类：arXiv，cs.AI；AI
  • 直接 PDF：PDF；代码：GitHub
  • 核心问题：agent 中不同调用点的能力、安全和成本需求不同，单一“全局模型排行榜”不能回答是否应在每个调用点使用前沿模型。论文在部署的 Wactorz 智能家居系统中按意图识别、HA 动作、执行器、规划器和代码生成五个调用点测评 9 个模型。
  • 方法与基线：在两套真实 Home Assistant 安装、280 个案例和 2,520 次评分调用中比较 Qwen3.5 0.8B/2B/4B、Gemma4 E2B/4B/12B/26B，以及 Claude Haiku 4.5/Sonnet 5；本地模型在 DGX Spark 128GB 上以 4-bit 运行，温度为 0。作者另做 46 个 live 案例，并记录每调用点的成本、延迟和误动作。执行器调用平均约 28,122 个输入 token，占托管费用约 81%。
  • 关键结果：最佳本地 Gemma4 26B 的总体准确率约 90.7%，Sonnet 5 约 95.4%；最佳本地模型在 5 个调用点中的 4 个与托管模型差异不显著。按调用点路由的本地组合达到约 91.8% 且推理成本为 0；全部 Sonnet 基准约 95.4%、成本 12.13 美元，生成调用改用 Sonnet 约节省 82%。但小模型安全校准差异很大：某 Gemma E2B 对非所属设备请求有 87.2% 的误动作倾向，另一个模型全部拒绝；70 个错误请求中 53 个引用了注册表已有设备，说明约束解码不足以解决权限语义。
  • 创新与证据限制：论文将模型选择单位从“agent”下沉到“调用点”，并展示质量—成本—安全的条件化权衡。限制包括仅两套安装、单一评分者、温度 0、小子群、框架 bug、后验修改标签、没有学习型路由器，以及本地成本依赖特定硬件；因此不能直接推广到其他家庭、模型和任务分布。
  • 适合谁读：做 agent 架构、模型路由、边缘部署与 AI 安全的人。建议优先读第 3–5 节、表 1–4 和限制部分。
  • 证据状态：已核阅摘要与 PDF；实地结果为小规模部署报告，非大规模线上 A/B 实验。

Reliability of LLM Judges for Evaluating Entity Alignment

  • 作者：Vaibhava Lakshmi Ravideshik、Mayank Kejriwal
  • 来源/分类：arXiv，cs.AI；AI
  • 直接 PDF：PDF；代码：GitHub
  • 核心问题：LLM-as-a-judge 在实体对齐中是否真正判断语义匹配，还是仅跟随题目里可见的 MATCH/NON-MATCH 标签。论文在 DBpedia–Wikidata、DBpedia–YAGO 和 MeSH–SNOMED 三个数据集上对 3 个闭源 judge、4 个实体对齐系统及其消融进行反事实测试。
  • 方法与基线：比较 evidence-locked CoT、最小标签可见和无标签预测三种提示；通过标签翻转、身份匿名化、平衡类别和 102 对人工标注检验锚定偏差。实验共约 153,000 次调用、2.388 亿 token，成本约 577.17 美元；人工一致性报告为 κ=0.902。
  • 关键结果：可见标签时 J-ROC-AUC 可降至 0.12–0.53，无标签且实体名称有辨识度时可达 0.93–1.00；标签翻转率为 53%–99%，Claude Opus 4.7 在部分设置达到 99%。更强的 judge 反而可能更敏感于标签；身份匿名化后 BIO 的判别仍约 61%–69%，人类总体准确率约 91.3%。标签可见时 MATCH 相关性降到约 0.228–0.412，而 NON-MATCH 仍约 0.779–0.867。
  • 创新与证据限制：把“与人类相似”拆成标签遵从、反事实稳定性和证据约束三类属性，并提醒 aggregate accuracy 可能掩盖系统性偏差。限制包括仅 3 个闭源模型、单一供应商、类平衡协议、英语数据和作者标注；无标签提示也改变了任务定义，不能把结果外推成所有 LLM judge 都不可靠。
  • 适合谁读：做知识图谱、数据集评测、LLM judge 和科学测量的人。建议优先读第 3–5 节、表 1–2 及限制部分。
  • 证据状态：已核阅摘要与 PDF；代码链接来自论文提供的信息，数值为作者报告。

Agentic Discovery of Neural Architectures: AIRA-Compose and AIRA-Design

  • 作者：Alberto Pepe、Chien-Yu Lin、Despoina Magka、Bilge Acun、Thomas Simon Foster、Yannan Nellie Wu、Anton Protopopov、Carole-Jean Wu、Yoram Bachrach
  • 来源/分类：arXiv，cs.AI；AI
  • 直接 PDF：PDF
  • 核心问题：让 agent 搜索神经网络架构、复用组件并提出训练改进，究竟能否超越人工设计；论文包含 AIRA-Compose、AIRA-Design 和 autoresearch 三个设置。
  • 方法与基线：AIRA-Compose 用 11 个 agent 在固定时限内组合约 100–200 个小架构，随后在 1B/3B 规模、等 token 预算上扩展；AIRA-Design 用 20 个 agent、1,680 次运行和 6 个长上下文任务配置比较 one-shot 与多轮 greedy；autoresearch 在小规模训练沙盒中比较无文献、带文献和贪心策略。实验跨 H200/H100 预算，但部分基线为近似复现。
  • 关键结果：1B AIRAformer-D Stretched 的验证损失 2.734、平均零样本准确率 59.7%，论文报告优于 Llama3.2 的 2.815/57.5%；AIRAhybrid-D 的损失 2.719、准确率 60.5%，与 Nemotron2 近似基线相近，并非所有指标都胜出。AIRA-Design 最好峰值距离人工 SOTA 约 2.3%–2.6%，但非配置任务归一化得分很低（如 ListOps 约 0.257、文本约 0.199、检索约 0.197），one-shot 没有有效提交。autoresearch 中只有约 34.1% 的 11,530 次训练步得到有效 fitness，最佳 BPB 约 0.968。
  • 创新与证据限制：论文贡献是把架构组合和实验反馈纳入 agent 搜索，并量化搜索预算与配置空间的影响。限制很实质：代理多数是在重组 Performer/Longformer/Conformer 等已有部件，尚不能称为独立科学创新；小 proxy 未必能外推到大规模训练，整文件重写妨碍因果归因，PyTorch/JAX 和显存限制会造成搜索偏差，跨论文基线还存在近似复现问题。
  • 适合谁读：做 AutoML、架构搜索、AI for Science 和实验自动化的人。建议优先读第 2–3、5–6.2 节、表 2–5 和限制部分。
  • 证据状态：已核阅摘要与 PDF；性能数字是作者自报，并应结合每个预算、种子和近似基线解读。
