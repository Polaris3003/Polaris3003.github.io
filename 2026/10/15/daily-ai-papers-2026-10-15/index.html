Google Earth AI Geospatial Reasoning Agent: Capabilities and a Systematic Evaluation

  • 作者：Noam Slonim、Aviv Slobodkin、Gil Fidel、Gal Moshitch、Mimi Sun、Lily Mihalkova、Joydeep Paul、Per Bjornsson、Sydney Lin、Jamie McPike、Samapriya Roy、Utkarsh Patel、Gia Jung、Zachary Luna、Allison Berman、William Cai、Xiao Wu、Mohit Agarwal、Mandar Sharma、Aliza Hoffman、Mark Young、Rama Pasumarthi、Roy Lee、Ruth Alcantara、Luke Barrington、Aaron Bell、Reuven Sayag、Avinatan Hassidim、Yossi Matias、Tyler McHenry、Ronald Ho、Christopher Haire、Oliver Guinan、Niv Efron、Tim Thelin、Gautam Prasad、Shravya Shetty
  • 来源/分类：arXiv，cs.AI；AI / 地理智能体
  • 直接 PDF：PDF
  • 核心问题：地理问题通常没有唯一答案，需要从大型目录发现数据、组合空间工具并处理会变化的地面真值；普通 LLM 能否完成这种开放式分析，工具和前置规划各贡献多少？
  • 方法与基线：GRA 将 Google Earth AI 的遥感、人口、天气、洪水、地图和 Earth Engine 等能力包装为按需加载的模块化技能，并在调用工具前生成能力感知的计划。作者在 GeoExpertQueries（101 个开放式问题，76 个测试项）、GeoKTools（305 个模板，220 个测试项）、CBGB 和 UnivEARTH 上，用同一 Gemini 3.1 Pro/3.8 Flash 比较无工具、基础工具、GRA 工具但无前置规划、完整 GRA 四种配置；开放题由三名专家工作流形成共识流程，并以人类校验的工具无关 autorater 打分。
  • 关键结果：GeoExpertQueries 测试集上，Gemini 3.8 Flash 的无工具、基础工具、GRA 工具和完整 GRA 分数分别为 3.3、3.3、52.2、62.7；Gemini 3.1 Pro 的完整 GRA 为 47.6。GeoKTools 全部 220 题上，Flash 的四种配置为 40.5、40.0、86.0、85.9，说明工具贡献远大于仅加基础工具，且工具复杂度从 1 到 4 类时 GRA 分数仍在约 82–91。完整 GRA 的 Flash 每题估算 LLM token 成本为 0.199 美元，高于无工具但低于 Pro 的 0.688 美元；UnivEARTH 各配置已达 86.9–98.8，作者据此判定该基准饱和，不能证明真正做了地理分析。
  • 创新、局限与失败条件：四配置控制和开放式专家工作流是较好的基线隔离；但 GeoKTools 偏向 GRA 已有工具，开放题分数依赖 LLM autorater，评测排除了需要不可用数据的任务，也没有覆盖其他模型家族。公开结果还显示工具失败会使前置计划停在较弱代理数据上；研究未做训练数据污染审计，闭源 Gemini 的内部可复现性和 Earth Engine 外部成本也无法由分数替代。
  • 适合谁读：做地理 AI、科学 agent、工具编排和开放式评测的人。建议先读第 3–5.7 节、表 5–9、UnivEARTH 饱和度分析与第 6.2 节。
  • 证据状态：已核阅摘要与 PDF；结果是作者在 GRA、Gemini、指定数据工具和 autorater 下的报告。

Safety for Whom? Benchmarking Understanding Beyond Refusal in Egocentric Multimodal Assistants

  • 作者：Yewon Han、Jisu Jeon、Suhyun Choi、Juan Yeo、Minsoo Jo、Gihoon Kim、Hyunggyu Lim、Taesup Kim
  • 来源/分类：arXiv，cs.AI、cs.HC；AI 安全 / 多模态助手
  • 直接 PDF：PDF；项目页：STOU
  • 核心问题：第一视角多模态助手的回答会直接影响佩戴者和旁人，但单一拒答率无法区分“没理解风险却拒答”和“理解风险仍然协助”，也无法看出伤害对象是谁。
  • 方法与基线：STOU 含 2,902 条第一视角视频—音频/文本查询，将目标分为 Self、The Others、Others、Unspecified，并把安全理解拆成意图识别、伤害存在与目标识别、后果理解，再与是否拒答交叉。作者评估 7 个开放模型和 3 个闭源模型，音频输出先用 Whisper Turbo 转写；GPT-4.1 作 judge，并在 225 个样本上与 3 名人类评审校验。
  • 关键结果：不同模型的 unsafe response rate 差异很大，Qwen2.5-Omni-3B 在音频到文本设置的总体 UR 为 86.6%，Gemini-3-flash-preview 为 57.7%，Muse Spark 1.2 为 15.9%；Self 和 Unspecified 往往是更脆弱或更难理解的目标。安全理解率方面，Gemini-3-flash-preview 为 67.0%，Muse Spark 1.2 为 80.7%，最高的拒答不等于最高的理解。汇总后，模型理解请求时的拒答率约为 50.2%，其余约 24.4%，但理解了的请求仍有约一半被回答；GPT-4.1 judge 与人类在安全理解组件上的一致性超过 80%，最佳阈值的平衡准确率为 0.894。
  • 创新、局限与失败条件：把伤害目标和安全理解与拒答分离，能揭示开放模型的 Comprehension Gap 与闭源模型的 Alignment Gap。限制是数据由场景构造而来，10 个模型的默认解码和模型提示不同，judge 仍可能受模型偏差影响；论文没有提供训练数据污染审计，且拒答/理解指标并不等于真实穿戴设备中的长期伤害率或物理安全。
  • 适合谁读：做多模态安全、可穿戴助手、红队评测和安全—效用权衡的人。建议先读第 3–5.2 节、表 2–3、图 7–8 和附录。
  • 证据状态：已核阅摘要与 PDF；结果是作者在 STOU 与其评测协议下的报告。

A Persian Vision-Language-Action Dataset and Benchmark for Ambiguity- and Infeasibility-Aware Instruction-to-Plan Grounding

  • 作者：Abdollah Pourasghari、Saeedeh Sadat Sadidpour、Mohammad Roustaei
  • 来源/分类：arXiv，cs.CV、cs.CL；AI / 具身多模态评测
  • 直接 PDF：PDF
  • 核心问题：现有指令到行动计划 benchmark 多为英语、模拟场景且假设指令清晰可执行；在真实家庭/办公室照片中，模型能否识别歧义、提出澄清问题，并拒绝物理上不可执行的计划？
  • 方法与基线：论文构建 230 张照片、258 个实例的波斯语 VLA 数据集，显式标注 23 个歧义指令、13 个不可执行指令、参考计划和澄清问答；PGOS-FA 在旧 PG2S 上加入步骤顺序、过度生成惩罚和波斯语 embedding。消融比较无检索、检索增强、CoT、澄清 agent，并与独立复现的三 agent 外部基线和更强闭源 planner 比较。
  • 关键结果：在 39 个验证实例上，所有 14 个“加入检索对比无检索”的 PGOS-FA 比较经校正后显著，最大校正 p 约 0.0017；但其余 22 个细粒度增量中 20 个未通过校正。99 个留出测试实例上，英文 prompt 的 baseline PGOS-FA 为 0.376，RAG+澄清+CoT 为 0.524，带 CoT 示例的配置为 0.507；LLM judge 的对应准确率只有 0.212、0.253、0.283，baseline 与最佳配置在该指标上不显著。与独立外部基线共享 96 个实例时，本文最佳配置均值 0.531、外部基线 0.413，配对 Wilcoxon p=0.00003。
  • 创新、局限与失败条件：论文对统计功效和负结果交代得很清楚，主效应更像“本地语言检索资源有效”，而不是每个 CoT/澄清组件都被证明有效。数据规模小、每个实例没有独立第二标注者、验证集没有真正的歧义实例，且静态单图计划没有实际执行；因此 PGOS-FA 与真实机器人成功率不是同一指标，波斯语/伊朗场景外推也未验证。
  • 适合谁读：做低资源语言 VLA、具身规划、benchmark 设计和自动评测的人。建议先读第 III–V-E 节、表 VI–VII、表 X 与第 VI 节限制。
  • 证据状态：已核阅摘要与 PDF；数据集、PGOS-FA 和评测代码据摘要称可按合理请求获取，本文未给出直接公开代码 URL。

AuthGateBench: Benchmarking LLMs as Authorization Gate

  • 作者：Zhixiong Zhuang、Jin Jia、Zhiwei Shang、Ziyu Wang
  • 来源/分类：arXiv，cs.AI；AI agent 安全 / 授权判断
  • 直接 PDF：PDF
  • 核心问题：编码 agent 在自动执行模式下需要一个“允许/阻止”门；仅用恶意请求测试拒答，无法测量良性请求下的越权、过度阻止和对上下文授权的理解。
  • 方法与基线：AuthGateBench 从五类真实事故抽象出 1,400 个实例，包含 350 个 base triplet、350 个只改请求文本的反事实对和 700 个环境信号增强实例。对比的四个模型是 DeepSeek-V4-Flash、GLM-5.2、Kimi-K2.7-Code、Qwen3.7-Plus；指标区分准确率、把未授权动作放行的 FNR、把合法动作阻止的 FPR，以及同一动作/轨迹在请求翻转后仍给相同决策的 invariant rate。
  • 关键结果：在未提供显式政策时，Credential Exploration 和 External Sharing 两类的所有模型 FPR 都至少 80%；GLM-5.2 在前者把 92.86% 的可授权动作、后者把 97.14% 的可授权动作错误阻止。相同动作和轨迹只改变请求文本时，External Sharing 的平均 action-anchored invariant rate 为 95.36%，说明模型常被动作表面风险锚定。加入只读环境证据后，Scope Escalation 初始错误中 25.2% 被纠正、7.6% 被误导，Inferred Parameters 为 24.3% 对 10.5%；显式提供生成标签的政策也能改善准确率，主要减少过度阻止。
  • 创新、局限与失败条件：对比对把“动作风险”和“用户授权”分离，是比单纯拒答率更接近自动执行门的测试。可是数据和环境信号均由 LLM 合成，只有一个生成政策，真实事故长尾和用户政策差异未覆盖；结果也不证明检索环境证据在真实工具链上同样可靠。论文未给出训练数据污染审计和端到端执行事故率，因此不能把 benchmark 准确率当作部署安全保证。
  • 适合谁读：做 coding agent、工具授权、policy-as-code 和安全门的人。建议先读第 3–5.2 节、表 2–3、图 3–5 与第 7 节。
  • 证据状态：已核阅摘要与 PDF；结果是作者在合成 AuthGateBench 和四个模型上的报告。

When Agent Evaluation Becomes Unreliable: An Empirical Study of Oracle Failures and Configuration-Dependent Measurement in an LLM Agent Benchmark

  • 作者：Junjie Chen
  • 来源/分类：arXiv，cs.SE、cs.AI；AI 评测可靠性
  • 直接 PDF：PDF
  • 核心问题：agent benchmark 的 reward/oracle 本身是软件；如果它修改了被评分环境，或测量结果受提示、工具描述和错误字符串影响，leaderboard 分数还代表模型能力吗？
  • 方法与基线：作者把评测 harness 当作被测系统，用 5 个状态完整性不变量、3 个 known-answer control 和 7 类 fault injection 审计 oracle，并在两个任务域和一个合成域中测量检测能力。对一个广泛使用的工具 agent benchmark，作者重放已记录的 tool calls；另用 3,240 个 episode 做 policy、tool description、error string 的组件消融，并在第二独立实现的 benchmark 上检验可迁移性。
  • 关键结果：7 类注入缺陷在所测实现中均被检测，修复后的 oracle 没有假阳性；但在 21 个具体变体与 3 个目标的组合中，主分母检测为 54/57，保守分母为 56/63，说明“全覆盖”不成立。最重要的缺陷是 reward 计算为生成 ground-truth hash 重置数据库却未恢复：4,320 个 episode 的原始 database-pass 标签为 4,194/4,320、成功率 94.3%，独立干净重放后为 2,883/4,320、65.5%。组件消融中 tool descriptions 的探索性影响约 −9.2 个百分点，error strings 约 −5.3 个百分点；换到另一任务域，语言效应方向反转。
  • 创新、局限与失败条件：论文明确把 oracle 缺陷与“模型行为”区分，且发布冻结记录、故障注入目录和离线重算入口；但方法依赖可重建的 reference terminal state，第二个独立 benchmark 因 API-call log 不足无法验证。次要消融跨运行批次、无不可变模型版本，结论只适用于测过的实现、任务和配置，不能直接泛化为某个模型的内在能力。
  • 适合谁读：做 agent benchmark、LLM-as-judge、测试工程和可复现性的人。建议先读第 3.2–3.6、4.1–4.3、6.3 和第 7 节。
  • 证据状态：已核阅摘要与 PDF；论文称附带离线复现包，但摘要页未提供该复现包的直接公开 URL。

Equal-information evaluation of credit assignment in modular financial reinforcement learning

  • 作者：Gennadiy Chistiakov、Yury Yanovich
  • 来源/分类：arXiv，cs.AI；AI / 金融强化学习评测
  • 直接 PDF：PDF
  • 核心问题：模块化金融 RL 中，归因信号可能只改善组件损失，却没有增加信息、改善最终决策或降低经济风险；如何用等信息控制和预先定义的下游护栏拆开这些效应？
  • 方法与基线：作者在 AMATS 交易架构背景下，做三组受控实验：残差调度与普通 loss-budget 的更新分配、native outcome 与 shortfall target 的表示比较、scalar 与 component critic supervision 的投资组合控制。对比保持信息接口、固定 utility、seed/path 和 accounting contract，并用 decoded outcome、certainty equivalent、最大回撤等下游指标做 guardrail，而非只看组件预测损失。
  • 关键结果：分配实验中，归因调度与普通 loss-budget 在 24 个模拟主配对和 12 个历史配对中完全一致，未显示归因特有优势。表示实验的 both-shift 条件下，shortfall MAE 从 5.2860 降至 4.4028 bps，但 decoded-y MAE 从 6.2014 升至 6.4320 bps，四个条件的非劣性标准均未通过。投资组合实验中，component critic 相对 scalar supervision 的风险条件 CE 差异为 −0.0619 bps/clock，风险条件 MDD 增加 0.0151，净收益非劣性也未通过；这些结果是固定 utility、两项合成资产和指定执行假设下的对照，不是实盘回测。
  • 创新、局限与失败条件：equal-information reconstruction 能避免把可由普通 learner 重构的信号误称为信息增益，且把统计/预测改进与经济决策结果分开。限制是小规模 seed/path、合成市场、当前中价执行、无 funding/order book，历史 Bar 记录只有两个资产和两个窗口；论文明确不提供投资建议，也没有完成完整系统、实时延迟和 live trading 验证。金融解读应把它看作方法学审计，不是交易策略优劣结论。
  • 适合谁读：做金融 RL、模块化 agent、归因学习和回测评测的人。建议先读第 3、5.1–5.3、表 2–4 和第 8 节。
  • 证据状态：已核阅摘要与 PDF；作者报告的结果来自指定合成/历史工程协议，非独立复现。

Large language model-generated patterns for epidemiological modeling: a multi-benchmark evaluation framework

  • 作者：Sophia Mao、Keshav Gandhi、Alexander Gutfraind
  • 来源/分类：arXiv，cs.AI；AI / 流行病学建模
  • 简介：以注射吸毒者丙肝相关行为为案例，研究三个 LLM 生成的行为关系是否与文献方向、agent-based model 相关性和调查相关性一致。作者报告 28 个保留关系的无条件方向恢复率为 46%–68%，直接询问“该关系方向是什么”时为 82%–93%，与 ABM/调查相关矩阵的平均绝对差为 0.11–0.13/0.15–0.18。价值在于把“知道某个关系”与“无提示地生成可用于模拟的关系”分开；样本、模型、提示和外部 benchmark 都有限，不能把部分一致性当作可直接用于传播模拟的行为真值。

UDHRBench: Benchmarking Human Rights in Large Language Models

  • 作者：Alak Raad、Noreldin Morssy、Zeerak Suhail、Serin Atiani、Mustafa Jarrar

EHR-Bench: A Chinese Multi-Task Benchmark for Recruitment AI

  • 作者：Ruijia Yang、Bing Xu、Zulong Chen、Zhipeng Xu、Jia Xu、Yipeng Yu、Ying Zhou、Zeyi Wen

Self-Representation Alignment in Diffusion Models for Video Background Music Generation

  • 来源/分类：arXiv，cs.AI；AI / 视频条件音乐生成
