2026-10-10 GitHub 热榜简报：Agent 工作流、代码质量与空间计算

GITHUB TRENDING · 2026.10.10

今天的 GitHub all-languages 日榜列出 11 个仓库条目；按工程机制是否可复现、README 是否足够清晰、许可证与近期维护状态筛出 9 个。主线有三条：Agent 正从提示词走向可安装的工程流程，AI 工具开始承担代码质量与模型路由基础设施，视觉创作、3D 重建和平台逆向则继续把模型能力推向真实运行环境。日增 stars 只是公开快照，不是质量证明。

Agent 工作流代码审查模型网关逆向工程本地创作3D 重建

今日要点

REA、AnyPS5 与 LingBot-Map分别把 Agent 逆向、可执行文件移植和流式 3D 重建落到二进制、ABI、几何上下文与显存等具体边界上；值得学习的是它们如何把“模型会做什么”变成可检查的工具链，而不是一句泛化的能力宣称。

Open Code Review、LiteLLM 和两个工程技能包则把 Agent 接入交付流程：前者用确定性文件选择与规则匹配约束审查，后者统一模型供应商接口，mattpocock/skills与addyosmani/agent-skills分别强调可组合技能和生命周期门禁。它们共同说明，AI 工程的瓶颈正在从“能不能调用模型”转向上下文、权限、成本和反馈回路。

knowledge-work-plugins把岗位知识与连接器包装成可审阅目录，ArtCraft则把图像、视频、3D 场景和模型选择放进桌面 IDE；两者都适合拆解“领域工作流如何产品化”，但都不应被仅凭热度当作成熟度证明。

值得尝试

morluto/rea

REA把 MCP 与 CLI 接到原生二进制、JavaScript/Electron、.NET、网站等目标，分析在本地运行，并为结论返回证据与限制。它适合安全研究、互操作和想学习可追溯逆向工作流的工程师；已知限制是需要 Node.js 22.x，原生分析通常还需要 Hopper、Ghidra 或 IDA，而 JavaScript 静态分析不需要这些引擎。日榜记录主要语言为 TypeScript、当日新增 14,927 stars；仓库页显示总 stars 47,735，许可证为MIT，最新 Release rea-agents-6.3.0，最近提交为同步 6.3 checkpoint。

boykopovar/AnyPS5

AnyPS5用 relinker 把 PS5 可执行文件转换为 Linux/Windows 的目标格式，并提供可动态链接的 system PRX 实现，不依赖模拟器或独立运行时。它适合研究 ABI、动态链接、着色器重编译和平台兼容边界；已知限制是兼容性仍以已验证游戏列表为准，README 也明确要求用户自行确保所用二进制符合适用法律和许可。日榜记录主要语言为 C++、当日新增 5,868 stars；仓库页显示总 stars 22,570，许可证为GPL-2.0-only，最新 Release v0.1.1，最近提交合入了提高打开文件上限的修复。

alibaba/open-code-review

Open Code Review是 AI 代码审查 CLI：读取 Git diff，把变更文件交给可配置的 LLM Agent，并生成精确到行的结构化评论，也支持没有有效 diff 时的整文件扫描。它适合想把代码审查做成 CI/本地可复用管线的团队；已知限制是需要 Git 2.41+ 和已配置的模型端点，README 的基准测试还明确承认其召回率低于通用 Agent，不能当作全覆盖安全审计。日榜记录主要语言为 Go、当日新增 326 stars；仓库页显示总 stars 45,287，许可证为Apache-2.0，最新 Release v1.12.13，最近提交补充了allowlist 扩展消失的测试。

BerriAI/litellm

LiteLLM提供统一的 OpenAI 风格接口，覆盖 100+ LLM 供应商，既能作为 Python SDK，也能部署成带虚拟密钥、成本统计、guardrails、负载均衡和管理面板的自托管网关。它适合需要在供应商、模型和 Agent 协议之间切换的工程团队；已知限制是不同上游的能力、认证和错误语义仍需单独核对，enterprise 目录也有独立商业许可边界。日榜记录主要语言为 Python、当日新增 95 stars；仓库页显示总 stars 60,692，LICENSE说明非 enterprise 内容为 MIT，最新 Release v1.104.2，最近提交处理了Gemini 预置 TTS 声音映射。

mattpocock/skills

这个仓库把小型、可编辑、可组合的 Agent 技能整理成跨宿主安装包，README 覆盖 Claude Code、Codex、Copilot、Gemini CLI 和 skills.sh 的安装路径，并用 setup 流程固化问题跟踪、标签和文档位置等工程约束。它适合把对齐、测试、调试和反馈回路写成可审阅文件；已知限制是它不是运行时或服务框架，安装多个同类技能包会重复，最终效果仍取决于宿主能力和项目纪律。日榜记录主要语言为 Shell、当日新增 1,687 stars；仓库页显示总 stars 282,801，许可证为MIT，最新 Release v1.3.1，最近提交修正了多个技能模板。

addyosmani/agent-skills

agent-skills提供 25 个工程技能和 9 个 slash commands，把定义、计划、构建、测试、审查到发布映射成带质量门禁的生命周期。它适合希望把“先规格、再实现、再验证”固化到多个 coding-agent 宿主的团队；已知限制是单独安装某个技能时可能拿不到仓库级 references，README 已记录这一可移植性缺口，且完整效果依赖宿主是否支持原生插件。日榜记录主要语言为 JavaScript、当日新增 436 stars；仓库页显示总 stars 104,021，许可证为MIT，最新 Release 0.6.12，最近提交调整了宿主指南的书面门槛。

anthropics/knowledge-work-plugins

knowledge-work-plugins开源了 11 个面向生产力、销售、支持、产品、数据和研究等岗位的插件，每个插件把 skills、连接器、slash commands 与子 Agent 组合进文件型目录。它适合团队研究如何把岗位知识和 MCP 连接器封装成可审阅工作流；已知限制是它主要面向 Claude Cowork、兼容 Claude Code，连接器仍受第三方权限、数据范围和宿主能力约束，仓库目前未列出公开 Release。日榜记录主要语言为 Python、当日新增 709 stars；仓库页显示总 stars 28,295，许可证为Apache-2.0，最近提交更新了Qodo 插件版本。

storytold/artcraft

ArtCraft把交互式 AI 图像与视频创作做成桌面 IDE：可以在 2D 中合成、在 3D 中布景，并选择不同模型完成图像、视频、声音和网格工作流。它适合研究创作工具如何提供构图、角色、镜头和模型选择的可重复控制；已知限制是稳定版本主要面向 Windows/macOS，Linux 需要从源码构建，且WIP Fair Source 许可允许个人使用但限制商业销售和竞争产品开发，不能按 OSI 开源许可证理解。日榜记录主要语言为 Rust、当日新增 3,752 stars；仓库页显示总 stars 11,644，许可证字段为 Other，最新 Release artcraft-v0.41.0，最近提交处理了0.42.0 桌面端更新。

Robbyant/lingbot-map

LingBot-Map用 Geometric Context Transformer、paged KV cache 和 trajectory memory 做流式 3D 重建，README 报告在 518×378 分辨率下约 20 FPS、可处理超过 10,000 帧的长序列，并提供交互式 demo 与评测脚本。它适合 3D 视觉、SLAM、机器人和长视频几何建模学习；已知限制是安装路线偏 CUDA/PyTorch，README 推荐 CUDA 12.8 与 PyTorch 2.8，FlashInfer 不可用时才回退到 SDPA，显存和速度需要按硬件重新验证。日榜记录主要语言为 Python、当日新增 110 stars；仓库页显示总 stars 17,727，许可证为Apache-2.0，未发现公开 Release，最近提交修正了天空遮罩阈值。
