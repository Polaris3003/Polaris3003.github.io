PROOF-Gen: From Optimized Data to Better Distillation

摘要：Apple Machine Learning Research 介绍 PROOF-Gen，用于改进工具调用能力的蒸馏流程。论文摘要指出，传统“生成并筛选”流程会丢弃失败轨迹；在 τ 2-bench 上，教师模型试验有 57% 失败，其中约三分之二属于大部分工具调用正确但未完成的近失误。来源摘要没有说明 PROOF-Gen 的完整算法和最终指标，本文数字只代表摘要披露的实验背景。来源：Apple Machine Learning Research，发布于 2026-08-26。

IDEA Prune: An Integrated Enlarge-and-Prune Pipeline in Generative Language Model Pretraining

摘要：Apple Machine Learning Research 提出 IDEA Prune，把“先扩大模型预训练、再结构化剪枝”作为一个整合流程研究，而不是只训练目标规模模型。论文要回答两个问题：即使扩大后的模型不会部署，额外预训练是否值得；以及如何优化扩大—剪枝流程。来源摘要没有给出模型规模、压缩比例或基准提升，原文未说明。来源：Apple Machine Learning Research，发布于 2026-08-26。
