FraudBench：金融风控对抗鲁棒性首先是协议问题

论文：FraudBench: Protocol-Sensitive Benchmarking of Adversarial Robustness for Financial Risk Assessment（arXiv:2608.24551）
作者：Xitong Zeng、Zhaoge Bi、Yitian Yang、Huaming Chen、Quan Z. Sheng
来源/分类：arXiv · cs.LG、cs.CR、cs.AI
全文状态：已核阅公开 PDF。

这篇论文问的是：金融表格风控模型的“对抗鲁棒性”到底属于模型能力，还是攻击协议、特征可修改性和部署约束的产物。FraudBench 在 4 个公开金融数据集上比较神经网络、树模型和集成模型，并把攻击拆成无约束攻击、攻击后过滤，以及在攻击过程中直接加入预算、特征可修改性和部署约束的投影式攻击；同时区分白盒、黑盒和不同攻击知识条件。这样做的价值是把“能不能翻转预测”改成“在真实可执行约束下能否找到可行翻转”，并检查攻击协议变化是否会改变模型排名。

作者报告，在相同预算下，LCLD 上后处理过滤与“投影 + 可修改特征掩码”协议得到的可行翻转计数分别为 3.7 和 2,832.3；IEEE-CIS 等数据集上，攻击的可行性与攻击能力也不应混为一个指标。黑盒协议会改变模型排序，没有一种架构在所有协议下都天然稳健。这里的数字是作者在其威胁模型和数据集上的实验结果，不是金融机构真实欺诈损失或监管安全保证。创新在于把 attack feasibility、capability 和 deployment-aware constraint 放进同一评测协议；局限是公开数据与人工定义的可修改性仍不能完全代表机构生产特征，攻击预算、查询限制和分布漂移也会影响结论，论文没有因此建立因果意义上的“模型更安全”。适合风控建模、对抗机器学习和模型治理读者；建议优先读 §3 的协议定义、§4 的数据与攻击设置、表 2–5、§5 的黑盒结果和 Limitations。

RGV：搜索 agent 的置信度不能被“复制粘贴”骗高

论文：Beyond Confidence: Test-Time Scaling for Multi-Turn Search Agents via Retrieval Grounding（arXiv:2608.24024）
作者：Hyunho Kook、Junhyuk So、Tianyu Fu、Haizhong Zheng、Beidi Chen
来源/分类：arXiv · cs.AI、cs.IR、cs.CL
全文状态：已核阅公开 PDF。

论文针对多轮搜索 agent 的 test-time scaling：当多个候选答案由 token log-probability 或投票挑选时，检索到的原文会被放入上下文，候选若重复原文就可能获得虚高的“置信度”，即 copy inflation。RGV（Retrieval-Grounded Verification）因此不再读取被检索文档污染的上下文置信度，而是计算最终回答文本与检索证据之间的词汇重合，作为一个额外的、无需调用 LLM 的验证信号，再与候选选择结合。核心对照是普通 confidence voting，而不是重新训练一个更大的裁判模型。

作者在 4 个搜索基准、5 个 LLM 上报告 RGV 最高带来 5.4% 的准确率提升，少数派正确候选比例提升 35%；论文把这些视为其测试时选择协议下的结果。它的工程创新是识别“上下文中证据同时是答案来源和置信度输入”的测量污染，并把验证信号移到证据外部。局限也很明确：词汇重合偏好复述证据的答案，无法保证语义蕴含；检索质量、语言和答案格式会改变分数，且四个基准和五个模型不足以说明长时交互或开放域搜索中的普适性。适合搜索 agent、RAG 评测和 test-time compute 读者；建议读 §2 的 copy inflation 分析、§3 的 RGV、表 1–3、§4 的跨模型实验和 §6 的失败案例。

PHMForge：工业预测性维护 agent 需要算法工具，而不只是检索

论文：PHMForge: Evaluating LLM Agents on Industrial Prognostics through MCP-Native, Algorithm-Grounded Tools（arXiv:2604.01532）
作者：Yusheng Li、Tianjun Feng、Yunfeng Chen、Chun-Yi Tsai、Yihan Sun、Ayan Das、Kaoutar El Maghraoui、Shuxin Lin、Dhaval Patel
来源/分类：arXiv · cs.AI、cs.LG、cs.ET
全文状态：已核阅公开 PDF。

PHMForge 研究 LLM agent 是否能在工业 prognostics and health management（PHM）中完成从数据诊断到算法选择、执行和解释的完整任务。作者收集 99 个 SME 编写的场景，覆盖 8 类资产、19 个公开数据集，并把 39 个已发表 PHM 算法封装为 MCP 工具；实验比较 3 种 agent 框架和 6 个 LLM backbone，既测最终答案，也测工具调用、参数和结果是否满足场景约束。它的主要基线不是“一个更大的聊天模型”，而是不同的 agent 编排、RAG 与算法工具接入方式。

作者报告，在完整 99 任务上，Claude Code + Opus 4.6 的 pass@1 为 80.8%；旋转机械/航空等 30 个场景的 SME 评分者一致性约为 α=.74–.82。电池 RUL 扩展中，RAG 方案只有 1/5 个任务同时通过 3 项要求，而 MCP 算法工具方案为 5/5；面对未知工具，系统通过率从 74.6% 降到 53.3%，完整运行成本约为 20–50 美元。后两项尤其说明工具协议和失败处理是能力的一部分，但不是生产维护节省金额。局限包括 SME 场景数量有限、公开数据与真实传感器流的差异、工具包装正确性可能影响结果、不同模型的上下文和调用成本没有完全等价，且摘要所称开源材料需要按论文版本实际复现。适合工业 AI、MCP 工具设计和可靠 agent 评测读者；建议读数据集与任务定义、§4 的工具/agent 对照、表 4–8、未知工具消融和成本分析。

链接：arXiv 摘要页 · PDF

LUCAID：肺癌精准病理的多模块 agent，强项和边界都在模块级数字里

论文：LUCAID: Agentic Multimodal AI for Lung Cancer Precision Pathology（arXiv:2608.23803）
作者：Marie-Lisa Eich、Kai Standvoss、Timo Milbich、Alexander Möllers、Miriam Hägele、Philipp Anders、Lars Tharun、Hanna Kontradiuk、Sebastian Kons、Nader Aldog、Recepcan Adigüzel、Adam Narai、Lukas Hönig、Jonathan Striebel、Binru Yang、Mihnea P. Dragomir、Marvin Sextro、Philipp Keyl、Philipp Jurmeister、Rosemarie Krupar、Evelyn Ramberger、James Wells、Julika Ribbat-Idel、Andreas Kunft、Hussam Shuaib、Christian Grohé、Reinhard Büttner、David Horst、Klaus-Robert Müller、Lukas Ruff、Maximilian Alber、Frederick Klauschen、Simon Schallenberg
来源/分类：arXiv · cs.CV、cs.AI、q-bio.QM
全文状态：已核阅公开 PDF。

LUCAID 不是单一分类器，而是面向肺癌精确病理的九模块多模态系统，覆盖切片质量控制、肿瘤检测/分割、亚型、肿瘤微环境、细胞量、PD-L1/MET/TROP-2 评分和报告生成。开发集包含 1,620 例多中心病例、105,227 条专家标注，另有 115 例带 KRAS VAF 的分子队列；前瞻性评估包含 70 例 nNGM 病例、5 项任务和 338 次任务级评估。方法上的重点不是“一个模型包打天下”，而是让模块输出作为后续报告和临床决策解释的证据链。

作者报告的模块级 F1 为：H&E/IHC 质量控制 .91/.88，分割平均 .93（癌 .98），H&E 细胞表型平均 .95，IHC 细胞表型中 TROP/MET .86、PD-L1 .90，生物标志物评分中 PD-L1 .93、MET/TROP 膜 .87、TROP 胞质 .82。细胞量与 KRAS VAF 的相关性从病理医师 r=.20、MAE 24.42 个百分点，提高到核面积法 r=.46、MAE 17.1 个百分点；报告评估的 1,365 个原子陈述中，134 条模块输出全部有证据支撑，解释陈述 1,194/1,231 正确。前瞻性 70 例中，系统与专家小组的临床行动一致率为 93.0%，而 5 位病理医师为 68.3%–81.1%；任务 MAE 依次为细胞量 3.46、PD-L1 6.70、MET 19.11、TROP 膜 20.82、TROP 胞质 24.20 个百分点。这些是作者在特定机构、标注和评分协议下报告的诊断一致性，不是替代病理医师的临床结局证据。局限包括报告评估仅 10 份、尚未测量真实工作流影响、外部部署与病例分布仍需验证，且作者披露部分 Aignostics 相关利益关系。适合数字病理、临床多模态 AI 和可追溯报告系统读者；建议读模块方法、表 2–4、KRAS VAF 分析、前瞻性评估和 Limitations。

Neurosymbolic Alignment：用生理约束压低临床语言模型的危险答案

论文：Neurosymbolic Alignment for Physiologically-Safe Clinical Language Models（arXiv:2608.24534）
作者：Abdulhady Abas Abdullah、Erik Cambria、Milena Zivkovic
来源/分类：arXiv · cs.AI、cs.CL、q-bio.QM
全文状态：已核阅公开 PDF。

论文把临床语言模型对齐从“偏好更安全的回答”推进到生理可行性约束。作者在 7B Mistral 上加入 4 层异构图神经网络，图谱包含 847,392 个节点和 3,241,567 条边，用稳态约束、路径合理性和药物相互作用惩罚评估候选回答；随后以 K=8、T=5 的迭代 ORPO 反复生成、筛选和更新。评估用 CSB 合成临床场景，2,500 条样本按 1,750/250/500 划分，并与普通 ORPO、GPT-4 五样本提示和多项去除组件的消融比较。

作者报告，相比 ORPO，CSS 从 69.5 提升到 90.8（+21.3 个百分点），RSS 从 65.2 到 86.4，DID 从 72.8 到 91.6，医师标注的危险率从 14.1 降到 5.1；GPT-4 五样本提示的 CSS 为 80.6。去除 HGNN 后 CSS 降至 74.6，去除迭代后降至 79.3；在 200 条医师标注上 ECE=.038、κ=.91。实验使用 5 个随机种子、8 张 A100，总计 42.6 GPU-hours，约为一次 ORPO 的 4 倍。创新在于把“医学上说得通”变成训练时可计算的结构化约束；证据限制更重要：9.2% 的不安全残留来自合成场景，尚无真实 EHR、真实患者结局或临床前瞻性验证，数据和代码的公开状态也需以接收后版本为准。适合医疗安全、神经符号学习和偏好优化读者；建议读 §3 的生理图与安全评分、§4 的 ORPO 迭代、表 2–5、消融、噪声实验和 Limitations。
