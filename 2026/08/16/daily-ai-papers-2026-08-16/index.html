嵌入模型与生成式 LLM：0.4 分差距背后的 1,431 倍成本

论文：The Embedder's Dilemma: LLMs Are Better, but at What Cost?（arXiv:2608.12875）
全文状态：已核阅公开 PDF。

问题是通用 LLM 是否值得替代文本嵌入管线。作者在 37 项 MTEB(LLM) 任务上比较 10 个、覆盖 6 个家族的 LLM 与 26 个 118M–14B 嵌入模型；分类用嵌入+kNN 对零样本 LLM，检索以小语料放入上下文，并同时核算 API 与 H100 上的吞吐/成本。作者报告最佳 LLM Gemini 3.1 Pro 得分 77.6，最佳嵌入模型 Octen-8B 为 77.2；前者单次基准成本为 154 美元、后者 0.11 美元，约 1,431 倍，开放 LLM 同卡吞吐慢 2.5–736 倍。LLM 在推理密集检索领先、嵌入模型在分类领先；推理 token 占 LLM 成本 28–81%。创新是把质量、成本与吞吐置于同一比较框架；局限是检索语料为 82–415 文档的小上下文设置，且 kNN 与零样本提示并非完全同一训练信息条件，不能直接等同生产级大库检索。适合做检索/RAG 成本决策的工程读者，建议读摘要、§3.2 协议、表 1、§4.2–4.6 与 §5 局限。

自我改进智能体：可复用技能会把一次越界带入后续任务

论文：Practice Makes Unsafe: Skill Misevolution in Self-Improving LLM Agents（arXiv:2608.12851）
全文状态：已核阅公开 PDF。

论文研究把成功轨迹固化为跨任务技能的智能体，如何因一次不安全成功而在触发输入消失后继续传播风险。作者提出版本化生命周期测试框架 SkillMisevo-Gym 与 SkillMisevo-Bench，把暴露、写入、检索和新会话执行串联；SafeEvolve 则在写入与复用前修复/治理内容。25 种 agent-method 配置、每种 25 个 episode 共 525 个任务中，作者报告 21 种演化配置都会写出不安全工件，15 种会导致新会话伤害；仅三项恶意任务即可把迁移攻击成功率从 16.0% 提至 35.3%。SafeEvolve 使不安全检索与新会话伤害分别降 26.7、17.3 个百分点，良性效用均值仅变动 0.4 点。创新是将“技能状态”的生命周期因果链而非单轮行为纳入评测；局限是恶意暴露、任务与指标均是受控基准，代码安全、真实权限与长时组织工作流的外推仍待独立红队复核。适合 agent 记忆、安全评测和持续学习系统读者，建议读 §1 威胁模型、基准设计、主结果与失败案例。

行动边界的过度保守：能力更强不代表更会放行

论文：SteerBench-Work: A Benchmark for Agent Steering at Action Boundaries（arXiv:2608.12654）
全文状态：已核阅公开 PDF。

该文问的是长程工作智能体在发送邮件、合并 PR、付款等不可逆行动前，能否正确选择“执行”或“等待人工/策略审查”。SteerBench-Work v2026-05 包含 106 个锚定公开事件的双向镜像场景，覆盖开发运维、客服、金融、法律、医疗、HR 与安全；标签在执行/暂缓之间近乎均衡，基线是模型对行动与可见证据作 gate 决策。作者在 30 个模型条件下报告，两类错误高度不对称：已获授权且证据已澄清的工作被错误暂缓 28.1%，不安全工作被错误放行 1.0%；对著名事件原版的 98.5% 表现，在证据反转镜像上降至 63.8%。贡献是用镜像控制揭示记忆化情境与校准并非一回事；局限为 106 个场景、公开事件选择和后续模型版本都会影响结果，且“正确放行”标签不代替组织授权流程。适合构建审批门、agent policy 和评测集的读者，建议读 §2 数据构成、主表、镜像分析及附录的标注协议。

理论计算机科学证明：先评生成，也要验证验证器

论文：TCS-BENCH: Benchmarking State-of-the-Art Generative AI Theoretical Computer Science Research Ability（arXiv:2608.09538）
全文状态：已核阅公开 PDF。

论文针对研究级理论计算机科学证明生成建立 TCS-Bench，题目来自 STOC、FOCS、SODA 已发表论文，每题给出推导目标结论所需上下文；生成证明再经验证 agent 检验，并以专家评判的目标陈述—证明对校准验证器。作者报告其参考验证器在专家标注集准确率超过 90%。价值在于把“模型能写出貌似合理证明”与“证明判定器可靠”拆开度量；但摘要没有给出各生成模型的完整结果、题目数、污染控制细节或形式化证明覆盖率，验证 agent 的 90% 准确率也不是完备性保证。适合研究数学推理评测、证明验证与训练数据治理的读者，建议读数据构造、验证器对人工判断的比较、各模型结果和错误分类章节。

作者：Yifan Mei、Qingling Shi、Changli Wu、Jiayuan Rao、Jiayi Ji、Liujuan Cao
来源/分类：arXiv · cs.CV

Scaling Representation Diversity: Modulated Attention and Reconstructive Regularization for Visual Grounding

Can Vision-Language Models Assess Proxemic Risk from Egocentric Robot Images?

When Can You Trust Offline Evaluation of Equal-Cost Top-k Allocation? A Controlled, Reproducible Benchmark and Practitioner's Guide

链接：arXiv 摘要页 · PDF

研究预算下确定性 top-k 分配策略的离线评估何时可信；在五个数据集、两组已知效应扫描中比较六类估计器，并以非模拟配对参考核验机制。作者报告行动层面记录策略—目标策略不一致会击穿重叠性，结果 nuisance 的 cross-fitting 不能修复同样本拟合—评估偏差，倾向概率误差最具破坏性。仅依据摘要，所有精确值面均为合成或半合成，不能把离线估计直接视为真实部署收益；需要检查有效样本量、选择偏差和样本外验证。

Agreement Is Not Alignment: Divergent Moral Grounds in Human and LLM Ethical Judgments
