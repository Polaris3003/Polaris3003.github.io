MetaReason：用可编辑结构化表示做几何多模态推理

论文：MetaReason: Precise Interleaved Multimodal Reasoning via Editing Meta Information for Solving Geometry Problems（arXiv:2608.15006）
全文状态：已核阅公开 PDF。

核心问题是：视觉语言模型在平面几何中需要画辅助线，却容易因像素生成失真或逐步写绘图代码而出错。方法先把图形解析为由点和形状组成的 JSON 元信息，MetaJudge 重渲染并核对结构；通过后，MetaReasoner 只可调用连线、求交点、作垂线三种工具，并以 SFT 加 GRPO 学习工具序列；若结构不可靠则回退文本推理。对比对象包括 CodePlot-CoT、VisualSketchPad、直接生成中间图的统一模型及开闭源 VLM。论文报告 TutorGeo 含 13.7 万样本（其中 1.7 万图到元信息、6 万纯文本轨迹、6 万交错轨迹），ExamGeo 含 1,000 道按人类难度分层的题；在 ExamGeo 达 56.1%，较基础模型提高 43.0 个百分点。创新在于用可验证、确定性渲染的中间状态取代“看起来正确”的图像。局限是元信息抽取失败时仍回退 CoT，且基准集中在平面几何；训练数据、闭源模型比较及推理成本仍须独立复核。适合多模态推理、工具调用与教育 AI 读者；建议先读摘要、§3、§4、表格实验与消融。
链接：PDF · 代码

AeroCopilotBench：静态知识分数不能替代安全执行评测

论文：AeroCopilotBench: A Two-Tier Benchmark for Evaluating LLM Agents as Aviation Copilots in an Interactive Virtual Cockpit Environment（arXiv:2608.16349）
全文状态：已核阅公开 PDF。

该文检验 LLM 能否在局部可观测的驾驶舱中完成程序并保持安全，而非只会回答航空知识题。ACOE 将 POH 程序编码成状态转移、终局条件与硬安全约束；Tier-1 有 1,200 道选择题，Tier-2 有 73 个紧急/异常任务，模型可使用 12 个固定工具，成功必须同时完成目标且不违反任何硬约束。12 个模型在 Tier-2 各运行 219 次；论文报告最高成功率为 72.6%，最优开权重模型为 53.0%，且 451 个复盘失败中 416 个落在遗漏关键步骤、错误语义先验、状态门控失败与长程漂移四类。创新是把任务完成与轨迹安全分离计分；代价是每回合模型会消耗大量工具调用和 token，最高分仍有 27.4% 失败。局限是只覆盖两种机型、12 个场景模板，且无连续空气动力学、传感器噪声、真实时间压力或外部检索。适合高风险 agent、评测和回归测试读者；建议读 §3.4、表 2–3、§5.2 与限制部分。
链接：PDF

CompoSkill：逐个扫描安全的技能，组合后仍可能危险

论文：CompoSkill: Compositional Skill Chain Attacks from Individually Scanner-Passing LLM Agent Skills（arXiv:2608.16246）
全文状态：已核阅公开 PDF。

论文挑战“每个技能通过扫描器，系统即安全”的节点级假设。方法将风险定义为路径性质：白盒攻击者直接注入技能 ID 链，黑盒攻击者仅知道角色画像、下载常用技能后在 Skill Composition Graph 中搜索隐式诱导链；CompoSkill-Bench 覆盖 5 类威胁、6 类场景、76 个职业工作流，含 380 个任务的三种变体，共 1,140 条记录。论文报告白盒/黑盒的风险链形成率最高分别为 83.3%/80.6%，现有逐技能扫描器只能拦截一部分；超过三跳后 ASR 下降，提示链长与攻击可执行性并非单调关系。创新是把审计对象从包升级为能力、输出与副作用相连的路径。局限是市场技能池、威胁模板与受测智能体的代表性决定结果，攻击成功不等于真实业务已被攻破；应在真实权限、审批和隔离环境中红队复验。适合 agent 平台、插件生态与安全工程读者；建议读威胁模型、基准构造、RQ1–RQ2 与失败分析。
链接：PDF

Representation Signatures and Risk-Feedback Alignment in LLM Trading Agents

作者：Weicheng Xue
来源/分类：arXiv · cs.LG、q-fin.CP · 【跨主题】
链接：arXiv 摘要页 · PDF · 代码/数据

仅依据摘要：研究 LLM 交易智能体在压力下的表征漂移与风险反馈；TradeArena 记录可回放轨迹，并在 80 个失败锚点、8 条模型轨迹上比较多种探针。论文报告计划/风险融合表征可区分回撤前状态，但真实审计反馈对校准和收益的作用因模型而异。价值在于将“交易好不好”改成可审计的对齐问题；这不是盈利证据，51 只股票的日内实验、回测设定和成本均限制外推。

MetaReason: Precise Interleaved Multimodal Reasoning via Editing Meta Information for Solving Geometry Problems

作者：Penghao Yin、Haomin Wang、Qihong Tang、Xiaoye Qu、Hongjie Zhang、Xiao-Ping Zhang
来源/分类：arXiv · cs.CV、cs.AI、cs.MM
链接：arXiv 摘要页 · PDF · 代码

研究图形几何中如何以结构化元信息和有限工具构造高保真辅助线；数据包含图到元信息、文本及交错多模态轨迹，并以 SFT/RL 训练。论文报告优于所比较开源模型、接近专有模型。值得关注的是可验证中间状态；基准范围、训练数据污染控制、比较模型版本和推理算力仍需结合全文审查。

AeroCopilotBench: A Two-Tier Benchmark for Evaluating LLM Agents as Aviation Copilots in an Interactive Virtual Cockpit Environment

作者：Yuchen Yuan、Zhenghuang Wu、Yuangan Li、Liang Ma、Ke Li
来源/分类：arXiv · cs.AI
链接：arXiv 摘要页 · PDF

研究航空智能体如何从静态知识走向带硬安全约束的交互式执行；基准含 1,200 道知识题与 73 个任务。论文报告最高 Tier-2 成功率 72.6%，且静态知识不稳定地转化为程序执行。价值在于安全门控评测；虚拟环境、有限机型和冻结工具接口不能证明真实飞行可用性。

CompoSkill: Compositional Skill Chain Attacks from Individually Scanner-Passing LLM Agent Skills

作者：Mingxiao Liu、Zhoumian Jiang、Jianan Ma、Jian Zhang、Jialuo Chen、Xinhao Deng、Zhen Wang
来源/分类：arXiv · cs.CR、cs.AI
链接：arXiv 摘要页 · PDF

研究单技能认证为何遗漏跨技能攻击链；以白盒/黑盒攻击者和 1,140 条长程工作流记录测试路径级风险。论文报告两种设置的链形成率最高达 83.3% 与 80.6%。价值在于把安全边界扩展到组合；模拟场景和技能市场覆盖仍是关键证据限制。

Insurance as AI Risk Infrastructure: A Generative-Agent Simulation of AI Adoption

作者：Yixuan Yuan、Dedai Wei、Chudong Qian、Jielin Feng、Ziyue Lin、Yuheng Zhao、He Cao、Erasmo Purificato、Xinwu Ye
来源/分类：arXiv · cs.MA
链接：arXiv 摘要页 · PDF

仅依据摘要：研究保险能否为企业采用 AI 的残余尾部损失提供事后风险转移；以 LLM 驱动的多智能体社会仿真评估。论文报告该框架降低企业暴露并提高总体采用、偿付能力与资本。价值在于把技术防护与金融兜底区分；仿真的行为有效性和参数设定不等于真实保险市场或因果效果。

FinFraudBench: A Heterogeneous Graph Benchmark for Financial Fraud Detection

来源/分类：arXiv · cs.LG、cs.AI
链接：arXiv 摘要页 · PDF · 代码/数据

仅依据摘要：研究异构金融实体与极端类别不平衡下的欺诈检测；发布两套最高 899 万节点、8,923 万有向类型边的数据及排序/不平衡分类协议。论文报告基线实验揭示现有方法局限。价值在于接近运营数据结构；匿名发布、标签质量、时间切分与潜在泄漏决定其真实泛化。

LAPF: LLM-Agent-Based Path Finder Using the UAVScenes Dataset

作者：Yousef Emami、Mohammadhossein Homaei、Hao Zhou、Miguel Gutiérrez Gaitán、Atefeh Hajijamali Arani、Rui Zhang
来源/分类：arXiv · cs.RO、cs.AI
链接：arXiv 摘要页 · PDF

仅依据摘要：研究 LLM 无人机导航如何结合感知、记忆、计划与动作闭环；在开放场地和障碍场景各做三次独立试验。论文报告平均路径为 512.83/506.37 米，相对 CoT 缩短 17.2%/15.6%。价值在于将危险绑定到有限纠正动作；试验次数少、仿真场景与直线最优基准均不足以说明真实飞行安全。

Agentic Data Cleaning Without a Clean Reference: An Experimental Study of Capabilities and Trade-offs

作者：Hadi Fadlallah
来源/分类：arXiv · cs.AI、cs.DB
链接：arXiv 摘要页 · PDF

仅依据摘要：研究没有干净真值时，证据检索、可执行检查、保守修复和溯源日志的权衡；在金融、临床、环境数据的受控损坏上完成 126 次运行。论文报告确定性 profiling 基线的检测 F1 为 0.561，最完整 LLM 配置为 0.421，且没有配置全面占优。价值在于反对“能力叠加必然更好”；合成损坏与未直接修复限制对生产清洗的结论。

Don't Drop the BATON: Long-Horizon Robot Manipulation via Agentic Subtask Exploration and Transition-aware Memory

作者：Bingxin Xu、Yuzhang Shang、Emilio Ferrara
来源/分类：arXiv · cs.RO、cs.AI、cs.CV
链接：arXiv 摘要页 · PDF

仅依据摘要：研究长程机械操作中阶段误差累积；BATON 按子任务探索并用过渡感知记忆处理前后条件。论文报告在 RoboMemArena 上任务成功率及累计成功率较 SOTA 提高 11.6%/14.9%。价值在于将探索成本从约 TK 降为 T×K 的设计思路；基准、冻结 VLA 与无参数更新设定限制机器人迁移判断。

LLMs for Zero-Shot Threat Detection via Structured Risk Indicators

作者：Abdullah Alghamdi、Siamak Layeghy、Marius Portmann
来源/分类：arXiv · cs.CR、cs.LG、cs.NI
链接：arXiv 摘要页 · PDF

仅依据摘要：研究零样本威胁检测，先由 LLM 从日志生成可解释风险指标，再跨时间分类，并比较是否使用 RAG。论文报告相对 GABM 在 CERT r5.2/PicoDomain 的最佳 F1 分别提高 11.40/31.50 个百分点。价值在于指标层的可解释性；基准漂移、告警成本和检索历史泄漏仍需核验。

A Human-LLM Teaming Framework for Privacy Risk Analysis: An Illustration with CBDC-Based Welfare Schemes

来源/分类：arXiv · cs.ET、cs.AI、cs.CE、cs.CY
链接：arXiv 摘要页 · PDF

仅依据摘要：研究 CBDC 福利系统的隐私风险评估如何人机协作；LLM 汇总文档、专家辨别证据和推断并迭代修订。论文以 PRIAM 的数据刻画活动作示例，报告人类可发现信息缺口和无支撑输出。价值在于保留专家最终判断；这是说明性案例，不能证明框架在不同制度或真实损害上有效。

A Policy Algebra for Trust-Preserving Agentic AI Execution

NumerosityVLM: A Cognitively Inspired Benchmark for Interpreting Numerosity Representations in Vision-Language Models

来源/分类：arXiv · cs.CV、cs.AI
链接：arXiv 摘要页 · PDF · 代码/数据 · 数据集

仅依据摘要：研究 VLM 的数量感是否被大小、布局等视觉相关因素混淆；基准用 10,800 张合成图正交控制因素，并评测 7 个模型。论文报告架构解释的方差最大（partial ω²=0.325），数量信号早现于视觉编码器。价值在于诊断而非纯分数；合成刺激是否代表自然图像计数仍有限制。

From "What-If" to "What-Is": Counterfactual Thinking-Inspired Semantic Alignment for Visual Brain Decoding

LLMs Can Predict Failure Risk, But Struggle to Predict Which Collaboration Protocol Pays Off: Cost-Aware Protocol Routing Across Reasoning Tasks

链接：arXiv 摘要页 · PDF

IP Protection in the Era of Visual Generative AI: A Survey

AeroGround: A Comprehensive Benchmark for Aerial-Ground Collaborative Reasoning
