ATBench：安全识别尚可，风险机理诊断仍明显不足

论文：ATBench: A Diverse and Realistic Agent Trajectory Benchmark for Safety Evaluation and Diagnosis（arXiv:2604.02022）
全文状态：已核阅公开 PDF。

论文关注多步工具调用中的安全风险能否被可靠评估，而不是测量部署中 agent 的实际作恶率。ATBench 用“风险来源、失败模式、现实伤害”三维分类生成并审计完整轨迹：1,000 条样本（503 安全、497 不安全），平均 9.01 轮、3.95k token，调用 1,954 个工具，候选工具池为 2,084 个；生成后再经规则过滤、LLM 过滤与五名审阅者的全量人工核验。比较对象包括前沿闭源/开源模型和专用 guard 模型，统一读取同一条完整 ReAct 式轨迹。

论文报告 GPT-5.4 的二分类 F1 最高也只有 76.7%，其风险来源、失败模式和伤害的细粒度诊断准确率分别为 33.6%、13.5%、30.2%；AgentDoG-Qwen3-4B 的风险来源与伤害诊断较强（46.8%、40.6%），但失败模式也仅 16.5%。这说明“发现结果不安全”与“复原风险如何经工具接口、状态和延迟触发演化”是不同能力。创新在于把可控覆盖、长上下文和可诊断标签放入同一评测面；局限是轨迹仍由合成引擎构造，人工审核可修正标签却不能证明其分布等同真实生产日志，且评测模型、提示模板和安全分类法都会影响数值。适合 agent 安全、运行时监控、评测工程读者；建议优先读摘要、§3 构造流程、表 2、§4.2 及跨基准比较。

AI4AI-Bench：当前 agent 距“改进训练算法”仍很远

论文：AI4AI-Bench: Benchmarking LLM Agents in Algorithmic Design for Recursive Self-Improvement（arXiv:2608.20318）
全文状态：已核阅公开 PDF。

论文把“递归自我改进”收窄为更可测的问题：agent 是否真的改写了训练算法，而非只搜数据、调超参或改变运行配置。基准冻结 10 个研究仓库、覆盖 10 类训练算法；每个任务给 agent 4 小时和一张 B300 改写算法，随后从头运行最多 12 小时，由隐藏固定评测器与原仓库算法在相同流程下比较。由于任务指标不可直接比较，作者把各任务线性映射为 0（无信息模型）、0.1（原始算法）和 1（任务最优）。

在 6 个系统、29 个配置、全部 10 个任务的结果中，论文报告平均分为 0.166，最佳系统为 0.250，仍未走完“原算法到最优”距离的五分之一；真正更改学习机制的提交平均 0.226，未更改者为 0.126。提高推理投入将这类提交比例从 8% 提到 64%，均分从 0.094 提至 0.196。它的价值是把“会做 AI 研究”从模糊演示转成可复跑、等算力预算的算法设计测验；局限是 10 个冻结仓库的代表性、隐藏评测器的目标函数和 4/12 小时预算都会塑造结论，且分数改善不等于跨领域或真实研发效率提升。适合研究 agent、训练算法与 AI 能力评测读者；建议读摘要、§2 任务定义、§3 评测协议、主结果表和失败案例。

CAViAR：VLM 的感知正确不等于能判断事故责任

论文：CAViAR: A Causal Video Dataset for Fine-Grained Accident Reasoning in Real-World Scenarios（arXiv:2608.19380）
全文状态：已核阅公开 PDF。

论文研究驾驶事故视频中“谁看起来应负责、违反了什么规则”能否由 VLM 从可见证据推断。CAViAR 基于 CCD 的 1,500 段和 Nexar 的 749 段真实行车记录构成 2,249 段视频、20,108 条问答；以 CCD 训练、Nexar 测试，明确无共享视频、场景或设备。标注覆盖天气、光照、路况、事故类型、因果说明、表面责任主体、受影响主体和可见规则违规类别；责任标签对证据不足的样本留空，且论文强调它们不是法律责任认定。作者在 Cosmos-Reason2、Qwen3-VL、InternVL3 的 2B/8B 版本上比较零样本与 LoRA 微调，并加入多数类/随机基线、平衡准确率和 macro-F1。

作者报告在 Nexar 上，微调可显著改善部分小模型，例如 Qwen3-2B 的 MCQ 准确率从 55.67% 到 67.16%、BERTScore-F1 从 20.07 到 45.36；但 8B 模型的 MCQ 增量落在作者给出的 bootstrap 不确定性范围内。模型对光照等易感知属性相对更好，天气/路况经类别不平衡校正后可接近或低于多数类基线，而事故类型及责任推断明显退化。创新是将视频感知、因果链与可见规则相关的责任标签合并，并采用跨数据源测试；局限是责任的“表面”定义、四人标注与 GPT-4 语言润色流程、使用 GPT-4o 作开放题裁判及单次训练运行都会限制外推。适合自动驾驶安全、交通视频理解和多模态评测读者；建议读 §3 标注与切分、表 2/3、§4.1 指标协议和误差分析。

链接：arXiv 摘要页 · PDF · 代码与标注

SameCapRisk-Bench：检索到“对的技能族”仍可能把错的技能放进上下文

论文：Right Family, Wrong Skill: Benchmarking Risk Exposure in Agent Skill Retrieval（arXiv:2606.10388）
全文状态：已核阅公开 PDF。

论文聚焦 agent 技能检索中更细的失败：检索器找到正确能力族，却把同族中不满足当前资源、前置条件、时效或输出契约的“危险兄弟技能”排入 top-K。SameCapRisk-Bench 有 1,190 个技能风险单元、1,686 个查询：核心层在 8,048 个公开候选中施压，困难层让两项技能在成对查询中互换“有用/危险”角色。除 Recall/NDCG 外，作者提出 HSR@K（危险兄弟暴露率）及 CleanHit@K（检索到有用项且未暴露危险兄弟）。

论文报告 SkillRouter、SkillRet、R3-Skill 的 Recall@3 为 0.848、0.873、0.888，但 HSR@3 也分别为 0.346、0.362、0.372；即高召回并没有排除错误的可执行上下文。使用已发布的受控家族关系的参考管线将 HSR@3 降至 0.007，Recall@3 为 0.833；不使用家族标签的文本聚类选择器仍只能把 HSR@3 降至 0.128–0.182。创新在于把“检索相关性”与“查询条件下的执行契约安全”分开报告；局限是 HSR 仅度量标注的兄弟项暴露，不等于完整运行时安全率，参考管线还使用基准关系及部分训练信号，不能与完全公开检索器当作同等部署条件比较。适合 agent 技能市场、RAG 路由和软件供应链治理读者；建议读 §3 指标、表 2、§4.3、表 4 与 §5 的执行范围界定。

链接：arXiv 摘要页 · PDF

DARS: Dual-Level Credit Assignment RL with Structured Reasoning for Instruction-Based Image Editing

作者：Haoxiang Cao、Jiajiong Cao、Xuanpu Zhang、Changqian Yu、Chaoqun Wang
来源/分类：arXiv · cs.AI
链接：arXiv 摘要页 · PDF

仅依据摘要：研究图像编辑的规划器—渲染器为何难从最终奖励获得正确归因。作者以多规划/多渲染 rollout 区分模块间与模块内方差，用结构化四字段推理、前缀门控奖励和 token 级优势重权，并在五个基准与相同骨干、数据、奖励模型、rollout 预算的 Joint RL 基线比较。论文报告整体优于基线，推理密集编辑收益最大；奖励模型偏差、训练数据污染、审美主观性及额外 rollout 算力是关键限制。

Rethinking the Evaluation and Optimization of LLM-Based Social Simulation

作者：Pei Wang、Xu Chen、Ji-Rong Wen
来源/分类：arXiv · cs.AI
链接：arXiv 摘要页 · PDF

仅依据摘要：研究社会模拟把单个人类答案当唯一正确标签的评测偏差。作者提出主观性系数与适应性软标签训练 SALT，构建含 19,300 个上下文、193 位标注者、100 个主观问题的 SUBJSIM，并以完整回应分布评测。论文报告该方法在 SUBJSIM 上更有优势。价值在于将“拟合一个观察值”与“拟合行为分布”区分；聚合邻域、标注者代表性、问题覆盖及模拟到真实人群行为的外推仍不成立。

Accelerated Genetic Programming Hyper-Heuristics for Simulation-Based Scheduling via Agentic AI
