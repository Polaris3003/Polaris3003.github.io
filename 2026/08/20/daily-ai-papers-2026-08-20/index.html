PathPocket：把病理多模态问答接到可追溯证据图谱

论文：A Multimodal Agentic Pathology Co-pilot via Evidence Grounded Reasoning（arXiv:2606.08093）
全文状态：已核阅公开 PDF。

问题是通用多模态模型在病理诊断中容易给出难以追溯的结论。PathPocket 以约 110,472 份分层证据构建含 455 万实体、710 万关系的病理超图，再由理解、检索、过滤、诊断生成等协作代理处理文本、ROI 与全切片图像；比较 GPT-4.1 mini、GPT-5 mini、Grok 4.1 Fast、Qwen3.7 Plus，以及 CONCH、PLIP 等模型。作者报告：在 1,854 例私有文本病例的 SMU-Text 4 上为 93.1%，高于 Qwen3.7 Plus 的 85.6%；BreakHis ROI 任务为 74.3%，高于 Qwen3.7 Plus 的 71.6%；SMU-VL 6 为 84.7%，高于 GPT-5 mini 的 78.4%。创新是让输出绑定分级医学证据而非仅依赖参数记忆。限制同样实质：多项私有、恶性病例占比较高的数据集限制外部复现和泛化；证据库覆盖、检索遗漏、以及用户研究设计仍须独立审计，不能作为临床决策替代。适合计算病理、RAG 与高风险 agent 读者；建议读 §2、§3、图 3–5、附录检索消融。

MobileWorldSafety：手机 GUI agent 对环境注入仍普遍脆弱

论文：MobileWorldSafety: Benchmarking GUI Agent Safety Against Environmental Injection Attacks in Android Apps（arXiv:2608.17659）
全文状态：已核阅公开 PDF。

论文评估普通 App 环境中的间接提示注入，而不是只测网页或文本聊天。基准在真实 Android 应用上定义 142 个风险任务，最终状态先由规则验证、歧义案例再由 LLM 裁决，从而区分任务能力失败与安全失败；对比 4 个通用 agent 和 2 个专用 GUI agent。作者报告攻击成功率为 40.4%–66.9%：Gemini-3-Pro 为 66.9%、任务完成率仅 30.0%；Qwen3.5-397B-A17B 加系统安全提示后 ASR 从 51.6% 降至 37.0%，但停滞样本从 2 增至 20。专用 GUI agent 的较低 ASR 与更多运行失败混在一起，不能直接解释为更安全。贡献是可程序化的移动端安全终态评测；限制是只做了初步防御、模型版本与本地配置影响结果，且 142 个任务无法穷尽真实权限、第三方登录和跨设备攻击面。适合 agent 安全、移动自动化与红队读者；建议读 §3.4、表 1–3、§4.4 与 Appendix A。

PACE：把 DeFi agent 的许可绑定到具体交易字节

论文：PACE: Policy-Attested Contract Execution for Safe AI Agents in Decentralized Finance（arXiv:2608.17220）
全文状态：已核阅公开 PDF。

核心问题是模型通过了策略或模拟检查后，提交到链上的 calldata 仍可能被替换。PACE 使用类型化意图、确定性策略验证器、仿真报告和签名 PDR，将许可、策略和交易字节加密绑定；在 Solidity 智能账户中执行并对比 6 个非 PACE 基线。作者在内存 DeFi 模拟器的 40 任务、10 种子、2,800 次确定性试验中报告 PACE 的不安全执行和良性误报均为 0，而无防护基线不安全执行率为 0.80；移除 calldata 绑定后为 0.025，放宽策略后为 0.575。三模型实时 LLM 试验（595 次）也报告 PACE 防护后的攻击成功率为 0，但误报为 5.0%–12.8%；链上验签额外消耗 29,826–31,822 gas。创新是将“批准”做成可验证的交易级不变量。作者明确限制：主要结论来自简化模拟器与 regex mock LLM；0 率是该基准中的逻辑属性，不是主网安全保证，也非投资建议。适合智能合约安全与 agent 执行层读者；建议读 §4–7、表 1–3、威胁模型和限制。

来源/分类：arXiv · cs.AI

EvoTS-Agent: A Self-Evolving LLM Agent for Financial Time Series Change Point Detection
