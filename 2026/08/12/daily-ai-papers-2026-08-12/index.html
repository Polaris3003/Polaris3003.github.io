每日 AI 论文简报｜医疗 Agent、可演化安全与技能检索

重点关注

以下均为 arXiv 预印本，尚未经同行评审；“论文报告”不是独立验证结论。

GatorOnco：结直肠癌治疗规划 Agent

Mengxian Lyu 等｜arXiv 2608.09142｜cs.CL｜PDF

  • 问题、方法与基线。 面向需要随指南更新的结直肠癌治疗计划，作者从 Llama-3.1-8B 出发，以 2,820 亿生物医学 token（其中 UF Health 临床文本 1,660 亿）持续预训练、模型合并、SFT 与带交错检索的 GRPO；训练/验证使用 316/79 例真实病例。比较 Llama-3.1-8B、Llama-3.3-70B 与 MedGemma-27B，并由 5 名肿瘤科医生盲评。
  • 作者报告的结果。 单治疗宏 F1 为 0.924（基线 0.748–0.910），多治疗集合正确 73/79（92.4%，基线 55–68 例）；医生评分中，正确性 4.09 对 4.11、安全性均 4.22，均与医生无显著差异。可读性/完整性更高不等价于临床疗效或可自主部署。
  • 创新、局限与阅读。 将动态 NCCN 检索、分层安全奖励和临床领域适配整合到治疗规划，实测比仅问答更接近真实工作流。样本来自单一医疗系统且只有 79 例留出集；对数据漂移、指南更新、少见病情、偏见和前瞻性临床结局仍无证据。适合医疗 AI、RAG 与安全团队；优先读第 3–4 节、图 3–4 及局限讨论。

SHE：从失败轨迹演化 Agent 安全壳

Wanying Qu 等｜arXiv 2608.09885｜cs.AI、cs.CV｜PDF｜项目代码

  • 问题、方法与基线。 论文不直接改模型权重，而将 harness 分为系统提示、规则库、安全记忆、工具策略四件可归责产物；用 rollout 失败诊断、局部编辑与安全—效用验证循环更新。对比静态 SafeHarness、Memskill-SafeHarness 等；进化用 15 个任务/90 个条件，余下 185 个任务及 AgentHarm 留出。
  • 作者报告的结果。 在 Agent-SafetyBench，平均攻击成功率从 seed 的 8.6% 降为 5.5%，clean UBR 从 25.7% 降为 19.8%，平均效用从 33.5% 升至 47.6%；AgentHarm 留出集 Harm Score 9.8%、Harm Refusal 86.4%。实验裁判和演化模型均为 LLM，因此不是独立安全保证。
  • 创新、局限与阅读。 贡献是让安全修复可定位、可回滚并做组件消融，而非全量重写提示词。评估使用固定基准、温度 0 与模型裁判，可能存在基准/裁判过拟合；攻击覆盖、跨工具成本和对抗性迁移仍待红队复现。适合 Agent 平台与安全工程；读第 3 节、表 1–3、4.3 节。

SkillReason：把“推理”留在技能检索训练期

Donghong Jiang 等｜arXiv 2608.08640｜cs.AI｜PDF

  • 问题、方法与基线。 针对用户请求短且隐含能力需求的技能库检索，作者新建含 3,729 查询、61,228 个技能、9 个领域的 SkillReason-Bench；先用强教师的能力推理轨迹做对比/分布/语言模型训练，再以 retrieval-guided GRPO 训练，推理时只编码原查询。基线包括 BM25、Qwen3-Embedding、SkillRouter/SkillRet 等。
  • 作者报告的结果。 4B 模型在 SkillReason-Bench 的 R@10 为 78.84、NDCG@10 为 65.93；0.6B 版相对自身 Qwen3-Embedding-0.6B 的 R@10 平均提升 17.56 点，并在三套基准多数指标领先。它仍是离线检索结果，不证明下游工具执行会成功。
  • 创新、局限与阅读。 训练时显式学能力推断、部署时避免自回归 CoT，兼顾检索延迟与隐含意图。教师轨迹质量、技能语料污染、top-k 之外的执行可靠性及 GRPO 训练成本需要独立测量。适合做工具路由/Skills 的工程师；读第 3 节、表 2–3 与附录数据构造。

CodecArena：以内容保真而非纹理相似评估视频编码

Jiaye Fu 等｜arXiv 2608.09139｜cs.CV｜PDF｜项目页

  • 问题、方法与基线。 LPIPS/DISTS 可能给“错误人物、文字失真”却视觉自然的视频高分。CodecArena 用参考视频条件下的成对比较，以身份、对象、文字、纹理、时序五维 Facet-GRPO 奖励；训练集含 1,500 比较组，评测集按源视频切分并有人类排序。对比 PSNR、SSIM、VMAF、LPIPS、DISTS 和多种 VLM 评估器。
  • 作者报告的结果。 Qwen3-VL-8B 版在 K=1/7/14 的成对偏好准确率为 93.7%/94.9%/93.0%，VMAF 为 85.8%/89.2%/90.0%；消融显示最终 facet anchor 的 SRCC/PLCC 高于仅偏好奖励。该结果衡量人类排序的一致性，不是编码压缩率或终端 QoE 的直接收益。
  • 创新、局限与阅读。 细分内容失真能暴露感知指标的“好看但不忠实”失败模式。偏好数据的一部分为自动生成，基准规模和视频分布仍有限，VLM 推理算力也可能高于传统指标。适合视频编码、生成视频与评测团队；读第 3 节、表 1–3、难例分析。

AI 论文

以下与重点关注合计 18 篇去重候选；每篇均保留摘要页和 PDF。除已在上节注明全文核验的 4 篇外，均仅依据摘要。

GatorOnco：结直肠癌治疗规划 Agent

Mengxian Lyu 等｜arXiv 2608.09142｜cs.CL｜PDF

研究高风险肿瘤治疗计划的指南一致性；以领域持续预训练、模型合并、两阶段后训练、Agent RL 与动态 RAG 处理患者信息和时效指南。论文报告在 5 位医生的盲评中优于开源 LLM，且多项评分与肿瘤科医生相当；值得关注的是临床 RAG 的可审计性。单中心、留出病例较少、没有前瞻性结局和真实部署审计，不能把作者结论视为临床安全证明。

PortBench：LLM 投资组合全流程基准【AI/金融】

Yuxuan Zhao 等｜arXiv 2605.27887｜cs.AI、q-fin.PM｜PDF｜代码

研究 LLM 能否完成跨资产配置而非只答金融题；基准覆盖六类资产、十年数据、6,269 道静态题和五阶段动态配置流程。论文报告十个前沿模型在 2024 年 90% 的模型—风险画像组合未能胜过等权，压力期仍有大回撤。它提醒金融问答强不代表配置能力；历史市场污染、回测摩擦、样本外滚动与真实可交易性仍须核查，不构成投资建议。

CodecArena：视频编码质量评估

Jiaye Fu 等｜arXiv 2608.09139｜cs.CV｜PDF

研究传统感知指标漏掉身份、文字和时序失真的问题；用参考条件下比较推理、五维保真面与 Facet-GRPO 训练 VLM，并建立自动偏好集与源视频隔离的人类排序集。论文报告优于既有感知/VLM 评估器。价值在把“视觉自然”与“内容忠实”分开；自动偏好监督、数据覆盖和 VLM 成本限制泛化。

多模态损伤评估系统

Kalelo Dukuray 等｜arXiv 2608.08935｜cs.AI｜PDF

研究灾损场景中的文档推理和恶劣环境感知；组合 RAG、知识图谱检索、热红外、视觉基础模型与无线感知。论文报告动态检索优于静态 few-shot，图谱检索在跨文档问题更强。价值在多模态冗余；摘要未给出统一端到端量化、真实灾害外推与合成图像偏差审计，证据有限。

HDR 近距离放疗沉浸式训练 Agent

Ronghua Xu 等｜arXiv 2608.08163｜cs.AI｜PDF

研究危险医疗操作的低风险训练；以 Meta Quest 3、移动端和本地 GPU 后端结合临床指南 RAG 助手。作者报告原型的端到端延迟、上下文精度与回答完整性“适合”教学。原型可行不等于改善培训或患者结局；缺少受训者对照、误导率与真实流程验证。

MRBench：人体动作—文本检索基准

Fulong Liu 等｜arXiv 2608.07993｜cs.CV｜PDF

研究动作文本检索的跨域与粒度不足；收集 3,390 个动作、118 类和 10,170 条多粒度描述，并训练轻量粒度感知模型。论文报告混合粒度检索改善且不损标准描述性能。它暴露跨数据集泛化缺口；伪监督文本、动作来源混合和描述标注仍可能带来分布偏差。

FinTrace：长程金融工具调用评测【AI/金融】

Yupeng Cao 等｜arXiv 2604.10015｜cs.AI、cs.CE、cs.CL、cs.MM｜PDF

研究“选对工具”是否等于“用好工具”；800 条专家标注轨迹覆盖 34 类金融任务，并以九个过程/结果指标评估 13 个 LLM。论文报告工具选择较强但信息利用和最终回答仍弱，DPO 提升中间指标却未消除端到端瓶颈。适合审计金融 Agent；标注口径、工具环境和金融时效性限制外推，非投资建议。

LLM 强化学习中的信用分配综述

Chenchen Zhang｜arXiv 2604.09459｜cs.CL｜PDF

研究稀疏奖励下 token、工具、记忆或 Agent 的贡献如何识别；综合 69 篇论文并提出六项诊断与 CA-ID Card。作者报告双人盲编码 252 格中一致 223 格。价值是明确因果可识别性与报告控制；其证据主要是文献审计，分类边界和研究覆盖会影响结论。

BAD-ACTS：Agent 对抗伤害鲁棒性

Jonathan Nöther 等｜arXiv 2508.16481｜cs.LG｜PDF｜代码

研究提示注入和恶意 Agent 如何诱发有害行动；基准含五种环境、238 个高质量样例及 699 个扩展对抗动作。论文报告不同模型攻击成功率在 40%–90%，零样本消息监控可缓解。基准覆盖并非现实威胁全集，防御对自适应攻击与效用损失仍需复现。

MateInfoUB：竞赛型多语多模态教育基准

Adrian M. Dumitran 等｜arXiv 2507.03162｜cs.CY、cs.AI、cs.CL、cs.LG｜PDF

研究 LLM 在罗马尼亚语/英语、图文并存的高阶计算机竞赛题中的能力；构建双语选择题并系统测评模型。论文报告语言选择会改变表现，并讨论考试公平。价值是脱离英文单模态基准；题库规模、泄漏与以选择题代理真实学习能力的局限必须注意。

SHE：安全壳演化

Wanying Qu 等｜arXiv 2608.09885｜cs.AI、cs.CV｜PDF

研究 Agent harness 如何随失败轨迹迭代安全边界；将提示、规则、记忆、工具政策解耦并做归责式局部演化。论文报告平均 ASR 由 8.6% 降至 5.5%，同时提升效用。LLM 裁判、有限进化任务和基准外攻击是关键限制，不能视为全面安全认证。

ATLAS：老年多病共存用药安全

Zihan Wang 等｜arXiv 2608.09443｜cs.AI｜PDF

研究患者遗漏信息时的用药冲突审查；把指南建成安全图、通过追问生成个体冲突图并由多 Agent 风险优先决策。论文报告在欧洲基准的严格成功率较最强专有基线高 53.73 点。自动评估中的“无不安全建议”不等于真实临床无害；跨指南、病例代表性与医生最终责任不可省略。

SafeSceneReason：工业安全多模态推理

Yuanchi Zhu 等｜arXiv 2608.09230｜cs.AI｜PDF

研究从工业图像推断违规、事故机制与预防；用场景图程序执行和事故报告证据图构建 123,695 个问答。作者报告代表性 VLM 在技术性、多证据推理仍弱。合成/抽取的题目结构可能放大规则线索，现场可靠性和责任界限仍无证据。

PROSLEX：印度法律条款预测与解释

Subinay Adhikary 等｜arXiv 2608.08830｜cs.AI｜PDF｜代码与数据

研究法律条款预测为何需要可解释推理；数据含 1,623 份专家标注文档和 7,450 条解释，并比较多种提示策略。论文将预测与理由的连贯性/法律有效性并评测。法律解释生成不等于司法正当性，司法区、标注一致性和幻觉风险限制使用。

FitAQA：健身动作质量评测

Kaili Zheng 等｜arXiv 2608.08736｜cs.AI｜PDF

研究 MLLM 能否识别、判断并定位动作错误；基准含 2,219 视频、5,512 QA、30 项徒手动作及 38 类错误。作者报告给真值视觉证据时判断大幅提高，视觉感知是瓶颈。专家分类与拍摄条件的覆盖限制家庭/医疗运动场景泛化。

TomaMMU：番茄叶病多模态理解

Gia-Han Truong 等｜arXiv 2608.08727｜cs.CV、cs.AI｜PDF｜数据

研究 VLM 的植物病理理解；28,808 图像、15 类病害和 213,119 人工标注问答支撑七项任务。论文报告微调后挑战 MCQ 准确率达 96.09%。田间地域、品种、相机和病害共现的分布变化仍可能使效果下降。

SkillReason：隐式请求的技能检索

Donghong Jiang 等｜arXiv 2608.08640｜cs.AI｜PDF

研究从简短目标推断所需技能；用教师推理轨迹与 GRPO 训练检索器，部署时不生成 CoT。论文报告在三基准领先。离线 R@k 未覆盖技能实际执行、版本冲突、权限和延迟，须以端到端任务复验。

开放权重模型的金融文本理解【AI/金融】

Jan Spörer｜arXiv 2608.08634｜cs.AI、cs.CL、cs.IR、q-fin.GN｜PDF

研究开放模型能否读懂年报；更新后的 Financial Touchstone 含 495 份国际年报、2,967 题，比较 20 个模型。论文报告 Claude Opus 4.6 准确率 88.4%、Gemini 2.5 Pro 幻觉率 0.08%，检索占失败 48.9%。年报问答分数不代表投研可靠性；资料时效、评测污染与供应商访问路径都会影响结论，非投资建议。
