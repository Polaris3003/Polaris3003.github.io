FinRCA-Bench：把“取证失败”和“推理失败”拆开量化

论文：FinRCA-Bench: Benchmarking Evidence Retrieval and Reasoning for Financial AI Systems（arXiv:2608.18534，跨主题）
全文状态：已核阅公开 PDF。

问题是财务对账诊断的答案对不对，常把“模型没拿到关键流水”误当成“模型不会推理”。论文构造 2,250 个应付账款至银行对账的确定性合成案例：14 张运营表、15 类注入原因中的 1,500 个失败案例，以及 750 个正常或困难负例；模型看得到记录，评测方私有根因与逐记录证据契约。作者固定下游推理模型、提示与生成设置，只更换检索器，比对 Rules/SQL、经典 ML、稠密语义检索、关系扩展和仅沿持久化交易关系遍历的 TPGR。

作者报告 Rules/SQL 的留出精确准确率为 84.97%，经典 ML 为 95.44%；在固定推理设置下，宏观必需记录召回从 0.83% 升至 77.70%，16 类精确准确率从 2.05% 升至 72.44%（配对差 70.39 个百分点，95% bootstrap CI 为 66.06–74.72），而 TPGR 使用的记录和源 token 更少。更关键的是，结构性检索失败与“证据已足仍推理错”的数量为 95:15；即使标签答对，严格返回证据契约的准确率也仅 5.72%。创新不是宣称图检索普遍更好，而是用受限、可解释的检索干预识别证据访问的作用。限制很明确：数据为合成、因果类别与持久化关系是人为设计的；经典结构化方法已很强，结果不能外推成所有财务 RAG 的结论，更不能替代审计或业务判断。适合财务 AI、企业 RAG 和可审计 agent 读者；建议先读摘要、§3–5、表 1 与 §7 的失败归因。

AFANet：多 agent 失败归因未必需要长上下文大模型

论文：Beyond LLM-Based Reasoning: Lightweight GNNs for Agent Failure Attribution（arXiv:2608.18575）
全文状态：已核阅公开 PDF。

论文研究失败的多 agent 轨迹中，哪一个 agent 以及哪种错误类型是根因。AFANet 将逐步语义信号与 agent 间关系编码为对话图，用 GNN 消息传递归因；基线包括直接提示、Qwen 2.5/3 的预训练、SFT 与 GRPO 版本。它在 AEGIS-Bench 与 Who&When 上报告与或优于这些 LLM 基线的表现，并在 OOD 基准上尝试低成本测试时适配。

图 1 报告相对 LLM 路线最高约 70 倍训练加速与 300 倍推理加速；表 1 同时显示该任务本身仍难，尤其错误类型与 agent-错误配对分数远低于单纯 agent 识别。贡献在于把“读完整轨迹后生成解释”的问题重构为结构化归因，并显式将成本纳入比较。需要谨慎：两项基准及其标签定义决定了图结构可利用程度；论文的“近零推理成本”不包含生成/提取轨迹语义特征的端到端系统成本，且 OOD 的可迁移性仍依赖适配数据。适合维护生产 agent、关注 observability 和成本的工程团队；建议读摘要、§3–5、表 1、图 1 与消融实验。

FM-Bench：把长期经营与竞争放进无 LLM 裁判的环境

论文：FM-Bench: A Benchmark for Long-Horizon Management with Competing Agents（arXiv:2608.18423）
全文状态：已核阅公开 PDF。

FM-Bench 用足球俱乐部管理检验语言模型 agent 的长期决策，而非单回合工具调用：每个 agent 在 20 个赛季、约 340–400 个决策点、26 个工具下完成引援、合同、设施、青训、阵容与董事会约束；最终分由确定性引擎累计，不用 LLM judge。论文让 15 个前沿模型分别面对冻结脚本世界（solo），并在共享的 20 年经济体中竞争（Arena），另有脚本与人类首玩对照。

作者报告所有模型在 3 个种子下走完全程，盲脚本基线的 9 次运行中有 7 次“死亡”；claude-fable-5 在 solo 和 Arena 均居首，solo 分数 90.94，接近可见隐藏状态的脚本上界 95.54。联赛冠军却轮转于 10 个模型，说明静态 solo 排名不能预测对抗环境；高分行为与临近终点减少长周期投资（Spearman −0.58）、少持闲置现金（−0.50）、提早续约（+0.45）相关，token 消耗则不相关。创新是把长期、竞争、部分可观测和多目标压力放入同一可重复、无裁判模型的基准。限制是足球模拟器及其分数函数仍是作者设定，跨模型、种子和价格的结论不等于现实企业经营；“人类较低”也只是首玩对照。适合 agent benchmark、记忆系统与经济仿真读者；建议读摘要、§3、两个赛道设置、图表与行为分析章节。

作者：Mohammad Zamani、Fatemeh Ziaeetabar

Beyond LLM-Based Reasoning: Lightweight GNNs for Agent Failure Attribution

作者：Ting-Wei Li、Yuanchen Bei、Xiao Lin、Hanghang Tong
来源/分类：arXiv · cs.CL

研究失败多 agent 轨迹的责任 agent 与错误类型归因，以逐步语义和 agent 关系的图网络替代重型 LLM 推理。作者报告 AFANet 在域内匹配或超过微调 LLM，并可在 OOD 上做低成本适配。价值在于将可观测性转为结构化学习问题；基准标签、特征提取成本和真实系统迁移仍需审计。

FinRCA-Bench: Benchmarking Evidence Retrieval and Reasoning for Financial AI Systems

作者：Pratik Ghawate
来源/分类：arXiv · cs.AI、cs.IR · 【跨主题】
链接：arXiv 摘要页 · PDF

研究财务对账中证据检索与根因推理的可分离评测，覆盖 2,250 个合成案例与 14 张表。作者报告只改检索即可大幅改变必需记录召回和分类准确率。价值是防止把答案正确误判为可审计；合成关系图与真实企业数据质量、权限和流程差异限制外推。

CL4D: Contrastive Language-4D Pretraining for Vision-Language Reasoning in Dynamic Scenes

作者：Kumal Hewagamage 等 7 位作者
来源/分类：arXiv · cs.CV
链接：arXiv 摘要页 · PDF

仅依据摘要：以动态点云和文本对比预训练 CL4D，并在 DynAction4D 上训练直接读 4D 点云的 4DVLM。作者报告多项 4D 动作基准约提升 16.75%，且胜过给 RGB 视频的 Gemini/GPT-5。价值在于把几何与运动共同建模；数据集构成、2D/4D 输入公平性、闭源模型版本和算力均需阅读全文核查。

FinSkillBench: Evaluating AI Agents and Domain Skills for Investment Management

作者：Jermyn Zhen Yong Bek、Zhuang Qiang Bok、Zhongtian Sun
来源/分类：arXiv · cs.AI、q-fin.PM · 【跨主题】
链接：arXiv 摘要页 · PDF

仅依据摘要：评测 agent 在组合、风险和基本面 12 个子任务、2,603 个点时 episode 中调用金融技能的能力。作者报告 9 个模型的均分从无技能的 0.366 升至策划技能的 0.528，自生成技能成本更高且收益很小；另一框架的 5,280 episode 复现方向。价值是将“模型能力”与可验证流程区分；是任务成功分而非投资业绩，数据、执行摩擦与可交易性未由摘要证明。

Large Language Model for Verilog Code Generation: Literature Review and the Road Ahead

ConspirED: A Dataset for Cognitive Traits of Conspiracy Theories and Large Language Model Safety

Mise-en-Scène: Implicit Layout Emergence in Diffusion Transformers for Human-AI Design Co-Creation

DentAgent: Evidence-Centric Multi-Agent Coordination for Multimodal Dental Reasoning

The Lifecycle of LLM-as-a-Judge for Large-Scale Recommendation Explanations

来源/分类：arXiv · cs.AI
链接：arXiv 摘要页 · PDF
