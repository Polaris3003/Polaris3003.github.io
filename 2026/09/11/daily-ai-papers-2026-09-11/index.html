1. 多模态提示注入：完成率只有约 1%，暴露面却不能只看最终成功

论文：An Experimental Evaluation of Multimodal Prompt Injection Attacks on Agentic AI Frameworks（PDF，arXiv:2609.09404）
作者：Viet K. Nguyen、Mohammad I. Husain
来源/类别：arXiv RSS；cs.CR、cs.AI；AI 安全
全文状态：已核阅公开 PDF（12 页）。

研究问题：能读图并调用工具的 agent，会把藏在图像中的指令带到哪一步？只统计“是否真的完成攻击”会不会低估已经发生的识别、规划和工具尝试风险？

方法与数据：作者构造 MMPIBench，把 6 种视觉载体（OCR 文本、视觉叠加、EXIF 元数据、二维码、伪界面截图、混合载体）与 4 类目标（误用工具、数据外泄、记忆污染、跨 agent 传播）组合成固定攻击集，放入 LangGraph、AutoGen、CrewAI、Semantic Kernel、OpenAI Agents SDK、LlamaIndex 六个框架。5 个视觉模型覆盖 Claude Opus 4.8、GPT-5.4、Gemini 3.1 Pro、Grok 4.3、Llama 4 Maverick，共 720 个模型—框架—攻击单元；工具使用 mock 环境，并用三个跨供应商 judge 判断是否尝试与完成。

作者报告的结果：720 次中只有 8 次完成攻击，约 1.11%（95% Wilson 区间 0.6%–2.2%），但有 92 次尝试，约 12.8%；其中 72 次部分执行、12 次失败、8 次成功。模型差异明显：Claude 没有尝试，59.7% 的单元明确识别注入；GPT-5.4 尝试率 4.2%，Gemini 12.5%，Grok 与 Llama 各 23.6%。8 次完成中 7 次由 OCR 载体触发，目标几乎都落在工具误用；元数据和二维码约 88% 的单元甚至没有被感知。最常见的阻断点是规划阶段：模型读到了指令但选择不执行。

作者还做了音频扩展：只有 5 个模型中的 2 个能接收原生音频、6 个框架中的 3 个能传递音频；在信号确实到达的 72 个单元里，完成率为 49%，其中一个模型达到 75%。这组结果与图像任务的提示形式和工具权限不同，不能直接当作同口径的视觉—音频比较。

创新、局限与复现边界：论文的价值在于把攻击暴露拆成“感知—规划—工具调用—执行”，而不是只报终点成功率。局限包括每个单元只有一次试验、框架重执行与配置并不完全均衡、音频和图像任务不完全同构、mock 工具不代表真实损害、部分标签依赖 LLM judge；它测的是攻击面，不是防御方案或生产事故率。因而 12.8% 是受控实验中的尝试暴露，不能直接转成现实系统的入侵概率。

适合谁读：agent 安全、工具权限、输入隔离和红队评测团队。建议读 §IV 威胁模型、§§D–H 方法、§VI 结果、§VII 音频扩展和 §VIII 局限。

2. OpenDiscoveryTrace：科学 agent 的过程轨迹比最终答案更容易暴露失效模式

论文：OpenDiscoveryTrace: Process Traces for Evaluating AI Scientist Workflows（PDF，arXiv:2609.09203）
作者：Aayam Bansal、Keertan Balaji
来源/类别：arXiv RSS；cs.AI；AI 科学 agent 评测
代码：OpenDiscoveryTrace
数据：Hugging Face 数据集
全文状态：已核阅公开 PDF（12 页）。

研究问题：只看代码、假设或论文等最终产物，无法区分稳健推理与“碰巧猜对”，也无法审计工具误用、错误修正和信心变化。作者因此把科学 agent 的执行过程变成可分析的数据对象。

方法与数据：数据集包含 558 条完整轨迹，覆盖药物发现、材料科学、基因组学和科学文献分析 124 个任务。每一步记录 9 个字段：阶段、思考、工具调用及输入输出、观察、错误、修订触发器、信心、步骤 ID/时间戳。样本包括 GPT-5.4、Claude Opus 4.6、Gemini 3.1 Pro 三个 frontier 模型各 124 条轨迹，Qwen2.5-7B、Mistral-7B-v0.3、Phi-3.5-mini、Qwen2.5-1.5B 四个开源模型各 30 条，以及 60 条 live-retrieval 变体。作者定义结果预测、错误定位、主张核验、自主性分类、过程质量评分五个任务，并用逻辑回归、随机森林、梯度提升、LSTM、Transformer 作基线。

作者报告的结果：对 363 条由 LLM 判分的 frontier 轨迹，三者任务成功率相近：GPT-5.4 为 88.6%、Claude 为 83.9%、Gemini 为 89.3%；但 Claude 平均每条轨迹显式错误 2.5 个，GPT-5.4 只有 0.08 个，差异检验 p<0.0001、Cliff's δ=0.613。Claude 的错误中 66.7% 属工具误用，GPT-5.4 的错误中 83.6% 属推理错误。平均每条轨迹 4.1 步、3 次工具调用、0.87 次修订，31.2% 至少出现一个错误。

结果预测的多数类基线准确率约 0.693、AUROC 0.5；逻辑回归、随机森林、梯度提升、LSTM 和 Transformer 都没有稳定超过它。LLM 标注者在 60 条样本上的一致性从 correctness 的 α=.629 到 autonomy 的 α=.820；这说明过程标注本身仍需人类专家阶段来校准。

创新、局限与复现边界：它把“结果好不好”与“过程是否可审计”分开，并提供公开 schema、harness 与数据。限制包括当前任务数量和轨迹数仍是 pilot 规模、错误分类含关键词启发式、主要标注依赖 LLM 而非专家、frontier 轨迹部分使用模拟检索、六阶段 prompt 与 30 步上限会塑造行为；复现还需要 API 密钥或 GPU。论文的 84%–89% 是这套任务与 judge 下的成功率，不是科学发现能力的普适排名。

适合谁读：科学 agent、过程监督、AI 治理和可复现性团队。建议读 §§2–5，以及附录 M–N 的 schema、标注和基线细节。

3. Harbor Adapters 与 Harbor-Index：大规模 agent 评测的主要瓶颈是基础设施和任务质量

论文：Harbor Adapters and Harbor-Index: Infrastructure and a Curated Meta-Dataset for Large-Scale Agentic Evaluation（PDF，arXiv:2609.04298）
作者：Lin Shi、Haowei Lin、Zixuan Zhu、Xiaoyue Zhou、Xiang Li 等（完整作者名单见原文）
来源/类别：arXiv RSS；cs.AI、cs.CL；agent 评测基础设施
代码/基础设施：Harbor、Harbor-Index
全文状态：已核阅公开 PDF（84 页）。

研究问题：agent 基准越来越多，但每个基准都有自己的环境和集成方式；如果无法统一运行、审计任务质量和控制 harness 差异，模型排行榜的可比性就会被基础设施吞掉。论文同时解决“怎么跑”和“跑什么”。

方法与数据：Harbor Adapters 把 80 多个基准接入统一任务 schema，并在 54 个基准、8 个模型上比较 Terminus-2 与 3 类 native harness；大规模实验有 3 次 trial，约 0.3M 条轨迹、226B tokens、超过 30 万美元计算成本。Harbor-Index 从 6,627 个任务开始，经过难度筛选、AI 审计、人审和 audit-and-fix，最后保留 82 个来自 29 个基准的困难任务。

作者报告的结果：剩余基准之间存在明显冗余：在 12 个选定基准后，其他基准与模型排序的 Spearman 相关至少为 .7；52 个基准中每个只取 3 个任务，平均排序相关约 .923，但 FinanceAgent、LabBench 等专门基准较难被替代。难度的 ICC 为 .75；模型效应范围 .451，harness 效应 .087，模型影响约为 harness 的 5.2 倍，但 harness 仍不能忽略。Harbor-Index 的 9 个模型×2 个 harness×82 任务共 1,476 次运行，没有任何配置通过率超过 30%；GPT-5.5 with Codex 最强，达到 28.0%。全量运行中错误主要是超时、近失和远失，native harness 的超时约 26%，Terminus 约 42%，后者缺少部分原生图像/网页工具。

创新、局限与复现边界：论文把 adapter、任务审计、模型—harness 交互和成本放在同一个实验框架里，贡献不只是新榜单。限制包括已适配基准仍有限、任务可能被 reward hack 或环境瑕疵污染、模型与 harness 覆盖不是全体组合；Harbor-Index 的“28%”是特定 82 任务、特定工具和超时协议下的通过率，不能直接当作一般 agent 能力上限。

适合谁读：agent 评测平台、benchmark 维护者、模型工程和评测预算管理团队。建议读 §§2–4、§6，以及附录 D–G、H 的任务筛选、失败与成本分析。

4. AgentAudit：任务完成相似的模型，信任风险可能完全不同

论文：AgentAudit: An Open, Extensible Framework for Full-Lifecycle Trust Evaluation of AI Agents（PDF，arXiv:2609.09875）
作者：Shrey Nag、Sachita、Abhishek Kumar Singh、Lipi Goel、Rajeshwar Singh Janwar
来源/类别：arXiv RSS；cs.AI；AI agent 信任与安全
代码：AgentAudit
全文状态：已核阅公开 PDF（23 页）。

研究问题：任务成功率只告诉我们 agent 做没做成，却无法定位规划、记忆、工具选择、工具执行、忠实性或安全上的失效。AgentAudit 试图在不改变 agent 内部实现的前提下，对完整执行轨迹做生命周期审计。

方法与数据：框架从被测 agent 读取记录好的 trace，在 instruction integrity、planner、memory、tool selection、tool invocation、tool correctness、alignment、tool faithfulness、security、execution integrity 十个维度打分，再做行为分类和失败归因。实验覆盖 Banking、Email、Identity Docs、Trip Planner、Marketplace、Payments 六类环境中的 9 个能力/对抗任务，比较 GPT-5、Claude Sonnet 5、Sarvam 105B、Llama 3.3 70B、Gemini 2.5 Flash。

作者报告的结果：Composite Trust Score（0–100）均值为 Claude Sonnet 5 95.1、GPT-5 80.6、Sarvam 105B 57.6、Llama 3.3 70B 45.7、Gemini 2.5 Flash 22.6。Sarvam 在多项对抗任务中被归类为 Unsafe_Compliance，Llama 则多次是 Safe_by_incompetence：前者可能按不安全要求行动，后者可能只是没有能力完成；这两类行为在 pass/fail 评测中容易混在一起。

创新、局限与复现边界：只接入 trace、分阶段归因和安全/忠实性封顶规则，使它适合做部署前审计。主要限制是每个单元一次运行、需要完整 trace 和隐藏 ground truth、只测单 agent；所有分数由一个固定 judge Claude Sonnet 5 给出，而该模型也是被评测对象，存在重叠偏差。Gemini 使用 Flash 代替 Pro 也影响横向可比性。Composite Trust Score 是该 rubric 的审计指标，不是客观的“可信度真值”。

适合谁读：agent 观察性审计、工具权限、红队和治理团队。建议读 §§III–IV、V、VII，尤其是 judge 偏差和失败归因部分。

5. GenAC：生成式 critic 改善 LLM 强化学习的价值估计，但计算代价约为 PPO 的 2 倍以上

论文：Bringing Value Models Back: Generative Critics for Value Modeling in LLM Reinforcement Learning（PDF，arXiv:2604.10701）
作者：Zikang Shan、Han Zhong、Liwei Wang、Li Zhao
来源/类别：arXiv RSS；cs.LG、cs.AI、cs.CL；LLM 强化学习
全文状态：已核阅公开 PDF（20 页）。

研究问题：现代 LLM 强化学习常绕开 value model，因为传统一次性标量 critic 难训练、扩展也不稳定；如果让 critic 先生成推理再输出价值，能否提高 credit assignment，而不是只增加一个更大的回归器？

方法与数据：GenAC 用生成式 critic 先做 chain-of-thought，再给出 0–10 的价值估计，并用 In-Context Conditioning（ICC）让 critic 随当前 actor 校准。受控 value approximation 使用固定的 Qwen3-8B policy、DeepScaleR，包含 1,024 个问题、14,190 个状态、每个状态 16 条 partial rollout，critic 规模覆盖 0.6B–14B、10 个 seeds。下游 RL 比较 GRPO、RLOO、VC-PPO 与 GenAC，在 AIME24、AMC23、MATH500、AIME25、Olympiad、Minerva 六个数学基准上用 avg@16 评估。

作者报告的结果：带 ICC 时，GPT-5 critic 的 MSE 从 .164 降至 .129，Qwen base 从 .308 降至 .299，Qwen+SFT 为 .137，Qwen+RL 为 .051。GenAC 在 2/4/8 个候选中的 top-1 排序准确率为 .711/.492/.332，传统 discriminative critic 为 .604/.388/.204；OOD MSE 在 DeepScaleR、MATH500、AIME24、GPQA 上分别减少 20.3%、39.3%、52.5%、48.5%。六个数学集平均分 GRPO 50.22、RLOO 49.93、VC-PPO 50.39、GenAC 51.90。

创新、局限与复现边界：论文把 value modeling 从“标量近似”改成“可生成的分步判断”，并把校准与 actor 变化联系起来。代价也清楚：作者报告 GenAC 每次迭代约为 PPO 的 2.1 倍，FLOPs 表中 GRPO 4,194M、PPO 7,549M、GenAC 18,866M；可通过更粗分段或抽样压缩。限制包括只测数学推理、固定 actor、有限的理论—实践验证，以及 segment 长度和 critic 成本仍需调优。分数提升是受控 RL 实验结果，不等于通用 agent 或真实任务收益。

适合谁读：LLM RL、value model、credit assignment 和训练基础设施团队。建议读 §§4–6、§7 以及附录 B、E 的成本和消融。
