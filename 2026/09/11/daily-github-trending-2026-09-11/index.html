2026-09-11 GitHub 热榜简报：Agent 工具链分层，本地模型与真实工作流汇合

GITHUB TRENDING · 2026.09.11

今天的 all-languages 日榜 共 16 个候选；过滤掉自动交易机器人、以提示词案例与模板为主的仓库后，留下 14 个值得继续验证的项目。主线已经从“哪个 Agent 更会回答”转向“如何安装、约束、协作、评测并把 Agent 接到真实工件”：输出纪律、开发方法、团队知识、模型选型、持久化知识库和桌面工作区正在分层成一条工具链。星标与日增只是注意力快照，不是质量、维护性或安全性的证明。

Agent 工具链团队知识本地模型教育与知识库3D / 图形

今日要点

Agent 相关项目正在形成清晰的层次：i-have-adhd 约束输出节奏，Superpowers 约束规格、测试与实现流程，skills 负责发现和安装能力，TeamAI 再把 skills、规则、MCP 与团队经验放进共享 Git 流程。它们不是同一个产品的重复实现，而是交互、方法、分发与组织协作四个不同边界；组合时仍要逐项审查权限、写入路径和更新策略。

另一条线是 Agent 开始进入更具体的工作对象：llmfit 和 colibri 让本地模型选择与推理硬件更可测，LLM Wiki 把资料变成持续维护的知识图谱，OpenMAIC 把课程生成做成可回溯的工作台，PI-Desktop 则把长时编码会话放进本地桌面工作区。与此同时，God's Eye View、ArmorPaint 与 Diagram Design 提醒我们：有价值的 AI 工具最终仍要落到空间数据、图形资产和可读工件上。

值得尝试

ayghri/i-have-adhd

i-have-adhd 是给编码助手使用的输出纪律 skill，要求先给行动、编号步骤、复述当前状态，并以一个明确下一步收尾，README 还列出 10 条具体规则。它适合减少交互层的冗长铺垫，但只改变输出协议，不等于提升模型推理或代码质量，安装后仍要确认宿主是否真的加载了 skill。抓取时主要语言为 Python，日榜日增 3,882、总 stars 38,482（日榜来源），许可证为 MIT；最近提交为 2026-09-10，暂无可识别的最新 Release。

bilawalsidhu/gods-eye-view

God's Eye View 是浏览器中的 3D 空间情报工作台，把飞机、船舶、卫星、地震、交通和公共摄像头等公开信号放进可交互地球，并支持语音控制。它适合研究实时数据融合、地理可视化与本地工具链，但 README 明确说明交通是模拟数据、摄像头位置和火箭轨迹是粗略估计，不能当成经过加固的情报系统。主要语言为 JavaScript，日榜日增 1,762、总 stars 24,442（日榜来源），许可证为 MIT；最近 Release 为 v0.1.1（2026-09-01），最近提交为 2026-09-05。

obra/superpowers

Superpowers 把编码 Agent 的工作组织成一套可组合 skills 与开发方法：先澄清规格，再做计划、红绿 TDD、YAGNI/DRY，最后用子 Agent 执行和审查。它适合个人或团队把“让 Agent 写代码”变成可重复流程，但方法论较强约束，不同 harness 需要分别安装，长时间自主运行仍需要人类复核。主要语言为 Shell，日榜日增 732、总 stars 284,729（日榜来源），许可证为 MIT；最近 Release 为 v6.3.0（2026-08-12）。

Tencent/teamai-cli

TeamAI 是 TypeScript CLI，把团队的 skills、rules、agents、hooks、MCP 与知识通过共享 Git 仓库分发到 Codex、Claude Code、Cursor、OpenCode 等 Agent 工具，并提供 Team Context、Knowledge Recall 与 Codebase Graph 等 beta 能力。它适合把个人 Agent 习惯变成可审查、可同步的团队资产，但需要团队仓库写权限，beta 功能、hooks 与环境变量都应先做权限边界设计。主要语言为 TypeScript，日榜日增 841、总 stars 3,832（日榜来源），许可证文件声明为 MIT；最近 Release 为 v0.23.1（2026-09-09），最近提交为 2026-09-10。

AlexsJones/llmfit

llmfit 是 Rust 编写的 TUI/CLI，会读取 CPU、内存、GPU、显存与加速器配置，按模型参数、上下文长度和 GGUF/AWQ/GPTQ/EXL2 等量化格式估算哪些本地模型适合运行，并支持 Ollama、llama.cpp、MLX 等运行时。它适合在下载模型前缩小选择空间，项目还提供基于真实机器 benchmark 的回填机制；但估算仍应由自己的硬件实测替代，不能把推荐分数当成吞吐保证。主要语言为 Rust，日榜日增 258、总 stars 35,766（日榜来源），许可证为 MIT；最近 Release 为 v1.1.15（2026-09-10），最近提交为 2026-09-10。

liquidslr/system-design-notes

system-design-notes 是围绕系统设计面试材料整理的持续更新笔记，覆盖扩展性、限流、一致性哈希、键值存储、消息队列、搜索与常见系统案例。它适合用来建立分布式系统的第一层直觉，但 README 明确标注 work in progress，内容不能替代生产架构评审，仓库当前也没有可识别的许可证声明。主要语言未在日榜标注，日榜日增 900、总 stars 18,826（日榜来源）；最近提交为 2026-08-12，暂无可识别的最新 Release。

cathrynlavery/diagram-design

Diagram Design 是面向 Claude Code、Codex、Pi 等宿主的图表 skill，提供 39 种自包含 HTML + SVG 的编辑式图表，并能重绘 draw.io、Mermaid 与 Excalidraw 来源，静态输出仍是默认模式。它适合把架构、流程、权限边界和数据关系做成更可读的工程工件，但它解决的是生成与风格一致性，不会替代对语义、无障碍和数据正确性的人工检查。主要语言为 HTML，日榜日增 1,294、总 stars 37,803（日榜来源），许可证为 MIT；最近提交为 2026-09-10，Release 页面当前未显示可识别的最新版本标签。

armory3d/armorpaint

ArmorPaint 是用 C 开发的 3D PBR 纹理绘制工具，仓库面向开发者，README 提供 Windows、Linux、macOS/iOS 与 Android 的构建路径。它适合研究原生图形工具、材质工作流和跨平台构建，但项目明确提醒开发版可能不稳定，发行二进制需要付费，编译还依赖对应平台的编译器与 SDK；公开仓库没有找到明确的 LICENSE/COPYING 文件，不能擅自推断使用权利。主要语言为 C，日榜日增 72、总 stars 4,433（日榜来源）；最近 Release 为 26.09（2026-09-03），最近提交为 2026-09-09。

diegosouzapw/OmniRoute

OmniRoute 是 TypeScript 自托管 AI 网关，把多个兼容 API、路由策略、fallback、MCP/A2A 与本地控制面放到一个入口，并包含凭据加密、限流和 guardrail 等实现方向。它适合研究多供应商接入和故障切换，但 README 中关于 provider 数量、免费额度、token 节省和测试规模的数字属于项目自述且会变化，不能把这些营销指标当成质量证明；接入上游服务前仍要审查条款、密钥流向和费用边界。主要语言为 TypeScript，日榜日增 626、总 stars 64,275（日榜来源），许可证为 MIT；最近 Release 为 v3.8.50（2026-08-26），最近提交为 2026-09-09。

JustVugg/colibri

colibri 是纯 C、零推理引擎依赖的 MoE 推理项目，尝试把 VRAM、RAM 与 NVMe 当成同一层级的权重存储，让 744B 到 2.8T 参数模型可以在消费级或异构硬件上运行。它适合研究磁盘流式专家、内存分层和本地推理的真实性能边界，但快速运行与可用运行并不是一回事，模型权重的许可也要和引擎许可分开审查。主要语言为 C，日榜日增 98、总 stars 27,485（日榜来源），许可证为 Apache-2.0；最近 Release 为 v1.10.2（2026-09-06），最近提交为 2026-09-06。

THU-MAIC/OpenMAIC

OpenMAIC 是一个多 Agent 互动课堂平台，当前的 Agent workbench 能根据材料规划、生成和修订整套课程，并提供幻灯片、测验、互动内容、PBL、图像、视频、语音与 .pptx 导入等工具。它适合教育产品原型和多 Agent 编排研究，但运行仍需要至少一个模型/媒体服务配置，生成的课程内容也必须做事实、版权与教学质量复核。主要语言为 TypeScript，日榜日增 837、总 stars 35,365（日榜来源），许可证为 MIT；最近 Release 为 v1.0.1（2026-09-06），最近提交为 2026-09-11。

nashsu/llm_wiki

LLM Wiki 是跨平台桌面知识库，把 PDF、Office、EPUB、网页剪藏等资料增量整理成可互联的 wiki，并加入知识图谱、Louvain 社区发现、来源约束检索、Rust 后端 Agent、MCP 与本地 API。它适合把“每次从头 RAG”改造成可持续维护的个人知识系统，但模型配置、联网检索和 shell approval 都会改变数据边界，部署前要先决定哪些来源可以进入长期记忆。主要语言为 TypeScript，日榜日增 142、总 stars 18,152（日榜来源），README 声明许可证为 GPL-3.0；最近 Release 为 v0.6.11（2026-08-25），最近提交同为 2026-08-25。

vercel-labs/skills

skills 是开放 Agent skills 生态的 CLI，支持发现、列出、安装、更新或临时使用技能，并能把技能定向到 Codex、Claude Code、OpenCode、Cursor 等多个宿主。它适合建立“能力包可复用、可更新、可按项目或用户范围安装”的工作流；但跨宿主的实际行为仍取决于各自的加载机制，安装第三方 skill 前必须检查其内容和权限。主要语言为 TypeScript，日榜日增 122、总 stars 31,174（日榜来源），许可证为 MIT；最近 Release 为 v1.5.25（2026-09-08），最近提交为 2026-09-08。

vastsa/PI-Desktop

PI-Desktop 是本地优先的 AI coding agent 桌面工作区，用 Electron + Rust host core + pi Agent Harness 管理项目、会话、模型、工具、审查、文件预览与可安装扩展，并让特权操作经过权限层。它适合想在本地管理长时 Agent 会话、模型和插件的开发者，但项目明确处于 Early Preview，API、扩展接口和桌面行为仍会变化，本地运行也不会自动解决凭据和数据治理问题。主要语言为 TypeScript，日榜日增 624、总 stars 2,331（日榜来源），许可证为 LGPL-3.0；最近 Release 为 v0.14.6（2026-09-10），最近提交为 2026-09-11。
