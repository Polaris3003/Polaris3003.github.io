2026-09-10 GitHub 热榜简报：Agent 走向团队协作与本地工作台

GITHUB TRENDING · 2026.09.10

今天的 all-languages 日榜 给出的主线，不是又一个聊天壳，而是 Agent 的工作边界正在向团队知识、长期流程、桌面工作区和物理世界延伸：从先改变回答方式，到同步规则与记忆，再到操作 3D 场景、生成 CAD 资产。值得注意的项目都把“能做什么”与“如何限制它”放在同一张设计图里；星标和日增只是注意力快照，不是质量、维护性或安全性的证明。

Agent 工程团队知识本地优先3D / CAD系统学习

今日要点

Agent 工具正在形成一条更完整的栈：i-have-adhd 处理交互输出的节奏，TeamAI 把 skills、rules、MCP 和团队经验放进共享 Git 流程，Superpowers 把规格、测试、计划和子 Agent 组织成方法论，ECC 则继续向记忆、安全和多宿主 harness 扩展。它们适合放在一起比较，但职责并不相同：输出纪律不是工程流程，工程流程也不等于权限治理。

另一条线是 Agent 开始接触更具体的工作对象：Pascal Editor 把 3D 建筑场景与 MCP 相连，text-to-cad 把 CAD、机器人描述和制造检查包装成可安装的技能，PI-Desktop 把 coding agent 放进本地桌面工作区。与此同时，AI Engineering from Scratch 与 system-design-notes 提供了从基础概念到系统设计的学习路径：真正的趋势不是“模型替你做完”，而是围绕模型建立可复用的环境、工件和判断框架。

值得尝试

ayghri/i-have-adhd

i-have-adhd 是面向编码助手的输出纪律 skill，要求先给行动、编号步骤、复述当前状态，并以一个具体下一步收尾。它适合想减少 Agent 长篇铺垫、让调试建议更快进入执行的人，但它只改变交互层，不会直接提升模型推理或代码质量，跨宿主能否稳定生效也取决于 skill/plugin 的加载机制。抓取时日增 +4,650、总 stars 34,783，主要语言 Python，许可证为 MIT；最近提交是 ff690b6（2026-09-10），暂无 release。

Tencent/teamai-cli

TeamAI 是 TypeScript CLI，把团队的 skills、rules、agents、hooks、MCP 和知识通过共享 Git 仓库分发到 Claude Code、Codex、Cursor、OpenCode 等 Agent 工具，并提供 recall、codebase graph 和 session digest 等 beta 能力。它适合希望把个人 Agent 习惯变成可审查、可同步的团队工程资产的人；但它需要团队仓库写权限，部分 Team Context/Improvement 能力仍标为 beta，环境变量和 hooks 也必须按权限边界管理。抓取时日增 +556、总 stars 3,043，主要语言 TypeScript，许可证为 MIT；最近 release 是 v0.24.0-beta.3（2026-09-09）。

obra/superpowers

Superpowers 是建立在可组合 skills 和初始指令之上的编码 Agent 开发方法，强调先澄清规格，再做计划、红绿 TDD、YAGNI/DRY 和子 Agent 驱动的实现与审查。它适合想把“让 Agent 写代码”变成一套可重复开发流程的个人或团队，但方法论本身较为强约束，且不同 harness 的安装与执行边界不同，长时间自主运行仍需要人类复核。抓取时日增 +688、总 stars 284,061，主要语言 Shell，许可证为 MIT；最近 release 是 v6.3.0（2026-08-12）。

pascalorg/editor

Pascal Editor 是基于 React Three Fiber 和 WebGPU 的本地优先 3D 建筑编辑器，可在浏览器或 CLI 中运行，并通过 MCP 让 Agent 读取和操作场景。它适合建筑/空间设计、3D 数据建模以及想研究“Agent 如何操作结构化空间状态”的开发者；但本地 CLI 要求 Node.js 22.13 或更高版本，WebGPU、CLI 预览版本与 MCP 服务的兼容性都应按实际环境验证。抓取时日增 +107、总 stars 22,960，主要语言 TypeScript，许可证为 MIT；最近 release 是 pascal-agent-skills--v0.1.7（2026-09-09）。

earthtojake/text-to-cad

text-to-cad 是一组面向 CAD、CAE、CAM 和机器人描述的 Agent skills，可从自然语言或本地文件生成、检查、采购、切片并交接 STEP、STL、3MF、URDF、SDF、SRDF 等工件。它适合机械设计、机器人和制造流程的开发者，用来观察 Agent 如何从文本进入可验证的几何与工程文件；但需要 Python 3.11+ 及相应外部工具，生成的几何、可制造性和机器人约束仍不能跳过专业校验。抓取时日增 +124、总 stars 15,052，主要语言 Python，许可证为 MIT；最近 release 是 v0.5.1（2026-09-08）。

liquidslr/system-design-notes

system-design-notes 把《System Design Interview》两卷的内容整理成 28 个章节，覆盖扩展性、限流、一致性哈希、键值存储、消息队列、监控告警、支付和交易系统等常见设计题。它适合准备系统设计面试或想用案例建立分布式系统直觉的人，但这是明确标注为 work in progress 的学习笔记，不是生产架构规范；仓库也没有可识别的许可证声明，引用与再分发前应先确认权利边界。抓取时日增 +1,397、总 stars 18,033，主要语言未标注；最近提交是 9d83887（2026-08-12，修正文档拼写），暂无 release。

rohitg00/ai-engineering-from-scratch

AI Engineering from Scratch 是一套从基础到 Agent、MCP 和编码 Agent 的 AI 工程课程，README 标注 523 节课、20 个阶段、约 342 小时，并为每节课提供 prompt、skill、agent 或 MCP 等可复用工件。它适合希望系统补齐 AI 工程能力、又不想只停留在 API 调用层的学习者；但体量很大，翻译页面与模型/供应商文档的时效性也需要自行复核，它不是可以直接投入生产的框架。抓取时日增 +343、总 stars 53,726，主要语言 Python，许可证为 MIT；最近 release 是 v2026.09（2026-09-07）。

vastsa/PI-Desktop

PI-Desktop 是本地优先的 AI coding agent 桌面工作区，把项目、会话、模型、工具、审查、文件预览和可安装扩展放在一个 Electron + Rust 主机中，并允许用户接入自己的模型或兼容 API。它适合想摆脱单一编辑器/托管服务、在本地管理长时 Agent 会话的开发者；但项目明确处于 Early Preview，API、扩展接口和桌面行为仍可能变化，而且本地运行不会替你承担模型、硬件和数据治理成本。抓取时日增 +417、总 stars 1,696，主要语言 TypeScript，许可证为 LGPL-3.0；最近 release 是 v0.14.6-rc.4（2026-09-09）。

affaan-m/ECC

ECC 是覆盖 skills、instincts、memory、security 和 research-first development 的 Agent harness，面向 Claude Code、Codex、OpenCode、Cursor 等多种宿主，并把工程流程、安全检查与持久化经验放进同一套工具链。它适合希望把 Agent 从提示词集合推进到可维护运行系统的人，但集成面越大，权限、凭据、写入路径和跨宿主差异越需要逐项审查；项目也明确要求只从官方来源安装。抓取时日增 +1,133、总 stars 255,207，主要语言 JavaScript，许可证为 MIT；最近 release 是 v2.2.1（2026-09-08）。
