1. FinRED：金融大模型红队评测中的领域风险与专家量表

  • 论文：FinRED: An Expert-Guided Benchmark Generation and Evaluation Framework for Financial LLM Red-Teaming（arXiv:2606.19887）
  • 作者：Chaeyun Kim、Daeyoung Park、Junghwan Kim、Jinyoung Jeong、Eunji Song、Yongtaek Lim、Minwoo Kim
  • 来源与链接：arXiv 摘要页 · PDF · 代码/论文仓库 · 受限数据集
  • 证据状态：已核阅公开 PDF；结果是论文报告，尚未独立复核。

核心问题。 通用安全 benchmark 容易漏掉监管规避、金融犯罪、消费者权益和金融系统信任等领域风险。FinRED 试图回答：把 FATF、EU DORA 等标准映射到两级风险分类，再把真实金融文档转成有上下文的攻击种子，是否比通用提示和只检查免责声明的裁判更能暴露金融模型失效。

方法与基线。 框架用专家定义的 schema 生成种子，再用 GCG、AutoDAN、TAP、GPTFuzzer、AutoDAN-Turbo 和未优化的 Direct Request 攻击 12 个开源、金融专用及 API 模型。主实验固定了攻击预算，例如 GCG 500 步、GPTFuzzer 1,000 次查询，并在 12 名金融安全专家参与的 270 条种子盲评中比较无上下文、带文档上下文和 schema 驱动三种流水线；另用 130 个 prompt-response 对比较 HarmBench 与 FinRED Judge。

论文报告的主要结果。 schema 驱动流水线在通用小模型、金融专用小模型和 API 模型上的平均攻击成功率分别为 58.05%、70.28% 和 44.44%，高于两个简化流水线；GPTFuzzer 是整体最强的黑盒攻击，开放模型和金融专用模型也更脆弱。FinRED Judge 与专家判断的一致率从 76.92% 提高到 88.46%，Cohen's κ 从 0.47 提高到 0.68，关键假阴性从 28 个降至 12 个。这里的“成功率”和“裁判一致率”都是受控实验指标，不是生产事故概率。

创新、局限与适用边界。 贡献是把监管知识、攻击生成和领域裁判放到同一条可审计流水线，并在韩国金融安全研究院监管沙盒中试用。局限包括 12 名专家均来自同一机构、攻击方法与 API/白盒访问条件并不对称、数据和提示采用受限发布以控制双重用途，且没有独立团队复现；建议金融安全评测、合规红队和模型治理读者优先读摘要、§IV 实验、§V 专家验证及伦理说明。

2. PACT：从 token credit assignment 到 critic alignment

  • 论文：PACT: From Credit Assignment to Critic Alignment（arXiv:2609.26355）
  • 作者：Jiayan Fu、Hang Xu、Yong Zhang、Zhaokai Luo、Yao Hu、Dongyan Zhao、Mu Chuan
  • 来源与链接：arXiv 摘要页 · PDF
  • 证据状态：已核阅公开 PDF；结果是论文报告，尚未独立复核。

核心问题。 LLM 强化学习中，token 级 credit 没有公认定义，critic 又可能在 actor 更新后失配。论文先用 Completeness、Prefix Consistency、Neutrality 三个条件刻画唯一的 token credit，再问 actor 先更新、critic 后用重要性修正同步，是否能减少这种失配。

方法与基线。 PACT 采用 Actor-then-Critic 顺序，以更新前后策略的 continuation importance ratio 修正 critic 目标，并用 BCE critic；数学推理使用 Qwen3.5-4B、3,200 道问题，比较 GRPO、PPO（λ=0.95/1.0）、SAO 和不做 importance sampling 的 PACT，编码任务使用 Qwen3.6-35B-A3B、OpenSWE 与 SWE-bench Verified。作者还报告长响应下精确重要性比率可能高方差，实际以截断和 mask 稳定训练。

论文报告的主要结果。 四个数学 benchmark 的 Avg@16 平均准确率为 72.87%，高于 GRPO 的 64.07%、PPO（λ=1.0）的 59.71% 和 SAO 的 51.14%；去掉重要性修正后为 67.74%。SWE-bench Verified pass@1 为 67.4%，高于 GRPO 65.4%、PPO 65.0% 和 SAO 63.6%。这些是论文指定模型、rollout 和训练预算下的 benchmark 结果，不足以证明在其他模型或任务上普遍成立。

创新、局限与适用边界。 亮点是把 credit 的数学公理、critic 目标和训练顺序连起来，并用消融区分 BCE 与 importance correction 的贡献。局限包括仅覆盖数学推理和代码 agent、依赖特定 Dressage/slime 训练框架，长序列比率仍需裁剪，且理论刻画不等于对真实语言模型内部 credit 的完整证明；建议读 §3–§5、附录 C 的重要性推导和附录 E/F 的训练细节，适合做 LLM post-training、RLHF/RLVR 和 critic 设计的人。

3. CoVeR：用覆盖率路由减少 agent 检索验证调用

  • 论文：CoVeR: Coverage-Based Routing of Verifier Calls in Agentic Retrieval（arXiv:2609.26086）
  • 作者：Daeyoung Roh、Donghee Han
  • 来源与链接：arXiv 摘要页 · PDF
  • 证据状态：已核阅公开 PDF；结果是论文报告，尚未独立复核。

核心问题。 多跳检索 agent 每轮都让 LLM verifier 重读累积证据，成本随轮数重复增长。CoVeR 不试图替代“证据是否足够”的判断，而只识别明显尚未覆盖的状态，把 verifier 保留给模糊状态。

方法与基线。 在 HotpotQA、2WikiMultiHopQA 和 MuSiQue 上，主实验使用 Self-Ask + Qwen2.5-3B、BM25 闭合检索池、最多 6 轮，并比较 full-budget、每轮 always-verify 和 CoVeR-gated 三种相同轨迹。路由器只用冻结句向量的 coverage margin，另与证据计数、词汇重叠、BM25 和学习型路由比较；还测试 Qwen2.5-7B、公开 NLI decider 及 921k 参数的无 LLM drafter。

论文报告的主要结果。 在训练 verifier 的留一 agent 出实验中，CoVeR 与两种参考的 EM 差异不超过 0.3 个百分点，HotpotQA、2Wiki 和 MuSiQue 分别减少 62.2%、67.8% 和 93.0% 的 verifier 调用；前两个数据集的 95% 区间均在约 ±1.2 个百分点内。coverage margin 对 oracle 标签的 AUROC 为 0.892/0.895/0.831，但对可部署的 generated-claim 标签只有 0.686/0.680/0.760，这正说明它能路由“明显不够”，不能单独判定“已经足够”。

创新、局限与适用边界。 贡献是把验证成本拆成可路由的工作量，同时保留语义 verifier 作为最终裁判。局限包括闭合的 gold+distractor 检索池、固定 Self-Ask/模型与缓存 verifier，MuSiQue 的高节省率还处于几乎不触发 verifier 的饱和区；真实开放网页、检索失败、网络延迟和不同 verifier 可能改变结果。建议读 §3–§5、表 1–3 和 §7 限制，适合检索 agent、推理成本优化和可部署评测工程。

4. FinFIRST：金融搜索 agent 的答案、来源与可追溯性

  • 论文：FinFIRST: Benchmarking Search Agents for Financial Information Retrieval, Sourcing and Traceability（arXiv:2609.25192）
  • 作者：Wenqing Wang、Haitao Xiang、Xinyi Zhao、Mingming Yin、Ying Zhong、Zhaoxin Huan、Qiheng Zhou、Jin Zhu、Xiaolu Zhang、Shi Chang、Jun Zhou
  • 来源与链接：arXiv 摘要页 · PDF
  • 证据状态：已核阅公开 PDF；结果是论文报告，尚未独立复核。

核心问题。 金融搜索不只是答对最终数字，还要满足时间有效、权威来源、实体/期间/单位对齐和每个结论可验证。FinFIRST 将这些过程要求拆为原子评分，研究只看最终答案的 benchmark 会漏掉多少“答对但没有证据链”的情况。

方法与基线。 数据集有 123 个专家任务、701 个原子标准和 12,300 个加权评分点，覆盖 60.2% 中文、39.8% 英文；超过四成问题包含多个子问题，61.8% 需要计算，32.5% 需要多来源，75.6% 需要开放搜索。15 个模型配置共享 ReAct 工具、网页搜索、页面访问和 Python 执行；自动裁判按 raw-information、source verification、computation & answer formation 三维打分，并用 8 名专家标注 50 个样本，Cohen's κ=0.816。

论文报告的主要结果。 Claude-Opus-5 的 Atomic/Loose Pass 最高，分别为 87.59%/87.61%；GPT-5.6-SOL 的 Strict Pass 最高，为 71.54%。所有系统的 computation and answer formation 都落后于原始信息获取，复杂度和多来源任务的 Strict Pass 明显下降；在可分解问题中，平均 17.74% 的“答对”属于证据不完整的 Q3，若只看答案会高估可追溯成功率。

创新、局限与适用边界。 价值是把金融研究 agent 的来源链、计算和答案形成单独测量，而不是把正确字符串等同于可靠研究。局限是每个模型配置只跑一个指定温度的运行、自动裁判仍是 LLM、专家一致性样本较小，且 benchmark 正确不等于实时市场研究或投资回报；建议读 §2–§4、表 3–4 和附录的工具/模型卡，适合金融 RAG、搜索 agent、审计与评测设计。

5. MemCalib：LLM agent 该如何使用记忆

  • 论文：MemCalib: Benchmarking and Optimizing Memory Use in LLM Agents（arXiv:2609.24259）
  • 作者：Ruike Cao、Fanyu Zhao、Fugen Yao、Liang Dong、Jian Xu、Guanjun Jiang、Yifei Zhao、Han Zhang、Li Xiao
  • 来源与链接：arXiv 摘要页 · PDF
  • 证据状态：已核阅公开 PDF；结果是论文报告，尚未独立复核。

核心问题。 agent 记忆的关键不是“能否看到”，而是每条记忆对当前回答的影响是否恰到好处。论文把每个 memory atom 的理想使用水平与实际使用水平分成 Ignore、Bound、Control 三类，分别测量 over-use、under-use，并研究常规 post-training 是否会出现一边改善、一边恶化的 calibration seesaw。

方法与基线。 MemCalib 有 13,500 条训练样本、1,500 条测试样本，使用 Qwen3-8B、Ministral-3-8B-Instruct 和 Qwen3.5-35B-A3B；指标包括 SCS、Exact、over/under-use 严重度及发生率。MemCalib-RL 将九类理想—实际转移拆成奖励通道，用 exact atom ablation 得到 token 级反事实 credit，再与 SFT、OPSD、GRPO、GDPO 比较；人工抽样 150 个判断与 judge 的一致率为 96.7%，κ=0.872。

论文报告的主要结果。 MemCalib-RL 在三个模型上都取得最高 SCS/Exact：Qwen3-8B 为 79.54/67.89，Ministral 为 79.00/66.31，Qwen3.5-35B-A3B 为 81.12/70.16；相对最强基线的提升范围为 1.73–7.29 和 0.87–9.98 个百分点。Qwen3-8B 的 token-level ordered localization 比 sentence-level ordered 高 1.36 个 SCS 点、2.22 个 Exact 点；关键句只占 34.6% 的 response tokens，却获得 61.9% 的 credit。

创新、局限与适用边界。 论文把“记忆是否被正确使用”从主观案例变成可测的双向校准问题。局限是 use-level judge 与反事实 token attribution 仍是代理，记忆场景和外部 RPEval 不等于长周期真实 agent，且作者承认 attribution 不总是精确；建议读 §2–§4、表 1–3、§5 限制和附录 H/I，适合 agent memory、RL credit assignment 和上下文工程研究者。

12. SambaGraph: Action-Reaction Spatio-Temporal Graphs for Soccer Tactical Response Modeling（arXiv:2609.25569）

  • 来源/分类：arXiv · cs.LG
  • 链接：摘要页 · PDF · 代码与数据
  • 简介：研究足球进攻动作如何改变防守反应；数据来自 2022 世界杯 64 场比赛，整理 4,070 个 episode、23 节点球员—球图序列和 26,270 个 split-safe 配对。作者报告 signature MLP 的 response macro-F1 为 0.796±0.007，双编码器 Hit@5/10 为 0.471±0.029/0.655±0.051；本地 LLM 分类不如监督 encoder，但能提供有依据的战术解释。仅依据摘要，未核查赛事实体泄漏、跨联赛泛化与算力公平性。

13. The AI Neuroscientist: An Interactive Agentic Interface for Neuroimaging Analysis（arXiv:2609.25254）
