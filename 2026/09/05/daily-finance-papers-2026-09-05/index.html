1. Entropic Factor Model：用熵约束组合复制的风险与换手

论文：An Entropic Factor Model for Robust Portfolio Replication（arXiv:2609.03552）
全文状态：已核阅公开 PDF（20 页）。

核心问题：用有限资产复制目标指数或因子是病态逆问题，普通 OLS 在冲击、异常值和滚动再平衡中容易产生不稳定暴露。论文提出两阶段 Entropic Factor Model（EFM）：先在由数据约束的经验边界内估计因子载荷，再用同一类 Fermi–Dirac 熵求复制权重。

方法与基线：作者与 OLS 比较五组实验：20 只美股复制 SPY、含加密资产的多资产合成、注入 AMZN -25% 异常的 flash-crash stress test、2019–2023 滚动窗口标准市场回测，以及覆盖 2020 COVID 冲击、每 10 个交易日再平衡且收取 10bp turnover cost 的 SPY 复制回测。评价同时报告 tracking error、bias、turnover、net return、volatility 和 maximum drawdown。

作者报告的结果：在 2021–2023 的样本外普通复制中，EFM 的年化 turnover 115.37% 对 OLS 的 117.94%，volatility 14.50% 对 15.13%，最大回撤 17.53% 对 19.24%，但 tracking error 7.22% 高于 6.79%，net return 7.06% 低于 7.25%。AMZN 异常实验中，EFM 将该资产权重压到 0.27%，OLS 为 5.73%；作者报告 EFM 年化净收益 17.01% 对 15.54%，最大回撤 7.73% 对 7.92%。COVID 回测中，EFM turnover 266.93% 对 418.51%，净收益 27.85% 对 25.64%，最大回撤 30.04% 对 31.27%，但 tracking error 6.11% 高于 OLS 的 5.76%。

创新、局限与经济解释：论文把“稳定性—跟踪精度—交易摩擦”放在同一回测表里，熵边界在异常值下像 probabilistic circuit breaker。结果是样本外回测/压力测试，不是因果识别，也不是实盘可交易证明；股票池是作者选定的 20 只资产，危机窗口只有一段，交易成本假设和做空/流动性约束决定结论。普通市场中 EFM 并非每项指标都胜出，不能把作者报告的净收益直接转成投资建议。

适合谁读：组合复制、稳健优化和交易成本建模读者。建议读 §3–§4 的两阶段约束、§5.1–§5.5 的样本内/样本外实验、§5.6 的 turnover–tracking error 权衡和 §6 的结论。

2. The Analyst in the Prompt：同一份 10-K/10-Q，角色提示会改变“中性”判断

论文：The Analyst in the Prompt: Role, Retrieval, and Memory Biases in LLM Financial Analysis（arXiv:2609.03218）
全文状态：已核阅公开 PDF（26 页）。

核心问题：个性化金融 agent 可能不是只检索了不同证据，而是在读到同样证据后，以不同角色解释同一份申报。论文要把 evidence selection、fixed-evidence interpretation 和 user-context routing 分开测量。

方法与基线：作者在 3,575 份 SEC filings 上测试 12 个 LLM，设置 Persona Retrieval（角色同时影响检索和回答）、Neutral Retrieval（所有角色收到 byte-identical chunks）和 Memory with Neutral Retrieval（中性助手把投资偏好放入用户 profile）。角色覆盖 ShortSeller、RiskManager、LongOnly、ESG、Momentum 等，比较 evidence-based score、rationale 和 personalized score 的变化，并用 downstream quintile spread 做附带信号检查。

作者报告的结果：固定检索后，evidence-based role effect 平均仍保留 69%，中位数 68%，模型范围 44%–89%；最强的 ShortSeller/DownsideProtection 配对在 NR→MEM 重述后缩小 51%–87%。双输出路由让 12 个模型的平均 leakage 都低于“完全不分离”的 0.5，但范围仍为 0.05–0.37；DeepSeek-V3.1 的证据 rationale 与中性基线余弦相似度从 PR 的 0.721 提到 NR 的 0.805，再到 MEM 的 0.849。作者另报告 9 个 persona 中 8 个的高低分位一年异常收益差为正，12 模型平均 +2.96%，但明确说这不是论文的交易主目标。

因果、样本外与局限：prompt 条件是在模型上的受控机制实验，可以支持“角色框架影响模型解释”的判断，但不能识别人类分析师行为的因果效应；异常收益分位数是描述性排序，不等于样本外、扣成本、可执行的策略。主实验依赖一套 retrieval encoder 和 prompt family，数据只来自 SEC filing；小盘/不标准化文件的 residual leakage 更高，且论文没有证明 dual-output 在真实投顾流程中消除偏差。

适合谁读：金融 LLM 评测、投研 workflow 和模型治理读者。建议读 §3 的三臂设计、§4.1–§4.5 的分解与消融、§4.6 的非主目标信号检查、§5 的讨论和 §6 的限制。

3. Scaling Laws：精算频率模型的 scaling 取决于数据 regime 和结构偏置

论文：Scaling Laws, Tabular Data and Actuarial Ratemaking Models（arXiv:2609.03106）
全文状态：已核阅公开 PDF（78 页）。

核心问题：语言模型的 scaling law 是否也适用于异质、噪声大、以表格为主的保险定价数据？论文用 held-out Poisson deviance 研究训练行数、参数和 compute 的边际收益，并把 GLM 作为强基线，而不是默认神经模型必胜。

方法与基线：研究使用一套大型 motor insurance portfolio，按不同训练数据比例、五个随机种子和多个模型容量重复训练；比较 GLM、FFN、vanilla Transformer、MultiCLS/TokenMoE/SSL 变体、TabM 和 TabM-mini。主要评测是样本外 Poisson deviance，另外报告 seed ensemble、train–test gap 和拟合的 data/parameter/compute scaling exponent。

作者报告的结果：在约 400 万训练行的 regime，TabM/TabM-mini 的数据 scaling exponent 约为 α=0.31–0.41，且 TabM 风格模型比纯 supervised Transformer 更能利用新增数据；full-data TabM xlarge 的 test deviance 为 0.28984，GLM 为 0.29200，差 0.00216，TabM-mini gigantic 为 0.28885，差 0.00315。Transformer 单纯增大参数收益弱，加入 TabM-style inductive bias 或 self-supervision 后才改善；seed averaging 对 attention 模型尤其有用，作者给出的平均 ensemble gain 约为 supervised Transformer 的 0.001003、GLM 的 0.000018。

创新、局限与经济意义：价值在于把“多一点数据/模型/算力是否值得”变成可估计斜率，而不是把 benchmark 胜负当作 scaling law。局限很硬：单一 motor portfolio、固定特征、IID/random split，未做完整 GBDT 公平 sweep，也未系统调参；外推只在观测到的约 4×106 行和模型容量内有效。Poisson deviance 是统计拟合指标，不能直接转成保费充足性、loss ratio、利润或投资收益，仍需时间切分、校准、费用和治理验证。

适合谁读：精算定价、表格深度学习和模型容量规划读者。建议读 §2 的指标解释、§6 的模型族、§7 的 scaling 实验、§8.2–§8.4 的限制与实际解读。代码：frmtpl-scaling-laws。

4. Metaorder modelling：用公开数据重建订单拆分，但识别不能靠“拟合出来”

论文：Metaorder modelling and identification from public data（arXiv:2602.19590）
全文状态：已核阅公开 PDF（23 页）。

核心问题：LMF order-splitting theory 通常需要带 trader identifier 的专有数据；没有账户级身份时，能否从匿名 transaction/quote data 构造 synthetic metaorders，并检验 square-root impact、执行形状、衰减和 γ≈α^-1 等 stylised facts？

方法与比较对象：作者使用 JSE 市值最大的 239 只股票，样本为 2023–2025 年交易与报价数据，对 metaorder 重建参数做 grid search。关键比较不是传统 predictive baseline，而是两种选择准则：最小化 aggregate impact stylised-fact 误差 e_M，或最小化 LMF 关系误差 e_LMF；再分别检查 impact curve、执行 profile、post-execution decay 和 γ≈α^-1。

作者报告的结果：e_M 选择的配置能重现 pooled square-root-like impact、凹形执行和衰减，但不能恢复 γ≈α^-1；e_LMF 选择的配置可以让该关系近乎精确，例如部分股票年份的 e_LMF 为 0，同时仍保留若干聚合 impact 特征，但 stock-level execution/decay 拟合较弱。论文特别承认后者是“按该关系选择出来”的兼容性，而不是独立验证；任何一种目标都没有证明 synthetic partitions 就是真实 latent metaorders。

识别边界与复现条件：这是结构兼容性和方法识别研究，不是因果估计，也不提供交易收益或样本外策略；JSE 单一市场、匿名重建、BMLL 数据访问和移动中的代码仓库都会限制复现。读者应重点区分“聚合 stylised facts 被拟合”与“微观订单拆分机制被识别”，不能把二者混为一谈。

适合谁读：市场微观结构、market impact 和可复现量化研究读者。建议读 §3 的重建算法、§4 的校准、§5.1–§5.3 的双目标结果、§6–§8 的结论与数据/代码可复现说明。代码：Metaorder modelling and identification。
