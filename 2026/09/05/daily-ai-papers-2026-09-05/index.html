1. MINT-Safe / TAD-Align：多模态多轮安全不能只看单轮拒答

论文：Towards Multi-modal Multi-turn Safety: From Agentic Interaction to Strategic Alignment（arXiv:2601.04736）
全文状态：已核阅公开 PDF（24 页）。

核心问题：多模态模型面对连续对话时，攻击者可以把有害意图拆成多个看似无害的视觉—文本请求，单轮安全并不等于整段对话安全。论文要解决的是：在减少昂贵人工偏好标注的同时，能否让模型识别跨轮风险并保持帮助性。

方法与基线：作者构建 MINT-Safe，包含 11,270 条多图对话和 500 条拒答 VQA，通过 Attack Planner、Attacker、Responder 的多智能体交互与 T2I 工具调用生成，再用交叉评判、相似度过滤和人工质检清洗。TAD-Align 先做拒答模板学习，再用基于 rollout 安全分数方差的 turn-aware dual-objective reward，把高不确定且不安全的轮次加权。实验在 Qwen2.5-VL-7B-Instruct、LLaVA-NeXT-7B 上，与 RLHF-V、Safe RLHF-V、MM-DPO、SPA-VL 等对比。

作者报告的结果：在 SafeMT 的 8 轮对话设置中，Qwen2.5-VL 的攻击成功率由 48.92% 降到 28.06%；LLaVA-NeXT 的帮助性/无害性 win rate 分别达到 82.10%/69.18%。跨 JailbreakV、MM-SafetyBench、MMSafe-PO 等测试，作者报告帮助性、无害性和 ASR 的综合表现优于比较方法，并称在专业领域样本上减少有害或误导性建议，同时保留对正常问题的回答。

创新、局限与复现成本：创新在于把多轮风险定位为“轮次不稳定性”，而不是只在整段对话上施加统一惩罚；但训练只使用 7,000 条对话、8 张 H800、少于 15 个 epoch，外部 judge 的评分偏差会进入奖励。论文没有评测专门的对抗 jailbreak 基准，也没有覆盖专用 reasoning model；这些数字是作者实验，不是独立复核结论。

适合谁读：多模态安全、对齐训练和红队评测工程师。建议先读 §1、§3 的数据构造与 turn weighting、§4.1–§4.2 的基线和主实验，以及 §5 的局限。

2. SENTINEL-RL：把 SOC 的拓扑推理从语言模型上下文中外置

论文：SENTINEL-RL: Offloading Topological Reasoning from LLM Agents in the Security Operations Center（arXiv:2609.04159）
全文状态：已核阅公开 PDF（10 页）。

核心问题：企业认证图可能有数千万条边，LLM 上下文无法完整容纳；直接让模型生成隔离动作，也无法保证动作符合网络拓扑。Sentinel-RL 将拓扑推理和语言叙事拆开：异构图注意力编码器把两跳认证子图压成固定状态，PPO policy 只从受限动作集合中选择调查动作，LLM 负责在 critic 门控后生成分析员可读的说明。

方法与基线：实验使用 LANL Comprehensive Multi-Source Cyber-Security Events 数据集和 Indiana University Quartz HPC 集群；检测结果与 Bowman、Euler、PIKACHU、LMDetect 等图检测基线比较。工程侧还比较 Neo4j 的单阶段 MERGE 与两阶段 CREATE 写入方案，并把告警、子图提取、HetGAT、PPO、critic 和 8B 叙事模型串成“检测—调查—建议—人工批准”闭环。

作者报告的结果：在单个 32 核节点上，两阶段 CREATE 将 2,400 万条认证边写入 Neo4j 用时 852 秒，而 MERGE 在六小时上限后按线性外推为 21,600 秒；25 个事件/10 秒窗口的告警延迟平均 2.31 秒、P99 为 2.45 秒。PPO 运行 200 次迭代后平均 episodic return 为 8.74±0.31；在未见过的 LANL 最后 8 天红队时间片上，precision/recall/F1/AUC 为 0.91±0.02、0.87±0.03、0.89±0.02、0.96±0.01。端到端中位延迟 6.33 秒，其中 60% 用在 4-bit 8B 模型生成叙事，而非图决策本身。

创新、局限与部署边界：最可迁移的贡献不是某个分数，而是 hot-node deadlock 的两阶段写入、HPC anchor-node 共址和分级权限：只读侦察可自动执行，可逆隔离需 critic，不可逆网络改动必须人工批准。局限是主要验证集中在 LANL/Quartz 原型与一段留出时间片，尚未证明真实企业网络的跨组织泛化；系统仍依赖规则化的人审、回滚脚本和 sandbox，不能把检测 benchmark 直接等同于生产自主防御能力。

适合谁读：安全运营中心、图机器学习和高风险 agent 部署团队。建议读 §III 的威胁模型、§IV–§V 的系统和 HPC 工程、§VI 的四类评测，以及 §VII 的企业控制面。

3. SVG-Score：先修正评测器，才能比较文本到 SVG 生成器

论文：SVG-Score: Human-Aligned Evaluation of Text-to-SVG Generation（arXiv:2609.03806）
全文状态：已核阅公开 PDF（26 页）。

核心问题：CLIPScore 等自然图像指标对 SVG 的颜色、数量和空间关系错误不敏感；通用 VLM judge 虽更敏感，但在不同风格上的反应不稳定。论文把“语义对齐”定义为 SVG 是否忠实表达 caption，并用人类标注训练两个互补评测器。

方法与基线：作者先用 200 个 SVG 做颜色、数量、空间关系和图像替换扰动，验证 vanilla CLIP 与 zero-shot Qwen3-VL-8B 的盲点；再收集 12,957 个 caption-SVG 评分，覆盖 8,671 个 SVG、1,858 个 caption，由 1–5 分人工判断。CLIP 路线在 3.2M SVG-caption 对上做 SVG 域适配，再用 LoRA 做人类偏好对齐；VLM 路线用 Qwen3-VL-8B 做 SFT，随后用包含 ordinal 和同 caption 排序奖励的 GRPO 训练。基线包含 vanilla/fine-tuned CLIP、Aesthetic、ImageReward、PickScore、HPSv2、VectorGym 和多种通用 VLM。

作者报告的结果：在人类评分留出集上，最强的 SVG-CLIP-H 达到 Spearman ρ=63.18、pairwise accuracy=80.64；人类对齐 VLM 的 ρ/r/τ/MAE/PA 为 74.85/74.90/65.08/0.68/79.59，高于 zero-shot Qwen3-VL-8B 的 67.76/67.48/59.14/0.80/74.97。独立生成器基准含 1,616 个难度递增 caption；在最难的 116 条中，作者的 judge 仍把 Claude Sonnet 5 排在高位，同时暴露多个开源生成器 30% 以上的渲染失败率。

创新、局限与数据污染边界：数据按 caption 与 SVG 双重 disjoint 切分，且作者检查了规范化 caption、SVG hash 和 pair overlap；但不能排除外部基础模型预训练时见过评测内容。论文只衡量渲染结果与文字的 Semantic Alignment，不衡量路径可编辑性、代码质量、图层组织或文件效率；独立生成器 benchmark 本身没有人工标签，结论依赖已单独验证的自动 judge。建议把它看作“更接近人类的评测器”，而不是完整的 SVG 质量标准。

适合谁读：生成式图形、VLM-as-a-Judge、评测数据集和 SVG 工具链读者。建议读 §3 的扰动实验、§4–§5 的数据/训练、§6.1–§6.3 的结果，以及附录 E 的范围限制。项目页/代码：SVG-Score。

4. FinRAG-QA：金融长文档问答的主要瓶颈仍在检索与成本

论文：Enhancing Financial Question Answering: A Novel Benchmark Dataset of Banks' financial statements（arXiv:2609.03654）
全文状态：已核阅公开 PDF（15 页）。

核心问题：银行年报和 Pillar 3 报告长、跨机构口径不一，同时混合文本与数值；金融 QA 不能只在短的美国单公司文件上测。FinRAG-QA 提供跨机构检索基准，并把检索、重排、上下文和生成阶段分开评估。

方法与基线：数据集含 999 个从业者整理的问题、10 个标准化指标、24 家欧美银行的 209 份 2019–2023 年报告，平均每份约 19.8 万词。RAG 管线比较 OpenAI 与 VoyageAI embedding、普通/带标题/上下文增强 chunk、Cohere rerank-3.5，以及 GPT-4o 和 GPT-o1-high；检索用 NDCG，生成只在 ground truth 已进入上下文时按数值答案准确率评估。

作者报告的结果：上下文增强加 VoyageAI embedding 将 NDCG@10 从 OpenAI baseline 的 0.322 提升到 0.710；重排对强的首阶段检索反而使该配置下降。检索到证据后，GPT-o1-high 的加权答案准确率为 79.0%，GPT-4o 为 44.6%，但平均生成时间约 35.0 秒对 1.8 秒，约 20 倍延迟；对 reasoning 模型，top-1 chunk 往往比更大的上下文更准。

创新、局限与复现成本：贡献在于把“检索到正确数字”和“从数字生成正确答案”拆成可诊断的两层；但上下文增强需要对整份长文档调用大模型，成本高，rerank 结果不稳定，reasoning model 有随机性。实验使用 2024–2025 年可用的模型，不能直接代表今天的模型排序；NDCG 的相关性定义依赖检索到数值 ground truth，也不等于开放式回答的事实完整性。

适合谁读：金融 NLP、企业 RAG 和文档问答评测团队。建议读 §3 的数据结构、§4 的 RAG 组件、§5 的 retrieval/generation 表格和 §6.2 的限制。代码/数据：FinRAG-QA。

5. ARTEMIS：自动优化 agent 的收益取决于基线是否还有“余量”

论文：Evolving Excellence: Automated Optimization of LLM-based Agents（arXiv:2512.09108）
全文状态：已核阅公开 PDF（27 页）。

核心问题：agent 的 prompt、工具说明、模型参数和重试策略互相耦合，人工调优可能持续数周；但已有方法常只改一个组件，或要求修改内部架构。ARTEMIS 将 agent 视为黑盒配置空间，通过语义感知的遗传 mutation/crossover 在执行日志和 benchmark 反馈上联合搜索。

方法与基线：用户只需提供 benchmark script 和自然语言目标；平台自动发现可调组件，按局部优化与全局搜索生成候选，并用分层评测控制昂贵 benchmark 调用。论文在 ALE/AtCoder、Mini-SWE/SWE-Perf、CrewAI/Math Odyssey 和 Qwen2.5-7B 的 MathTales-Teacher/GSM8K 上比较原始配置与优化配置，也比较 prompt optimization 和 search strategy。

作者报告的结果：ALE acceptance rate 从 0.660 到 0.750（相对提升 13.6%，p=0.10，未达到统计显著）；Mini-SWE score 从 0.891 到 0.981（+10.1%，p<0.005）。CrewAI 的 token 从每题 12,033 降到 7,330（-39.1%，p<10^-6），但 accuracy 从 0.82 降到 0.76（p=0.027）；Qwen2.5-7B 的 MathTales evaluation accuracy 从 0.59 到 0.81（+37.3%，p<0.001），completion rate 从 0.796 到 0.917。ALE 全部优化实验累计约 671.7 小时，Mini-SWE 约 9 小时。

创新、局限与算力成本：论文最有用的结论是“优化器不会凭空创造能力”：初始配置粗糙、任务指标客观且有明确 headroom 时收益更大；已经接近最优的 agent 可能只能拿成本换准确率。Mini-SWE 在不同项目上的增益从 +7.2 个百分点到接近 0，说明 benchmark 特定性和泛化仍是风险；ALE 的提升没有显著性，CrewAI 的成本优化牺牲了正确率。作者提供案例代码，但完整平台不可共享，复现不等于零成本。

适合谁读：agent 评测、prompt/tool 配置和自动化工程团队。建议读 §3–§4 的搜索空间与平台、§5 的实验设置、§6.5–§6.6 的统计和失败条件，以及 §8 的限制。

研究印度宗教节庆、政治集会和文化活动中的 misinformation detection 如何反映本地语境与事件动态；BharatGather 含 14,646 条记录，混合事实核查网站抓取、多媒体转写和 LLM 合成增强，目标是二分类 benchmark。价值在于把文化和事件条件带回高风险信息检测；证据状态：仅依据摘要，合成增强比例、标签质量、时间切分、语言覆盖和跨事件泛化尚未核验。

Evolving Excellence: Automated Optimization of LLM-based Agents

作者：Paul Brookes、Vardan Voskanyan、Rafail Giavrimis、Matthew Truscott、Mina Ilieva、Chrystalla Pavlou、Alexandru Staicu、Manal Adham、Will Evers- Hood、Jingzhi Gong、Kejia Zhang、Matvey Fedoseev、Vishal Sharma、Roman Bauer、Zheng Wang、Hema Nair、Wei Jie、Tianhua Xu、Aurora Constantin、Leslie Kanthan、Michail Basios
来源/分类：arXiv · cs.SE、cs.AI
链接：arXiv 摘要页 · PDF

研究如何用黑盒、无代码的进化搜索联合调节 agent 的 prompt、工具说明、参数和执行设置；ARTEMIS 在竞争编程、代码优化、数学推理和小模型数学任务上以 benchmark 日志反馈搜索配置。作者报告 ALE acceptance rate +13.6%、Mini-SWE +10.1%、CrewAI token cost -39.1%、Qwen2.5-7B 数学准确率 +37.3%。证据状态：已核阅公开 PDF（27 页）；收益依赖初始配置和指标 headroom，ALE 未达统计显著，CrewAI 的成本收益伴随准确率下降，优化本身的评测算力也很高。

VKnowU: Evaluating Visual Knowledge Understanding in Multimodal LLMs

作者：Tianxiang Jiang、Sheng Xia、Yicheng Xu、Linquan Wu、Xiangyu Zeng、Limin Wang、Yu Qiao、Yi Wang
来源/分类：arXiv · cs.CV
链接：arXiv 摘要页 · PDF

研究多模态模型是否具备超越物体识别的视觉知识，包括直觉物理和人的意图；VKnowU 含 1,680 个问题、1,249 个视频和 8 类视觉知识，评估 28 个 MLLM。作者报告 VideoKnow+ 的 See-Think-Answer 与视觉知识 reward 在 VKnowU、MVBench、Video-MME、MMVU 上分别带来 +3.7%、+5.4%、+7.0%、+5.7%。证据状态：仅依据摘要；模型版本、数据污染控制、奖励成本与各类别失败样例需读全文。

WorldReward: Reward Modeling for Camera-Conditioned World Models

作者：Yibin Wang、Zehan Wang、Junshu Tang、Zhimin Li、Yujie Zhou、Jiazi Bu、Pengyang Ling、Feng Han、Zhixiong Zhang、Long Xing、Shengyuan Ding、Ziang Li、Cheng Jin、Yuhang Zang、Jiaqi Wang、Tianyu Pang
来源/分类：arXiv · cs.CV
链接：arXiv 摘要页 · PDF

研究 camera-conditioned world model 的 reward 是否能同时判断动作执行一致性、外观质量和运动质量；WorldReward 将长视频按 action 对齐切块，用 VLM 结构化证据做 pairwise preference，再投票聚合为视频级 reward，并发布人工标注 WorldReward-Bench。作者报告三维人类偏好一致性分别比 GPT-5.5 高 3.42、1.45、3.56 个百分点，且用于 HY-WorldPlay 1.5 的 RL 后训练时改善短到长时域表现。证据状态：仅依据摘要；VLM 生成偏好数据、judge 反馈闭环和真实交互泛化需要全文核验。

Value-Preserving Architectures for Agentic AI Systems

作者：Alessandro Pesare、Tommaso Dolci、Katja Hose、Emanuel Sallinger
来源/分类：arXiv · cs.AI
链接：arXiv 摘要页 · PDF

讨论多智能体系统的架构选择如何影响隐私、公平和安全，而不只是功能正确性；论文提出联邦拓扑的 privacy-aware architecture、促进 pluralism 的 distributed architecture，以及用于检测/缓解不公平的 guard-agent architecture，并用代表性场景说明。证据状态：仅依据摘要；这是架构模式与设计论证，摘要未提供可比较的实证指标、部署成本或失效边界。

STAIR (STructure Aware Information Retriever): A novel dataset and LLM based retriever for document structure augmentation

作者：Vineet Kumar、Meghanadh Pulivarthi、vishwajeet kumar、Jaydeep Sen、Riyaz Ahmad Bhat、Sachindra Joshi
来源/分类：arXiv · cs.AI
链接：arXiv 摘要页 · PDF

研究长文档按长度切 chunk 时丢失目录和全局结构，能否把 Table of Contents 注入 Differentiable Search Index；作者发布覆盖 18 本书、6 个领域的 SearchTome，并报告 STAIR 的 Recall@1 为 82.6%，高于 DSI 的 76.9%、DPR 的 68.7%、BM25 的 59.5% 和 out-of-the-box Mistral 的 13.8%，生成式 IR hallucination rate 低于 0.05%。证据状态：仅依据摘要；18 本书的领域规模、训练/测试切分、低 hallucination 的判定方式和与现代 dense retriever 的公平成本比较需全文核查。

IndicSafeEval: Safety Robustness of Large Language Models under Multilingual Persuasive Jailbreak Attacks

作者：Saikat Mondal、Mamta、Deeksha Varshney、Oana Cocarascu、Asif Ekbal
来源/分类：arXiv · cs.CL、cs.AI
链接：arXiv 摘要页 · PDF · 代码

研究英语中心的安全评测是否漏掉印度语言中的说服式 jailbreak；IndicSafeEval 覆盖 10 类安全内容、6 类类人说服策略和 Hindi、Bengali、Marathi、Punjabi 四种语言，共 7,200 条 adversarial prompts，黑盒评估多个开源模型。作者发现安全性随语言、措辞和风险类别显著变化。证据状态：仅依据摘要；摘要没有给出逐语言 ASR、翻译质量、攻击模板污染和模型版本，且示例数据可能包含有害内容。

KC-Bench: A Dynamic Interactive Benchmark for Evaluating Knowledge Conflicts in LLM Agents

作者：Yaxing Lyu、Shengjie Zhou、Binbin Toh、Pengyu Zhu、Lijun Li
来源/分类：arXiv · cs.AI
链接：arXiv 摘要页 · PDF

研究 agent 如何在用户指令、参数知识和动态工具观察冲突时修正事实并避免错误行动；KC-Bench 从 1,000 多个生成候选中人工筛出 238 个任务，结合用户模拟器、stateful tools、确定性环境断言、开源自然语言 evaluator 和人类轨迹核验，测试 9 个模型。作者报告没有模型能在事实纠正、身份一致性和时间冲突三类场景都稳定可靠，遗漏冲突可能传导到工具调用或合成受保护数据流。证据状态：仅依据摘要；模型具体分数、工具任务代表性和 evaluator 的跨模型公平性需读全文。

FPCO-Dialog: A Multi-Turn False-Premise Benchmark for Correction and Cooperation in Vision-Language Models

研究 VLM 在用户持续重复视觉错误前提时，能否既纠正事实又保持合作；FPCO-Dialog 含 1,080 张图像、10,800 个问题轮次，使用“先正确对话前缀、再连续 10 轮 false premise”的协议，按视觉复杂度、对象类型和错误类别分层，提出 CorrTP@K 并测试 20 个商业/开源 VLM。作者报告不同模型在总体纠错倾向、轮次动态和 false-premise 类型上存在持续差异。证据状态：仅依据摘要；摘要未给出 baseline 数字、检测器误差、数据污染处理和跨分布泛化结果。
