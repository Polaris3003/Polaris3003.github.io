1. little m：把工业流程描述转成可审阅的优化模型

论文：arXiv 摘要页 · 直接 PDF · 代码与 IPC-Bench

作者：Yongchao Ye、Xinyu He、Dutliff Boshoff、Way Kuo、Lishuai Li

来源/分类：arXiv 官方 RSS；cs.AI。

全文状态：已核阅公开 PDF（18 页）。

核心问题：工业过程控制的输入往往是自然语言、流程图和未写出的工程常识，输出却必须是变量、目标函数和物理约束都清楚的数学模型。论文问的是：知识库、分阶段交互和多模态输入，能否比通用 LLM 更稳定地生成可供工程师审阅的候选模型。

方法与基线：little m 采用“信息结构化—策略设计—数学建模”三阶段流水线，以 LLM-RAG 连接领域知识库；每一阶段都允许用户确认或补充信息。作者构造了包含 50 个教科书式流程控制场景的 IPC-Bench，其中 20 个案例进入双盲人工评估；机器评估覆盖全部 50 个案例，基线为 Qwen3-Next-80B-A3B-Instruct 和 DeepSeek-V3.2。人工评估由 8 名来自计算机、数据科学和控制工程的专家完成，每个案例由 2–4 人独立评分。

论文报告的主要结果：在人工偏好率上，little m 的目标函数、决策变量、约束和总体质量分别为 58%、60%、52% 和 66%，均高于随机三选一基线；机器结构分数中，决策变量为 0.733、目标函数为 0.518、约束为 0.418。对缺失输入先提问的交互恢复，把决策变量分数从 0.721 提到 0.802、约束从 0.314 提到 0.423，但目标函数仅从 0.431 到 0.443；去掉知识库后约束分数降至 0.381，去掉流程图后目标函数和约束分数分别为 0.468 和 0.383。上述数字是论文报告的结构匹配或专家偏好，并不是求解器可行性或闭环控制收益。

创新、局限与适用边界：价值在于把中间结构和人工确认点显式化，减少“看起来像公式、实际不对应拓扑”的输出。限制同样关键：IPC-Bench 只有 50 个教科书案例，知识库需要专家维护，机器评估含 LLM 语义映射，等价公式可能被惩罚；论文没有运行求解器、证明形式物理有效性或测试真实工厂闭环性能，也无法排除公共教材被预训练见过。适合工业 AI、运筹建模和控制工程团队；建议先读第 4、6、8 节，部署前把求解器、单位检查和独立工艺审查接上。

2. BLINDSPOT：长时程工具调用中的安全不是一次拒答

论文：arXiv 摘要页 · 直接 PDF

作者：Sadia Asif、Mohammad Mohammadi Amiri、Momin Abbas、Tejaswini Pedapati、Prasanna Sattigeri

来源/分类：arXiv 官方 RSS；cs.AI、cs.CE、cs.CL、cs.LG、cs.MA。

全文状态：已核阅公开 PDF（34 页）。

核心问题：有状态工具、持久化环境和不断变化的授权，会让安全失败在多轮之后才出现。BLINDSPOT 不只问模型“拒绝了吗”，而是沿整条用户—agent—环境轨迹区分安全完成、正确拒答、不安全完成、过度拒答和无法判定。

方法与基线：基准包含 22 个攻击家族、35 个场景、7 个领域和超过 2,500 条长时程轨迹，平均每条 14.7 轮；评测 13 个闭源与开放权重模型，报告不安全完成率（UCR）、正确拒答率、良性完成率、过度拒答率、安全校准分数、Fail@k 和拒答后失败率等 8 个指标。攻击由响应条件的 User Agent 生成，工具执行和环境状态变更作为裁决证据；论文还比较非自适应攻击、文本-only 环境和匹配的安全孪生任务。

论文报告的主要结果：GPT-5.6 Sol 的完整轨迹 UCR 为 2%、安全校准分数为 96.0；GPT-4o 为 22%，Mistral Large 3 为 58%。把交互预算从 1 轮扩展到完整轨迹时，GPT-4o 的 UCR 从 5% 升到 22%，Mistral 从 18% 升到 58%；响应条件自适应把 GPT-5.6 Terra 从 3% 推到 8%、GPT-4o 从 11% 推到 22%。重复同一配置 10 次后，GPT-5.6 Sol 的 Fail@10 为 11%，GPT-4o 为 51%，Mistral 为 87%。安全孪生还显示“更常拒答”不等于“更校准”：Claude Opus 4.6 的对抗 UCR 为 4%，但良性完成率只有 74%，而 GPT-5.6 Sol 的良性完成率为 95%。

创新、局限与适用边界：论文最重要的工程含义是把持久状态、攻击自适应和重复运行纳入安全验收；只测首轮或最终文本会漏掉一部分失败。当前结果仍是作者设计的 live simulation，不是线上事故发生率；13 个模型的版本、场景分布和裁决器会影响绝对百分比，跨领域配置也不是纯粹的单变量因果实验。适合 agent 安全、工具权限和红队评测团队；建议先读第 4、6、D 节，把 UCR 与良性完成率、Fail@k、PFR 一起纳入自己的门禁，而不要用单一拒答率排名。

3. Spurious Tool Use：RL 可能学会“看到暗号就调用工具”

论文：arXiv 摘要页 · 直接 PDF

作者：Yiwei Yang、Haoxiang Zhang、Bingbing Wen、Yao Lu、Yuchen Wu、Lei Zhang、Julian McAuley、Pan Lu、Bill Howe

来源/分类：arXiv 官方 RSS；cs.CL。

全文状态：已核阅公开 PDF（14 页）。

核心问题：最终答案正确并不代表中间的工具选择是合理的。论文用反事实输入测试 RL agent 是否会因为与工具相关、却与任务无关的提示线索而调用搜索或 Python，并进一步问任务能力和线索语义是否决定捷径的形成。

方法与基线：作者从 Natural Questions 和 DeepMath-103k 各抽取 500 题，构造 1,000 条平衡训练集，并把 [WEB INDEX 742]、[REFERENCE]、<answer>、Jupyter 单元格头等线索注入一侧任务。基座是 Qwen2.5-7B-Instruct，使用 VERLTOOL 的 GRPO 训练，4×H100、30 步、每种线索一个独立运行；评测还用 GSM8K 和 2Wiki 做留出测试。核心指标是同一道题有无线索时的工具调用率差异；对照方法是在每次工具决策上用 GPT-5 Nano judge 给出“是否必要”的稠密奖励，惩罚系数为 0.5。

论文报告的主要结果：搜索语义线索被放在事实任务训练中后，数学题上出现显著的无必要搜索：[WEB INDEX 742] 在 DeepMath 和 GSM8K 上分别带来 +19.9 和 +39.2 个百分点，<answer> 分别带来 +21.7 和 +9.5 个百分点。相反，把代码语义线索放入数学训练、再到事实题上测试，Python 调用增幅通常不超过 3.8 个百分点。训练曲线显示 NQ 验证准确率约从 45% 升至 75%，而 DeepMath 约停留在 45%–50%；线索与工具的语义对齐会放大效应，相关性降到 70% 或更低时该效应在所测设置中大多消失。必要性奖励把线索驱动调用压到接近零，同时保持或提高任务准确率。

创新、局限与适用边界：它把“工具调用是否必要”从最终答案奖励中分离出来，给出了可复现的反事实审计思路。证据边界也很清楚：训练集是合成控制环境，只有一个 7B 基座和每条件一个 seed，必要性标签依赖 GPT-5 Nano，线索与自然生产提示仍有距离；论文还没有在大规模、自然生成的 agent 训练上复现。适合 RL agent、工具成本优化和数据污染审计团队；建议先读第 3–5 节，并在真实流量上记录“任务需要什么”和“模型实际调用什么”的差异。

4. BrainVLM：面向 12 类脑肿瘤的多模态诊断模型

论文：arXiv 摘要页 · 直接 PDF · 代码仓库

作者：Yinong Wang、Jianwen Chen、Zhou Chen、Shuwen Kuang、Haoning Jiang、Yanzhao Shi、Huichun Yuan、Yan-ran Wang、Bing Wang、Lei Wu、Bin Tang、Li Meng、Baihua Luo、Bin Zhou、Wei Ding、Weiming Zhong、Wei Hou、Yuanbing Chen、Zhiping Wan、Wei Wang、Zhenkun Xiao、Wenwu Wan、Allen He、Yuyin Zhou、Longbo Zhang、Feifei Wang、Zhixiong Liu、Michael Iv、Xuan Gong、Liangqiong Qu 等

来源/分类：arXiv 官方 RSS；cs.CV、cs.AI、cs.DB。

全文状态：已核阅公开 PDF（94 页）。

核心问题：MRI 上不同脑肿瘤的影像表现可能重叠，且稀有类别和临床解释都难。BrainVLM 试图同时完成 WHO CNS5 的 12 类肿瘤分类、置信度估计和放射学报告生成，并检验 AI 是否真的能帮助不同资历的放射科医师。

方法与基线：BrainTumor48K 汇集 39 个公开来源和 12 家医疗机构的 47,947 人；模型训练使用 40,043 人的 MRI、人口学信息和报告，回顾性测试为主院 3,877 人、11 家独立医院 1,334 人。架构以 Llama-3.1-8B-Instruct 为语言骨干，视觉编码器、MLP projector、LoRA 和混合 2D/3D MRI 输入配合三阶段训练；比较对象包括 RadFM、Merlin、Video-Swin Transformer 和零样本 ChatGPT-4o。另有 248 例、12 名神经放射科医师的盲法交叉阅读，以及 1,009 例真实世界前瞻性评估。

论文报告的主要结果：主院回顾性测试的 macro-AUC/F1 为 0.85/0.82，神经放射科医师 F1 为 0.80；外部 11 院为 0.80/0.75，对照医师 F1 为 0.71。前瞻性手术组 F1 在主院/外部为 0.78/0.80，对照医师为 0.75/0.77；非手术组为 0.85/0.75，对照为 0.79/0.72。248 例多读者研究中，AI 辅助使总体 F1 相对提高 27.6%，诊断时间减少 34.7%（绝对 55.8 秒，均 p<0.0001）；低置信度触发第二候选后，主院 F1 从 0.82 到 0.86，外部从 0.75 到 0.78。5,211 例中，72% 的正确诊断置信度高于 90%，70% 的错误诊断落在 50%–85% 的较低置信度区间，ECE 为 0.036。

创新、局限与适用边界：多中心外部集、前瞻性队列、报告生成和不确定性机制构成了比单一分类分数更完整的证据链；作者还公开代码，真实临床数据因隐私不能完全公开。不能把论文报告的 F1 当作临床结局：前瞻性现实数据主要来自东亚人群，罕见肿瘤仍样本有限，读者研究只给医师 MRI、年龄和性别，可能低估医师在真实场景中的表现；作者也承认去标识数据带来的残余重叠/泄漏风险，且没有测量治疗决策、手术并发症或长期预后。适合医学影像、临床 AI 和可靠性评测团队；建议先读方法、外部验证、多读者研究和局限部分，部署前必须由临床试验与责任边界重新验收。

5. Agentic Search Spaces：让 agent 设计搜索空间，而不是替代 HPO

论文：arXiv 摘要页 · 直接 PDF · 代码仓库

作者：Renat Sergazinov、Artem Chistyakov、Sergey Pankevich、Artem Babenko

来源/分类：arXiv 官方 RSS；cs.LG。

全文状态：已核阅公开 PDF（43 页）。

核心问题：LLM agent 是否适合直接逐步修改模型并看验证集，还是更适合先提出一组可执行的模块候选，再交给传统超参数优化器选择？论文将 agent 的角色限制为“搜索空间设计者”，以减少每个数据集重复调用和数据接触。

方法与基线：作者把 MLP、TabM、RealMLP、LightGBM 和 TabICLv2 拆成预处理、嵌入、架构、训练、推理等模块，由 Claude Code/Opus 4.8 生成可执行候选，再用 Optuna TPE 在联合空间中搜索；候选生成阶段不接触目标数据。主评测覆盖 45 个分类和回归数据集，使用 100/200 次试验预算、留出测试和 15 个随机种子；基线是作者原始 HPO 空间、AutoKeras、AutoPyTorch 和 AutoGluon，另在 51 个 TabArena 数据集上做协议外转移检查。

论文报告的主要结果：单模型相对原始搜索空间的平均提升为 DNN 0.5%、GBDT 0.8%、TabICLv2 0.5%；小中型回归上 MLP 为 +3.7%、LightGBM 为 +2.1%。集成收益更明显，MLP 平均 +0.9%，代理空间中成员相关性也下降；TabArena 上 5 个模型家族中 4 个 Elo 提升，最高约 125 点。AutoGluon 加入 agent 生成的 RealMLP/TabM 后，在 45 个数据集中的 43 个选入这些模型，平均权重 54%。生成一个模型家族搜索空间需要约 35–100 分钟，且作者测得不同模型的单次拟合时间相对原空间可从 0.9 倍到 2.4 倍。

创新、局限与适用边界：结果支持一个很实用的分工：LLM 提供多样的实现候选，TPE 负责数值探索；作者的消融也显示单一候选没有跨数据集通吃，收益来自数据集特定组合。风险是搜索空间变大可能过拟合验证集，agent 生成代码可能有 bug，候选与提示会随模型版本变化，45 个数据集不足以支持普遍收益；该研究还没有对所有家族做交叉验证，也没有做数据集专用生成。适合 AutoML、表格建模和模型工程团队；建议先复现同一预算下的 base/agentic 对照，再核查候选实现与拟合成本。

6. Spurious Tool Use: When RL Agents Learn the Wrong Reason to Act

作者：Yiwei Yang、Haoxiang Zhang、Bingbing Wen、Yao Lu、Yuchen Wu、Lei Zhang、Julian McAuley、Pan Lu、Bill Howe

来源/分类：arXiv 官方 RSS；cs.CL。

论文：arXiv 摘要页 · 直接 PDF

证据状态：已核阅公开 PDF；详细分析见“重点关注”。论文报告线索—工具捷径最多提高 39.2 个百分点，但该现象依赖任务能力、语义对齐和控制环境，尚非自然生产数据上的普遍定律。

8. World Model Science: Self-Organized Criticality, Weak Chaos, and Metastable Belief Dynamics in Long-Horizon LLM Agents

作者：Xinyuan Song、Zekun Cai

证据状态：仅依据摘要。

10. ToMAS: A Pilot Failure-Grounded Theory-of-Mind Benchmark from Multi-Agent LLM Failures
