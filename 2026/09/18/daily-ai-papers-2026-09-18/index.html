1. StableEval Arena：金融风险评测不能只看准确率

论文：arXiv 摘要页 · 直接 PDF · 代码 · 数据集

作者：Sean Wan、Dongping Liu、Luyao Zhang

来源/分类：arXiv 官方 RSS；cs.LG、cs.AI、cs.CE、econ.GN、q-fin.CP、q-fin.EC。

全文状态：已核阅公开 PDF（约 20 页）。

核心问题：稳定币风险预测同时涉及稀有事件、类别不平衡和 agent 的运行可靠性。论文问的是：如何在同一协议下比较 LLM agent 的稳定/观察/压力分类、脱锚风险概率、延迟、token 消耗、成本和结构化输出，而不是把多数“稳定”样本带来的准确率当成能力。

方法与基线：StableEval Arena 使用 USDT、USDC、DAI 的小时级价格、成交量和市场背景特征；每个案例给模型 30 天、720 小时的历史窗口，隐藏未来 7 天、168 小时，要求输出 stable/watch/stress、脱锚概率、最大偏离、方向、置信度和理由。作者设计了 120 个压力富集案例和 507 个自然分布案例，后者包含 441 stable、45 watch、21 stress；比较 6 个 LLM agent 配置与 always-stable、历史持续、阈值规则、简单逻辑回归等基线。统一后端为 qwen/qwen-2.5-72b-instruct，温度为 0，禁止网页浏览，并记录严格 JSON、延迟和 token 成本。

论文报告的主要结果：在 120 案例压力验证中，表现最好的 agent 是 Nanobot，校准后准确率 0.442、Macro-F1 0.351、平衡准确率 0.393，但 stress recall 只有 0.095；历史持续基线的 stress recall 为 0.333。507 案例自然分布中，always-stable 准确率可达 0.870，却没有任何 watch/stress 召回；简单逻辑回归的 Macro-F1 为 0.402、stress recall 为 0.381，反而高于所有 agent。21 个真实 stress 案例中，6 个 agent 配置合计只捕获 2 个，作者报告各 agent 均漏掉 19/21；校准能把最佳 agent 的 Macro-F1 从 0.301 提到 0.351、stress recall 从 0 提到 0.095，但 verifier 层把 Nanobot 总成本从每 120 案例约 0.345 美元推到 0.978 美元。

创新、局限与适用边界：价值在于把“金融风险识别”和“按协议输出 JSON”拆开，并同时报告 rare-stress recall、missed-depeg rate、校准和成本。局限是样本只覆盖三种稳定币与历史回放，风险标签依赖预先设定的偏离阈值；共同 Qwen 后端、适配器执行模式和 507 案例的稳定类不平衡都会影响结论。论文没有证明 agent 能在真实市场中减少损失，更不是稳定币或相关资产的交易建议。适合做金融 agent 评测、风险工程和安全门禁的人，建议优先读第 3 节任务构造、第 3.5 节指标、第 4 节两种分布结果和成本/校准分析。

2. SurgRAW：多智能体协作把手术视频理解拆成可验证任务

论文：arXiv 摘要页 · 直接 PDF · 代码与数据

作者：Chang Han Low、Ziyue Wang、Tianyi Zhang、Zhu Zhuo、Zhitao Zeng、Evangelos B. Mazomenos、Yueming Jin

来源/分类：arXiv 官方 RSS；cs.AI、cs.RO。

全文状态：已核阅公开 PDF（约 10 页）。

核心问题：机器人辅助手术视频同时包含器械识别、动作识别、下一步动作、患者细节和手术结果；单一视觉语言模型容易受到领域差距、幻觉和任务之间依赖关系的影响。论文试图构造一个既能跨任务推理、又能提供临床语境的零样本工作流。

方法与基线：作者从 12 个公开的达芬奇前列腺切除/肺叶切除视频中抽取 2,277 帧和 14,256 个 QA，覆盖五项任务，并按患者划分监督训练的 8/4 个视频。SurgRAW 用中央 orchestrator 把任务拆成 Visual-Semantic 与 Cognitive-Inference 两条流，再由专门 agent 进行器械、动作、结果和患者信息推理；Visual-Semantic 流增加 panel discussion，Cognitive-Inference 流加入检索增强生成（RAG）和领域 CoT。基线包括 GPT-4o、Qwen3VL-8B、LLaVA-OV、MedGemma、LLaVA-Med、LLaVA-CoT、MDAgents、MedAgents，以及需要训练的 Surgical-VQA。

论文报告的主要结果：表 III 中，SurgRAW-Qwen3VL-8B 的总体准确率为 64.03±1.51%，SurgRAW-GPT-4o 为 61.73±2.42%，监督基线 Surgical-VQA 为 58.76±11.18%；论文摘要把相对监督基线的提升报告为 14.61%，按表格绝对差为 5.27 个百分点。Qwen 版本在动作预测、结果、患者细节上的准确率为 51.65%、50.82%、86.12%，在动作识别和器械识别上为 62.47%、67.33%。GPT-4o 版本的认知推理平均为 70.39%，视觉语义平均为 49.81%。消融中，CoT、RAG 和 panel discussion 各自提供互补改善；作者指出 CoT 是认知推理提升的主要来源。开源模型实验在单张 NVIDIA A6000 上运行，但多 agent 工作流的推理开销高于单次 VLM。

创新、局限与适用边界：创新是把临床知识检索、任务分解、协作讨论和结果验证放进同一个可测基准，而不是只报告某一项识别准确率。限制包括视频数量小、来源为公开手术视频、帧级评测没有完整利用时间连续性，问题由 GPT-4o 生成且尚未经过临床工作流验证；高分也不能推出可在手术室独立使用。适合医疗多模态、手术视频理解和临床 AI 评测读者，建议读第 III 节数据与工作流、第 IV-A 节基线和表 III/IV 的消融；任何部署都需要外部临床专家复核和安全验证。

3. WFM：把稠密文档语义和图结构放进同一个 agent 记忆层

论文：arXiv 摘要页 · 直接 PDF

作者：Junnan Dong、Linhao Luo、Senlei Zhang、Gong Chen、Taian Guo、Yifei Yu、Rong Tao、Tao Guo、Qian-Wen Zhang、Siyu An、Ruizhi Qiao、Xing Sun

来源/分类：arXiv 官方 RSS；cs.AI。

全文状态：已核阅公开 PDF（约 16 页）。

核心问题：传统图检索擅长显式关系，但把文档压成稀疏三元组会丢掉上下文；纯文本 RAG 又难以处理多跳关系、长期记忆和大规模传播。WFM（Wiki Foundation Model）问的是：能否把实体拓扑和段落语义作为同一张 agent-native Wiki Graph 来学习和检索。

方法与基线：WFM 把实体、关系和文档段落映射到共同传播空间，用 query-conditioned relation-aware attention 做消息传递，并在检索后通过最多 4 轮 self-reflection 继续寻找遗漏证据。系统还实现了 NCCL 原生的边界交换，避免分布式图训练中的 CPU 序列化和内存拷贝。多跳问答使用 HotpotQA、2WikiMultihopQA、MuSiQue，各 1,000 个留出问题；长期记忆使用 PersonaMem-1M 和 RHELM。基线包括 zero-shot LLM、Native RAG、RAPTOR、GraphRAG、HippoRAG、Youtu-GraphRAG、GFM-RAG，以及 A-mem、MemoryOS、LightMem；答案生成/评判分别使用 DeepSeek V4 Flash/Pro，统一 embedding 和检索深度。

论文报告的主要结果：多跳 QA 上，WFM 在 HotpotQA、2Wiki、MuSiQue 的 Open/Reject 准确率分别为 89.6/84.3、90.2/82.4、69.8/52.6；相对 Youtu-GraphRAG 的提升为 2.8/4.1、3.2/4.8、4.1/5.1 个百分点。Recall@20 在前三个数据集为 93.20、90.15、75.24，相对 GFM-RAG 高 11.82、17.52、26.67 个百分点。长期记忆总体准确率在 PersonaMem 为 58.49、RHELM 为 52.17，论文报告分别比最强非 WFM 基线高 8.39 和 5.37 个百分点。系统部分报告 bit-exact 的训练步耗时从 2.40 秒降到 0.23 秒，即 10.5 倍加速；这衡量的是论文所设定的训练集群与实现，不是通用硬件保证。

创新、局限与适用边界：WFM 的关键贡献是把“证据覆盖”和“文本语义”一起优化，再用 agent loop 主动补证据；在 MuSiQue 这类长链任务上，Reject 模式的提升也比 Open 模式更能说明检索质量。限制是结果依赖 DeepSeek 生成与 LLM judge、既定基准和 1M context 设置，闭源组件与分布式算力成本削弱独立复现；PDF 的实现说明还提示部分新完成的诊断单元需要实测复核。适合做 RAG、长期记忆和图学习系统的人，建议读第 3 节表示/传播、第 4.3–4.7 节基线、结果和消融，以及第 6 节结论。

4. DualViewEval：用执行轨迹压缩 agent 基准，但不牺牲行为差异

论文：arXiv 摘要页 · 直接 PDF

作者：Xinshuai Guo、Junjie Wu、Dolly Deng、Yinghui Li、Hai-Tao Zheng、Suncong Zheng、Maxm Pan

来源/分类：arXiv 官方 RSS；cs.CL、cs.AI。

全文状态：已核阅公开 PDF（约 16 页）。

核心问题：agent 基准一次运行可能要花大量 API 费和数小时；只看最终成功/失败又会把“同分但行为不同”的 agent 当成同一种。DualViewEval 研究能否利用工具调用过程，把大基准压缩为一个固定大小的 miniset，同时保留未见 agent 的总分和排名。

方法与基线：论文汇总 BFCL、τ²-Bench、Terminal-Bench 2、SWE-bench Verified、APEX-Agents 五个基准，共 1,983 个任务、262 个 agent 配置、132,387 个对齐的 agent-任务结果。作者从轨迹中抽取 6 个过程特征：agent steps、tool failed rate、tool-category entropy、validation-tool rate、required-write execution、read-write-validate closure；再把 outcome relation 与 process relation 融合，用 straight-through hard Top-K 选择恰好 K 个任务，用 Kernel Ridge 同时优化 score loss 和 ranking loss。基线为 Anchor Points、gp-IRT、TailoredBench、EssenceBench、SparseEval。

论文报告的主要结果：摘要报告在 APEX-Agents 和 BFCL 只用 20 个任务时，可达到 24–40 倍压缩，MAE 相对最强竞争者降低 14.5%–28.2%，在 SWE-bench Verified 上相对 EssenceBench 的 Kendall’s τ 提升最高 7.2%。完整实验中，DualViewEval 相对最直接的 SparseEval，跨五个基准的 MAE 降低 30.5%–45.1%，Kendall’s τ 平均提高 0.089–0.115；例如 BFCL 的 K=20 时，DualViewEval 的 MAE/τ 为 4.202/0.843，SparseEval 为 6.273/0.766；APEX-Agents K=20 时为 3.785/0.780，对照为 5.763/0.680。随着 K 增大，方法差距收窄，说明过程特征主要在预算紧张时有价值。

创新、局限与适用边界：它把“评测样本选择”直接和下游分数、排名目标耦合，并用硬 Top-K 保证部署时预算不会悄悄膨胀。局限是过程特征需要针对不同轨迹格式写 adapter，训练 agent 数量和公开 leaderboard 的覆盖会影响选择；压缩基准可以减少成本，却不能自动消除数据污染、任务代表性或 judge 偏差。适合评测平台和 agent 工程团队，建议读第 3.2–3.3 节过程指标/选择器、第 4.1–4.3 节数据和主结果，以及第 5 节关于训练数据比例和 K 的分析。

5. Safety-Flag：内容审核要同时看误报、漏报、校准和人工复核价值

论文：arXiv 摘要页 · 直接 PDF · 代码与复现实验 · 数据归档 DOI

作者：Yibo Hu

来源/分类：arXiv 官方 RSS；cs.CL、cs.CY、cs.LG。

全文状态：已核阅公开 PDF（约 13 页，含附录）。

核心问题：内容审核的 aggregate accuracy 可能掩盖两种相反失败：把大量良性内容误报，或放过有害内容。Safety-Flag 把七个公开安全基准统一成 balanced flag/do-not-flag 任务，研究模型的错误方向、概率校准和置信度能否有效决定哪些样本交给人工。

方法与基线：论文评估 6 个通用 LLM、4 个专用 guard 和 3 个参考模型，保留 item-level verdict 与 confidence；七个基准为 BeaverTails、XSTest、Ethics、WildGuard、Aegis、ToxiChat、ToxiGen。作者报告 false-alarm、miss、ECE、AURC 和 selective risk，并用温度缩放校准概率、用置信度排序做 abstention；WildGuard/Aegis 与训练数据可能重叠，因此相关单元被单独标记。

论文报告的主要结果：摘要给出的极端差异是：一个模型会把 85% 的 benign 内容误报，另一个模型会漏掉 54% 的 harmful 内容。通用模型普遍过度自信；单模型温度缩放让校准误差降低 2.8–6.0 倍，不改变标签或置信度排序。公开表格中，Qwen2.5-32B 的 pooled ECE 为 0.126、Llama-3.1-8B 为 0.368；在 50% 覆盖率下，Qwen2.5-32B 的 selective risk 为 0.044，而全量自动处理为 0.136，说明把低置信样本交给人类确实能降低剩余错误。专用 guard 的平均误报率和校准更好，但 Llama Guard 3 漏掉 34.5% 的有害样本，ShieldGemma 漏掉 50.2%，覆盖范围外的召回更差。

创新、局限与适用边界：论文把模型选择写成依赖 harmful prevalence 和 miss/false-alarm 成本的部署决策，而不是单一排行榜。限制是约每个基准 200 个平衡样本、英语、单轮二元判定，没有群体/方言条件分析；置信度是模型自身信号，且多 agent 审核不在范围内。论文结果仍是作者统一协议下的报告，不能替代产品域的红队与人工审计。适合内容安全、审核路由和模型校准读者，建议读第 3–5 节任务/结果、第 7 节成本函数和附录 C–E 的校准、abstention 与提示敏感性。

10. From Pixels to Pairs：噪声 OCR 下的键值抽取基准

论文：arXiv 摘要页 · 直接 PDF

作者：Zahra Anvari、Vassilis Athitsos

来源/分类：arXiv 官方 RSS；cs.CL、cs.CV。

简介：论文在 FUNSD、CORD、SROIE 上比较 Gemma、Mistral、Qwen2.5、LLaMA 3、DeepSeek 等开源指令模型，分别使用金标准文本和 PaddleOCR、EasyOCR、Tesseract 的 OCR 输出，测量键值对抽取在噪声下的变化。作者报告高质量文本时模型接近布局感知监督系统，OCR 噪声会显著降低性能并缩小模型差距，常见失败包括键值错配、幻觉和数字损坏。价值是把清洁文本评测和真实输入条件分开；摘要未提供各模型的完整数值、污染控制或部署延迟。证据状态：仅依据摘要。

简介：论文调查本校 12 门 AI 相关课程的 118 名学生，按 GenAI 使用、依赖和感知收益识别用户群，并用多变量回归关联早期依赖、学业任务支持、可靠性信心、教师政策与学习体验。作者报告四类使用者、免费/付费版本和单/多工具使用者之间存在差异，早期依赖同时与感知收益和负面影响相关，且评价素养会改变这种关联。价值在于把工具使用、认知依赖和课程政策放到一起；这是小样本、单机构的观察性调查，不能从回归相关性推断 AI 造成了学习变化。证据状态：仅依据摘要。

13. Agentic AI Workflow Portfolios：组合多个工作流是否值得算力成本

论文：arXiv 摘要页 · 直接 PDF

作者：Mojtaba Abdolmaleki、Stefanus Jasin、Boyu Wang

来源/分类：arXiv 官方 RSS；cs.AI。

简介：论文把多个有不同推理、核验和计算成本的 workflow 视为一个 portfolio，并联合决定运行数量、分配和最终 selector；方法给出 odds-lift、线性规划松弛、随机舍入和基于 pricing oracle 的大类搜索。作者在 ABCD、Schema-Guided Dialogue、HotpotQA 上报告，相对最佳单一 workflow，held-out selector accuracy 分别提高 3.1、7.5、0.9 个百分点；dual-guided workflow generation 在 ABCD 和 HotpotQA 还提高 3.5 和 24.1 个百分点，但在 Schema-Guided Dialogue 没有额外收益。价值是明确把多样性收益与 compute cost 放在同一优化问题中；摘要未说明 selector 是否独立于测试数据、推理预算和额外错误候选如何计价。证据状态：仅依据摘要。
