重点关注

以下 5 篇重点论文已核阅公开摘要页和 PDF。数字与结论均为作者报告，未做独立复现；其余条目明确标注“仅依据摘要”。阅读 AI benchmark 时，应区分基准分数提升与真实能力，检查比较基线、公平的输入与监督、数据污染、可复现性和算力成本。

1. Agentick：把不同范式的序列决策 agent 放到同一张考卷上

  • 论文：Agentick: A Unified Benchmark for General Sequential Decision-Making Agents（arXiv:2605.06869）
  • 作者：Roger Creus Castanyer、Pablo Samuel Castro、Glen Berseth
  • 来源与链接：arXiv · cs.AI · 摘要页 · PDF · 项目与排行榜
  • 证据状态：已核阅公开 PDF；结果是论文报告，尚未独立复核。

核心问题。 强化学习、LLM/VLM agent 和人类通常在不同环境、输入接口和指标下被测，分数无法直接比较。Agentick 试图建立一份横跨“从零训练 RL 到预训练 foundation model”的统一序列决策考卷。

方法与基线。 基准包含 37 个程序生成任务，分为导航、规划、推理、记忆、泛化和多智能体六类，四个难度、五种同步观察模态，并提供 Gymnasium 接口、oracle policy、120k/250k/500k 轨迹、SFT 数据集和可组合 agent harness。核心指标 ONS 以随机策略为 0、任务 oracle 为 1，使用固定种子和每个任务—难度组合 25 个评测 episode。PDF 版本比较 31 个配置、冻结 frontier/open-weight LLM、像素 PPO 以及 Qwen3.5-4B 的 120k/250k oracle-trajectory LoRA SFT；这不是 compute-matched 的总冠军赛，而是共享协议下的能力剖面。

论文报告的主要结果。 108,550 个已完成 episode 中，SFT-250k 总体 ONS 为 0.447，冻结 GPT-5 mini 为 0.309，PPO Dense 2M 为 0.287；SFT-250k 在导航、规划、推理和记忆领先，GPT-5 mini 在泛化为 0.437，PPO 在多智能体为 0.432。Reasoner harness 使 Qwen3.5-4B 的 ASCII ONS 从 0.023 提到 0.228，整体改善约 3–10 倍；ASCII 也稳定优于自然语言。最难推理任务中 GraphColoring、LightsOut、SwitchCircuit、ProgramSynthesis 和 SymbolMatching 对三种 frontier LLM 都为 0 成功率。

创新、局限与适用边界。 贡献是把任务语义、动作空间、观察模态、训练数据和评测种子一起对齐，并把“模型本身”和“推理脚手架”分开。局限是离散、二维、回合制任务不代表连续控制、实时、开放世界或持续学习；oracle 不保证随机任务的全局最优；不同范式的监督量、算力和模态并不匹配，也未覆盖 VLM、混合 RL/FM 和旗舰 frontier 模型。适合 agent 评测、RL 后训练和 harness 设计读者，建议先读 §3 的任务与 ONS 定义，再读 §4.2–§4.6 的整体排名、能力拆解和推理脚手架，最后读 §5 的限制。

2. CARGO：生产环境的 LLM-as-a-judge 不应把“换了实体”判成幻觉

  • 论文：CARGO: Context-Aware Retrieval-Gated Evaluation of Agentic AI in Production（arXiv:2609.30471）
  • 作者：Mukul Chhabra、Shail Patel、Luigi Medrano
  • 来源与链接：arXiv · cs.CL、cs.AI、cs.LG · 摘要页 · PDF
  • 证据状态：已核阅公开 PDF；结果是论文报告，尚未独立复核。

核心问题。 企业 agent 面对工单、资产和账户等动态实体时，最近的参考答案往往描述的是“另一实体上的正确流程”。传统 reference-based judge 逐字比较，会把正确的实体替换误报为错误或幻觉。论文把这个问题命名为 reference–instance divergence（RID）。

方法与基线。 CARGO 将参考答案视为流程范例，把事实判断锚定在当前实例的可观察上下文；对每条 claim 输出 supported、contradicted 或 unverifiable 三态，只惩罚有证据的矛盾，并用检索置信度 gate 选择需要评估的流量。CARGO-Bench 通过扰动构造 246 个有 ground truth 的条目，生产实验另抽取 400 条去标识 trace。作者比较 DIRECT、只追加 live context 的 DIRECT+CTX、CARGO、去掉 exemplar/UNV 的消融、无参考的 NOREF，以及 BM25、dense 和 hybrid 检索与不同 gate；使用 gpt-oss-120b 和 gpt-oss-20b 两个 judge。

论文报告的主要结果。 CARGO-Bench 的 7,872 次成功判断中，DIRECT 在所有正确的 entity transplant 上都处罚，DI 约为 0；CARGO 对 50/50 个注入矛盾（较弱 judge 为 49/50）保持近完整召回，同时对 50 个正确替换为 0 次误罚，对 96 个“真但未观察到”的条目仅 3 次误罚，DI 为 0.58（120B）和 0.56（20B）。但程序性 corruption 是明确失败条件：CARGO 只抓到 10/50，LLM annotator 加书面指南和仲裁也只抓到 3/10；post-hoc 的 authority split 没有修复这一盲点。

创新、局限与适用边界。 论文把评测器本身当作 selective prediction 系统，明确拆开“实体事实矛盾”和“流程正确性”。主要限制是 CARGO-Bench 的 ground truth 来自构造，生产流量的专家一致性和 gate 校准仍是预注册协议而非本文已完成的主结果；unverifiable 不等于 verified，且对流程层面的过度宽容可能漏掉真实错误。适合生产 agent 评测、RAG 监控和 LLM judge 工程，建议读 §2–§4 的 RID、方法与基准，§6.1 的表 1/消融，及 §7–§10 的失效分析。

3. MM-ContextFold：多模态检索 agent 不必一直背着原始图片

  • 论文：MM-ContextFold: Context Folding for Multimodal Agentic Retrieval（arXiv:2609.23121）
  • 作者：Yang Tian、Fan Liu、Jingyuan Zhang、Zhenyang Li、Yupeng Hu、Liqiang Nie
  • 来源与链接：arXiv · cs.CV、cs.AI、cs.IR、cs.MM · 摘要页 · PDF · 代码与数据 · DOI
  • 证据状态：已核阅公开 PDF；结果是论文报告，尚未独立复核。

核心问题。 ReAct 式多模态检索会把原始图片、工具调用和全部历史不断追加到同一上下文。论文先问视觉证据在长轨迹的哪个阶段仍有用，再问能否按需加载和释放图片而不损害回答。

方法与基线。 作者分析约 10,000 条轨迹的 Visual Search、Text Retrieval 和 Web Visit，提出双状态、训练免费的 MM-ContextFold：主状态只保留文本规划和折叠后的证据；遇到视觉子任务时开临时 branch，加载相关图片、完成检索，再把短文本摘要 RETURN 到主状态并丢弃 branch。基线是标准 ReAct，评测覆盖七个 MAR benchmark、五个 backbone；消融包括从不同 step 开始移除图片、输出熵变化和按 benchmark 类型拆分。

论文报告的主要结果。 在整体实验中，相对 ReAct 平均准确率提升 6.3 个百分点，工作上下文长度减少 27.5%。图片移除在第 1 步会使准确率下降 25.2%，第 2 步下降 3.9%；从第 6 步开始平均反而提升约 1–2%。但最佳释放时点依任务而异：原子事实和动态检索较早进入文本主导阶段，视觉深度研究任务仍需要更久的图片访问，因此不存在可以无条件复用的固定 step。

创新、局限与适用边界。 贡献不是再训练一个更大的模型，而是把视觉 grounding 和高层规划的上下文生命周期分离。局限是结果依赖七个 benchmark、五个 backbone 和作者的工具/提示协议；上下文长度下降未自动证明端到端延迟、费用或真实研究质量都改善，复杂视觉深度研究仍可能因过早释放图片而受损。适合多模态 agent、深度检索和上下文工程读者，建议读 §3.2 的移除实验、§3.3 的双状态机制、§4 的跨 benchmark 结果和附录中的实现细节。

4. CRC-Router：把医疗 agent 的“何时升级人工”变成风险约束

  • 论文：CRC-Router: Risk-Constrained Routing for Medical Agentic AI Systems（arXiv:2609.30714）
  • 作者：Xueyang Li、Mingze Jiang、Gelei Xu、Jun Xia、Ching-Hao Chiu、Mengzhao Jia、Danny Z. Chen、Yiyu Shi
  • 来源与链接：arXiv · cs.AI · 摘要页 · PDF · 代码
  • 证据状态：已核阅公开 PDF；结果是论文报告，尚未独立复核。

核心问题。 医疗 agent 的安全不只取决于预测准确率，还取决于它能否把高风险病例交给人工，而不是把不确定性继续传给临床决策。CRC-Router 直接控制 wrong-accept risk，即“系统接受且错误”的风险。

方法与基线。 在 NIH ChestX-ray14 的 112,120 张胸片、14 个 finding 上，作者使用患者级 0.5/0.25/0.25 划分，训练由五个分类器组成的 MoE、24 个 radiomics 特征、轻量 MLP 风险模型，再用 Conformal Risk Control 在目标风险 α=5% 下校准每个 finding 的 accept/escalate 阈值。基线包括 MaxProb、MCD-MI 和 Conformal Prediction；同时把模块接到 MedRAX，比较原 agent、TTA 估计不确定性和 MoE 版本。

论文报告的主要结果。 在约 91% 宏观 coverage 的公平比较下，CRC-Router 宏观 wrong-accept risk 为 3.9%，Accept-All 为 9.2%，作者报告相对下降 58%；14 个 finding 中 13 个达到 ≤5%，Conformal Prediction 为 10 个，MaxProb 和 Entropy 为 7 个。唯一超过目标的是 Pneumothorax，5.9%。接入 MedRAX 后，NIH 子集的 coverage/risk 从 62.9%/5.7% 变为 TTA 的 81.5%/4.8%，CheXpert 从 65.6%/20.9% 变为 68.4%/4.6%；MoE 版本在 NIH 为 91.3% coverage、3.8% risk。

创新、局限与适用边界。 亮点是把 uncertainty ensemble、预测分数和 conformal calibration 组合成可插拔路由层，而不是要求重新训练底层 agent。结果仍是回顾性胸片数据上的 risk–coverage 证据，不是临床因果效果或前瞻性安全认证；Conformal 控制依赖校准与部署样本的交换性，MedRAX 的部分结果使用分层子样本和 TTA 近似不确定性。适合医疗 AI 安全、selective prediction 和 agent 部署读者，建议读 §III 的路由定义、§IV 的数据/基线、Table I–II 和 §V.3 的消融。

5. UltraG-Bench：语义答对，不代表找到了超声图像证据

  • 论文：UltraG-Bench: A Multi-task Benchmark for assessing Large Vision-Language Models on Pixel-level Evidence Grounding in Ultrasound（arXiv:2609.30928）
  • 作者：Quanhao Zhu、Bo Xu、Rui Lin、Chenyuan Wang、Yu Shao、Boling Zhu、Jiuyan Sun、Liang Zhao、Hongfei Lin、Feng Xia
  • 来源与链接：arXiv · cs.CV、cs.AI · 摘要页 · PDF · 代码与数据
  • 证据状态：已核阅公开 PDF；结果是论文报告，尚未独立复核。

核心问题。 医疗 VLM 可能在 VQA 中给出正确语义答案，却不能指出支持答案的像素区域。UltraG-Bench 把“说对”和“证据落在正确位置”拆开评测。

方法与基线。 论文整合 40 个公开超声分割数据集、13 个解剖类别，构造 instruction-guided segmentation、evidence-grounded VQA、evidence-grounded report generation 三类任务，分别有 331,125、666,779 和 138,832 条标注。指标为 IoU/Dice、答案准确率 Acc 与同时要求文本和 mask 对齐的 G-Acc、ROUGE-L、四属性 SemAcc。实验比较 14 个 MLLM、BiomedParse、UltraSAM3，并提出将 VLM 与超声专用分割器 UltraSAM3 组合的 UltraG-Agent。

论文报告的主要结果。 语义与 grounding 的差距很大：GPT-5.4 的 VQA Acc 为 0.3631，但 G-Acc 仅 0.0609；InternVL3.5-8B 的 Acc 为 0.3678，G-Acc 为 0.0081。最佳 UltraG-Agent（InternVL3.5-14B + UltraSAM3）六项指标分别为 IoU 0.5564、Dice 0.6384、Acc 0.5970、G-Acc 0.4531、ROUGE-L 0.3971、SemAcc 0.6687；相较 UltraSAM3 单独的 IoU/Dice 0.5478/0.6190，还能提供 VQA 和报告生成。作者的消融把 UltraSAM3 识别为主要收益来源。

创新、局限与适用边界。 论文把 pixel-level evidence 作为独立目标，避免用语义准确率代替可验证定位。局限是 13 类超声器官和公开数据集的组合仍不是临床工作流；不同数据集的标注、设备和分布可能造成跨域差异，benchmark 成绩也不等于诊断安全或患者结局。适合医疗多模态评测、视觉 grounding 和超声系统工程读者，建议读 §2–§3 的任务/标注协议、§5.2 的指标、Table 2 和附录 A.8–A.9 的错误分析。

  • 简介：重点论文已在上文详述。其关键审计是把 semantic Acc 与 grounded Acc 分开；G-Acc 极低说明“答案正确”不能替代像素证据。结果基于公开超声数据集和离线 benchmark，不是临床诊断验证。

11. The Price of Thought: Does Test-Time Reasoning Pay in LLM Trading?（arXiv:2609.30705）

  • 作者：Jiayi Chen、Guiling Wang
  • 来源/分类：arXiv · cs.AI
  • 链接：摘要页 · PDF
  • 简介：仅依据摘要。 论文把 test-time reasoning 当作金融决策干预，在 DeepSeek、GPT、Gemini 家族、美国股票一年窗口、数值/可识别新闻/遮蔽新闻三种输入下比较，覆盖 80 万以上资产预测和重复生成。作者报告额外推理没有稳定改善扣交易成本后的净组合回报，DeepSeek 效果非单调且重复生成导致选股不稳定；这是回测实验，摘要未给出完整样本外和成本敏感性，不能当成投资建议。

13. Cartograph: Federated Tool Discovery with Operator-Attested Retrieval for AI Agents（arXiv:2609.30293）

  • 来源/分类：arXiv · cs.CL、cs.AI

  • 简介：仅依据摘要。 Cartograph 用 operator-attested、Ed25519 签名的 capability card、Rift confusable-cluster 分析和 server→tool 两级检索，把 agent 可见的工具定义从 O(n) 目录遍历改为 O(k) 渐进披露。作者在 22 server/374 tool 部署和 49 query benchmark 上报告 R@5 为 0.816 对 0.592、top-5 交换 475 token 对 42,450，网关平均增加 5ms/0.8%；作者自建 query 集和描述生成过程仍需独立复现。
